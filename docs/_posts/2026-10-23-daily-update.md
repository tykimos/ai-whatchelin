Today (Oct 23) is OpenAI's legacy API shutdown D-Day. At least 11 model endpoints — GPT-4, GPT-4 Turbo, GPT-3.5 Turbo, o1, o1-pro, o3-mini, o4-mini, and gpt-4.1-nano — are permanently shut down with no grace period([Geeks IT](https://geeks.it.com/?p=976)). Requests to pinned model IDs will fail immediately with no automatic fallback, and GPT-5.6 Sol is the official replacement([Layer3 Labs](https://www.layer3labs.io/guides/openai-deprecated-models)). Given the week-long "model not supported" errors that followed GPT-5.5's October 14 retirement, similar disruption is all but certain. Meanwhile, GPT-4o, GPT-4o mini, GPT-4.1, and GPT-4.1 mini will remain available until January 14, 2027, with GPT-6 Luna as the official successor([The New Stack](https://thenewstack.io/openai-gpt4o-api-shutdown)).

## Copilot: Climbs to 53, Universe D-5

Copilot rises to 53, sustaining its +2/day streak for the 11th consecutive day([GitHub Blog](https://github.blog/changelog/2026-09-25-default-enablement-of-copilot-features-for-copilot-business-and-enterprise)). Yesterday's Default Enablement policy is now in effect, auto-activating MCP servers, code review, and agent capabilities across unconfigured organizations, which is driving additional usage growth. On October 7, local sandboxing went GA — powered by Microsoft MXC (eXecution Container), it lets Copilot CLI, the Copilot app, and VS Code Agent Host restrict file access, network, and Git credentials at the OS level([GitHub Blog](https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available)). [GitHub Universe 2026](https://github.blog/news-insights/company-news/your-guide-to-github-universe-2026-is-here-the-schedule-just-launched/) (Oct 28–29, Fort Mason) is 5 days away — headline sessions include a panel with Anthropic, OpenAI, and GitHub on AI-assisted development, Copilot agent delegation, and MCP server security([Blockchain News](https://blockchain.news/news/github-universe-2026-schedule-ai-focus)).

## Codex CLI: GPT-6.1 Sol Now Default Model

Codex CLI v0.161.0 (Oct 7) switched the default model to GPT-6.1 Sol([SessionWatcher](https://sessionwatcher.com/news/codex-cli-0-161-0-gpt-6-1-sol-default-model)). Voice conversation customization and task history browsing were also added. With 3M+ weekly active users (as of April), the expanded GPT-6 model access is strengthening the Codex CLI ecosystem.

## Anthropic: Public S-1 Imminent

Anthropic filed a confidential draft S-1 with the SEC on June 1([NPR](https://www.npr.org/2026/06/01/nx-s1-5843199)), and the public S-1 is expected by late October or early November. Bloomberg reports the company is targeting a SpaceX-scale IPO([The Next Web](https://thenextweb.com/news/anthropic-ipo-size-match-spacex-record)), with the $965B valuation anchored to the $65B Series H round. Anthropic is on track to go public ahead of OpenAI ($852B).
