GitHub Copilot's unified experience officially launched today (Sep 28). With OpenAI DevDay just one day away, the always-on "o" agent's three-tier pricing has leaked, and four legacy GPT-3.5 models have been retired for good.

## GitHub Copilot: Unified Experience Now Live

Starting today, GitHub has merged Copilot Chat on github.com, Copilot Chat in GitHub Mobile, and the Copilot cloud agent into a single unified experience ([GitHub Blog](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)). Separate policies have collapsed into one enabled by default. Chat data retention has expanded from 28 days to account lifetime, and code review defaults have shifted from Lite to Balanced ([C# Corner](https://www.c-sharpcorner.com/article/preparing-for-the-github-copilot-unified-experience-coming-september-28)). Organizations under GDPR or CCPA should review the new retention policy ([DevOps.com](https://devops.com/github-tightens-copilots-billing-and-governance-rules-ahead-of-a-busy-fall/)). New models including Claude Opus 5.5, GPT-6 Sol, GPT-6 Luna, and Grok 4.7 are now available ([GitHub Changelog](https://github.blog/changelog/2026-09-25-github-copilot-weekly-releases-september-21/)). Copilot's popularity score ticked up from 1 to 3 — its first movement in 85 weeks.

## OpenAI DevDay D-1: "o" Agent Three-Tier Pricing Leaks

OpenAI DevDay (Sep 29, Fort Mason, San Francisco) is tomorrow ([OpenAI](https://openai.com/index/devday-2026/)). Sam Altman's keynote will be livestreamed free, with the Astra AON-based always-on "o" agent and GPT-6 Cyber preview as headliners ([Forbes](https://www.forbes.com/sites/jonmarkman/2026/09/21/openai-plans-to-introduce-managed-agents-at-devday-2026/)). Code analysis of ChatGPT has revealed "o"'s three-tier pricing: Pro Lite at $100/month, Pro at $200/month, and Pro Max at $500/month ([Android Headlines](https://www.androidheadlines.com/2026/09/openai-leaks-always-on-o-chatgpt-assistant.html)). The agent's name and email suffix also leaked via the Pro subscription screen, making the announcement all but confirmed ([TestingCatalog](https://www.testingcatalog.com/openai-to-announce-o-always-on-agent-during-devday/)).

## End of the GPT-3.5 Era: Four Legacy Models Retired

As of today, gpt-3.5-turbo-instruct, babbage-002, davinci-002, and gpt-3.5-turbo-1106 are officially retired ([DigitalApplied](https://www.digitalapplied.com/blog/openai-devday-2026-what-to-prepare)). This marks the disappearance of the last GPT-3.5 API endpoints. The Sora API was also discontinued on Sep 24, as OpenAI accelerates its legacy cleanup ahead of DevDay.

## Cursor: 31st Straight Day of Decline, Drops to 35

Cursor fell to 35, marking its 31st consecutive day of decline since Aug 28. It has shed 64 points from its 99 peak, with OpenAI model access termination (Nov 12) now D-45 away ([CNBC](https://www.cnbc.com/2026/08/29/openai-cursor-spacex-model-access.html)). SpaceX shipped Grok 4.7 on Sep 21 ([MarkTechPost](https://www.marktechpost.com/2026/09/21/spacexai-releases-grok-4-7/)), but it hasn't slowed the bleeding. Community sentiment is increasingly dire — *"below 30 and there's no coming back"* is a common refrain.

## Antigravity: v1.2.12 Ships With Performance Gains

Antigravity CLI v1.2.12 (Sep 27) dramatically reduces CPU usage during long conversations and artifact scrolling, and eliminates wasteful API retries ([Havoptic](https://www.havoptic.com/)). The previous v1.2.11 (Sep 25) added adjustable AI reasoning effort levels and fixed diagram rendering in popular terminals. Antigravity's 28-week high streak continues.
