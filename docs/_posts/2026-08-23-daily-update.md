The AI coding tool market faces five major deadlines inside a week and a half. Starting tomorrow (Aug 24) when Cursor Auto drops its flat rate for per-model pricing, the countdown runs through o3's ChatGPT exit (Aug 26, D-3), DALL-E GPT retirement (Aug 30, D-7), GPT-5.4's Codex removal (Aug 31, D-8), and Copilot's six-model mass deprecation (Sep 1, D-9). This much change compressed into a single week is a first for 2026.

## Cursor: Auto Per-Model Pricing D-1

Cursor is replacing Auto mode's flat rate with per-model pricing starting August 24 ([explainx.ai](https://www.explainx.ai/blog/cursor-auto-per-model-pricing-usage-limits-august-2026)). Included usage goes up across all models, but routing to a frontier model will now cost roughly what picking it directly would. The change was announced only via subscriber email — no blog post or changelog entry ([blog.kilo.ai](https://blog.kilo.ai/p/all-roads-lead-to-metered-pricing)). As Kilo AI's analysis puts it, *"all roads lead to metered pricing"* — the entire AI coding tool market is converging on usage-based billing.

## Antigravity: IDE Extensions Break the Desktop Barrier

Google expanded Antigravity into VS Code, JetBrains (2026.2.1+), Zed, and Visual Studio (preview) ([The New Stack](https://thenewstack.io/google-antigravity-ide-extensions/)). Developers can now open agent conversations in a side panel, review inline diffs, and inspect plans without leaving their IDE or installing the desktop app ([antigravity.google](https://antigravity.google/blog/antigravity-ide-extensions)). Gemini Enterprise admins get project-level budget caps for cost control ([The Register](https://www.theregister.com/ai-and-ml/2026/08/21/google-tethers-antigravity-to-enterprise-controls-amid-ai-shakeup/5290730)).

## OpenAI: Cascading Retirements

o3 exits ChatGPT on August 26, completing the cleanup of all pre-GPT-5 model families ([andrew.ooo](https://andrew.ooo/answers/o3-retired-august-26-2026-what-to-use-instead/)). The DALL-E GPT retires August 30, replaced by ChatGPT Images — users should download any saved images before then ([Tom's Guide](https://www.tomsguide.com/ai/chatgpt/you-have-until-august-30-to-save-your-chatgpt-dall-e-images-heres-how-to-avoid-losing-them-forever)). Meanwhile, Codex CLI v0.149.0 shipped an interactive agents dashboard with /cd, /pwd, and /cwd commands, leveling up agent management UX ([Havoptic](https://www.havoptic.com/tools/openai-codex)).

## Copilot: Mass Deprecation D-9

Six models — including Claude Opus 4.5/4.6, Claude Sonnet 4.5/4.6, Gemini 3.1 Pro, and Raptor mini — will be removed from all Copilot experiences on September 1 ([GitHub Roadmap](https://github.com/github/roadmap/issues/1308)). MAI-Code-1-Flash follows on September 10, with 1.1-Flash as the replacement ([GitHub Changelog](https://github.blog/changelog/2026-08-11-upcoming-deprecation-of-mai-code-1-flash/)). The 103-consecutive-week popularity decline continues as model cleanup accelerates.
