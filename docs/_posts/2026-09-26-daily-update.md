Microsoft relaunched Copilot on September 25 as a single app combining chat, coding tools, and autonomous agents — a direct challenge to Anthropic and OpenAI ([CNBC](https://www.cnbc.com/2026/09/25/microsoft-copilot-ai-coding-anthropic.html)). The app is organized into three sections: Home (conversational chat plus embedded Office apps), Code (natural-language app building using GitHub Copilot technology), and Autopilot (always-on cloud agents). Code and Autopilot shift to usage-based pricing ([GeekWire](https://www.geekwire.com/2026/microsoft-unveils-all-in-one-copilot-app-taking-on-anthropic-and-openai-in-new-push-to-boost-adoption/)).

## Copilot Unified Experience D-2: Policy and Billing Overhaul

GitHub's unified Copilot experience is now just two days away on September 28 ([GitHub Blog](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)). Chat on github.com, GitHub Mobile, and the cloud agent merge under a single policy, with chat data retention expanding from 28 days to account lifetime. Code review defaults shift from Lite to Balanced, increasing AI credit consumption. Starting October 1, all new Business and Enterprise seats require prepaid billing ([DevOps.com](https://devops.com/github-tightens-copilots-billing-and-governance-rules-ahead-of-a-busy-fall/)).

## OpenAI DevDay D-3: $500 Pro Max Tier Imminent

OpenAI DevDay arrives September 29 at Fort Mason, San Francisco ([OpenAI](https://openai.com/index/devday-2026/)). The Pro Max $500/month plan discovered in ChatGPT's web app and Codex repository code is widely expected to headline the event, with Cerebras wafer-scale chip integration enabling ultra-fast inference ([BleepingComputer](https://www.bleepingcomputer.com/news/artificial-intelligence/openai-is-preparing-a-500-chatgpt-pro-max-plan-with-faster-codex/)). Forbes expects Managed Agents to be another major DevDay announcement ([Forbes](https://www.forbes.com/sites/jonmarkman/2026/09/21/openai-plans-to-introduce-managed-agents-at-devday-2026/)).

## Claude: Opus 4.6 Regression Controversy Accelerates Opus 5.5 Migration

Opus 4.6 has drawn community complaints since ~September 16 for date hallucinations, base64 corruption, and precision loss ([GitHub #96182](https://github.com/anthropics/claude-code/issues/96182)). Meanwhile, Opus 5.5, released September 22, offers a 1M-token context window, 128K output tokens, and 40% cost reduction ([Anthropic](https://www.anthropic.com/claude-opus-5-5)). The regression is effectively forcing migration to 5.5.

## Cursor: 38th Straight Day of Decline, Hits 39

Cursor dropped to 39, marking its 38th consecutive day of decline with D-47 until OpenAI model access terminates on November 12 ([Cursor](https://cursor.com)). Since the SpaceX acquisition closed on August 14, Cursor has shed 60 points from its 99 peak. Even the Projects beta and Lambda MicroVM integration have failed to slow the exodus ([Wikipedia](https://en.wikipedia.org/wiki/Cursor_(company))).
