GitHub Copilot's Default Enablement policy went live today (Oct 22). For Business and Enterprise organizations, every unconfigured GA feature — including MCP servers, code review, and agent capabilities — is now automatically turned on unless an admin has explicitly disabled it([GitHub Blog](https://github.blog/changelog/2026-09-25-default-enablement-of-copilot-features-for-copilot-business-and-enterprise)). Existing admin configurations are preserved and preview features remain opt-in, but organizations that left features unconfigured will see unexpected activations starting today.

## Legacy API Shutdown D-1: The GPT-4 Era's Last Night

Tomorrow (Oct 23), at least 11 legacy model endpoints — o1, o1-pro, o3-mini, o4-mini, GPT-3.5 Turbo, GPT-4, GPT-4 Turbo, and gpt-4.1-nano — will be permanently shut down with no grace period([Geeks IT](https://geeks.it.com/?p=976)). Requests to pinned model IDs will fail immediately with no automatic fallback. GPT-5.6 Sol is the official replacement for the GPT-4 family([Layer3 Labs](https://www.layer3labs.io/guides/openai-deprecated-models)). Given the week-long "model not supported" errors that followed GPT-5.5's October 14 retirement, similar disruption after the 23rd is all but certain.

## Copilot: Climbs to 51, Universe D-6

Copilot rises to 51, sustaining its +2/day streak for the 10th consecutive day. The gap over Cursor is now 50 points (51 vs 1), a new record. With the default enablement policy now live and MCP servers auto-activating across organizations, real-world usage metrics are likely to climb further. [GitHub Universe 2026](https://github.blog/news-insights/company-news/your-guide-to-github-universe-2026-is-here-the-schedule-just-launched/) (Oct 28–29, Fort Mason) is 6 days away — the session catalog features Copilot agent delegation, enterprise AI measurement, and MCP server security as headline topics([Gracker AI](https://gracker.ai/events/github-universe-2026/)).

## Anthropic IPO: Targeting SpaceX-Scale Debut

Bloomberg reports that Anthropic expects its IPO could match SpaceX's record-setting public debut([The Next Web](https://thenextweb.com/news/anthropic-ipo-size-match-spacex-record)). The company filed a confidential draft S-1 with the SEC on June 1([NPR](https://www.npr.org/2026/06/01/nx-s1-5843199)), and a public S-1 is expected by late October or early November. The $965B valuation is based on the $65B Series H round, with the revenue run rate growing rapidly from $65B as of August. Anthropic is on track to go public ahead of OpenAI ($852B).

## ChatGPT: GPT-6 + Intelligent UI Expanding

GPT-6 Sol/Luna and the Intelligent UI, launched October 7, continue rolling out across all tiers([LetsDatasScience](https://letsdatascience.com/news/openai-brings-gpt-6-and-intelligent-ui-to-chatgpt-4f0d797c)). Responses now include interactive charts, buttons, forms, and task-specific tools inline. GPT-6 Instant starts answering web search queries 44% faster on average than GPT-5.6 Instant([YourStory](https://yourstory.com/ai-story/gpt-6-intelligent-ui-chatgpt-answers)).
