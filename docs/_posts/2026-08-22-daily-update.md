OpenAI slashed its frontier GPT-5.6 Sol model API prices by more than 20% today — standard short-context input tokens drop from $5 to $4, and output tokens from $30 to $20 ([Business Standard](https://www.business-standard.com/technology/tech-news/openai-cuts-developer-pricing-for-gpt-5-6-sol-model-by-more-than-20-126082200107_1.html)). The three-month promotional cut follows last month's 20% Terra discount and 80% Luna discount ([CNBC](https://www.cnbc.com/2026/07/30/open-ai-price-cut-gpt.html)). The move is widely read as a defensive play to stem developer attrition amid growing pressure from Anthropic and Chinese AI models ([Finimize](https://finimize.com/content/openai-cut-gpt-56-sol-api-prices-to-keep-developers-close)).

## OpenAI: o3 Retirement D-4, GPT-5.4 Retirement D-9

The o3 model exits ChatGPT on August 26, now just four days away ([OpenAI](https://openai.com/index/gpt-5-6/)). GPT-5.4 and GPT-5.4 mini will be removed from ChatGPT-authenticated Codex sessions on August 31, though they remain available via API key authentication ([Releasebot](https://releasebot.io/updates/openai/codex)). GPT-5.6 Sol is cementing its position as the recommended default model ("Power" setting) before month's end.

## Copilot: Mass Model Deprecation D-10, 102-Week Decline

GitHub Copilot is now D-10 from its September 1 mass model deprecation ([GitHub Roadmap](https://github.com/github/roadmap/issues/1308)). Six or more models — including Gemini 3.1 Pro, Claude Opus 4.5/4.6, Claude Sonnet 4.5/4.6, and Raptor mini — will retire simultaneously ([GitHub Changelog](https://github.blog/changelog/2026-07-31-upcoming-august-2026-model-deprecations-in-github-copilot/)). The 102-consecutive-week popularity decline continues, with the June usage-based billing transition accelerating developer departures ([TechTimes](https://www.techtimes.com/articles/317536/20260601/github-copilot-pricing-change-drives-backlash-agentic-bills-jump-10x-50x-power-users.htm)).

## Cursor: Event-Driven Cloud Agents Take Shape

Cursor's August 19 update added event subscriptions to cloud agents — register PRs, Slack threads, or cron schedules as triggers and agents wake automatically to handle work ([Releasebot](https://releasebot.io/updates/cursor), [explainx.ai](https://www.explainx.ai/blog/cursor-event-driven-cloud-agents-isolated-vms-august-2026)). Subagents now run on isolated VMs for parallel execution without collisions, a practical leap for complex multi-step workflows.

## Claude Code: Cost Estimate Precision, Alpine Support

Claude Code now factors the 1.1x US-only-inference premium into cost estimates (`/cost`, status line, `--max-budget-usd`) for data-residency workspaces ([Releasebot](https://releasebot.io/updates/anthropic/claude-code)). Alpine/musl builds gained native image paste, clipboard, and audio-capture support, and the fullscreen renderer offer now surfaces on Bedrock, Vertex, and Foundry setups ([Gradually.ai](https://www.gradually.ai/en/changelogs/claude-code/)).
