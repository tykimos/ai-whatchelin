Anthropic just played its next card in the AI coding wars. Claude Ship, unveiled November 23, is a suite of AI agents that automatically review pull requests, fix issues, and decide what's ready to merge([TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes)). Currently in beta with early adopters testing it in production workflows, Ship marks a shift from AI that writes code to AI that validates and approves it.

## Claude Ship: Automating the Quality Gate

Claude Ship targets routine code changes, handling review, fixes, and approvals end-to-end([TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes)). Where Claude Code focuses on writing code, Ship takes over the next stage: the quality gate. The ecosystem around Claude Code is also expanding — Revenium launched Sidekick, a real-time cost tracker that displays budget levels and running session costs directly in the coding environment([IT Brief UK](https://itbrief.co.uk/story/revenium-launches-sidekick-for-claude-code-cost-control)). Anthropic also confirmed that Sonnet 4.5 will retire on November 30, replaced by Sonnet 5.5([Claude World](https://claude-world.com/articles/claude-code-november-2026-whats-new/)).

## Cognition and Replit: The Agent Swarm Race

Cognition released Devin Bots — persistent agents that split projects into tasks, run multiple Devin sessions in parallel, and communicate with teams via Slack. Usage among dozens of early customers surged tenfold in two weeks([Fortune](https://fortune.com/2026/11/17/exclusive-cognition-bets-on-devin-bots-coding-agents-in-challenge-to-anthropics-duet-and-openais-dots/)). Replit countered with Missions, an agent swarm that pursues goals over hours or days rather than responding to single prompts([The New Stack](https://thenewstack.io/replit-missions-agent-swarms/)).

## Terminal-Bench 4.1: Copilot Overtakes Claude Code

Terminal-Bench 4.1 results released November 22 show GitHub Copilot at 71.2%, overtaking Claude Code at 65.8%([MorphLLM](https://www.morphllm.com/best-ai-coding-agents-2026)). Just days after Nadella admitted IDEs "faded" because of Claude Code, Copilot quietly reclaimed the benchmark lead. Copilot's cloud sandbox billing also went live November 23.

## ANT Stock and the Cursor Blackout

ANT enters calendar day 6 after its November 19 IPO. The stock opened at $111.50 and has been oscillating in the $95–99 range, with the market watching whether the Claude Ship announcement moves the needle([Nasdaq](https://www.nasdaq.com/articles/why-anthropic-stock-and-down-today)). Meanwhile, Cursor's OpenAI model blackout stretches to day 13, and it has now spent 124 consecutive days at the bottom of popularity rankings([ClickUp](https://clickup.com/learn/topic/ai/tools/cursor/news/)).
