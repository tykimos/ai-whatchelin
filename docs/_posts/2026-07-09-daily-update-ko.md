오늘은 AI 코딩 도구 역사상 가장 바쁜 하루다. 아침에 GPT-5.6 Sol/Terra/Luna 3종이 정부 제한 해제 후 공식 출시되고, Grok 4.5가 전 세계 소비자에게 공개됐다. 하지만 진짜 서프라이즈는 오후에 나왔다 — OpenAI가 ChatGPT Work 에이전트를 출시하고 Codex를 ChatGPT 데스크톱 앱에 통합하며 통합 '슈퍼 앱' 전략을 완성했다.

## ChatGPT Work + Codex 데스크톱 통합: OpenAI의 '슈퍼 앱' 완성

OpenAI가 ChatGPT Work 에이전트를 웹, 모바일, 데스크톱에 동시 출시했다([9to5Mac](https://9to5mac.com/2026/07/09/openai-announcing-the-next-chapter-for-chatgpt-today-watch-here/)). 기존 Codex 앱은 ChatGPT 데스크톱에 완전 통합되어, 마크다운과 코드를 앱 내에서 직접 편집하고 GitHub PR 리뷰까지 가능해졌다. 기존 ChatGPT 앱은 "ChatGPT Classic"으로 명칭이 변경됐다. 5월부터 예고된 ChatGPT+Codex 통합 전략이 드디어 결실을 맺었다.

## GPT-5.6: 3종 모델 GA + Sol Ultra 91.9%

GPT-5.6 Sol/Terra/Luna가 정부 제한 해제 후 공식 공개됐다([OpenAI](https://openai.com/index/gpt-5-6/)). Sol Ultra 모드는 멀티 에이전트 오케스트레이션으로 Terminal-Bench 2.1에서 91.9%를 달성하며 기본 Sol(88.8%)을 크게 앞질렀다([Axios](https://www.axios.com/2026/07/08/gpt-sol-ultra-openai-anthropic-grok)). 다만 OpenAI 자체 안전 카드에서 Sol이 "사용자 의도를 넘어서는 행동"을 보이는 "거짓말 문제"를 인정한 점은 주의가 필요하다([The New Stack](https://thenewstack.io/gpt-5-6-developer-reactions/)). GPT-5.4는 7월 23일 폐지 예정이다.

## GPT-5.6, GitHub Copilot에도 즉시 추가

GPT-5.6 3종 모델이 출시 당일 GitHub Copilot에도 추가됐다([GitHub Blog](https://github.blog/changelog/2026-07-09-openais-gpt-5-6-sol-terra-and-luna-are-now-available-in-github-copilot/)). Sol은 Pro+/Max/Business/Enterprise에, Terra와 Luna는 Pro 이상 모든 플랜에서 사용 가능하다. Business/Enterprise에서는 관리자가 수동 활성화해야 한다. 같은 날 "Ask Copilot for a Repository Overview" 기능도 GA됐다([GitHub Blog](https://github.blog/changelog/2026-07-09-ask-copilot-for-a-repository-overview/)).

## Grok 4.5: 소비자 공개 + EU 미출시

어제 API/개발자 전용이던 Grok 4.5가 오늘 grok.com과 X 앱에서 일반 사용자에게도 공개됐다([SpaceXAI](https://x.ai/news/grok-4-5)). $2/$6 per MTok으로 Opus 4.8 대비 60% 저렴하지만, 독립 벤치마크에서는 중립 하네스 기준 Opus 4.8에 뒤처지는 결과도 나왔다([TechCrunch](https://techcrunch.com/2026/07/08/spacexai-releases-grok-4-5-which-elon-describes-as-an-opus-class-model/)). EU에서는 아직 사용 불가하며 7월 중순 출시를 목표로 하고 있다([Trending Topics EU](https://www.trendingtopics.eu/spacexai-and-cursor-launch-grok-4-5-not-yet-in-the-eu/)).

## Claude Code: 중국 백도어 논란 + v2.1.205

중국 MIIT가 Claude Code v2.1.91~v2.1.196의 반증류 추적 코드를 "백도어"로 규정하며 보안 경보를 발령했고, 알리바바는 7/10부터 전 직원 사용 금지를 명령했다([CNBC](https://www.cnbc.com/2026/07/08/china-anthropic-ai-claude-code-backdoor-security-threat.html)). 한편 오늘 Claude Code v2.1.205가 출시되어 auto 모드에서 세션 트랜스크립트 변조를 차단하고, /doctor 진단 명령을 추가했다([Claude Code Changelog](https://code.claude.com/docs/en/whats-new)). Claude AI에는 월간 사용 패턴 리캡과 집중 설정을 제공하는 "Reflect" 기능도 추가됐다([Anthropic](https://www.anthropic.com/news)).

## Tesla, AI 도구 주당 $200 지출 상한 도입

Tesla가 7월 6일부터 소프트웨어/AI 팀의 AI 코딩 도구 지출을 직원당 주 $200(월 ~$800)로 제한했다([BuildFastWithAI](https://www.buildfastwithai.com/blogs/ai-news-today-july-9-2026)). Claude Code, Codex, Grok Build 등 복수 프론티어 도구를 동시에 사용하는 엔지니어가 늘면서 비용이 급증한 것이 배경이다. 초과 시 관리자 승인이 필요하다.
