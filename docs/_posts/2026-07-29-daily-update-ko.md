Codex CLI가 세션 관리 체계를 전면 개편하며 에이전트 플러그인 생태계를 본격 가동하고, Cursor가 인도 시장에 국가별 맞춤 요금제로 진출하는 등 AI 코딩 도구 시장의 글로벌 확장이 가속되고 있다. 동시에 주요 AI 기업 직원 1,100명 이상이 AI 감속을 촉구하는 공개서한에 서명하면서 기술 발전과 안전의 균형에 대한 논의가 재점화됐다.

## Codex CLI v0.146.0: 세션 관리 전면 개편

Codex CLI가 v0.146.0으로 업데이트되며 세션 관리 체계를 대폭 강화했다([Codex Changelog](https://developers.openai.com/codex/changelog)). `/new`와 `/clear` 명령으로 세션에 이름을 부여하고, 중요 스레드를 핀 고정하며, 사이드 대화 간 전환과 페이지네이션 히스토리 기반 스레드 포크가 가능해졌다. 더불어 Agent Plugins 매니페스트 지원과 워크스페이스 플러그인 퍼블리싱이 추가됐으며, 마켓플레이스에서 Amazon Bedrock 및 Claude Code 플러그인을 바로 설치할 수 있다([Releasebot](https://releasebot.io/updates/openai/codex)). 원격 Code Mode 호스트용 WebSocket 지원도 포함됐다.

## Cursor Start: 인도 전용 ₹649 플랜 출시

Cursor가 인도 시장 전용 'Cursor Start' 플랜을 월 ₹649(약 $7 USD)에 출시했다([Cursor Blog](https://cursor.com/blog/cursor-start-india)). Grok 4.5 접근, Composer, 클라우드 에이전트, iOS 앱, 플러그인, MCP 서버, Hooks, Skills를 모두 포함하는 이 플랜은 Cursor 최초의 국가별 맞춤 가격이다. 인도는 3백만 명 이상의 개발자가 활동하는 Cursor의 세 번째 최대 시장으로, 글로벌 Pro 플랜($20) 대비 65% 할인된 가격으로 시장 점유율 확대를 노린다([The Next Web](https://thenextweb.com/news/cursor-start-india-pricing-own-models-spacex)).

## OpenAI: GPT Transcribe API 및 ChatGPT 통합 인증 출시

OpenAI가 두 가지 새 음성 전사 모델을 공개했다([OpenAI Release Notes](https://openai.com/products/release-notes/)). GPT Transcribe는 파일 기반 정밀 전사를, GPT Live Transcribe는 저지연 스트리밍 전사를 담당하며, 자유 형식 컨텍스트와 키워드 힌트를 지원한다. 또한 'Sign in with ChatGPT' 베타가 Airtable·GitLab·HubSpot·Notion·Supabase·Vercel에 순차 적용되며, 학술 연구자를 위한 12개월 무료 팀 워크스페이스 프로그램도 시작됐다([ChatGPT Release Notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)).

## AI 감속 공개서한: 1,100명 이상 서명

OpenAI·Anthropic·Google·Meta 직원 1,100명 이상이 국제적으로 검증 가능한 AI 감속 메커니즘을 구축할 것을 워싱턴에 촉구하는 공개서한에 서명했다([BuildFastWithAI](https://www.buildfastwithai.com/blogs/ai-news-today-july-29-2026)). 같은 날 Cyera가 AI 에이전트 보안 전문 기업 Oasis Security를 약 10억 달러에 인수하며, AI 안전성이 투자와 정책 양면에서 최우선 의제로 부상하고 있다.

## VS Code 1.131 Insiders: 서브에이전트 가시성 강화

VS Code 1.131 Insiders 빌드가 출시되며, 서브에이전트 활동의 모델명·경과 시간·활성 도구 호출이 대화를 열지 않고도 확인 가능해졌다([VS Code Updates](https://code.visualstudio.com/updates/v1_131)). 오프라인 Nemotron 모델 기반 실험적 딕테이션 기능과 Agents 윈도우용 하이브리드 마크다운 에디터도 추가됐다.
