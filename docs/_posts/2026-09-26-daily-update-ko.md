AI 코딩 도구 시장이 이번 주말 두 가지 대형 이벤트를 앞두고 숨을 고르고 있다. 9월 28일 GitHub Copilot 통합 경험 출시, 그리고 9월 29일 OpenAI DevDay — 두 이벤트 모두 시장 판도를 흔들 잠재력이 있다.

## Copilot 통합 경험 D-2: 마지막 준비

GitHub이 9월 28일로 예정한 Copilot 통합 경험 출시가 이틀 앞으로 다가왔다([GitHub Blog](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)). github.com 채팅, 모바일, 클라우드 에이전트가 단일 정책 하에 합병되며, 채팅 데이터 보관 기간이 28일에서 계정 수명 전체로 확대된다. 코드 리뷰 기본값도 Lite에서 Balanced로 전환되어 AI 크레딧 소비량이 증가할 전망이다. 10월 1일부터는 모든 새 Business/Enterprise 좌석에 선불 결제가 적용된다.

## OpenAI DevDay D-3: Pro Max $500 요금제 기대감

OpenAI DevDay가 9월 29일 샌프란시스코 Fort Mason에서 열린다([OpenAI](https://devday.openai.com/)). ChatGPT 웹 앱과 Codex 리포에서 발견된 Pro Max $500/월 요금제 코드가 DevDay 발표 후보로 유력시되고 있으며, Cerebras 웨이퍼 스케일 칩 연동으로 초고속 추론이 핵심 기능으로 예상된다([TestingCatalog](https://www.testingcatalog.com/openai-prepares-new-500-month-pro-max-plan-for-chatgpt/)). GPT-6 Sol과 Luna가 4일 전 출시되며 API 가격을 절반으로 낮춘 상태에서, DevDay는 추가적인 개발자 도구 확대를 예고하고 있다.

## Cursor: 38일 연속 하락, 39점 기록

Cursor가 39점으로 38일 연속 하락세를 기록하며 OpenAI 모델 접근 종료(11/12)까지 D-47에 도달했다([Cursor](https://cursor.com)). 지난주 출시한 Projects 베타(코디네이터 에이전트가 수천 개 서브에이전트에 작업 위임)와 Rollouts/Security Review 봇에도 불구하고 반전 기미가 보이지 않는다. SpaceX 인수(8/14) 이후 99점에서 60점이 빠졌으며, 개발자 이탈이 Claude Code와 Codex CLI로 가속화되고 있다.
