GitHub Universe 2026 opens tomorrow (Oct 28–29). With a next-gen Copilot agent roadmap reveal widely expected, the terminal agent camp is also shipping fast.

## Codex CLI v0.164.0: Saved Prompts and Inline Arguments

Codex CLI shipped v0.164.0 on October 23, introducing numbered prompt slots (1–10) for quick-recall of frequently used instructions([OpenAI Changelog](https://learn.chatgpt.com/docs/changelog)). Type `/1`, `/2`, etc. to fire a stored prompt instantly. The `/model` and `/permissions` commands now accept inline arguments, eliminating the need for interactive selection. A Windows proxy authentication bug was also fixed. Combined with last week's v0.163.0 `/config` command, the CLI's usability gap with IDE-class tools is narrowing rapidly.

## Claude Code v2.1.305: Fork Subagents Enabled by Default

Claude Code has been shipping rapid point releases through mid-October. Version 2.1.302 turned fork subagents on by default, and v2.1.299 added idle compaction for better context management([Chris Pirillo/X](https://x.com/ChrisPirillo/status/2112942903077298511)). The latest v2.1.305 fixes tool-search failures and prevents completed agents from being re-run during workflow resumption.

## Copilot: Hits 61, Universe D-1

Copilot's popularity score rises to 61, maintaining its steady recovery. Tomorrow's [GitHub Universe 2026](https://github.blog/news-insights/company-news/your-guide-to-github-universe-2026-is-here-the-schedule-just-launched/) (Fort Mason, San Francisco) is expected to unveil the next-gen Copilot agent roadmap. October has already brought computer-use public preview, local sandboxing GA, and Claude Haiku 5.5 model support([tech-insider.org](https://tech-insider.org/github-copilot-cli-computer-use-preview-2026/)) — Universe should add to the momentum.

## ChatGPT: Pro 500 Tier Launches, Grandfathering Change Oct 29

ChatGPT introduced a $500/month Pro 500 tier([dev.to](https://dev.to/edzon_perez_937ae1c10f9c5/what-18-ai-coding-agents-actually-cost-october-2026-16gg)). On October 29, grandfathered Pro $200 subscribers will see their usage allowance reduced. The GPT-5.5 retirement migration is mostly complete, though sporadic "model not supported" errors still surface in automated agent configurations.

## Cursor: New Pricing Tiers, Still at Rock Bottom

Cursor reorganized its pricing on October 18 — Free, Plus ($8, Grok models only), Premium ($30), Super ($100), and Ultra ($200)([AgentDeals](https://agentdeals.dev/digest/2026-w42)). Legacy Hobby/Pro/Pro+/Teams plans are being phased out. Despite the lower entry price, developer backlash over the Grok-only shared pool continues with no reversal signal.
