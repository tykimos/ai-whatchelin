One of Wall Street's most aggressive AI adopters just hit the brakes. Goldman Sachs has narrowed access to advanced AI coding tools — and it could be the first major signal that enterprise governance is catching up to the AI coding boom.

## Goldman Sachs: AI Coding Tools Now Engineer-Only

Goldman Sachs updated its internal guidance to restrict access to advanced AI coding tools like Claude Code and GitHub Copilot to engineers and Strats only, cutting off traders and bankers ([Wisevoter](https://wisevoter.com/world/us/2026/11/02/goldman-sachs-restricts-ai-coding-tools)). The October update followed a firm-wide productivity and risk review ([TokenPost](https://www.tokenpost.com/news/technology/46652)). Simultaneously, the bank is rolling out its in-house "GS AI Assistant" to approximately 46,000 employees. This follows April's Hong Kong-specific Claude ban, signaling an increasingly strict AI tool governance posture ([Bloomberg](https://bloomberg.com/news/articles/2026-04-29/goldman-staff-in-hong-kong-lose-access-to-anthropic-s-claude)).

## DeepSeek Harness: Open-Source Coding Agent Enters the Ring

DeepSeek released its coding agent framework "Harness" under MIT license on October 31 ([GitHub](https://github.com/deepseek-ai/awesome-deepseek-agent)). Built on DeepSeek-V4-Pro, the repo reportedly hit 4,000 GitHub stars within a day. It's the first serious open-source challenger to the Claude Code and Codex duopoly in the coding agent space.

## Claude: Mythos 5.5 Reference Spotted, Game Recreation Controversy

TestingCatalog reported on November 1 that a Mythos 5.5 reference appeared on Anthropic's Mythos page, with a possible launch "next week" — still unconfirmed ([TestingCatalog](https://www.testingcatalog.com/anthropic-prepares-to-release-claude-mythos-5-5-model/)). Separately, since around October 27 Claude Code has been enforcing a server-side rule ('tengu_heron_brook') blocking recreation of specific existing video games ([Game Developer](https://www.gamedeveloper.com/programming/anthropic-appears-to-have-ordered-ai-tool-claude-to-stop-remaking-video-games)). Anthropic confirmed it added two sentences to Claude Code's prompt on Opus 5.5 to prevent IP infringement ([VideoCardz](https://videocardz.com/newz/anthropic-restricts-claude-code-from-recreating-existing-games-developers-report-blocked-projects)).

## Cursor: OpenAI Cutoff D-10, Day 69 at Rock Bottom

The November 12 full cutoff of OpenAI model access is now just 10 days away ([Bloomberg](https://www.bloomberg.com/news/articles/2026-08-29/openai-to-end-partnership-with-cursor-after-spacex-acquisition)). Cursor remains at a score of 1 for 69 consecutive days following the SpaceX acquisition fallout. CEO claims OpenAI traffic is just 5%, but the symbolic weight is far heavier.

## GitHub Copilot: Climbs to 73, 38-Day Recovery Streak

Momentum from Universe 2026's Copilot Fusion GA continues, with 38 consecutive days of gains ([GitHub Blog](https://github.blog/changelog/)). A November 16 model lineup refresh (Opus 4.8/5 to Opus 5.5, GPT-5.6 Terra to GPT-6.1 Sol) is scheduled. Claude Fable 5.1 and Gemini 3.8 Flash were recently added to the model roster ([Technobezz](https://www.technobezz.com/news/github-copilot-claude-fable-gemini-flash)).

## Anthropic: IPO Roadshow One Week Away

Anthropic's S-1 was filed with the SEC on October 26, with the roadshow expected the week of November 9. Nasdaq ticker "ANT," 12-month revenue $19.7B, net loss $109.7B ([IPO Scoop](https://www.iposcoop.com/the-ipo-buzz-anthropic-ant-proposed-files-its-s-1/)). The potential overlap between a Mythos 5.5 launch and the roadshow has drawn strategic timing speculation.
