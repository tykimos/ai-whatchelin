어제까지 "오늘 자정 종료"라고 보도했던 Fable 5 무료 접근이 또 연장됐다. Anthropic은 7월 13일 새벽 @claudeai X 계정을 통해 모든 유료 구독자(Pro, Max, Team, Enterprise)의 Fable 5 플랜 포함 접근을 7월 19일까지 연장한다고 발표했다([BleepingComputer](https://www.bleepingcomputer.com/news/artificial-intelligence/claude-fable-5-stays-free-for-paid-users-until-july-19-as-anthropic-buys-more-time/)). 주간 사용량의 최대 50%를 추가 비용 없이 Fable 5에 할당할 수 있으며, 7월 19일 이후부터 $10/$50 per MTok 크레딧 과금이 적용된다([Dataconomy](https://dataconomy.com/2026/07/13/claude-fable-5-free-access-extended-july-19/)). 이번이 5주 만에 세 번째 연장으로, GPT-5.6과 Grok 4.5 동시 출시라는 경쟁 압박 속에서 유저 이탈을 막기 위한 방어적 결정으로 읽힌다.

## Claude Code 50% 한도 상향도 7/19까지 동시 연장

5월 13일부터 시행 중이던 Claude Code 주간 사용량 50% 추가 프로모션도 당초 7월 13일 18시(PDT) 종료 예정이었으나 7월 19일까지 연장됐다([Help Net Security](https://www.helpnetsecurity.com/2026/07/13/claude-code-weekly-limits-promotion-extended/)). Hacker News에서는 "정상 한도가 얼마인지 아무도 경험해본 적 없다"는 반응이 이어지며, 프로모션 종료 시 실질적 성능 저하를 우려하는 목소리가 커지고 있다([HN](https://news.ycombinator.com/item?id=48883064)).

## Cursor에서 "Claude Honeycomb EAP" 유출 — Opus 5 추측 확산

7월 8일 Cursor 모델 선택기에 "Claude Honeycomb EAP"라는 미발표 Anthropic 연구 모델이 짧게 노출됐다가 수시간 만에 제거됐다([HN](https://news.ycombinator.com/item?id=48842904)). 1M 컨텍스트, "extra high effort" 모드, Opus 4.8 안전 폴백 라우팅 등이 설명에 포함됐으며, 커뮤니티에서는 Opus 5 프리뷰라는 추측이 확산되고 있다([Explainx](https://www.explainx.ai/blog/claude-opus-5-release-speculation-july-2026)). 별도로 ToolCrush는 7월 11일 Dario Amodei가 Sonnet 5.5를 다음 주 출시한다고 확인했다고 보도했다([ToolCrush](https://toolcrush.io/blog/ai-news-this-week-july-11-2026)).

## Gemini 3.5 Pro D-4 — 7월 17일 출시 카운트다운

Google의 Gemini 3.5 Pro가 7월 17일 GA를 4일 앞두고 있다([BigGo Finance](https://finance.biggo.com/news/6f0c6bb2-795f-4c57-9d09-6db691d7638a)). 200만 토큰 컨텍스트 윈도우와 Deep Think 추론 레이어가 핵심이며, 원래 6월 출시 예정이었으나 코딩 성능과 장기 추론 품질 이슈로 지연됐다([CryptoBriefing](https://cryptobriefing.com/google-delays-gemini-35-pro-launch-to-july-2026/)). Copilot에서는 7월 31일까지 Gemini 2.5 Pro와 Gemini 3 Flash 지원이 종료되므로 마이그레이션이 필요하다([GitHub Changelog](https://github.blog/changelog/2026-07-02-upcoming-deprecation-of-gemini-2-5-pro-and-gemini-3-flash/)).

## Copilot Vision GA — 이미지·PDF 첨부 정식 출시

GitHub Copilot Chat에서 이미지와 PDF 파일을 첨부해 코드와 함께 추론할 수 있는 Copilot Vision이 정식 출시됐다([Releasebot](https://releasebot.io/updates/github)). Claude, ChatGPT 대비 뒤처졌던 멀티모달 코딩 워크플로우의 격차를 줄이는 업데이트지만, Copilot의 68주 연속 하락세(13)를 반전시킬지는 미지수다.
