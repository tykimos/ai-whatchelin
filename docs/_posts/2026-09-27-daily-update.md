The AI coding tool market is bracing for a pivotal weekend. GitHub Copilot's unified experience launches tomorrow (Sep 28), and OpenAI DevDay follows the day after (Sep 29) — two major events within 48 hours that could redraw the competitive landscape.

## GitHub Copilot: Unified Experience Launches Tomorrow

Starting September 28, GitHub will merge Copilot Chat on github.com, Copilot Chat in GitHub Mobile, and the Copilot cloud agent into a single unified experience ([GitHub Blog](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)). Separate policies will collapse into one, enabled by default. Chat data retention extends from 28 days to account lifetime, and code review defaults shift from Lite to Balanced ([C# Corner](https://www.c-sharpcorner.com/article/preparing-for-the-github-copilot-unified-experience-coming-september-28)). Prepaid billing becomes mandatory for all new Business/Enterprise seats from October 1.

## OpenAI DevDay D-2: The "o" Agent and Pro Max at $500/Month

OpenAI DevDay (Sep 29, Fort Mason, San Francisco) is two days away ([OpenAI](https://openai.com/index/devday-2026/)). Sam Altman opens the keynote, which will be livestreamed for free, with roughly a dozen product announcements expected. The always-on "o" agent, a GPT-6 Cyber security model preview, and the Pro Max $500/month plan are the headline items ([Forbes](https://www.forbes.com/sites/jonmarkman/2026/09/21/openai-plans-to-introduce-managed-agents-at-devday-2026/)).

## Codex CLI v0.156: Fullscreen TUI and Voice Conversations

Codex CLI shipped v0.156.0 with an optional fullscreen UI (`/tui`), voice conversations enabled by default (F8 toggle), a `/usage` dashboard, and worktree support on by default ([Releasebot](https://releasebot.io/updates/openai/codex)). GPT-6 Sol/Luna support and Amazon Bedrock integration are also included. Through September 22, the project has shipped over 1,125 releases — averaging more than two updates per day.

## Cursor: 39th Straight Day of Decline, Drops to 37

Cursor fell to 37, marking its 39th consecutive day of decline. Since the SpaceX acquisition closed on August 14, Cursor has shed 62 points from its 99 peak, with OpenAI model access termination (Nov 12) now D-46 away ([CNBC](https://www.cnbc.com/2026/08/29/openai-cursor-spacex-model-access.html)). Neither the Projects coordinator agent (Sep 10) nor the deployment bots Rollouts and Security Review (Sep 23) have slowed the exodus ([Cursor](https://cursor.com/changelog)).
