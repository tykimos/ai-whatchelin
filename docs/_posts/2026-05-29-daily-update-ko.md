Anthropic이 $650억 시리즈 H를 $9,650억 포스트머니 밸류에이션으로 마감하며, OpenAI를 넘어 세계 최고 가치 비상장 AI 기업이 됐다([Bloomberg](https://www.bloomberg.com/news/articles/2026-05-28/anthropic-raises-at-965-billion-valuation-eclipsing-openai)). 연간 매출 런레이트가 $470억에 달하며, 10월 IPO 전 마지막 비공개 라운드로 관측된다([TechCrunch](https://techcrunch.com/2026/05/28/anthropic-raises-65-billion-nears-1t-valuation-ahead-of-ipo/)).

## Anthropic: $1조 클럽 진입 목전

Sequoia, Dragoneer, Altimeter, Greenoaks가 공동 리드했으며, Amazon이 기존 약정 $150억 중 $50억을 이번 라운드에 투입했다([CNBC](https://www.cnbc.com/2026/05/28/anthropic-open-ai-startup-value.html)). 전날 출시된 Claude Opus 4.8이 SWE-bench Verified 88.6%, SWE-bench Pro 69.2%를 기록하며 코딩 벤치마크 1위를 유지하고 있다([Anthropic](https://www.anthropic.com/news/claude-opus-4-8)). Claude Code의 동적 워크플로우는 단일 실행에서 최대 1,000개 서브에이전트를 생성하며, Bun의 Zig→Rust 이전(75만 줄, 11일)이 시연 사례로 공개됐다([claude.com](https://claude.com/blog/introducing-dynamic-workflows-in-claude-code)).

## OpenAI: 전 서비스 대규모 장애

OpenAI가 5월 29일 ChatGPT, API, DALL-E, Codex, Sora, 로그인 시스템 전반에 걸친 장애를 겪었다([BusinessUpturn](https://www.businessupturn.com/technology/chatgpt-down-openai-users-report-widespread-problems-with-api-app-and-login-on-may-29)). 2026년 들어 가장 광범위한 동시 장애로, Anthropic의 $650억 라운드 마감과 같은 날 발생해 대조를 이뤘다.

## GitHub Copilot: 25주 연속 하락, D-3

Copilot 인기도가 58까지 떨어지며 역대 최저치를 경신했다([GitHub Docs](https://docs.github.com/en/copilot/how-tos/manage-and-track-spending/prepare-for-your-move-to-usage-based-billing)). 6월 1일 사용량 기반 과금까지 3일 — 코드 완성은 무료 유지되나 에이전트·채팅은 AI 크레딧을 소모한다. 4일 후 Microsoft Build 2026에서 자체 코딩 모델 공개가 유일한 반전 카드로 남아 있다([Digit.in](https://www.digit.in/news/general/microsoft-may-unveil-new-coding-focused-ai-model-next-week-here-is-what-we-know.html)).

## Codex CLI: v0.135.0 — 진단 강화

codex doctor가 환경·Git·터미널·앱 서버·스레드 인벤토리 진단을 강화했다([OpenAI Codex Changelog](https://developers.openai.com/codex/changelog)). Codex CLI가 영속 자율 에이전트 런타임으로 진화하는 추세가 이어지고 있다.
