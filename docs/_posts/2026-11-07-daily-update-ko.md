AI 코딩 도구 시장의 세 가지 카운트다운이 동시에 진행 중이다. Anthropic IPO 로드쇼 개시까지 이틀, Cursor의 OpenAI 모델 접근 차단까지 5일, GitHub Copilot 모델 대교체까지 9일. 이번 주와 다음 주가 2026년 하반기 AI 코딩 도구 시장의 분수령이 될 전망이다.

## Anthropic: IPO 로드쇼 11월 9일 주간 개시 전망

Anthropic이 10월 26일 SEC에 공개 S-1을 제출한 이후, 로드쇼가 11월 9일 주간에 시작될 것으로 전망된다([Implicator AI](https://www.implicator.ai/anthropic-could-start-ipo-roadshow-week-of-nov-9-putting-debut-before-thanksgiving/)). SEC 15일 규정상 가장 빠른 가격 결정일은 11월 13일이며, 첫 거래일은 11월 16일로 예상된다([SmartScope](https://smartscope.blog/en/blog/anthropic-ipo-s1-filing-nasdaq-ant-2026/)). 나스닥 티커 ANT로 상장 예정이며, 추수감사절 전 상장을 목표로 하고 있다([Invenglobal](https://www.invenglobal.com/articles/27712/anthropic-files-s-1-for-ipo-plans-nasdaq-listing-under-ticker-ant)). IPO S-1에서 Anthropic은 AI가 오용될 경우 "재앙적이고 실존적인 위험"을 초래할 수 있다고 경고해 주목을 받았다([ABC News](https://abcnews4.com/news/nation-world/gallery/anthropic-ipo-filing-warns-ai-could-pose-catastrophic-existential-risks-if-misused?photo=1)).

## Cursor: OpenAI 차단 D-5, 74일째 바닥

11월 12일 OpenAI 모델 접근 완전 차단까지 5일 남았다([OpenAI Blog](https://openai.com/blog/our-decision-on-cursor-following-its-acquisition-by-spacex)). SpaceX의 600억 달러 Anysphere 인수 이후 OpenAI가 이용약관 준수 우려를 이유로 접근을 종료하기로 결정한 것이다([CNBC](https://www.cnbc.com/2026/08/29/openai-cursor-spacex-model-access.html)). Cursor CEO는 OpenAI 모델이 전체 트래픽의 약 5%에 불과하다고 밝혔지만, 상징적 의미는 크다([Tom's Guide](https://www.tomsguide.com/ai/openai-is-leaving-cursor-in-november-here-are-your-3-options)). Grok 4.7과 Anthropic 모델로의 전환이 진행 중이며, 사용자들은 직접 OpenAI API 키를 입력할 수 있지만 Tab 자동완성, 클라우드 에이전트 등 핵심 기능에서는 사용 불가하다.

## GitHub Copilot: 43일 연속 상승, 83점 기록

GitHub Copilot이 43일 연속 상승하며 83점을 기록했다. 11월 16일 모델 대교체(Claude Opus 4.8/5 및 GPT-5.6 Terra 제거, Opus 5.5 및 GPT-6.1 Sol로 교체)까지 9일 남았다([GitHub Blog](https://github.blog/changelog/2026-10-15-upcoming-deprecation-of-selected-github-copilot-models-in-mid-november)). 하드코딩된 모델명을 사용하는 환경에서는 마이그레이션이 필수이며, Claude Opus 4.8은 연간 구독자에 한해 예외적으로 유지된다([SmartScope](https://smartscope.blog/en/blog/github-copilot-claude-opus-5-deprecation-november-16-2026/)). JetBrains Air와 Xcode 통합 이후 IDE 확장 전선에서의 모멘텀이 이어지고 있다.

## OpenAI Dots: 기본 활성화까지 11일

OpenAI의 상시 에이전트 Dots가 11월 18일부터 Enterprise, Edu, Healthcare 워크스페이스에서 기본 활성화된다([OpenAI Release Notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)). 관리자가 옵트아웃하지 않으면 자동으로 켜지며, Microsoft와의 Agent 365 거버넌스 통합 작업이 진행 중이다([InfoWorld](https://www.infoworld.com/article/4229252/openai-bets-enterprises-are-ready-to-delegate-real-work-to-autonomous-agents.html)). 골드만삭스의 AI 도구 접근 제한 사례가 보여주듯, 기업 환경에서 에이전트 거버넌스는 갈수록 중요해지고 있다.
