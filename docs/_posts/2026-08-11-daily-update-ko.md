AI 코딩 도구 시장의 지각 변동이 동시다발적으로 일어나고 있다. Cursor가 직원들에게 SpaceX의 $600억 전량 주식 교환 인수가 빠르면 다음 주, 늦어도 8월 말까지 확정된다고 통보했다([CBS News](https://www.cbsnews.com/news/spacex-cursor-60-billion-ai-acquisition/)). 6월 5일 서명된 인수 계약이 최종 규제 승인만을 남겨두고 있으며, Cursor 인력과 운영 도구 전체가 SpaceXAI에 직접 통합된다. 세계 최대 AI IDE가 SpaceX 산하로 편입되면서 독립 도구로서의 Cursor 시대가 공식적으로 막을 내린다.

## Anthropic: Theseus Infrastructure — 자체 데이터센터 제국

Anthropic이 Macquarie Asset Management·GIC와 파트너십을 맺고 Theseus Infrastructure를 설립한다고 발표했다([Bloomberg](https://www.bloomberg.com/news/articles/2026-08-10/anthropic-macquarie-and-gic-form-venture-for-ai-data-centers)). 미국 우선으로 AI 전용 데이터센터를 대규모로 구축·운영·임대하는 플랫폼이다. Macquarie와 GIC가 지분과 자본 대부분을 제공하며, Anthropic은 전력망 업그레이드 비용 100% 부담과 소비자 전기 가격 상승분 보전을 약속했다([Macquarie](https://www.macquarie.com/au/en/about/news/2026/anthropic-mam-gic-data-centre-infrastructure-partnership.html)). SpaceX Colossus, Akamai, TeraWulf에 이은 네 번째 대형 인프라 계약으로, IPO를 앞둔 Anthropic의 컴퓨트 자급자족 전략이 한층 구체화됐다.

## Claude Code: v2.1.227 + auto 모드 D-3

Claude Code v2.1.227이 배포됐다. Vim 모드에서 yank 레지스터가 다이얼로그·히스토리 검색·트랜스크립트 뷰를 거쳐도 유지되며, Google Vertex AI에서 도구 검색이 재활성화됐고, 다이내믹 워크플로우가 medium(15 에이전트 이하) 크기를 기본값으로 사용한다([Releasebot](https://releasebot.io/updates/anthropic/claude-code)). 8월 14일 auto 모드 기본 전환까지 3일 남았다.

## OpenAI: GPT-5-Codex-Mini + GPT-5.4 퇴장 예고

OpenAI가 GPT-5-Codex-Mini를 Codex CLI와 IDE Extension에 추가했다. GPT-5-Codex의 소형 버전으로, ChatGPT 구독 대비 최대 4배 사용량을 제공한다([OpenAI Codex Changelog](https://developers.openai.com/codex/changelog)). 한편 GPT-5.4와 GPT-5.4 mini는 8월 31일부로 ChatGPT 인증 사용자 대상 Codex에서 퇴출되며, gpt-5.6-luna로의 마이그레이션이 권고된다([OpenAI Help](https://help.openai.com/en/articles/9624314-model-release-notes)).

## Meta: Muse Glimmer 30B 후속 반응

어제 공개된 Muse Glimmer 30B가 오픈소스 커뮤니티에서 빠르게 확산 중이다. 양자화 20GB 미만으로 단일 소비자 GPU 실행 가능, 131K 컨텍스트, Apache 2.0 라이선스라는 조합이 Ollama $65M 시리즈 B에 이어 로컬 AI 에이전트 트렌드를 강화하고 있다([Meta AI Research](https://research.meta.ai/blog/introducing-muse-glimmer-open-agentic-model)).
