GitHub Copilot's sweeping overhaul is 8 days out. Starting September 28, Copilot Chat on github.com, mobile, and cloud agent will relaunch as a single unified experience with a single policy replacing separate ones ([GitHub Changelog](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)). Two days later on October 2, Gemini 3.5/3.6 Flash, Kimi K2.7 Code, and Claude Opus 4.7 will all be retired from Copilot ([AiCybr Blog](https://aicybr.com/blog/github-copilot-model-deprecation-october-2026)). Back-to-back changes in a 4-day span make late September a busy time for Copilot administrators.

## GitHub Copilot: Unified Experience D-8, Data Retention Policy Shifts

Starting September 28, Copilot Chat data retention extends from 28 days to the lifetime of the account ([GitHub Changelog](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)). Cloud agent will leverage Sandbox for a faster experience, and code reviews will default to Balanced — potentially increasing AI consumption unless organizations switch to Lite ([Developers Digest](https://www.developersdigest.tech/blog/github-copilot-september-policy-billing-reset-2026)). Admins who don't proactively adjust review depth should expect higher costs.

## Cursor: 51 Points, Day 31 of Decline — 50-Floor Within Reach

Cursor dropped to 51, marking 31 consecutive days of decline since the SpaceX acquisition closed on August 14 ([CNBC](https://www.cnbc.com/2026/08/29/openai-cursor-spacex-model-access.html)). With 53 days until OpenAI's November 12 model access cutoff, the 50-point psychological floor could break as early as tomorrow. Cursor Projects beta is now 10 days old but has failed to reverse the slide. Community sentiment is increasingly pessimistic: *"Below 50 and there's no coming back."*

## Claude Code: v2.1.278 Defaults to Server-Side Classifier

Claude Code v2.1.278 switches auto mode for API, Enterprise, Bedrock, Vertex, Foundry, and gateway users to the server-side classifier by default ([Claude Code Changelog](https://code.claude.com/docs/en/changelog)). This eliminates classifier overhead charges, delivering real cost savings. A new "Auto mode server" row in `/status` shows where the current session's classifier runs.

## Gemini 3.8 Flash: The Engine Behind Copilot's Model Refresh

Gemini 3.8 Flash will replace 3.5/3.6 Flash in Copilot starting October 2 ([9to5Google](https://9to5google.com/2026/09/02/gemini-3-8-flash-launch/)). Pricing holds steady at 3.7 Flash levels while benchmarks improve across the board ([Enterprise DNA](https://enterprisedna.co/resources/news/google-gemini-38-flash-coding-agents-enterprise-september-2026/)). This marks Google's third Flash update in six weeks — an aggressive iteration pace.
