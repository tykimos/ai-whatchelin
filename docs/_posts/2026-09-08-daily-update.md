GPT-6 Astra's staggered rollout is done — ahead of schedule. On the same day, Google's Threat Intelligence Group formally warned that AI coding agents have become the number-one target for cybercriminals and state-backed hackers. The collision between AI tool proliferation and security risk defined the day.

## GPT-6 Astra: Rollout Complete, Full GA

Microsoft's Foundry model catalog now labels gpt-6-astra as generally available ([Yotta Labs](https://www.yottalabs.ai/post/gpt-6-release-date-rumors-what-is-known-2026)). The staggered rollout completed in just five days — ahead of OpenAI's own timeline — and every Plus, Pro, and Business user received a full banked reset. At $10/$50 per million tokens with a 1.05M context window and 128K max output, OpenAI calls Astra the opening of "the AGI era" ([CNBC](https://www.cnbc.com/2026/09/03/open-ai-astra-gpt-6-cyber.html)). The cybersecurity "Critical risk" designation and "reasoning concealment" debate remain unresolved ([SecurityWeek](https://www.securityweek.com/openais-astra-becomes-first-model-to-cross-critical-cybersecurity-threshold/)).

## Google: "AI Coding Tools Now a Prime Target for Threat Actors"

Google's Threat Intelligence Group formally warned that AI coding tools have become a primary attack vector for cybercriminals and state-backed hackers ([Infosecurity Magazine](https://www.infosecurity-magazine.com/news/ai-coding-tools-threat-actors/)). The financially motivated group UNC6780 used autonomous AI frameworks to build Dustmaker credential theft operations across PyPI, npm, and Docker Hub in under six hours. Chinese state actor UNC6508's targeting of military and academic AI research was also disclosed ([Google Cloud Blog](https://cloud.google.com/blog/products/identity-security/beyond-source-code-the-files-ai-coding-agents-trust-and-attackers-exploit)). Google recommends treating AI agent configuration files as security-sensitive assets.

## Cursor: Score 73, 12th Consecutive Decline — D-65

Cursor dropped to 73, marking its 12th consecutive daily decline. The slide from 99 on August 27 now totals 26 points. Product improvements like self-hosted machines and Cursor Router Auto Intelligence continue ([Cursor Changelog](https://cursor.com/changelog)), but with the OpenAI model cutoff (Nov 12) now 65 days away, developer attrition concerns persist. Anthropic's public pledge to increase Claude compute in Cursor may help slow the bleeding ([WCCFTech](https://wccftech.com/anthropic-pounces-as-openai-abandons-spacexs-cursor-vowing-to-increase-claude-compute-even-as-openai-cites-contract-distrust/)).

## McKinsey: 32% of Enterprises Replacing SaaS with Agentic Coding

McKinsey's "State of AI 2026" report found that 32% of organizations have skipped buying at least one software product because agentic coding tools let them build internally ([McKinsey](https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai)). Among high performers — the 6% attributing 5%+ of EBIT to AI — nearly half are doing so ([Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/build-vs-buy-shift-32-113806700.html)). The build-vs-buy paradigm is shifting in real time.

## GitHub Copilot: Multi-Agent Team Model Expansion

GitHub expanded Copilot Workspace into a coordinated multi-agent team model where separate agents handle implementation, testing, and documentation simultaneously ([AI Agent Store](https://aiagentstore.ai/ai-agent-news/this-week)). A unified Chat/Mobile/Cloud Agent experience relaunch is planned for no earlier than September 28. Whether this structural overhaul can lift Copilot from its extended floor remains an open question.
