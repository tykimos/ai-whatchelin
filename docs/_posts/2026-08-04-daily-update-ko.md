터미널 기반 에이전트가 IDE 기반 도구를 인기도에서 처음으로 앞섰다. GPT-5.6 Luna 80% 인하 효과가 8일째 이어지며 Codex CLI가 98점을 기록, Cursor(97)를 추월한 것은 AI 코딩 도구 역사상 최초다. 한편 Anthropic은 $100억 규모의 인프라 계약으로 컴퓨팅 확보에 나섰고, Opus 4.1은 내일 API에서 완전히 사라진다.

## Codex CLI: 98점 — Cursor 사상 첫 추월, Luna 8일 연속 상승

GPT-5.6 Luna 80% 인하(7/30)의 파급 효과가 8일째 이어지고 있다([VentureBeat](https://venturebeat.com/technology/ai-price-wars-openai-cuts-gpt-5-6-luna-prices-by-80-as-model-competition-shifts-toward-cost)). Codex CLI는 91점에서 매일 1점씩 올라 어제 Cursor와 97점 동점을 이룬 뒤, 오늘 98점으로 사상 첫 추월을 달성했다. 자동 코드 리뷰 비용이 10배 절감된 것이 핵심 동력이다. Cursor는 iPad 출시와 Router로 97점을 유지하고 있지만, 터미널 중심 개발자 이탈이 뚜렷하다.

## Anthropic: Volta $100억 계약 — Opus 4.1 내일 영구 폐기

Anthropic이 Nvidia 지원 AI 클라우드 스타트업 Volta와 6년간 $100억 컴퓨팅 용량 계약을 체결했다([Anthropic](https://www.anthropic.com/news)). SpaceX Colossus(5/6), AMD 50억 달러(7/22), Akamai 18억 달러(5/8)에 이은 네 번째 대형 인프라 계약이다. 동시에 Claude Opus 4.1(claude-opus-4-1-20250805) API가 내일(8월 5일) 영구 폐기된다([Anthropic](https://platform.claude.com/docs/en/about-claude/model-deprecations)). 6월 5일 공지 후 정확히 60일이며, Opus 4.8 마이그레이션이 필수다([TheRouter.ai](https://therouter.ai/news/anthropic-deprecates-claude-opus-4-1-august-5-migration-guide/)). Claude Code 50% 사용량 부스트는 8월 19일까지 유지된다.

## OpenAI: o3 8/26 ChatGPT 퇴장, Astra 9월 이후

OpenAI o3가 8월 26일부로 ChatGPT에서 폐기된다([help.openai.com](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)). 에이전틱 기능은 ChatGPT/Codex에 통합되며, API 접근은 유지된다. Atlas도 8월 9일 서비스를 종료한다. Astra는 연방 사전심사(~30일)를 거쳐야 하며 최빠른 공개 시점은 9월이다([FelloAI](https://felloai.com/all-we-know-about-chatgpt-6/)). OpenAI는 Hugging Face 침해 기술 보고서도 8월 중 발표 예정이다([WinBuzzer](https://winbuzzer.com/2026/07/29/hugging-face-ceo-seeks-openai-traces-and-defensive-compute-xcxwbn/)).

## GitHub Copilot: 9/1 대규모 모델 폐기, Billing Preview 폐쇄

9월 1일부로 Copilot 전 경험에서 다수 모델이 폐기된다([GitHub Changelog](https://github.blog/changelog/2026-07-31-upcoming-august-2026-model-deprecations-in-github-copilot/)). Claude Sonnet 4.6은 연간 구독 개인 사용자에게만 유지되며, Gemini 2.5 Pro와 3 Flash는 이미 7월 31일 폐기됐다. Copilot Billing Preview App은 어제(8/3) 공식 폐쇄됐다([GitHub Changelog](https://github.blog/changelog/2026-07-07-copilot-billing-preview-app-will-be-retired-on-august-3/)).

## 커뮤니티: HN "고기 프록시 되지 마라" 1,753점

Hacker News에서 *"Don't be a meat proxy"* — AI 시대에 인간의 역할을 논하는 글이 1,753점, 708개 댓글로 1위를 기록했다([Hacker News](https://news.ycombinator.com/front)). Qwen3.8-Max가 1,082점으로 "코딩과 Cowork의 새 기준"으로 주목받고 있으며, 미국 정부의 중국 오픈소스 AI 모델 제재 논의도 뜨거운 화제다.
