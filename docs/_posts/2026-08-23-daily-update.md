The AI coding tool market faces five major deadlines inside a week and a half, while a quiet acquisition reshapes the enterprise landscape. Starting tomorrow (Aug 24) when Cursor Auto drops its flat rate for per-model pricing, the countdown runs through o3's ChatGPT exit (Aug 26, D-3), DALL-E GPT retirement (Aug 30, D-7), GPT-5.4's Codex removal (Aug 31, D-8), and Copilot's six-model mass deprecation (Sep 1, D-9).

## Tabnine: Acquired by Tricentis, End of an Independent Era

Tricentis acquired Tabnine to integrate its Enterprise Context Engine into the Tricentis testing platform ([Software Testing Magazine](https://www.softwaretestingmagazine.com/news/tricentis-has-acquired-tabnine-ai-coding-platform/)). Once the go-to option for air-gapped enterprise code assistance, Tabnine is no longer an independent product. The acquisition leaves a gap in the enterprise code assistant market that competitors like Amazon Q and Amp will compete to fill. Existing customers should watch for product roadmap changes.

## Cursor: Auto Per-Model Pricing D-1

Cursor is replacing Auto mode's flat rate with per-model pricing starting August 24 ([explainx.ai](https://www.explainx.ai/blog/cursor-auto-per-model-pricing-usage-limits-august-2026)). Included usage goes up across all models, but routing to a frontier model will now cost roughly what picking it directly would. As Kilo AI's analysis puts it, *"all roads lead to metered pricing"* — the entire AI coding tool market is converging on usage-based billing ([blog.kilo.ai](https://blog.kilo.ai/p/all-roads-lead-to-metered-pricing)).

## Anthropic: Mythos 5 Deployed for Enterprise Security

Anthropic expanded Claude Mythos 5 into Claude Security for Enterprise customers, enabling vulnerability scans powered by the restricted cybersecurity-focused model ([Anthropic Blog](https://claude.com/blog/bringing-claude-mythos-5-to-more-defenders)). A $35M open-source defense fund and expanded Cyber Verification Program accompany the launch ([MarkTechPost](https://www.marktechpost.com/2026/08/21/anthropic-brings-claude-mythos-5-to-claude-security/)). Claude Code updated to v2.1.241.

## Antigravity: IDE Extensions Break the Desktop Barrier

Google expanded Antigravity into VS Code, JetBrains (2026.2.1+), Zed, and Visual Studio (preview) ([The New Stack](https://thenewstack.io/google-antigravity-ide-extensions/)). Developers can now open agent conversations in a side panel, review inline diffs, and inspect plans without leaving their IDE ([antigravity.google](https://antigravity.google/blog/antigravity-ide-extensions)).

## OpenAI: Cascading Retirements + Sol Price Cut

o3 exits ChatGPT on August 26 ([andrew.ooo](https://andrew.ooo/answers/o3-retired-august-26-2026-what-to-use-instead/)). DALL-E GPT retires August 30, replaced by ChatGPT Images ([Tom's Guide](https://www.tomsguide.com/ai/chatgpt/you-have-until-august-30-to-save-your-chatgpt-dall-e-images-heres-how-to-avoid-losing-them-forever)). GPT-5.6 Sol API prices were slashed: input $5→$4 (20%), output $30→$20 (33%), promo through November 21 ([Business Standard](https://www.business-standard.com/technology/tech-news/openai-cuts-developer-pricing-for-gpt-5-6-sol-model-by-more-than-20-126082200107_1.html)).

## Copilot: Mass Deprecation D-9

Six models — including Claude Opus 4.5/4.6, Claude Sonnet 4.5/4.6, Gemini 3.1 Pro, and Raptor mini — will be removed from all Copilot experiences on September 1 ([GitHub Roadmap](https://github.com/github/roadmap/issues/1308)). The 103-consecutive-week popularity decline continues as model cleanup accelerates.
