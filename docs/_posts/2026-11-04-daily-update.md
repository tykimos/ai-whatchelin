If Goldman Sachs and ByteDance's access restrictions were the security turning point, Revolut's self-hosting pivot is the cost turning point. Enterprises are moving AI coding tools from simple subscriptions to managed infrastructure.

## Revolut: Self-Hosted GLM Cuts AI Coding Costs 90%

Revolut transitioned roughly 2,000 engineers from metered APIs like Claude Code to a self-hosted deployment of Z.ai's GLM-5.3, cutting AI coding inference costs by approximately 90% ([StartupHub.ai](https://www.startuphub.ai/ai-news/artificial-intelligence/2026/revolut-says-self-hosted-ai-cut-coding-costs-90)). The setup runs on 56 Nvidia B200 GPUs. Since self-hosting in April, Revolut reports 60% improvement in coding time and 70% in lead time. These figures were shared at an AI Engineer conference talk — Revolut has not yet published an official account.

## GitHub Copilot: Hits 77, 40-Day Streak — Model Swap D-12

GitHub Copilot extended its recovery to 40 consecutive days at a score of 77. On November 16, Claude Opus 4.8, Claude Opus 5, and GPT-5.6 Terra will be removed and replaced with Claude Opus 5.5 and GPT-6.1 Sol ([GitHub Blog](https://github.blog/changelog/2026-10-15-upcoming-deprecation-of-selected-github-copilot-models-in-mid-november)). Annual individual subscribers get an exception for Claude Opus 4.8 only. The full transition to AI credit-based billing arrives December 1 ([GitHub Blog](https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/)).

## Cursor: OpenAI Cutoff D-8, Day 71 at Bottom

Just 8 days remain until Cursor's access to OpenAI models is fully terminated on November 12 ([Bloomberg](https://www.bloomberg.com/news/articles/2026-08-29/openai-to-end-partnership-with-cursor-after-spacex-acquisition)). Notably, Goldman Sachs' AI tool restriction didn't even mention Cursor — its enterprise presence has effectively vanished.

## Enterprise AI Tool Operating Paradigm Is Shifting

Goldman Sachs restricting access (security), ByteDance blocking external tools (IP protection), Revolut self-hosting (cost) — enterprises are moving from "subscribing to" AI coding tools to "operating" them directly. MUFG built an in-house alternative to Claude Code, while Deutsche Bank provides coding assistants to 15,000 developers but holds them personally accountable for committed code ([PYMNTS](https://www.pymnts.com/news/artificial-intelligence/2026/goldman-benches-its-vibe-coders-while-bny-lets-everyone-build/)).
