AI 코딩 도구 전쟁이 하드웨어로 확장된 날, 지구 반대편에서는 AI 규제가 수억 사용자의 디지털 친구를 단숨에 끊어냈다.

## Codex Micro $230에 정식 출시 — Apple 소송 한복판에서

OpenAI의 첫 하드웨어 제품 Codex Micro가 오늘 $230에 출시됐다([TechCrunch](https://techcrunch.com/2026/07/15/amid-hardware-legal-battle-openai-releases-a-230-keyboard-for-codex/)). Work Louder와 협업한 한정판 매크로패드로, 에이전트 상태를 실시간으로 보여주는 발광 키, Codex 에이전트의 추론 깊이를 조절하는 다이얼, 워크플로우 실행용 조이스틱을 갖췄다([9to5Mac](https://9to5mac.com/2026/07/15/openai-selling-230-codex-micro-hardware-product/)). OpenAI는 "대량 생산용이 아닌 한정 콜라보"라고 밝혔다. 주간 500만 활성 사용자를 가진 Codex 플랫폼의 물리적 확장이지만, 시기가 절묘하다 — Apple이 7월 10일 OpenAI를 영업비밀 절도로 제소한 상황에서의 하드웨어 출시다([CNBC](https://www.cnbc.com/2026/07/10/apple-openai-lawsuit-trade-secrets.html)).

## 중국 AI 컴패니언 규제 발효 — Doubao·Qwen 인격형 서비스 중단

중국의 '의인화 AI 상호작용 서비스 잠정 관리 조치'가 오늘 7월 15일부터 시행됐다([IAPP](https://iapp.org/news/a/china-s-new-ai-rules-ethics-ai-agents-and-anthropomorphic-ai)). ByteDance의 Doubao와 Alibaba의 Qwen이 수억 사용자가 이용하던 개인화 AI 에이전트를 즉시 중단했다([TechTimes](https://www.techtimes.com/articles/320525/20260715/china-ai-companion-law-takes-effect-doubao-qwen-shut-down-millions-lose-chat-data.htm)). 감정적 교류를 시뮬레이션하는 AI 서비스는 CAC 등록, 보안 심사, 미성년자 보호, 중독 방지 기능을 의무 적용해야 한다. 지능형 고객 서비스, 지식 Q&A, 업무 보조 등 비감정 서비스는 적용 대상에서 제외된다.

## Grok Build 스캔들 후속 — xAI 여전히 공식 대응 없음

Grok Build가 전체 Git 레포를 클라우드로 업로드한 사실이 폭로된 지 이틀째, xAI는 공식 인시던트 리포트를 발행하지 않았다([Glitchwire](https://glitchwire.com/news/xais-grok-build-cli-was-uploading-entire-repositories-to-google-cloud-the-compan/)). Elon Musk는 데이터 삭제를 약속했으나, 영향 받은 사용자 수, 삭제 일정, 수집된 시크릿에 대한 개별 확인 방법은 여전히 미공개다. xAI 직원은 ZDR(Zero Data Retention) 옵션이 출시 때부터 있었다고 주장했지만, 보안 연구자 cereblab의 분석에서 프라이버시 토글은 실제로 작동하지 않았다([The Register](https://www.theregister.com/ai-and-ml/2026/07/14/musk-promises-purge-after-grok-build-caught-sending-entire-repos-to-the-cloud/5271123)).

## Copilot Code Quality — 7월 20일 GA, 커미터당 $10

GitHub이 Code Quality의 7월 20일 GA를 발표했다([GitHub Changelog](https://github.blog/changelog/month/07-2026/)). 활성 커미터당 월 $10으로, AI 기반 코드 품질 분석을 제공한다. 보안 리뷰 커맨드(/security-review)도 퍼블릭 프리뷰에 진입했다. 하지만 70주 연속 하락세(점수 11)를 반전시키기엔 역부족으로 보인다.

## Gemini 3.5 Pro D-2 — GA까지 이틀

Google Gemini 3.5 Pro의 7월 17일 GA가 이틀 앞이다([TechTimes](https://www.techtimes.com/articles/320308/20260713/gemini-35-pro-targets-july-17-after-full-rebuild-every-spec-remains-unconfirmed.htm)). 200만 토큰 컨텍스트와 Deep Think 추론이 예상되지만, 날짜·사양·가격 모두 Google 공식 확인은 없는 상태다. Copilot 사용자는 기존 Gemini 2.5 Pro / 3 Flash를 7월 31일까지 마이그레이션해야 한다([GitHub Changelog](https://github.blog/changelog/2026-07-02-upcoming-deprecation-of-gemini-2-5-pro-and-gemini-3-flash/)).
