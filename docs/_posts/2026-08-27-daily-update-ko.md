Nvidia가 AI 모델 허브 Hugging Face를 $129억에 인수하기로 합의했다고 CNBC가 보도했다([CNBC](https://www.cnbc.com/2026/08/27/nvidia-hugging-face-acquisition.html)). 칩 제조에서 소프트웨어 생태계까지 — Nvidia의 수직통합 전략이 본격화되며, AI 코딩 도구 생태계 전체에 파장을 예고한다.

## Nvidia × Hugging Face: 'AI의 GitHub' 인수

Nvidia가 Hugging Face를 $129억에 인수하기로 합의했다([TechCrunch](https://techcrunch.com/2026/08/26/nvidia-closes-in-on-hugging-face-acquisition/)). Hugging Face는 연간 $1.5억 매출의 오픈소스 모델 허브로, 개발자들이 AI 모델을 빌드·배포·공유하는 사실상의 표준 플랫폼이다. 인수가 완료되면 Nvidia는 칩 → 학습 인프라 → 모델 배포까지 전 과정을 지배하게 된다. 오픈소스 커뮤니티는 독립성 훼손을 우려하고 있으며, 정식 계약은 아직 체결 전이라 무산 가능성도 남아 있다([Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/nvidia-reportedly-acquiring-hugging-face-111038884.html)).

## Copilot: 9/1 대폐기 D-5 — 마이그레이션 마감 초읽기

GitHub Copilot의 9월 1일 모델 대폐기까지 5일 남았다([GitHub Changelog](https://github.blog/changelog/2026-07-31-upcoming-august-2026-model-deprecations-in-github-copilot/)). Gemini 3.1 Pro, Claude Opus 4.5/4.6, Claude Sonnet 4.5/4.6, Raptor mini가 전 Copilot 경험에서 제거된다. 9월 10일에는 MAI-Code-1-Flash도 추가 폐기 예정이다([GitHub Changelog](https://github.blog/changelog/2026-08-11-upcoming-deprecation-of-mai-code-1-flash/)). Enterprise 관리자는 대체 모델 정책을 지금 설정해야 한다.

## OpenAI: DALL-E GPT 은퇴 D-3, GPT-5.4 퇴출 D-4

이번 주 연쇄 은퇴가 계속된다. DALL-E GPT가 8월 30일 은퇴하고([OpenAI Help Center](https://help.openai.com/en/articles/9624314-model-release-notes)), GPT-5.4/mini는 8월 31일 Codex에서 퇴출된다. 어제 o3가 ChatGPT에서 공식 제거된 데 이어, 일주일 안에 총 4건의 모델이 사라지는 역대급 교체 주간이다.

## Anthropic: S-1 공개 제출 임박, 시장점유율 역전

Anthropic의 공개 S-1 서류 제출이 이번 주 내로 예상된다([Forge](https://forgeglobal.com/anthropic_ipo/)). Q2 2026 기업 LLM API 시장에서 Anthropic이 32%로 OpenAI의 25%를 처음 추월했다([CNBC](https://www.cnbc.com/2026/06/01/anthropic-ipo-s1-prospectus.html)). 10월 나스닥 상장 시 $2조 이상 밸류에이션이 기대되며, IPO 공시에 'AI 반발(AI backlash)'을 리스크 요인으로 명시할 예정이다.

## Cursor: Origin 데이터 약관 논란 지속

SpaceX 인수 후 첫 대형 제품인 Origin이 데이터 이용 약관 없이 출시되어 논란이 이어지고 있다([TechCrunch](https://techcrunch.com/2026/08/18/cursor-capitalizes-on-github-frustration-launches-rival-hosting-platform/)). 유료 개발자들의 코드를 SpaceX가 보유하게 된다는 점에서 프라이버시 우려가 확산 중이다. 한편 Origin은 GitHub 장애와 맞물려 빠르게 주목받고 있으며, Nokia가 20,000+명 엔지니어를 Cursor에 배치한 것이 역대 최대 규모 기업 도입으로 확인됐다.
