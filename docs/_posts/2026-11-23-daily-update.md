GitHub Copilot executed a sweeping model rotation this week. Claude Opus 4.8, Claude Opus 5, and GPT-5.6 Terra were removed from every Copilot surface on November 16([GitHub Blog](https://github.blog/changelog/2026-11-16-github-copilot-models-deprecated-on-november-16-2026)), replaced by Gemini 4 Carbon and MAI Code 2. For developers, the available model lineup has been completely refreshed in a single week.

## GitHub Copilot: Generational Shift Complete

As announced on October 15, Claude Opus 4.8, Opus 5, and GPT-5.6 Terra have been pulled from chat, inline edits, agent mode, and code completions([GitHub Blog](https://github.blog/changelog/2026-10-15-upcoming-deprecation-of-selected-github-copilot-models-in-mid-november)). GitHub recommends Claude Opus 5.5 and GPT-6.1 Sol as replacements; only individual annual plan subscribers retain Opus 4.8 access([SmartScope](https://smartscope.blog/en/blog/github-copilot-claude-opus-5-deprecation-november-16-2026/)). Meanwhile, the November 9 weekly release opened Gemini 4 Carbon to Copilot Pro+, Max, Business, and Enterprise users([GitHub Blog](https://github.blog/changelog/2026-11-16-github-copilot-weekly-releases-november-9)), and MAI Code 2 was enabled by default at Ignite([VPS Ranking](https://vpsranking.com/news/ai/ai-2026-11-17-github-copilot-ignite-updates/)).

## OpenAI: GPT-6.2 Astra Clears 'High' Self-Improvement Threshold

GPT-6.2 Astra and Sol launched on November 17([OpenAI](https://openai.com/index/introducing-gpt-6-2-astra-sol)). Astra is the first externally deployed model to meet OpenAI's "High" threshold for AI Self-Improvement([Pulse2](https://pulse2.com/openai-introduces-gpt-6-2-astra-and-sol-with-improved-performance-and-lower-task-costs/)). API pricing is $8/$40 per million tokens for Astra and $2/$10 for Sol — a 20% cut versus GPT-6 Astra([How2Shout](https://www.how2shout.com/?p=89215)). Sol has become the default model for many OpenAI employees across technical and non-technical work([Digital Trends](https://www.digitaltrends.com/computing/openai-gpt-6-2-astra-sol-launch/)).

## ANT: Day 5, Settling Near $99

Anthropic (ANT) has stabilized around $99 after opening at $111.50 on its IPO debut([Upstox](https://upstox.com/us-stocks/anthropic-pbc-class-a-share-price/), [TechRepublic](https://www.techrepublic.com/article/news-anthropic-ipo-nasdaq-trading-debut/)). The record $107.3B IPO total stands, with Amazon and Google holding approximately 28.4%([Stocktwits](https://stocktwits.com/news-articles/markets/equity/anthropic-stock-jumps-38-in-nasdaq-debut-after-record-107-3-b-ipo/cNbihePR900)).

## Cursor: OpenAI Blackout Day 12

OpenAI cut off model access to Cursor (SpaceXAI subsidiary) on November 12, and the blackout continues into day 12([ClickUp](https://clickup.com/learn/topic/ai/tools/cursor/news/)). Cursor 3 runs on its in-house Composer 2.5 and xAI models, but it has sat at the bottom of the popularity rankings for 92 consecutive days with no sign of recovery.
