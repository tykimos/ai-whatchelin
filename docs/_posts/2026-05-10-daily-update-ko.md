AI 코딩 도구 전쟁이 '에디터 전쟁'에서 '생태계 전쟁'으로 전환되고 있다. Codex CLI가 플러그인 공유 시스템을 도입하며 OpenAI의 에이전트 생태계 구축 의지를 드러냈고, Copilot은 사용량 기반 과금 D-21을 앞두고 8주째 하락 중이다. 한편 Google I/O 2026이 9일 앞으로 다가오며 Gemini 4.0 기대감이 커지고 있다.

## Codex CLI: 플러그인 공유 + Remote-Control로 생태계 확장

Codex CLI가 5월 9일 업데이트로 플러그인 공유 기능과 새로운 `codex remote-control` 진입점을 추가했다([GitHub](https://github.com/openai/codex/releases)). 스레드 페이지네이션(미로드/요약/전체 뷰)도 도입되어 대규모 세션 관리가 용이해졌다. Bedrock 인증에 AWS 로그인 자격증명을 직접 사용할 수 있게 되면서 엔터프라이즈 접근성도 개선됐다. 인기 점수 78에서 79로 상승, 3주 연속 상승세를 이어가고 있다.

## GitHub Copilot: D-21, 8주 연속 하락

사용량 기반 과금 전환까지 21일이다([GitHub Blog](https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/)). Pro/Pro+ 신규 가입 중단이 계속되는 가운데, 개발자 커뮤니티에서는 "같은 가격에 더 적게 받는다"는 불만이 확산 중이다([Visual Studio Magazine](https://visualstudiomagazine.com/articles/2026/04/27/devs-sound-off-on-usage-based-copilot-pricing-change-you-will-get-less-but-pay-the-same-price.aspx)). 인기 점수 77에서 76으로 하락, 8주 연속 하락이라는 기록을 세웠다. Claude Code(98)와의 격차가 22포인트로 벌어졌다.

## Gemini CLI: I/O 2026 D-9, Gemini 4.0 기대감

Google I/O 2026이 5월 19일로 9일 앞이다([Yahoo Tech](https://tech.yahoo.com/general/article/what-to-expect-at-google-io-2026-android-17-ai-announcements-and-more-131200028.html)). Gemini UI에서 "Omni" 비디오 모델이 포착됐고, Gemini 4.0 발표가 유력시된다. v0.41.2의 음성 모드와 오프라인 지원이 안착하면서 인기 점수는 71에서 72로 상승, I/O를 앞두고 모멘텀을 쌓아가고 있다.

## Snyk-Claude 보안 파트너십 + Coder Agents 베타

Snyk가 Claude 모델을 AI 보안 플랫폼에 통합했다([SD Times](https://sdtimes.com/ai/may-8-2026-ai-updates-from-the-past-week-coder-agents-launch-snyk-claude-partnership-opsera-cursor-partnership-and-more/)). 바이브코딩 보안 스캔들 이후 보안 도구-AI 모델 통합이 가속화되는 신호다. 한편 Coder가 자체 호스팅형, AI 모델 비종속 코딩 에이전트를 베타 출시했다([GlobeNewsWire](https://www.globenewswire.com/news-release/2026/05/06/3288916/0/en/coder-sets-a-new-standard-for-ai-coding-with-self-hosted-ai-model-agnostic-coder-agents.html)). 소스 코드를 외부로 보내지 않는 방식으로, 기업 70%가 에이전트를 부적합한 인프라에서 운영한다는 문제를 해결하려 한다.
