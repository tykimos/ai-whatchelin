Meta entered the AI coding tool arena with Muse Code, its first terminal coding agent. On the same day, Google DeepMind lost both its CEO and its chief scientist, signaling a generational talent shift across the AI industry.

## Meta: Muse Code Public Beta — Enters Terminal Coding Agent Market

Meta launched Muse Code, its first terminal coding agent, in public beta for macOS and Linux([CNBC](https://www.cnbc.com/2026/08/05/meta-debuts-muse-code-to-take-on-anthropic-and-openai-.html)). Powered by the in-house Muse Spark 1.2 model, pricing is set at $1.25/M input and $4.25/M output tokens, with a contributor tier at 10x cheaper([9to5Mac](https://9to5mac.com/2026/08/05/meta-launches-muse-code-ai-coding-agent-for-macos-and-linux/)). The standout feature is persistent background sub-agents working in parallel within isolated worktrees([Meta AI Research](https://research.meta.ai/blog/introducing-muse-code-and-muse-spark-1-2)). This makes Muse Code the fourth major terminal coding agent alongside Claude Code, Codex CLI, and Antigravity CLI.

## Google: Hassabis Steps Down, Jeff Dean Departs — Leadership Earthquake

Demis Hassabis stepped down as Google DeepMind CEO, moving to Chair of Google DeepMind and Chief Scientist of Alphabet([Bloomberg](https://www.bloomberg.com/news/articles/2026-08-05/google-deepmind-boss-hassabis-moves-to-chair-role-in-shakeup)). Former CTO Koray Kavukcuoglu takes over day-to-day operations as SVP, while Google stock fell roughly 4% on the news([Axios](https://www.axios.com/2026/08/05/google-deepmind-demis-hassabis-ai)). On the same day, Jeff Dean, Sanjay Ghemawat, Oriol Vinyals, and Quoc Le left Google to co-found Discovery Loop, an AI-for-science startup([Quartz](https://qz.com/jeff-dean-google-chief-scientist-discovery-loop-startup-080526)). The seed round is co-led by Radical Ventures and Khosla Ventures, with Google as a founding investor([TechTimes](https://www.techtimes.com/articles/323197/20260805/jeff-dean-sanjay-ghemawat-depart-google-co-found-discovery-loop.htm)).

## Microsoft: "Tokenmaxxing Is Not What We're Optimizing For" — AI Budget Caps Hit Engineers

Microsoft EVP Jay Parikh emailed all engineers introducing division-level "AI token budget targets," declaring that "tokenmaxxing is not what we are optimizing for"([404 Media](https://www.404media.co/microsoft-tells-engineers-tokenmaxxing-is-not-what-we-are-optimizing-for/)). GPT-5.6 is now the mandated default internal model, with some engineers reportedly spending hundreds to thousands of dollars monthly on tokens([TechRadar](https://www.techradar.com/pro/tokenmaxxing-is-not-what-we-are-optimizing-for-microsoft-tells-engineer-to-calm-down-on-ai-usage)). AT&T, Meta, Uber, Walmart, and Amazon have all introduced similar AI spend caps.

## Anthropic: Claude Opus 4.1 Permanently Retired

Claude Opus 4.1 (`claude-opus-4-1-20250805`) was permanently retired from the API today([Anthropic Docs](https://platform.claude.com/docs/en/about-claude/model-deprecations)). Migration to Opus 4.8 or Opus 5 is now mandatory([TheRouter.ai](https://therouter.ai/news/anthropic-deprecates-claude-opus-4-1-august-5-migration-guide/)). Sonnet 5 promotional pricing ($2/$10/MTok) ends August 31([FinOps LLM](https://finopsllm.com/research/sonnet-5-intro-pricing-deadline)).

## Codex CLI: Hits 99 — Top Five All Converge at All-Time High

The GPT-5.6 Luna 80% price cut continues to ripple on day nine, with Codex CLI reaching 99 to tie Claude Code and Antigravity at the all-time high([VentureBeat](https://venturebeat.com/technology/ai-price-wars-openai-cuts-gpt-5-6-luna-prices-by-80-as-model-competition-shifts-toward-cost)). All top five tools (Claude Code, ChatGPT, Antigravity, Claude AI, Codex CLI) have now converged at 99.

## Industry: Cloudflare OS Goes Open Source + Rust Publishes LLM Policy

Cloudflare open-sourced Cloudflare OS, an AI agentic workspace platform, under Apache 2.0([Cloudflare Blog](https://blog.cloudflare.com/cloudflare-os/)). It includes browser sessions, isolated runtime, and stablecoin wallets for AI agent payments([SiliconANGLE](https://siliconangle.com/2026/08/05/cloudflare-launches-cloudflare-os-open-source-ai-agentic-workspace-enterprise/)). The Rust project published an official LLM policy allowing LLMs to "answer questions, analyze, and review" but not to "create" code([Rust Blog](https://blog.rust-lang.org/inside-rust/2026/08/05/rust-langrust-is-adopting-an-llm-policy/)).
