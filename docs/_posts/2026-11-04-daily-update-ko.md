Goldman Sachs와 ByteDance의 AI 도구 접근 제한이 보안 측면의 전환점이었다면, Revolut의 자체 호스팅 전환은 비용 측면의 전환점이다. 기업들이 AI 코딩 도구를 단순 구독에서 인프라 관리로 재편하고 있다.

## Revolut: 자체 호스팅 GLM으로 AI 코딩 비용 90% 절감

Revolut이 약 2,000명의 엔지니어를 Claude Code 등 메터드 API에서 Z.ai의 GLM-5.3 자체 호스팅으로 전환해 AI 코딩 추론 비용을 약 90% 절감했다([StartupHub.ai](https://www.startuphub.ai/ai-news/artificial-intelligence/2026/revolut-says-self-hosted-ai-cut-coding-costs-90)). Nvidia B200 56대 위에서 운영되며, 4월 자체 호스팅 이후 코딩 시간 60%, 리드 타임 70% 개선을 보고했다. AI Engineer 컨퍼런스에서 공개된 수치로, Revolut 자체 공식 발표는 아직 없다.

## Anthropic IPO: 로드쇼 D-6, 추수감사절 전 상장 유력

Anthropic이 10월 26일 SEC에 S-1을 공식 제출한 후([CryptoBriefing](https://cryptobriefing.com/anthropic-nasdaq-ipo-listing-2026/)), 이르면 11월 10일 투자자 로드쇼가 시작될 수 있다([Leverage Shares](https://leverageshares.com/us/insights/when-is-the-anthropic-ipo/)). 티커 ANT, Nasdaq Global Select Market 상장. 추수감사절(11/27) 전 상장이 가장 유력한 시나리오로, 가격 범위가 담긴 수정 S-1이 아직 공개되지 않아 정확한 일정은 미정이다([Parameter](https://parameter.io/claude-creator-prepares-100-billion-public-offering-ahead-of-thanksgiving/)).

## GitHub Copilot: 77점, 40일 연속 상승 — 모델 교체 D-12

GitHub Copilot이 40일 연속 상승하며 77점을 기록했다. 11월 16일 Claude Opus 4.8, Claude Opus 5, GPT-5.6 Terra가 제거되고 Claude Opus 5.5와 GPT-6.1 Sol로 교체된다([GitHub Blog](https://github.blog/changelog/2026-10-15-upcoming-deprecation-of-selected-github-copilot-models-in-mid-november)). 연간 구독 개인 사용자는 Claude Opus 4.8만 예외적으로 유지된다. 12월 1일 AI 크레딧 기반 과금 전면 전환도 예정되어 있다([GitHub Blog](https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/)).

## Cursor: OpenAI 모델 차단 D-8, 71일째 바닥

11월 12일 OpenAI 모델 접근 완전 차단까지 8일 남았다([Bloomberg](https://www.bloomberg.com/news/articles/2026-08-29/openai-to-end-partnership-with-cursor-after-spacex-acquisition)). 공급망 공격 후속 조치와 맞물려 71일 연속 1점을 기록 중이다. Goldman Sachs의 AI 도구 제한 조치에서도 Cursor는 이미 제외 대상에서 빠져 있어, 엔터프라이즈 시장에서의 존재감이 사실상 소멸했다.

## 기업 AI 도구 운영 패러다임 변화

Goldman Sachs의 접근 제한(보안), ByteDance의 외부 도구 차단(기밀 보호), Revolut의 자체 호스팅(비용)까지 — 기업들이 AI 코딩 도구를 "구독하는 것"에서 "직접 운영하는 것"으로 이동하고 있다. MUFG는 Claude Code 대안을 자체 개발했고, Deutsche Bank은 1만 5천 명에게 코딩 어시스턴트를 제공하되 코드 책임은 개발자에게 귀속시킨다([PYMNTS](https://www.pymnts.com/news/artificial-intelligence/2026/goldman-benches-its-vibe-coders-while-bny-lets-everyone-build/)).
