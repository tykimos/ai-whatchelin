OpenAI switched GPT-5.6 Luna to the default model for all free users and removed text chat limits entirely. On the same day, Claude Code played its enterprise self-hosting card, and Cursor pushed model routing costs down by 68%. The AI coding tool market is shifting from price competition to infrastructure competition.

## ChatGPT: GPT-5.6 Luna/Sol Become Default Across All Tiers

OpenAI rolled out GPT-5.6 Luna as the default model for Free and Go users on August 6, removing all text chat limits for free users([9to5Mac](https://9to5mac.com/2026/08/06/openai-updating-chatgpt-with-a-smarter-gpt-5-6-sol-and-unlimited-free-chats/)). Previously limited free-tier text chats are now fully unlimited, with a new "Think" button for deeper reasoning. Plus and Pro users get GPT-5.6 Sol as their default, featuring adaptive detail and a thinking depth slider. OpenAI reports a 68% reduction in factual errors compared to GPT-5.5([The AI Insider](https://theaiinsider.tech/2026/08/07/openai-expands-chatgpt-access-with-new-models-details-emerge-on-upcoming-hardware-device/)).

## Claude Code: v2.1.224 — Self-Hosted Runners Target Enterprise

Anthropic shipped `claude self-hosted-runner` in Claude Code v2.1.224 for Team and Enterprise plans([code.claude.com](https://code.claude.com/docs/en/changelog)). Code and tool execution can now stay entirely within an organization's network. The release adds SHA-256-verified plugin installation, cross-session messaging via SendMessage/ListAgents, JWT-aware credential masking with AWS SigV4 re-signing, and removes the 200-subagent session cap. Yesterday's v2.1.223 patched a bash permission bypass([releasebot.io](https://releasebot.io/updates/anthropic/claude-code)). Meanwhile, Claude experienced widespread outages on August 6 across Mythos 5, Fable 5, Opus 5, and Sonnet 5, with service restored by August 7([StatusGator](https://statusgator.com/services/claude/claudeai)).

## Cursor: Router Auto Intelligence — Fable-Level Quality at 68% Lower Cost

Cursor Router unveiled Auto Intelligence and Auto Balance modes([cursor.com](https://cursor.com/changelog)). Auto Intelligence delivers above-Fable-level satisfaction at 68% lower cost — an 18% further reduction since launch. Auto Balance outperforms Opus 4.8 at 41% lower cost. Opus 5 has been integrated into the routing system. Cursor has reportedly crossed $3 billion ARR.

## GitHub Copilot: Kimi K3 Goes GA — Open-Weight Models Enter Enterprise

Moonshot AI's open-weight model Kimi K3 is now generally available across all GitHub Copilot plans([GitHub Blog](https://github.blog/changelog/2026-08-06-kimi-k3-is-now-available-in-github-copilot/)). Hosted on Fireworks AI at $3/$15 per million tokens, K3 delivers frontier-level agentic coding performance. Business and Enterprise admins must manually enable the Kimi K3 policy.

## DeepSeek Price Hike Fallout + Atlas D-2 Countdown

DeepSeek's "significant" price increase warning is on day three of community shockwaves([The Next Web](https://thenextweb.com/news/deepseek-significant-api-price-increase)). Startups dependent on V4 Flash pricing are accelerating evaluation of alternatives([SCMP](https://www.scmp.com/tech/tech-trends/article/3363129/deepseek-signals-significant-price-hike-amid-surge-demand-low-cost-ai-models)). OpenAI's Atlas browser shuts down August 9, with Codex Goal mode now GA across app, IDE, and CLI([OpenAI](https://openai.com/products/release-notes/)). DALL-E GPT retires August 30, replaced by ChatGPT Images.
