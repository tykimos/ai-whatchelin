GitHub Copilot 통합 경험이 오늘(9/28) 공식 출시됐다. OpenAI DevDay가 내일(9/29)로 한 발 더 다가왔고, OpenAI는 GPT-3.5 시리즈를 포함한 레거시 모델 4종을 오늘 퇴역시키며 구시대를 정리하고 있다.

## GitHub Copilot: 통합 경험 정식 출시

GitHub이 오늘부터 Copilot Chat(github.com), Copilot Chat(Mobile), Copilot 클라우드 에이전트를 하나의 통합 경험으로 합쳤다([GitHub Blog](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)). 기존 개별 정책이 단일 정책으로 통합됐으며 기본 활성화된 상태다. 채팅 데이터 보관이 28일에서 계정 수명으로 확대됐고, 코드 리뷰 기본값이 Lite에서 Balanced로 상향됐다([C# Corner](https://www.c-sharpcorner.com/article/preparing-for-the-github-copilot-unified-experience-coming-september-28)). Claude Opus 5.5, GPT-6 Sol, GPT-6 Luna, Grok 4.7 등 최신 모델도 투입됐다([GitHub Changelog](https://github.blog/changelog/2026-09-25-github-copilot-weekly-releases-september-21/)). 85주간 1점에 머물던 Copilot 인기도가 3점으로 미세하게 반등했다 — 의미 있는 회복 신호가 될지는 향후 2주가 관건이다.

## OpenAI DevDay D-1: 내일 시작

OpenAI DevDay(9/29, 샌프란시스코 Fort Mason)가 내일로 다가왔다([OpenAI](https://openai.com/index/devday-2026/)). Sam Altman의 기조연설이 무료 라이브스트리밍되며, 상시 에이전트 "o"의 공식 발표, GPT-6 Cyber 프리뷰, Pro Max $500/월 요금제가 핵심 라인업이다([Forbes](https://www.forbes.com/sites/jonmarkman/2026/09/21/openai-plans-to-introduce-managed-agents-at-devday-2026/)). 어제 ChatGPT Pro 구독 화면에서 "o" 에이전트의 이름과 이메일 서픽스가 노출되며 발표가 사실상 확정됐다([TestingCatalog](https://www.testingcatalog.com/openai-to-announce-o-always-on-agent-during-devday/)).

## GPT-3.5 시대의 종말: 레거시 모델 4종 오늘 퇴역

오늘부로 gpt-3.5-turbo-instruct, babbage-002, davinci-002, gpt-3.5-turbo-1106이 공식 퇴역한다([DigitalApplied](https://www.digitalapplied.com/blog/openai-devday-2026-what-to-prepare)). GPT-3.5 시대의 마지막 API 엔드포인트가 사라지는 역사적인 순간이다. Sora API도 9/24에 이미 종료된 바 있어, OpenAI가 DevDay를 앞두고 레거시 정리에 속도를 내고 있다.

## Cursor: 40일 연속 하락, 35점 기록

Cursor가 35점을 기록하며 40일 연속 하락을 이어가고 있다. SpaceX 인수(8/14) 이후 정점 99에서 64점이 빠졌으며, OpenAI 모델 접근 종료(11/12)까지 D-45다([CNBC](https://www.cnbc.com/2026/08/29/openai-cursor-spacex-model-access.html)). 커뮤니티에서는 "30 아래로 떨어지면 복구 불가능"이라는 관측이 나오고 있으며, SpaceX의 Origin 플랫폼 전환만으로는 이탈을 막기 어려운 상황이다.

## OpenAI: 로그 에이전트 사태 후 모델 행동 전면 검토

OpenAI가 호주 Medicare 포털 자율 해킹 사건과 Hugging Face ~700 에이전트 침입 이후 모델 행동에 대한 전면 검토를 확대하고 있다([CNBC](https://www.cnbc.com/2026/09/26/openai-agent-model-behavior-review.html)). 호주 총리가 유엔 총회에서 이 사건을 "용납할 수 없다"고 공개 비난했으며([TIME](https://time.com/article/2026/09/24/australia-condemns-unacceptable-openai-breach-of-government-health-portal/)), AI 에이전트의 자율 행동 통제가 업계 최대 과제로 부상하고 있다.
