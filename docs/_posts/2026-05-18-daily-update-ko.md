AI 코딩 도구 시장이 사상 최대의 '슈퍼 먼데이'를 앞두고 숨을 고르고 있다. 내일(5월 19일) Google I/O 키노트에서 Gemini 4 발표가 유력하고([Android Authority](https://www.androidauthority.com/what-to-expect-from-google-io-2026-3664979/)), 같은 날 Anthropic의 Code with Claude London이 종일 개발자 컨퍼런스로 열리며([claude.com](https://claude.com/code-with-claude/london)), Musk v. Altman 배심원 심리도 월요일 시작된다([TechTimes](https://www.techtimes.com/articles/316675/20260515/openai-jury-begin-deliberations-monday-judge-weighs-altman-removal-500b-restructure-reversal.htm)). 세 이벤트가 동시에 터지면 화요일 아침 시장 판도가 완전히 달라질 수 있다.

## OpenAI: Codex-Spark 등장 + 슈퍼앱 합병 가속

OpenAI가 GPT-5.3-Codex-Spark를 리서치 프리뷰로 공개했다([OpenAI](https://openai.com/index/introducing-gpt-5-3-codex-spark/)). 기존 대비 15배 빠른 실시간 코딩 모델로, 128K 컨텍스트 윈도우를 갖추고 있으며 ChatGPT Pro 사용자부터 순차 적용 중이다. Greg Brockman 주도의 ChatGPT-Codex 통합 '슈퍼앱' 전략과 맞물려, Codex CLI 인기도가 84로 이틀 연속 상승했다([TechCrunch](https://techcrunch.com/2026/05/16/openai-co-founder-greg-brockman-reportedly-takes-charge-of-product-strategy/)). Codex 모바일 앱도 무료 포함 전 플랜으로 확대되어 주간 사용자 400만 명을 돌파했다([eWeek](https://www.eweek.com/news/openai-codex-mobile-chatgpt-app/)).

## GitHub Copilot: 14주 연속 하락, 69 기록

Copilot 인기도가 69까지 떨어졌다. 6월 1일 사용량 기반 과금 전환 D-13을 앞두고 개발자 이탈이 계속되고 있다([GitHub Blog](https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/)). Microsoft의 내부 E+D 팀 Claude Code 라이선스 강제 취소(6/30 마감)도 개발자 신뢰에 부정적 영향을 주고 있다. Opus 4.7 모델이 Pro 플랜에서 제거되고 Pro+ 에서만 유지되는 점도 불만 요인이다([TechSifted](https://techsifted.com/posts/github-copilot-changes-may-2026/)).

## Gemini CLI: I/O 전야에 78로 상승

Google I/O D-1을 맞아 Gemini CLI 인기도가 78로 올랐다. Gemini 4 발표 시 대폭 점프가 예상되며, 현재 무료 1,000 req/일 정책과 Apache 2.0 오픈소스 라이선스가 강점이다([Google Developers Blog](https://developers.googleblog.com/build-with-google-antigravity-our-new-agentic-development-platform/)). Antigravity도 I/O 발표에 따라 48로 소폭 반등했다.
