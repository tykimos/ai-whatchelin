SpaceXAI와 Cursor가 $60B 인수 합의 후 첫 공동 모델 Grok 4.5를 전격 공개했다. '내일'을 기다릴 필요 없이 오늘부터 Grok Build와 Cursor 전 플랜에서 이용 가능하다. 한편 GPT-5.6은 내일 3종 동시 GA를 앞두고 있고, 중국 AI 모델은 미국 기업 토큰 사용량의 46%까지 치고 올라왔다.

## Grok 4.5: SpaceX-Cursor 첫 공동 모델 — Opus급, 가격은 60% 저렴

SpaceXAI와 Cursor가 1.5T 파라미터 V9 파운데이션에 Cursor의 개발자 데이터를 보조 학습시킨 Grok 4.5를 공개했다([Axios](https://www.axios.com/2026/07/08/spacexai-grok-new-model)). 입력 $2/출력 $6(MTok당)으로 Opus 4.8($5/$25) 대비 60% 이상 저렴하면서 "여러 벤치마크에서 Opus 4.8을 능가"한다고 주장한다([The Next Web](https://thenextweb.com/news/spacexai-grok-4-5-cursor-opus-class-coding-model)). Grok Build, Cursor 전 플랜, SpaceXAI 콘솔에서 즉시 사용 가능하며, 내일(7/9) 더 넓은 공개가 예정되어 있다. EU에서는 아직 미제공([AI Weekly](https://aiweekly.co/alerts/spacexai-ships-grok-45-with-cursor-eu-access-delayed)).

## GPT-5.6: 트럼프 행정부 승인 — 내일 Sol/Terra/Luna 3종 GA

트럼프 행정부가 상무부 AI 표준혁신센터(CAISI) 추가 테스트를 거쳐 GPT-5.6 공개를 승인했다([Axios](https://www.axios.com/2026/07/08/openai-gpt-trump-ban-lifted)). Sol($5/$30), Terra($2.50/$15), Luna($1/$6) 3종이 내일 7/9 GA된다([OpenAI](https://community.openai.com/t/introducing-gpt-5-6-series-sol-terra-and-luna/1384931)). Cerebras 파트너십으로 Sol Fast 모드 초당 750토큰도 7월 중 예정이다.

## 중국 AI 모델: 미국 기업 토큰 점유율 46% 돌파

CNBC 보도에 따르면 중국 AI 모델이 OpenRouter를 통한 미국 기업 토큰 사용량에서 30~46%를 차지하고 있다([CNBC](https://www.cnbc.com/2026/07/07/chinese-ai-models-costs-us-openai-anthropic.html)). 1년 전 미국 모델이 70%를 차지하던 것이 30%로 급감했다([The Decoder](https://the-decoder.com/chinese-ai-models-regularly-pass-30-percent-on-openrouter-as-cost-gap-widens/)). 특히 Zhipu AI의 GLM-5.2는 Vercel에서 첫 주 27배 일간 토큰량 증가, 80배 고객 성장을 기록했다([BuildFastWithAI](https://www.buildfastwithai.com/blogs/ai-news-today-july-8-2026)).

## Fable 5: 크레딧 전환 반발 → 7/12까지 구독 연장

오늘부터 Fable 5가 $10/$50/MTok 크레딧 전용으로 전환됐으나 반발이 거세지자 Anthropic이 7/12까지 기존 구독자 대상 연장 조치를 발표했다([Forbes](https://www.forbes.com/sites/sandycarter/2026/07/07/claude-fable-5-extends-by-five-more-days-10-moves-to-make-now/)). 동시에 Anthropic ID 인증(여권·신분증 + 셀카) 정책이 오늘부터 발효됐다([BuildFastWithAI](https://www.buildfastwithai.com/blogs/ai-news-today-july-8-2026)).

## VS Code 1.128: Claude 멀티챗 에이전트 세션

VS Code 1.128이 오늘 출시되며 Claude 에이전트 세션에서 멀티챗이 가능해졌다 — 접근 방식 비교, 기존 턴에서 포크, 병렬 작업을 하나의 세션 안에서 수행한다([Visual Studio Code](https://code.visualstudio.com/updates/v1_128)). Copilot Vision(이미지·PDF 첨부) GA도 포함됐다.

## 트럼프, AI 행정명령 서명 취소

트럼프 대통령이 예정된 AI 행정명령 서명식을 전격 취소했다. "중국 대비 미국의 우위를 약화시킬 수 있다"는 우려를 이유로 들었다([BuildFastWithAI](https://www.buildfastwithai.com/blogs/ai-news-today-july-8-2026)). 8/1 NSA·CISA 프레임워크 마감일만 유효하다.
