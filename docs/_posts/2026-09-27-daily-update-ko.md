AI 코딩 도구 시장이 이번 주말 세 가지 대형 이벤트로 뒤흔들리고 있다. GitHub Copilot 통합 경험이 내일(9/28) 출시되고, OpenAI DevDay가 모레(9/29) 열리며, Cognition은 $48B 밸류에이션으로 AI 코딩 역사상 최대 규모의 라운드를 마감했다.

## OpenAI DevDay D-2: "o" 에이전트와 Pro Max $500 요금제

OpenAI DevDay(9/29, 샌프란시스코 Fort Mason)까지 이틀 남았다([OpenAI](https://openai.com/index/devday-2026/)). Sam Altman의 기조연설이 무료 라이브스트리밍되며, 약 12개의 제품 발표가 예상된다. 상시 에이전트 "o"의 공식 출시, GPT-6 Cyber(사이버보안 특화 모델) 프리뷰, 그리고 Pro Max $500/월 요금제가 핵심 발표로 꼽힌다([Forbes](https://www.forbes.com/sites/jonmarkman/2026/09/21/openai-plans-to-introduce-managed-agents-at-devday-2026/)). GPT-6 Cyber는 2026년 네 번째 보안 모델이 될 전망이다([Crypt0's News](https://www.crypt0snews.com/news/2026-09-25-openai-s-september-29-devday-brings-a-fourth-security-model-.html)).

## GitHub Copilot: 통합 경험 D-1, 내일 출시

GitHub이 9월 28일부터 Copilot Chat(github.com), Copilot Chat(Mobile), Copilot 클라우드 에이전트를 하나의 통합 경험으로 재출시한다([GitHub Blog](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)). 기존 개별 정책은 단일 정책으로 통합되며 기본 활성화된다. 채팅 데이터 보관이 28일에서 계정 수명으로 확대되고, 코드 리뷰 기본값이 Lite에서 Balanced로 상향된다([C# Corner](https://www.c-sharpcorner.com/article/preparing-for-the-github-copilot-unified-experience-coming-september-28)). Claude Opus 5.5, GPT-6 Sol, GPT-6 Luna, Grok 4.7 등 새 모델도 투입됐다([GitHub Changelog](https://github.blog/changelog/2026-09-25-github-copilot-weekly-releases-september-21/)).

## Cognition: $48B 밸류에이션, ARR $1B 돌파

Cognition이 9월 8일 시리즈 E를 마감하며 $48B 밸류에이션에 $2B 이상을 조달했다([TechCrunch](https://techcrunch.com/2026/08/12/ai-coding-startup-cognition-reportedly-already-in-talks-to-raise-at-40b-valuation/)). 9월 25일 기준 연간 매출 $1B 달성으로, 5월 $492M 대비 6개월 만에 두 배 이상 성장했다. SWE-2(차세대 소프트웨어 엔지니어링 모델)가 리서치 프리뷰로 배포 중이며([Devin Docs](https://docs.devin.ai/release-notes/overview)), GPT-6 Astra를 통합해 테스트 자동화 품질도 크게 향상됐다([OpenAI](https://openai.com/index/cognition-devin-testing-with-astra/)).

## Claude Code: /buddy 삭제 논란과 Fable 5.1 독주

Claude Code가 LogRocket AI 개발 도구 랭킹에서 1위를 유지하며 Fable 5.1의 WebDev Arena 최고 점수로 격차를 벌리고 있다([LogRocket](https://blog.logrocket.com/ai-dev-tool-power-rankings/)). 다만 /buddy 기능 삭제에 대한 커뮤니티 반발이 거세다 — Issue #45596에 270개 댓글과 1,184개 업보트가 달리며 역대 가장 뜨거운 이슈 중 하나가 됐다.

## Cursor: 40일째 추락, SpaceX 인수 후유증

Cursor가 37점을 기록하며 39일 연속 하락세를 이어가고 있다. SpaceX 인수(8/14) 이후 99에서 62점이 빠졌으며, OpenAI 모델 접근 종료(11/12)까지 D-46이다([CNBC](https://www.cnbc.com/2026/08/29/openai-cursor-spacex-model-access.html)). 에이전트 하네스 최적화로 토큰 비용 7%를 절감했지만([Cursor Changelog](https://cursor.com/changelog)), 하락 반전 조짐은 보이지 않는다.

## Codex CLI: v0.157.0 안정 릴리스, 대화 포킹 도입

Codex CLI가 v0.157.0 안정 빌드를 9/25 출시했다([GitHub](https://github.com/openai/codex/releases)). GPT-6 Sol/Luna의 Amazon Bedrock 지원, 풀스크린 트랜스크립트 기본 활성화, 자동 백그라운드 서버 시작이 핵심 기능이다. 특히 대화 포킹(f 단축키)으로 다른 앱에서 열린 대화를 그대로 복사해 이어갈 수 있게 됐다. 9/26에는 Windows 안정성 패치(v0.157.1)가 뒤따랐다.
