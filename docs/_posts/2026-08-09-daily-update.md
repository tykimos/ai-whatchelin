OpenAI Atlas permanently shuts down today. It lasted barely 9 months since its October 2025 launch. OpenAI concluded that embedding agentic browsing into existing products (ChatGPT, Codex) was the better bet over asking users to switch to a standalone browser. Bookmarks and browsing history won't auto-migrate — users needed to manually export as HTML before today's deadline([9to5Mac](https://9to5mac.com/2026/08/04/openai-explains-what-will-happen-when-chatgpt-atlas-shuts-down-this-weekend/)).

## OpenAI: Codex CLI v0.147.0 — The Plugin Play Begins

While Atlas closes, OpenAI's real terminal weapon leveled up. Codex CLI v0.147.0 introduces portable agent plugins searchable across local, personal, workspace, and remote catalogs, plus a `--approve-for-me` flag for automated approval workflows([releasebot.io](https://releasebot.io/updates/openai/codex)). MCP 2026-07-28 protocol support with paginated discovery adds another layer of extensibility. Separately, GPT-5.4 and GPT-5.4 mini will be removed from Codex for ChatGPT-authenticated users on August 31 — API key access remains([OpenAI](https://openai.com/products/release-notes/)).

## Cursor: Router Auto Intelligence — What 68% Cost Reduction Means

Cursor Router Auto Intelligence now delivers above-Fable quality at 68% lower cost (a further 18% reduction since launch), while Auto Balance outperforms Opus 4.8 at 41% lower cost([cursor.com](https://cursor.com/blog)). Opus 5 has been integrated into the routing mix. This isn't just a price cut — it's the automation of model selection itself, removing the "which model should I use?" decision from developers entirely.

## Claude Code: v2.1.226 — Stability Sprint

Anthropic shipped Claude Code v2.1.226 with bug fixes and stability improvements([havoptic.com](https://www.havoptic.com/tools/claude-code)). Following v2.1.225's gateway spend-limit support and workspace trust prompts, this release focused on hardening. Three consecutive daily releases (v2.1.224-225-226) show a notably fast cadence.

## DeepSeek: Price Hike Countdown Day 5

DeepSeek's "significant" price increase warning is now on day five of market reverberations([Bloomberg](https://www.bloomberg.com/news/articles/2026-08-06/deepseek-plans-significant-price-increase-for-its-ai-services)). Founder Jun Song indicated a 2-10x increase while noting DeepSeek would "still undercut most Western rivals." The exact percentage, affected tiers, and effective date remain undisclosed([explainx.ai](https://www.explainx.ai/blog/deepseek-api-price-increase-jun-song-august-2026)). V4 Flash processing 8 trillion tokens in a single day on August 1 — overwhelming compute capacity — is the driving force.

## GitHub Copilot: Kimi K3 GA, September Deprecation D-23

Moonshot AI's open-weight Kimi K3 model is now generally available in Copilot at $3/$15 per MTok for frontier agentic coding([github.blog](https://github.blog/changelog/2026-08-06-kimi-k3-is-now-available-in-github-copilot/)). But the September 1 mass model deprecation is now 23 days away — Claude Sonnet 4.6 will only remain for annual individual subscribers.
