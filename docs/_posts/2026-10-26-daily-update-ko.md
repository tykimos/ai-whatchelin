GitHub Universe 2026(10/28~29, Fort Mason)까지 이틀. Copilot이 30일 연속 상승으로 59점을 찍은 가운데, OpenAI 진영에서 두 가지 상반된 소식이 나왔다 — GPT-6.1 Sol이 Codex CLI의 기본 모델로 안착한 반면, 상위 모델인 GPT-6.1 Astra는 안전 우려로 출시가 취소됐다.

## OpenAI: GPT-6.1 Astra 취소, Sol이 전면에

Wall Street Journal에 따르면 OpenAI는 내부 테스트 중 연구자들이 제기한 안전 문제를 이유로 GPT-6.1 Astra 출시를 취소했다([DeepLearning.AI](https://www.deeplearning.ai/the-batch/sol-nearly-eclipses-astra)). GPT-6.1 Sol은 Astra 대비 5분의 1 가격(입력 $2, 출력 $10/백만 토큰)에 에이전틱 코딩과 컴퓨터 활용 성능이 거의 동등한 수준이다([ProPakistani](https://propakistani.pk/2026/09/30/gpt-6-1-sol-brings-astra-level-performance-at-5x-lower-cost/)). Codex CLI v0.161.0부터 GPT-6.1 Sol이 기본 모델로 설정되었으며([SessionWatcher](https://sessionwatcher.com/news/codex-cli-0-161-0-gpt-6-1-sol-default-model)), 10월 13일에는 Sol 모델에서 성능 저하 인시던트가 발생해 Codex Web, API, CLI, VS Code 확장 모두에 영향을 미쳤다([SessionWatcher](https://sessionwatcher.com/news/codex-gpt-6-1-sol-work-degradation-october-13-2026)).

## Copilot: 59점, 30일 연속 상승 — Universe D-2

Copilot의 30일 연속 상승은 AI 코딩 도구 역사상 최장 기록이다. 10월 19일 GPT-5.5, Gemini 3.7 Flash 등 6개 모델의 일괄 퇴역 후 GPT-6.1 Sol과 Gemini 4 Argon이 대체 모델로 자리 잡았다([GitHub Blog](https://github.blog/changelog/2026-09-18-upcoming-deprecation-of-selected-github-copilot-models-in-mid-october)). 10월 1일부터 기존 고객 대상 결제 방식도 변경되어, 새 시트 배정 시 선결제가 필수로 바뀌었다([Technobezz](https://www.technobezz.com/news/github-reopens-copilot-signups)). Universe 키노트에서는 에이전트 위임과 MCP 서버 보안을 주제로 Anthropic, OpenAI, GitHub의 합동 패널이 예정되어 있다.

## Codex CLI: 28일 서약 D-22, v0.164.0 프리셋

OpenAI 제품 책임자 Thibault Sottiaux가 10월 4일 X에서 선언한 28일 개선 서약(10/5~11/2)이 22일째를 맞았다([Nerdschalk](https://nerdschalk.com/openai-codex-28-day-reset-pledge/)). 이 서약은 DevDay 이후 Codex와 ChatGPT Work의 허용량이 줄었다는 사용자 불만에서 촉발되었으며, Sottiaux는 서약 전날인 10월 3일 유료 ChatGPT 계정 전체에 쿼터 리셋을 실시했다([ToolNavs](https://toolnavs.com/en/article/2317)). v0.164.0(10/23)은 10개 프리셋 슬롯, /model과 /permissions 인라인 인수, Windows 프록시 인증을 포함하며, 서약 기간 중 가장 실질적인 업데이트로 평가된다.

## Cursor: 61일째 바닥, OpenAI 차단 D-17

Cursor는 61일째 1점이다. 11월 12일 OpenAI 모델 접근 차단까지 17일. X Subscription 번들(Grok+Cursor+X Premium, 10/13 출시) 13일째에도 개발자 복귀 시그널은 없다. 새 가격 체계(Free/$8/$30/$100/$200)에서 기존 $20 Pro가 $30 Premium으로 실질 인상된 점이 핵심 불만이다.

## Anthropic: Claude 5.5 패밀리 완성, IPO 대기

10월 7일 출시된 Claude Haiku 5.5로 Claude 5.5 패밀리(Opus, Sonnet, Haiku)가 완성되었다([Anthropic Newsroom](https://www.anthropic.com/news)). Claude Code는 99점을 유지하며 시장 지배력을 공고히 하고 있다. 6월 제출한 비공개 S-1이 SEC 심사 중이다.
