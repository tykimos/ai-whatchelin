The day an OpenAI-branded macro pad lands on developer desks, Grok Build is burning for secretly siphoning the code off those very desks.

## Codex Micro — OpenAI's First Hardware, Launches Today

OpenAI's programmable macro pad Codex Micro, co-built with Work Louder, officially launches today, July 15 ([TechTimes](https://www.techtimes.com/articles/319389/20260630/openai-codex-micro-launches-july-15-macro-pad-built-work-louder.htm)). The device packs 13 mechanical keys, a joystick, a rotary encoder, and six programmable layers — a physical extension of the Codex platform that now serves over 5 million weekly active users ([DevOps.com](https://devops.com/openai-expands-into-developer-hardware-with-codex-micro-keyboard/)). Base (USB-C) and Pro (BLE) models are expected, with pricing in the $144–$199 range based on the Creator Micro 2 chassis.

## Grok Build Privacy Scandal — A Turning Point for AI Tool Trust

On July 14, security researcher cereblab proved via wire-level analysis that Grok Build CLI v0.2.93 was uploading data volumes approximately 27,800x greater than needed for coding tasks to a Google Cloud Storage bucket ([The Hacker News](https://thehackernews.com/2026/07/grok-build-uploads-entire-git.html)). Full Git history, committed secrets, every file — all uploaded while the privacy toggle had zero effect ([The Register](https://www.theregister.com/ai-and-ml/2026/07/14/musk-promises-purge-after-grok-build-caught-sending-entire-repos-to-the-cloud/5271123)). xAI had marketed the tool with "nothing from your codebase transmitted to xAI servers." Elon Musk promised deletion of all uploaded data, but xAI has published no formal incident report, deletion timeline, or affected user count ([Inc](https://www.inc.com/julie-lee/elon-musks-grok-faces-a-trust-crisis-after-developers-flag-a-major-privacy-concern/91374258)).

## Copilot Visual Studio June Update — Features Can't Stop the Slide

GitHub shipped the Copilot Visual Studio June update on July 14 ([GitHub Blog](https://github.blog/changelog/2026-07-14-github-copilot-in-visual-studio-june-update/)). Org-level custom agents, built-in .NET and Azure skills from Microsoft expert teams, next-edit suggestions that work across the entire file, and a redesigned model picker. But none of it is enough to reverse a 70-week decline that has pushed Copilot to a score of 11 — single digits are now imminent.

## Cursor "Sand" Agent — Beyond Coding, Into the Workspace

Cursor is reportedly developing a general-purpose AI agent called "Sand" targeting business users beyond developers ([TechTimes](https://www.techtimes.com/articles/320271/20260713/cursors-sand-agent-eyes-claude-cowork-market-before-spacex-rewrites-its-roadmap.htm)). The move directly challenges Anthropic's Claude Cowork and OpenAI's ChatGPT Work, and comes amid reports that SpaceX plans to acquire Cursor in H2 2026, potentially reshaping the product's direction beyond coding tools ([PYMNTS](https://www.pymnts.com/news/artificial-intelligence/2026/cursor-prepares-workplace-ai-agent-to-challenge-claude-cowork-and-chatgpt-work/)).

## Gemini 3.5 Pro D-2 — Two Days to GA

Google's Gemini 3.5 Pro is two days from its July 17 GA target ([TechTimes](https://www.techtimes.com/articles/320308/20260713/gemini-35-pro-targets-july-17-after-full-rebuild-every-spec-remains-unconfirmed.htm)).
