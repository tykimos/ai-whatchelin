Anthropic closed a $65 billion Series H at a $965 billion post-money valuation, overtaking OpenAI to become the world's most valuable private AI startup ([Bloomberg](https://www.bloomberg.com/news/articles/2026-05-28/anthropic-raises-at-965-billion-valuation-eclipsing-openai)). With an annualized revenue run rate of $47 billion, this is likely the final private round before an October IPO ([TechCrunch](https://techcrunch.com/2026/05/28/anthropic-raises-65-billion-nears-1t-valuation-ahead-of-ipo/)).

## Anthropic: Knocking on the $1 Trillion Door

Sequoia, Dragoneer, Altimeter, and Greenoaks co-led the round, with Amazon contributing $5 billion from its previously committed $15 billion tranche ([CNBC](https://www.cnbc.com/2026/05/28/anthropic-open-ai-startup-value.html)). Claude Opus 4.8, launched the day before, holds the coding benchmark crown at 88.6% SWE-bench Verified and 69.2% SWE-bench Pro ([Anthropic](https://www.anthropic.com/news/claude-opus-4-8)). Dynamic Workflows in Claude Code can now spawn up to 1,000 subagents per run — showcased by Bun's 750K-line Zig-to-Rust migration in 11 days ([claude.com](https://claude.com/blog/introducing-dynamic-workflows-in-claude-code)).

## OpenAI: Broadest 2026 Outage Hits All Services

OpenAI experienced widespread disruptions across ChatGPT, API, DALL-E, Codex, Sora, and login systems on May 29 ([BusinessUpturn](https://www.businessupturn.com/technology/chatgpt-down-openai-users-report-widespread-problems-with-api-app-and-login-on-may-29)). The simultaneous multi-service failure — the broadest of 2026 — landed on the same day as Anthropic's record funding close, drawing sharp contrast between the two rivals.

## GitHub Copilot: 25-Week Low, D-3 to Billing Change

Copilot's popularity score dropped to 58, setting another all-time low ([GitHub Docs](https://docs.github.com/en/copilot/how-tos/manage-and-track-spending/prepare-for-your-move-to-usage-based-billing)). Just 3 days remain until June 1 usage-based billing — code completions stay free, but agent and chat consume AI Credits. Microsoft Build 2026 in 4 days, where a homegrown coding model is expected, may be the only counter-narrative ([Digit.in](https://www.digit.in/news/general/microsoft-may-unveil-new-coding-focused-ai-model-next-week-here-is-what-we-know.html)).

## Codex CLI: v0.135.0 — Richer Diagnostics

Codex doctor now reports environment, Git, terminal, app-server, and thread inventory diagnostics ([OpenAI Codex Changelog](https://developers.openai.com/codex/changelog)). The trend is clear: Codex CLI is evolving into a persistent autonomous agent runtime.
