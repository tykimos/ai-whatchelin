오늘은 AI 코딩 도구 시장의 판도를 바꿀 수 있는 날이다. OpenAI DevDay 2026이 샌프란시스코 Fort Mason에서 개최되며, Sam Altman의 기조연설이 오전 10시(PT)에 시작된다([OpenAI](https://openai.com/index/devday-2026/)).

## OpenAI DevDay 2026: 상시 에이전트 "o" 공개 임박

DevDay 최대 관심사는 상시 에이전트 "o"다. ChatGPT 코드에서 유출된 정보에 따르면, "o"는 채팅 세션 밖에서도 지속적으로 작동하는 에이전트로, 자체 이메일 ID까지 보유할 예정이다([TestingCatalog](https://www.testingcatalog.com/openai-to-announce-o-always-on-agent-during-devday/)). 요금은 Pro Lite $100/월, Pro $200/월, Pro Max $500/월 3단계로 유출됐다([Android Headlines](https://www.androidheadlines.com/2026/09/openai-leaks-always-on-o-chatgpt-assistant.html)). GPT-6 Cyber 프리뷰와 Ultrafast 티어(Cerebras 하드웨어 기반, 최대 750 토큰/초)의 정식 공개도 예상된다([Forbes](https://www.forbes.com/sites/jonmarkman/2026/09/21/openai-plans-to-introduce-managed-agents-at-devday-2026/)).

## Cursor: 32일 연속 하락, 33점

Cursor가 33점으로 떨어지며 8/28 이후 32일 연속 하락 기록을 갱신했다. 정점 99에서 66점이 빠졌다. OpenAI 모델 접근 종료(11/12)까지 D-44이며, SpaceX 인수 후 xAI 팀과의 통합 과정에서 인력 감축이 이어지고 있다([The Information](https://www.theinformation.com/articles/cursor-staff-meet-xai-employees-layoffs-exits-mount)). 한 커뮤니티 유저는 *"32일 연속 하락이면 이건 하락이 아니라 자유낙하"*라고 표현했다.

## GitHub Copilot: 통합 경험 출시 이후 반등 지속

어제 통합 경험을 정식 출시한 GitHub Copilot이 5점으로 소폭 상승했다([GitHub Blog](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)). 10월 2일에는 Gemini 3.5/3.6 Flash → Gemini 3.8 Flash, Claude Opus 4.7 → Opus 5, Kimi K2.7 Code → K3 등 대규모 모델 교체가 예정돼 있다([GitHub Changelog](https://github.blog/changelog/2026-09-25-github-copilot-weekly-releases-september-21/)). 85주간의 1점 정체에서 벗어났지만, 회복까지는 아직 갈 길이 멀다.

## Claude Code: LogRocket 1위 유지, Fable 5.1 독주

Claude Code가 LogRocket 9월 AI 개발 도구 파워 랭킹 1위를 유지하고 있다([LogRocket Blog](https://blog.logrocket.com/ai-dev-tool-power-rankings/)). Fable 5.1이 WebDev Arena에서 1,762 Elo를 기록하며 모든 코딩 도구 내 모델 중 최고 점수를 달성했다. Opus 5.5가 9/22 출시되며 비용도 40% 절감돼 사용자 만족도가 높은 상태다.
