Three days after the $60B SpaceX acquisition closed, Cursor is proving it can ship faster than ever. Today, Cursor launched its agent-first git hosting platform Origin in early beta across all paid plans ([Cursor Changelog](https://cursor.com/changelog/origin-code-hosting)). Starting with repos, pull requests, code browsing, and GitHub sync, Origin arrives weeks ahead of its "fall 2026" target — first announced at the Compile conference in June. Simultaneously, Cursor Builds went default for all Cloud Agent environments, using filesystem snapshots to fork live machines and cutting agent startup times by 3x ([TechTimes](https://www.techtimes.com/articles/324667/20260817/cursor-builds-goes-default-agent-fleets-survive-bad-commits-start-three-times-faster.htm)). Cursor's popularity score climbed from 98 to 99.

## Stripe: OpenRouter Acquisition Finalized at $7B+

Stripe finalized its deal to acquire AI model routing startup OpenRouter for more than $7 billion ([Bloomberg](https://www.bloomberg.com/news/articles/2026-08-16/stripe-nears-deal-to-buy-ai-firm-openrouter-for-over-7-billion)). That's a 5x+ markup from OpenRouter's $1.3B Series B valuation in May. With 8 million users accessing 400+ AI models, OpenRouter's routing and billing technology is set to integrate into Stripe's payment infrastructure — potentially establishing a new standard for AI service billing ([TechCrunch](https://techcrunch.com/2026/08/16/stripe-will-reportedly-acquire-ai-gateway-startup-openrouter-for-7b/)).

## DeepSeek: API Prices Surge Up to 371% Ahead of IPO

DeepSeek raised API prices dramatically as of 16:00 UTC on August 16 ([Bloomberg](https://www.bloomberg.com/news/articles/2026-08-13/deepseek-increases-prices-for-ai-services-by-multiple-times)). V4-Flash output tokens jumped from $0.28 to $1.32/M at peak hours (371% increase), while V4-Pro output rose from $0.87 to $3.96/M (355% increase) ([Quartz](https://qz.com/deepseek-api-price-increase-v4-peak-off-peak-081326)). The new peak/off-peak dual billing structure is widely interpreted as a monetization push ahead of a potential DeepSeek IPO ([Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/deepseek-raising-api-prices-1-174027670.html)).

## Claude: 36-Minute Outage Hits All Services

Anthropic's Claude platform suffered an authentication failure starting at 21:58 UTC on August 16 ([BleepingComputer](https://www.bleepingcomputer.com/news/artificial-intelligence/anthropic-confirms-claude-is-down-in-major-outage-affecting-multiple-services/)). The outage affected claude.ai, Claude Code, and Claude Cowork, with service restored by 22:34 UTC ([Unite.AI](https://www.unite.ai/anthropic-outage-disrupts-claude-services-fix-deployed-after-login-failures/)). Anthropic has not disclosed the root cause.
