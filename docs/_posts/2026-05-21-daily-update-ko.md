Anthropic이 하루 만에 4건의 메가딜을 터뜨렸다. CNBC 디스럽터 50 1위 등극에 이어 Microsoft Maia 칩 임대 협상, 게이츠 재단 $2억 파트너십, KPMG 27만 6천 명 전면 배포까지 — AI 코딩 시장의 무게중심이 빠르게 이동하고 있다.

## Anthropic, Microsoft Maia AI 칩 임대 협상

Bloomberg에 따르면 Anthropic이 Microsoft의 Maia AI 칩으로 구동되는 서버 임대를 위한 초기 협상에 들어갔다([Bloomberg](https://www.bloomberg.com/news/articles/2026-05-21/anthropic-in-talks-to-use-microsoft-ai-chips-information-says)). Maia 200 추론 칩은 경쟁 가속기 대비 달러당 토큰 30% 이상 우수한 효율을 보인다([CNBC](https://www.cnbc.com/2026/01/26/microsoft-reveals-maia-200-ai-chip-will-use-it-in-house.html)). 이 계약이 성사되면 Amazon, Google, Nvidia, SpaceX Colossus에 이어 다섯 번째 컴퓨트 소스가 추가된다. Microsoft 주가는 이 소식에 2% 상승했다([Investing.com](https://uk.investing.com/news/stock-market-news/microsoft-rises-2-as-anthropic-eyes-deal-for-custom-maia-ai-chips-4692950)).

## Anthropic-Gates Foundation $2억 파트너십 — 역대 최대 AI-자선 계약

Anthropic과 게이츠 재단이 4년간 $2억 규모 파트너십을 발표했다([Anthropic](https://www.anthropic.com/news/gates-foundation-partnership)). 보조금, API 크레딧, 기술 지원을 통해 보건(소아마비·HPV·자간전증), 교육(AI 과외·진로 탐색), 농업(현지 언어 정밀 농업)을 추진한다. OpenAI의 $5천만 게이츠 계약 대비 4배 규모로, AI 업계 역대 최대 자선 파트너십이다([TechFundingNews](https://techfundingnews.com/anthropic-gates-foundation-launch-200m-initiative-to-tackle-disease-and-education-gaps-with-ai/)).

## CNBC 디스럽터 50 1위 + KPMG 27만 명 배포

Anthropic이 OpenAI를 제치고 CNBC 디스럽터 50 1위에 올랐다([CNBC](https://www.cnbc.com/2026/05/19/2026-cnbc-disruptor-50-rankings-anthropic-no-1.html)). Q1 매출 80배 성장, 연간 런레이트 $300억 돌파. 같은 날 KPMG가 글로벌 전략 제휴를 체결하고 138개국 27만 6천 명 전원에 Claude를 배포한다고 발표했다([Anthropic](https://www.anthropic.com/news/anthropic-kpmg)). Big Four 최초의 전면 Claude 도입이다.

## Claude Code v2.1.145 + Code with Claude London 최종일

Claude Code v2.1.145가 `/code-review` 명령어(기존 `/simplify`에서 개명)와 MCP 페이지네이션 수정을 포함해 릴리스됐다([code.claude.com](https://code.claude.com/docs/en/changelog)). Code with Claude London Extended 최종일에서는 인디 개발자 워크숍과 Applied AI 팀 오피스 아워가 진행됐다.

## Antigravity 2.0 롤백 사태 3일째

Antigravity 2.0 자동 업데이트 참사가 3일째 이어지고 있다([Google AI Developers Forum](https://discuss.ai.google.dev/t/antigravity-2-0-a-rushed-un-tested-release/145483/6)). 설정 경로 불일치로 확장 프로그램이 통째로 삭제되며 개발자들이 v1.23.2로 수동 롤백 중이다. I/O 당일 62까지 급등했던 점수가 55로 추락 — 급등분의 2/3가 소실됐다.

## Copilot 17주 연속 하락 66

GitHub Copilot이 66으로 17주 연속 하락했다([GitHub Blog](https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/)). 6월 1일 사용량 기반 과금까지 D-11. GPT-5.3-Codex가 기본 모델로 강제 전환됐고 웹 채팅에서 Gemini 모델이 모두 삭제됐다.
