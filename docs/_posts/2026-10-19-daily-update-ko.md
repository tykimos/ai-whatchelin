오늘 GitHub Copilot의 10월 모델 대폐기가 실행됐다. GPT-5.5·GPT-5.4·GPT-5.4 mini·GPT-5 mini·Gemini 3.7 Flash·Grok 4.5가 모든 Copilot 경험에서 제거되며, GPT-5.6 Sol/Luna·Gemini 3.8 Flash·Grok 4.6으로 자동 전환된다([GitHub Changelog](https://github.blog/changelog/2026-09-18-upcoming-deprecation-of-selected-github-copilot-models-in-mid-october)). 10월 2일 1차 웨이브(Gemini 3.5/3.6 Flash, Kimi K2.7 Code, Claude Opus 4.7)에 이은 2차 정리로, 레거시 모델 부채를 일소하는 수순이다([GitHub Changelog](https://github.blog/changelog/2026-10-02-selected-models-in-github-copilot-deprecated)).

## Copilot: 45점 돌파, Universe D-9

두 차례 모델 대폐기를 마친 Copilot은 45점까지 상승했다. 10월 15일 GA로 전환된 에이전틱 자동수정(Agentic autofix)이 코드 스캐닝 알림을 자동 수정하고 드래프트 PR까지 생성하며 실무 효용을 높이고 있다([GitHub Blog](https://github.blog/changelog/label/copilot/)). 10월 28~29일 [GitHub Universe 2026](https://github.blog/news-insights/company-news/your-guide-to-github-universe-2026-is-here-the-schedule-just-launched/)이 9일 앞으로 다가왔으며, Copilot 에이전트 위임·MCP 서버 보안 세션 등이 예고되어 있다. 이 자리에서 차세대 Copilot 에이전트 로드맵이 공개될 가능성이 높다.

## Claude Code: v2.1.294 안전 후크 수정, Anthropic IPO 임박

Claude Code v2.1.294(10/8)에서 인스트럭션 기반 후크의 블로킹 룰이 정상 동작하도록 수정됐다([Havoptic](https://www.havoptic.com/releases/claude-code/2026/10)). v2.1.293(10/7)에서 기본 모델이 Haiku 5.5(1M 토큰 컨텍스트)로 전환된 데 이어, v2.1.292(10/6)에서는 마켓플레이스 플러그인 설치가 추가됐다. 한편 Anthropic의 IPO는 10~11월 중 실행이 예상되며, 연간화 매출 $2.5B를 넘긴 Claude Code가 핵심 성장 드라이버로 평가받고 있다([Yahoo Finance](https://finance.yahoo.com/markets/stocks/articles/anthropic-files-confidentially-ipo-965-162331922.html)).

## Cursor: 54일째 바닥, X Subscription 무반응

Cursor는 54일째 바닥권(1점)에 머물고 있다. SpaceX의 X Subscription 번들 출시 6일차이나 반등 신호가 없다([Trending Topics](https://www.trendingtopics.eu/x-subscription-grok-cursor-x-bundle/)). Plus($8)~Ultra($200/월) 5단계 구조이나, Grok 모델만 공유 풀에 포함되고 타사 모델은 별도 결제가 필요한 구조가 개발자 반감을 사고 있다. 11월 12일 OpenAI 모델 접근 차단까지 24일.
