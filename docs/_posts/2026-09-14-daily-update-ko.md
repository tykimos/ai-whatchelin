오늘(9월 14일) Claude Code의 50% 여름 부스트가 공식 종료되고 '영구 25% 인상'이 시작됐다([BleepingComputer](https://www.bleepingcomputer.com/news/artificial-intelligence/anthropic-is-cutting-claude-codes-current-weekly-limits-by-17-percent/)). 5월 이전 기준 대비 25% 증가이지만, 지난 4개월간 50% 부스트를 누리던 사용자에게는 실질적으로 16.7% 삭감이다([MindStudio](https://www.mindstudio.ai/blog/claude-code-weekly-rate-limit-changes)). Pro·Max·Team·Enterprise 전 플랜이 영향을 받으며, 5시간 세션 한도는 유지된다. Reddit과 HN에서는 "사실상 다운그레이드"라는 반응과 "원래 기준보다는 높으니 감사해야 한다"는 의견이 양립하고 있다([AI Catchup](https://aicatchup.com/news/claude-code-weekly-limits-permanent-25-percent-september-2026)).

## Cursor: Projects 7일차, 23일 연속 하락

Cursor의 인기도가 63까지 떨어지며 SpaceX 인수 이후 23일 연속 하락세를 이어가고 있다([Cursor Changelog](https://cursor.com/changelog/projects)). Projects 베타가 7일차에 접어들었고, 코디네이터 에이전트가 수천 개 서브에이전트를 클라우드에서 병렬 실행하는 아키텍처는 기술적으로 인상적이지만, OpenAI 모델 차단(11/12)까지 D-59로 다가오면서 독자 모델 전략 부재에 대한 우려가 커지고 있다([Technobezz](https://www.technobezz.com/news/cursor-projects-cloud-agents-beta)).

## Antigravity: v2.13.0 — 문서 섹션·UX 개선

Antigravity가 v2.13.0을 릴리스하며 새로운 Documents 섹션, C++/Python/Protobuf 구문 강조, 파일 필 호버 툴팁 등 16가지 개선과 16가지 버그 수정을 포함시켰다([Releasebot](https://releasebot.io/updates/google/antigravity)). 내장 Antigravity Guide 스킬도 추가돼 사용자가 도구 내에서 바로 도움말을 받을 수 있게 됐다. Google의 개발자 도구 통합 전략 하에 29주째 99점을 유지하고 있다.

## GitHub Copilot: 통합 경험 D-14

GitHub Copilot의 통합 경험(Chat·Mobile·클라우드 에이전트 단일화)이 9월 28일로 D-14 앞으로 다가왔다([GitHub Blog](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)). 통합과 함께 채팅 데이터 보존 정책이 28일에서 계정 수명으로 변경되며, Business·Enterprise 고객의 선불 좌석제가 10월 1일부터 의무화된다([Developers Digest](https://www.developersdigest.tech/blog/github-copilot-september-policy-billing-reset-2026)). 85주간 바닥을 기다가 통합 이후 어떤 변화가 올지 주목된다.
