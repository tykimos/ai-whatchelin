Google unveiled Gemini 4 Argon today, its new top-end frontier model built for sustained reasoning ([The Daily Star](https://www.thedailystar.net/news/technology/news/google-announces-gemini-4-argon-its-new-frontier-model-4287686)). It posts 77.9% on DeepSWE v1.1 — surpassing GPT-6 Astra's 74.1% — along with 91.7% on LVBench and a first-place 51.3% on AutomationBench ([Help Net Security](https://www.helpnetsecurity.com/2026/10/01/google-gemini-4-argon/)). Introductory pricing matches GPT-6.1 Sol at $2/$10 per million tokens, with cached input discounted 95% and the output token limit raised from 64K to 1 million. The catch: it's rolling out first to vetted cyber defenders through Google's Fairwind Program, with no public release date announced ([MalayMail](https://www.malaymail.com/news/tech-gadgets/2026/10/01/google-holds-back-gemini-4-argon-limits-release-to-vetted-cybersecurity-experts/237250)). This is Google's first frontier model release since February — eight months is an eternity in this race ([Yahoo Finance](https://finance.yahoo.com/technology/article/google-debuts-gemini-4-argon-its-latest-frontier-model-204002322.html)).

## GitHub Copilot: 4 Models Removed Tomorrow, 10 Total in October

GitHub Copilot begins its largest model cleanup tomorrow, October 2. Gemini 3.5 Flash, Gemini 3.6 Flash, Kimi K2.7 Code, and Claude Opus 4.7 will be removed across all Copilot experiences, with Gemini 3.8 Flash, Kimi K3, and Claude Opus 5 as replacements ([GitHub Changelog](https://github.blog/changelog/2026-09-03-upcoming-deprecation-of-selected-github-copilot-models/)). On October 19, GPT-5.5, GPT-5.4, GPT-5.4 mini, GPT-5 mini, and Grok 4.5 are next ([GitHub Changelog](https://github.blog/changelog/2026-09-18-upcoming-deprecation-of-selected-github-copilot-models-in-mid-october/)). Business and Enterprise customers now face upfront charges starting today ([GitHub Blog](https://github.blog/news-insights/company-news/10-technical-talks-im-excited-about-at-github-universe-2026/)).

## JetBrains Air: Agentic Development Enters the IDE

JetBrains launched the EAP for Air integration in JetBrains IDEs today ([JetBrains Blog](https://blog.jetbrains.com/ai/2026/10/air-in-ides-eap/)). Available in 2026.3 EAP builds or as a JetBrains Marketplace plugin, Air runs Codex, GitHub Copilot, Junie, Cursor, and other ACP-compatible agents directly inside the IDE ([SD Times](https://sdtimes.com/ai/sd-times-news-roundup-oct-1-2026-ibm-bob-jetbrains-air-qodo-3-0)). Users can leverage their existing AI subscriptions — no separate JetBrains AI purchase required.

## IBM Bob: Self-Hosted Deployment Goes Live

IBM announced self-hosted deployment for its agentic software development platform IBM Bob ([IBM Newsroom](https://newsroom.ibm.com/2026-10-01-ibm-introduces-self-hosted-deployment-for-ibm-bob-to-help-enterprises-advance-ai-sovereignty-and-governance)). Organizations can now deploy Bob on-premises, in private clouds, or in air-gapped environments where their code and data already reside ([SiliconANGLE](https://siliconangle.com/2026/10/01/ibm-allows-on-prem-deployment-of-its-bob-agentic-development-platform/)). The move reflects the growing enterprise trend of prioritizing data sovereignty over model quality.

## Qodo 3.0: Governance for the Agentic Software Factory

Qodo released version 3.0, a quality governance platform for the agentic development era ([Qodo Blog](https://www.qodo.ai/blog/introducing-qodo-3-0/)). PR Triage groups pull requests into work packages, the Agentic Toolbox lets coding agents reference organizational standards in real time, and Software Map auto-visualizes change blast radius ([GlobeNewswire](https://www.globenewswire.com/news-release/2026/10/01/3372954/0/en/qodo-3-0-brings-enterprise-grade-quality-control-to-agentic-software-development.html)). Supports Gerrit, GitHub, GitLab, Bitbucket, Azure DevOps, and on-premises deployment.

## Anthropic: Barclays Strategic Partnership Announced

Barclays officially announced an expanded strategic collaboration with Anthropic ([Anthropic](https://www.anthropic.com/news/barclays-scales-claude)). The bank targets 50% developer adoption of Claude Code by end of 2026, scaling to most developers by end of 2027. Claude is already routing 120,000 emails daily in the Global Markets division ([Bloomberg](https://www.bloomberg.com/news/articles/2026-10-01/barclays-expands-use-of-anthropic-s-claude-in-efficiency-push)).

## Claude Code: v2.1.286 Shipped

Claude Code v2.1.286 shipped today ([ClaudeCodeLog/X](https://x.com/ClaudeCodeLog/status/2105377563698696459)). Permission prompts now show stacked counts ('2 of 5'), sessions auto-retry the previous model once on API refusal, and secrets with invisible characters in key names are properly masked in logs.

## GPT-6.1 Sol: API Pricing Confirmed

The API pricing for GPT-6.1 Sol is now confirmed at $2/$10 per million tokens, with cached input at $0.10/MTok and long-context rates of $4/$15 above 272K input tokens ([OpenAI](https://openai.com/index/introducing-gpt-6-1-sol/)). It delivers near-Astra performance at one-fifth the price.
