A terminal-native agent has surpassed an IDE-based tool in popularity for the first time. Codex CLI hit 98 today — one point above Cursor's 97 — marking a historic first after an 8-day streak fueled by GPT-5.6 Luna's 80% price cut. Meanwhile, Anthropic locked in a massive $10B infrastructure deal with Volta, and Claude Opus 4.1 enters its final hours before permanent retirement tomorrow.

## Codex CLI: Hits 98 — First-Ever Cursor Overtake, Luna Streak Day 8

The ripple effects of GPT-5.6 Luna's 80% price cut (Jul 30) continue into day eight([VentureBeat](https://venturebeat.com/technology/ai-price-wars-openai-cuts-gpt-5-6-luna-prices-by-80-as-model-competition-shifts-toward-cost)). Codex CLI climbed from 91 to 98, gaining one point per day. After tying Cursor at 97 yesterday, it broke through today for a historic first overtake. The 10x reduction in auto-review costs is the primary driver. Cursor remains steady at 97 with its iPad launch and Router rollout providing support, but terminal-first developers are noticeably migrating.

## Anthropic: $10B Volta Deal — Opus 4.1 Permanent Retirement Tomorrow

Anthropic secured a $10 billion, six-year computing capacity deal with Volta, an Nvidia-backed AI cloud startup([Anthropic](https://www.anthropic.com/news)). This is the fourth major infrastructure agreement following SpaceX Colossus (May 6), AMD $5B (Jul 22), and Akamai $1.8B (May 8). Separately, Claude Opus 4.1 (claude-opus-4-1-20250805) permanently retires from the API tomorrow, August 5([Anthropic](https://platform.claude.com/docs/en/about-claude/model-deprecations)). This is exactly 60 days after the June 5 deprecation notice, and migration to Opus 4.8 is mandatory([TheRouter.ai](https://therouter.ai/news/anthropic-deprecates-claude-opus-4-1-august-5-migration-guide/)). The 50% weekly usage boost for Claude Code Pro and Max subscribers continues through August 19.

## OpenAI: o3 Exiting ChatGPT Aug 26, Astra September at Earliest

OpenAI o3 will be retired from ChatGPT on August 26([help.openai.com](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)). Agentic capabilities are being consolidated into ChatGPT and Codex, while API access continues. Atlas is also shutting down August 9. Astra has no confirmed release date, pricing, or API access and must pass a new federal pre-release review process (~30 days), putting the earliest public window in September([FelloAI](https://felloai.com/all-we-know-about-chatgpt-6/)). OpenAI is also expected to publish a technical report on the Hugging Face breach this month([WinBuzzer](https://winbuzzer.com/2026/07/29/hugging-face-ceo-seeks-openai-traces-and-defensive-compute-xcxwbn/)).

## GitHub Copilot: Major Model Deprecations September 1

GitHub announced it will deprecate multiple models across all Copilot experiences on September 1([GitHub Changelog](https://github.blog/changelog/2026-07-31-upcoming-august-2026-model-deprecations-in-github-copilot/)). Claude Sonnet 4.6 will remain available only for individual annual plan subscribers. Gemini 2.5 Pro and 3 Flash were already removed on July 31. The Copilot Billing Preview App was officially retired yesterday (Aug 3)([GitHub Changelog](https://github.blog/changelog/2026-07-07-copilot-billing-preview-app-will-be-retired-on-august-3/)).

## Community: HN "Don't Be a Meat Proxy" Hits 1,753 Points

*"Don't be a meat proxy"* — a post discussing the human role in AI-assisted development — topped Hacker News with 1,753 points and 708 comments([Hacker News](https://news.ycombinator.com/front)). Qwen3.8-Max drew 1,082 points as "A New Bar for Coding and Cowork." The US government's discussion of potential sanctions on Chinese open-source AI models also sparked heated debate.
