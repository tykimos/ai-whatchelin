AI 코딩 도구 시장의 기업 지각변동이 이번 주 절정을 향해 치닫고 있다. Anthropic IPO에 기관투자가들이 몰려들고 있지만 의구심도 함께 커지는 가운데, GitHub Copilot의 대규모 모델 퇴출이 48시간 앞으로 다가왔고, Cursor는 OpenAI 차단 후 3일째 핵심 기능이 멈춰 있다.

## Anthropic IPO: 수배 초과 청약, 그러나 "AI 리더십 얼마나 갈까"

Anthropic IPO 로드쇼 4일차, 기관투자가 수요가 SpaceX 초기 로드쇼를 능가하는 속도로 몰리고 있다([Quartz](https://qz.com/anthropic-ipo-oversubscribed-roadshow-demand-111126)). 주문장은 이미 수배 초과 청약 상태이며, 로드쇼가 진행됨에 따라 더 커질 것으로 은행들은 예상하고 있다([BusinessDay](https://www.businessday.co.za/companies/2026-11-14-investors-flock-to-anthropic-ipo-but-question-durability-of-ai-lead/)). 대만 Fubon Life는 최대 $7억을 입찰했다([BigGo Finance](https://finance.biggo.com/news/9812aa29-cc85-47d4-a68f-946ab4e6a228)). 그러나 투자자들은 Google 등 경쟁사가 빠르게 추격하는 상황에서 Anthropic의 AI 리더십이 코딩 분야를 넘어 얼마나 지속될 수 있을지 의문을 제기하고 있다([Reuters via The Star](https://www.thestar.com.my/tech/tech-news/2026/11/14/exclusive-investors-flock-to-anthropic-ipo-but-question-durability-of-ai-lead)). 가격 결정은 다음 주 수요일(11월 19일)경으로 예상된다.

## GitHub Copilot: 모델 대퇴출 D-2

11월 16일 Claude Opus 4.8, Claude Opus 5, GPT-5.6 Terra 세 모델이 Copilot 전 영역에서 완전 제거된다([GitHub Blog](https://github.blog/changelog/2026-10-15-upcoming-deprecation-of-selected-github-copilot-models-in-mid-november)). Chat, 인라인 편집, Agent 모드, 코드 자동완성이 모두 대상이다([dev.classmethod.jp](https://dev.classmethod.jp/en/articles/github-copilot-model-deprecation-nov-2026/)). 연간 구독 Individual 플랜만 Claude Opus 4.8 예외 적용. 관리자들은 마이그레이션 대상 모델(Opus 5.5, GPT-6.1 Sol) 활성화 상태를 점검해야 한다. Copilot은 97점으로 52일째 연속 상승 중이다.

## Cursor: OpenAI 차단 3일째, 미지의 항로

OpenAI 모델 접근 차단 후 3일째, Tab 자동완성·자동 모델 선택·클라우드 에이전트 등 핵심 기능이 여전히 동작하지 않는다([Tom's Guide](https://www.tomsguide.com/ai/openai-is-leaving-cursor-in-november-here-are-your-3-options)). SpaceX 인수 후 OpenAI가 "계약 위반 전력"을 이유로 차단을 단행했으며([OpenAI](https://openai.com/index/our-decision-on-cursor-following-its-acquisition-by-spacex/)), CEO Michael Truell은 전체 트래픽의 5%에 불과하다고 주장하지만 실질적 영향은 그보다 크다([CryptoBriefing](https://cryptobriefing.com/cursor-openai-5-percent-traffic/)). 83일째 바닥(점수 1)이다.

## Codex CLI: 11월 5연속 릴리스

Codex CLI가 11월 들어 0.165~0.169 버전을 연달아 릴리스했다([ChatGPT Changelog](https://learn.chatgpt.com/docs/changelog)). 0.165.0에서 Google Cloud Vertex AI 프로바이더가 내장되었고, 0.167.0에서는 `codex agents --no-daemon`으로 에이전트 커맨드 센터를 열 수 있게 되었다([WindowsReport](https://windowsreport.com/openai-gives-codex-a-major-upgrade-with-cloud-environments-voice-cli-code-review/)). 어제는 0.168.0(프로바이더 설정 후 모델 선택 수정, TUI 컴포저 로컬 이미지 썸네일)과 0.169.0(키보드/마우스 사이드 채팅 전환, 저장된 로컬 사이드 채팅 재시작 후 복원)이 연속 출시되었다([Releasebot](https://releasebot.io/updates/openai/codex)). ChatGPT 데스크톱 앱과 통합이 지속적으로 강화되고 있다.

## Claude AI: 로그인 장애 발생 후 복구

11월 13일 Anthropic 플랫폼에서 인증 관련 장애가 발생해 claude.ai와 Claude Code 사용자들이 접속 불가를 경험했다([BusinessToday](https://businesstoday.in/technology/news/story/claude-ai-outage-anthropic-investigates-login-failures-as-ai-chatbot-and-coding-tools-face-outage-567403-2026-11-13)). IPO 로드쇼 한복판에서 터진 장애라 타이밍이 좋지 않았으나, 같은 날 복구된 것으로 확인된다.

## ChatGPT: Wallet·Business Hub로 커머스 확장

OpenAI가 11월 13일 미국 Pro 구독자 대상으로 Wallet을 출시했다([Releasebot](https://releasebot.io/updates/openai/chatgpt)). 생체 인증으로 결제를 승인하며, 대체 결제 자격증명이 에이전트 결제 시 카드 정보를 숨겨준다. 11월 10일에는 Business Hub가 출시되어 사업자가 프레젠스를 등록하고 상품 피드를 연동해 고객 인사이트를 확인할 수 있게 되었다([Releasebot](https://releasebot.io/updates/openai/chatgpt)). Chat과 Work 탭도 하나로 통합되며, Codex는 데스크톱 앱에서 별도로 유지된다([TechCrunch](https://techcrunch.com/2026/11/02/openai-is-finally-merging-chatgpts-chat-and-work-tabs/)).
