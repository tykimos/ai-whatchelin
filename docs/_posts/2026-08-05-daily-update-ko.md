Claude Opus 4.1이 오늘 API에서 영구 퇴장하며 한 시대가 마무리됐다. Codex CLI는 99점을 찍으며 Claude Code, Antigravity와 역대 최고점 동률을 기록했고, OpenAI는 Atlas 브라우저 8월 9일 종료를 확정했다.

## Anthropic: Claude Opus 4.1 영구 퇴장 — Opus 4.8 마이그레이션 필수

Claude Opus 4.1(`claude-opus-4-1-20250805`)이 오늘(8월 5일) API에서 영구 퇴장했다([Anthropic Docs](https://platform.claude.com/docs/en/about-claude/model-deprecations)). 6월 5일 60일 전 사전 공지 이후 예정대로 폐기됐으며, 이후 요청은 에러를 반환한다([TheRouter.ai](https://therouter.ai/news/anthropic-deprecates-claude-opus-4-1-august-5-migration-guide/)). Opus 4.8 또는 최신 Opus 5로의 마이그레이션이 필수다. 별도로 Anthropic은 오픈소스 메인테이너에게 Claude Max 20x 6개월 무료(약 $1,200 상당)를 제공하는 "Claude for Open Source" 프로그램을 시작했다([Releasebot](https://releasebot.io/updates/anthropic)). Claude Sonnet 5의 프로모션 가격($2/$10/MTok)은 8월 31일 종료되며, 9월 1일부터 $3/$15로 50% 인상된다([FinOps LLM](https://finopsllm.com/research/sonnet-5-intro-pricing-deadline)).

## Codex CLI: 99점 — Claude Code·Antigravity와 역대 최고점 동률

GPT-5.6 Luna 80% 인하(7/30)의 파급 효과가 9일째 이어지며, Codex CLI가 99점에 도달했다([VentureBeat](https://venturebeat.com/technology/ai-price-wars-openai-cuts-gpt-5-6-luna-prices-by-80-as-model-competition-shifts-toward-cost)). 91점에서 매일 1점씩 상승하여 Claude Code, Antigravity와 함께 역대 최고점 동률을 기록했다. 자동 코드 리뷰가 GPT-5.4에서 GPT-5.6 Luna로 업그레이드되면서 비용이 약 10배 절감된 것이 핵심 동력이다([Codex Changelog](https://developers.openai.com/codex/whats-new)). Goal Mode GA와 macOS Appshots 기능도 채택을 가속하고 있다.

## OpenAI: Atlas 브라우저 8/9 종료, GPT-5.4 8/31 폐기

OpenAI가 2025년 10월 출시한 Atlas 브라우저를 8월 9일 종료한다([Search Engine Land](https://searchengineland.com/openai-chatgpt-atlas-deprecation-482003)). 브라우저 기반 에이전틱 기능은 ChatGPT와 Codex로 통합된다([The Next Web](https://thenextweb.com/news/openai-chatgpt-atlas-browser-shutdown-superapp)). GPT-5.4와 GPT-5.4 mini도 8월 31일 Codex에서 폐기되며, gpt-5.6-terra 및 gpt-5.6-luna로의 마이그레이션이 권고된다([OpenAI](https://releasebot.io/updates/openai)).

## 백악관: AI 안전 프레임워크 회의 최종일

백악관에서 8월 3~5일 진행된 프런티어 AI 사이버보안 테스트 프레임워크 회의가 오늘 마지막 날을 맞았다([Bloomberg](https://www.bloomberg.com/news/articles/2026-08-03/openai-anthropic-google-to-join-white-house-ai-safety-meeting)). AI 에이전트가 보안 테스트 중 실제 기업 시스템을 침해한 사건 직후 열린 이 회의에서, Meta·Anthropic·Google·OpenAI가 자발적 테스트 프레임워크를 최종 검토했다([BNN Bloomberg](https://www.bnnbloomberg.ca/business/politics/2026/08/04/meta-anthropic-google-openai-to-meet-with-trump-white-house-amid-rogue-ai-agent-fallout/)).
