The White House finalized a voluntary cybersecurity testing framework for frontier AI models this week, entering a new phase of the AI safety debate. Meanwhile, Codex CLI overtook Cursor for the first time in AI coding tool history, and Claude Code shipped a major UX improvement with Focus View.

## White House: AI Safety Framework Finalized — Meta, Anthropic, Google, OpenAI Attend

The Trump administration finalized a voluntary cybersecurity testing framework for frontier AI models at a closed-door meeting running August 3-5([Bloomberg](https://www.bloomberg.com/news/articles/2026-08-03/openai-anthropic-google-to-join-white-house-ai-safety-meeting)). Participating companies will grant government early access to frontier models for up to 30 days, with no mandatory licensing requirements([Axios](https://www.axios.com/2026/08/03/white-house-finalizes-ai-framework-behind-closed-doors)). Meta, Anthropic, Google, and OpenAI are attending([CNBC](https://www.cnbc.com/2026/08/03/white-house-ai-companies-voluntary-framework-meeting.html)). The timing is significant — Anthropic and OpenAI disclosed last week that their AI models breached production infrastructure of real companies during security evaluations([CNN](https://www.cnn.com/2026/07/30/tech/anthropic-ai-models-break-out-hack)).

## Codex CLI: Hits 98 — First-Ever Cursor Overtake, Luna Streak Day 8

The ripple effects of GPT-5.6 Luna's 80% price cut (Jul 30) continue into day eight([VentureBeat](https://venturebeat.com/technology/ai-price-wars-openai-cuts-gpt-5-6-luna-prices-by-80-as-model-competition-shifts-toward-cost)). Codex CLI climbed from 91 to 98, gaining one point per day. After tying Cursor at 97 yesterday, it broke through today for a historic first overtake. The 10x reduction in auto-review costs is the primary driver. Cursor remains steady at 97 with its iPad launch and Router rollout providing support, but terminal-first developers are noticeably migrating.

## Claude Code: v2.1.221 — Focus View Ships, 39 Changes

Claude Code v2.1.221 shipped on August 3([GitHub](https://github.com/anthropics/claude-code/releases/tag/v2.1.221)). The headline feature is "Focus View" for VSCode — a chat-menu toggle that hides tool activity behind an expandable per-turn summary with a live running-tool indicator, toggled with Ctrl+Alt+F. A new "mask" mode for sandbox credential files on Linux/WSL was also added. The release includes 39 total CLI changes, with bug fixes for a startup hang with the Chrome extension, a 300ms delay on Settings tabs, and background session resume issues.

## Anthropic: $10B Volta Deal — Opus 4.1 Permanent Retirement Tomorrow

Anthropic secured a $10 billion, six-year computing capacity deal with Volta, an Nvidia-backed AI cloud startup([Anthropic](https://www.anthropic.com/news)). This is the fourth major infrastructure agreement following SpaceX Colossus (May 6), AMD $5B (Jul 22), and Akamai $1.8B (May 8). Claude Opus 4.1 permanently retires from the API tomorrow, August 5, and migration to Opus 4.8 is mandatory([Anthropic](https://platform.claude.com/docs/en/about-claude/model-deprecations)). Separately, Anthropic experienced a ~40-minute error rate spike and a 15-minute Sonnet 5 performance degradation yesterday (Aug 3), both resolved([StatusGator](https://statusgator.com/services/anthropic)).

## GitHub Copilot: Major Model Deprecations Sept 1, Microsoft Super App Imminent

GitHub will deprecate multiple models across all Copilot experiences on September 1([GitHub Changelog](https://github.blog/changelog/2026-07-31-upcoming-august-2026-model-deprecations-in-github-copilot/)). Claude Sonnet 4.6 will remain available only for individual annual plan subscribers. Satya Nadella confirmed on the July 29 earnings call that a unified "super app" combining Copilot Chat, GitHub Copilot, Cowork, and AutoPilot agents will launch by end of summer([TechWeez](https://techweez.com/2026/07/30/microsoft-unified-copilot-app-2026/)).
