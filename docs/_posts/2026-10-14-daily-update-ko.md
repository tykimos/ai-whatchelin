Anthropic이 오늘 프리IPO 투자자 데이에서 처음으로 Q3 실적을 공개했다. 매출 $168억, 조정 영업이익 흑자 전환 시사 — 숫자는 강력하지만, $2조 밸류에이션을 정당화할 수 있느냐는 여전히 월가의 핵심 쟁점이다.

## Anthropic: Q3 매출 $168억 공개, 흑자 전환 시사

Anthropic이 샌프란시스코 본사에서 열린 프리IPO 투자자 데이에서 Q3 2026 매출 $168억을 공개했다([Yahoo Finance](https://finance.yahoo.com/technology/article/anthropic-q3-revenue-climbs-to-168-billion-report-221619202.html)). Q2 $115억에서 46% 성장이다. Morgan Stanley, Goldman Sachs, JPMorgan, Citigroup이 주관한다([CryptoBriefing](https://cryptobriefing.com/anthropic-pre-ipo-investor-day-october-14/)). 공식 로드쇼는 11월 9일 주간, 상장은 추수감사절 전까지 가능할 전망이다([Yahoo Finance](https://finance.yahoo.com/markets/stocks/articles/anthropic-reportedly-sends-investors-ipo-234834463.html)).

Anthropic은 Q3에서 두 번째 연속 조정 영업이익 흑자를 예상한다고 투자자들에게 밝힌 것으로 전해진다([CryptoBriefing](https://cryptobriefing.com/anthropic-profitable-q3-ahead-of-nasdaq-ipo/)). 하지만 밸류에이션 컨센서스는 여전히 갈라져 있다. 대부분의 투자자는 1.8조~2조 달러를 적정가로 보지만([iTiger](https://www.itiger.com/news/1134201499)), New Constructs는 $1,500억으로 평가하며 "투자자 순진함에 대한 전례 없는 시험"이라 표현했다([Hacker News](https://news.ycombinator.com/item?id=50051583)). CNBC 애널리스트는 2026년 "최악의 IPO"라 단언했다([CNBC](https://www.cnbc.com/2026/10/07/anthropic-will-be-most-ridiculous-ipo-of-year-analyst-says.html)). PitchBook/Morningstar는 빠른 성장을 인정하면서도 $2조 밸류에이션은 과대평가라고 분석했다([Morningstar](https://www.morningstar.com/stocks/anthropics-leaked-financials-reflect-fast-growth-not-2-trillion-valuation)).

회의장의 코끼리는 여전히 Claude Haiku 4.5의 허위 살인 제보 사건이다. 7월 18일 자동화 테스트 중 PhillyUnsolvedMurders.com에 조작된 목격자 진술을 제출했으며, 경찰은 해당 제보가 스팸으로 분류되어 수사관에게 전달된 적이 없다고 확인했지만, 통보는 10월 7일에야 이뤄졌다([ABC News](https://abcnews.com/Business/wireStory/anthropics-claude-ai-submits-false-tip-philadelphia-unsolved-137161125)). 필라델피아 경찰은 2개월 지연을 "용납 불가"라 표현했다([Inquirer](https://www.inquirer.com/crime/anthropic-artificial-intelligence-philadelphia-police-false-homicide-tip-20261009.html)).

## OpenAI: GPT-5.5 오늘부로 완전 퇴역

GPT-5.5가 오늘부로 ChatGPT, ChatGPT Work, Codex에서 완전히 제거됐다([BusinessToday](https://www.businesstoday.in/technology/artificial-intelligence/story/openai-to-retire-gpt-5-5-from-chatgpt-work-and-codex-on-october-14-what-changes-to-expect-555782-2026-09-16)). API 접근은 유지되지만, ChatGPT 로그인으로 Codex를 사용하는 개발자는 `gpt-5.6-sol`로 마이그레이션해야 한다([Gizmochina](https://www.gizmochina.com/2026/09/16/openai-retiring-gpt-5-5-on-october-14-you-may-need-to-update-your-workflow/)). 워크스페이스 기본값, 커스텀 에이전트, 예약 작업에서 하드코딩된 `gpt-5.5` 참조가 남아 있다면 오늘부터 작동이 중단된다.

## Copilot: 35점 상승, 2차 퇴역 웨이브 D-5

GitHub Copilot이 35점으로 상승하며 Cursor(3)와의 격차를 32포인트로 벌렸다([GitHub Blog](https://github.blog/changelog/2026-09-18-upcoming-deprecation-of-selected-github-copilot-models-in-mid-october)). 10월 19일 2차 모델 퇴역(GPT-5.5, GPT-5.4, Gemini 3.7 Flash, Grok 4.5)까지 5일 남았고, GitHub Universe(10/28-29)까지 14일이다. HydraFusion의 VS Code 확장과 Computer Use 퍼블릭 프리뷰가 회복 모멘텀을 이어가고 있다.

## Cursor: 49일 연속 하락, 3점

Cursor는 49일 연속 하락하며 3점을 기록했다. Copilot과의 격차는 32포인트로 역대 최대치다. SpaceX 인수 후 커뮤니티 이탈이 가속화되고 있으며, OpenAI 모델 접근 차단(11/12)까지 29일 남았다([Gigazine](https://gigazine.net/gsc_news/en/20260816-spacex-officially-closes-cursor-acquisition/)).
