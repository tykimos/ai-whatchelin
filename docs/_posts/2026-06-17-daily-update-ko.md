Cursor가 코드 에디터를 넘어 플랫폼 전쟁으로 확전했다. 오늘 Compile 컨퍼런스에서 발표된 Origin은 AI 에이전트를 일급 시민으로 설계한 git 호스팅 플랫폼으로, GitHub의 독점적 지위에 정면 도전하는 행보다.

## Cursor Origin: GitHub의 대항마 등장

Cursor가 Compile 컨퍼런스에서 에이전트 퍼스트 git 호스팅 플랫폼 Origin을 공개했다([AlphaSignal](https://alphasignal.ai/news/cursor-s-origin-takes-on-github-with-ai-agent-scale-git-hosting)). Graphite 인수 기술을 기반으로 구축된 Origin은 AI가 자동으로 머지 충돌을 해결하고, 코드 리뷰와 머지 상태가 기계 판독 가능하도록 설계됐다. 데모에서는 초당 22.6 커밋 처리를 시연했다([explainx.ai](https://explainx.ai/blog/cursor-origin-git-hosting-github-alternative-ai-agents-2026)). SpaceX의 $600억 인수와 결합하면, Cursor는 단순 에디터에서 코드 작성-호스팅-리뷰를 아우르는 풀스택 개발 플랫폼으로 진화하는 셈이다. 2026년 가을 출시 예정, cursor.com에서 대기자 명단을 받고 있다.

## Gemini CLI: D-1, 최종 카운트다운

내일 6월 18일부터 Gemini CLI의 `gemini` 명령어가 개인 사용자에게 에러를 반환한다([DigitalApplied](https://www.digitalapplied.com/blog/gemini-cli-to-antigravity-cli-migration-june-18-2026-guide)). CI/CD 파이프라인, 셸 스크립트, cron 작업 등 모든 자동화가 내일부터 깨진다. 대체제인 Antigravity CLI(`agy`)로의 전환이 가능하나, 오픈소스가 아닌 점과 주간 컴퓨트 캡 적용이 기존 무료 일 1,000회 호출 대비 다운그레이드라는 비판이 이어지고 있다([Linux Foundation](https://www.linuxfoundation.org/blog/gemini-cli-bait-and-switch)).

## Anthropic 집단소송: Max 플랜 "허위 사용량" 논란

6월 14일 캘리포니아 북부 연방법원에 집단소송이 제기됐다([Engadget](https://www.engadget.com/2194626/anthropic-hit-with-lawsuit-over-its-claude-max-usage-limits/)). Max 5x($100/월)와 Max 20x($200/월) 플랜이 광고된 사용량에 미달한다는 주장으로, Hacker News에서는 $100 플랜으로 30일간 API 환산 $1,850 상당 사용 경험이 공유되며 논쟁이 벌어졌다([Gizmodo](https://gizmodo.com/anthropic-accused-of-misleading-users-over-soaring-ai-costs-in-new-lawsuit-2000772061)).

## Copilot: 44주 연속 하락, 39점

GitHub Copilot이 39를 기록하며 44주 연속 하락세를 이어갔다([GitHub Community](https://github.com/orgs/community/discussions/192948)). 사용량 기반 과금 전환 17일째로, 시장점유율이 67%에서 51%로 하락했다([CNBC](https://www.cnbc.com/2026/05/22/github-copilot-outages-security-breaches.html)). Cursor Origin의 등장은 GitHub에 또 하나의 경쟁 압력이 된다.

## Fable 5: 정지 5일째, 복원 불투명

Claude Fable 5가 미 상무부 수출 통제 지시로 정지된 지 5일째다([Appwrite](https://appwrite.io/blog/post/claude-fable-5-and-mythos-5-access-suspended)). David Sacks가 "가능한 빨리" 복원을 시사했지만([FableRadar](https://fableradar.live/)), Polymarket 기준 6월 내 복원 확률은 약 35%에 머물고 있다([Polymarket](https://polymarket.com/event/claude-fable-5-restored-for-us-customers-by-20260613193753196)).
