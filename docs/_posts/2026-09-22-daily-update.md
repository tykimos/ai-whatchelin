xAI released Grok 4.7 yesterday (Sept 21). At 2.1 trillion parameters — a 40% jump over Grok 4.6 — it nearly doubled its Terminal-Bench 4.0 score from 20.3% to 38.0% ([DataCamp](https://www.datacamp.com/blog/grok-4-7)). Pricing stays at $2/$6 per MTok, matching Grok 4.6, and it's available immediately in Cursor, Grok Build, and the xAI API with no waitlist ([SQ Magazine](https://sqmagazine.co.uk/xai-launches-grok-4-7-coding-model/)). The coding benchmark race just got tighter.

## Grok 4.7: Terminal-Bench Doubled, Still Trailing Fable on CursorBench

Grok 4.7 posted 71.0% on DeepSWE v1.1 (up from 65.2%) and 46.3% on CursorBench 4.0, still slightly behind Fable 5.1 ([iWeaver](https://www.iweaver.ai/blog/grok-4-7/)). The biggest leap came on Terminal-Bench 4.0, which measures multi-hour terminal tasks, where it hit 38.0% — nearly double its predecessor's 20.3% ([LLM Stats](https://llm-stats.com/blog/research/grok-4-7-launch)). Musk confirmed 2.1T parameters, a 40% increase from Grok 4.6's 1.5T ([Android Headlines](https://www.androidheadlines.com/2026/09/grok-4-7-ai-launch-coding-upgrades-pricing.html)).

## Cursor: Day 33 Decline, 47 — OpenAI Cutoff D-51

Cursor fell from 49 to 47, marking 33 consecutive days of decline ([TechCrunch](https://techcrunch.com/2026/08/15/spacex-officially-closes-its-cursor-acquisition/)). With OpenAI's model cutoff 51 days away on November 12, Cursor claims OpenAI models account for only 5% of traffic, but market sentiment keeps eroding ([CNBC](https://www.cnbc.com/2026/08/29/openai-cursor-spacex-model-access.html)). The Projects beta and Origin Code Hosting from the acquired Graphite team remain as potential turnaround cards.

## Copilot Unified Experience D-6 — Code Review Default Shift Imminent

Starting September 28, Copilot Chat, Mobile, and Cloud Agent merge into a single unified experience ([GitHub Blog](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)). Code review defaults switch from Lite to Balanced, increasing token consumption — organizations need to explicitly select Lite before that date to keep costs unchanged.

## Codex CLI v0.155.1: Voice Chat and Touch ID

Codex CLI added experimental `/voice` conversations with live transcripts and microphone controls ([Releasebot](https://releasebot.io/updates/openai/codex)). Speak an instruction, review the transcript, then approve execution. On Mac, Touch ID verification for MCP requests is now available. The follow-up v0.155.1 fixed reasoning summary defaults for provider compatibility ([Releasebot](https://releasebot.io/updates/openai/codex)).
