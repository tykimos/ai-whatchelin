Anthropic will effectively cut Claude Code's weekly usage limits by 17% starting September 14, ending a temporary 50% promotion and replacing it with a permanent 25% increase over pre-promotion levels ([BleepingComputer](https://www.bleepingcomputer.com/news/artificial-intelligence/anthropic-is-cutting-claude-codes-current-weekly-limits-by-17-percent/)). The change affects Pro, Max, Team, and Enterprise tiers ([Android Headlines](https://www.androidheadlines.com/2026/08/anthropic-claude-code-weekly-limits-update.html)). Anthropic frames it as a "25% permanent increase," but the community was quick to note the math: relative to current levels, it's a 17% reduction ([Claude Lab](https://claudelab.net/en/articles/claude-code/claude-code-weekly-limit-change-september-14-percent-math)).

## McKinsey: 32% of Enterprises Skipping Software Purchases to Build Internally

McKinsey's 2026 State of AI survey found that 32% of surveyed organizations have decided against purchasing software products because they could build the functionality with agentic coding tools ([Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/build-vs-buy-shift-32-113806700.html)). Among "high performers" — the 6% deriving 5%+ of EBIT from AI — nearly half have forgone purchases ([McKinsey](https://www.mckinsey.com.br/capabilities/quantumblack/our-insights/the-state-of-ai)). This trend threatens to reshape the entire SaaS revenue model ([ANI News](https://aninews.in/news/business/ai-coding-agents-threaten-to-reshape-software-spending-as-companies-choose-to-build-rather-than-buy-mckinsey20260906210256/)).

## Cognition AI: $2B Series E at $48B Valuation

Cognition AI, parent company of Devin and Windsurf, closed its $2B Series E co-led by Andreessen Horowitz and Accel ([TechCrunch](https://techcrunch.com/2026/09/08/cognition-hits-48b-valuation-signaling-investors-believe-ai-coding-is-far-from-a-winner-take-all-market/)). The valuation nearly doubled from $26B in just four months, with run-rate revenue surging to approximately $900M ([Unite.AI](https://www.unite.ai/cognition-raises-over-2b-series-e-at-48b-valuation-to-scale-devin-agents/)). Enterprise customers now include Citi, Goldman Sachs, NASA-JPL, and the U.S. Navy ([ITdaily](https://itdaily.com/news/business/cognition-raises-2-dollars-billion/)).

## GitHub Copilot: 9/28 Unified Relaunch + 10/2 Model Swap

GitHub Copilot will merge Chat, Mobile, and Cloud Agent into a single unified experience on September 28 ([GitHub Changelog](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)). The default code review level shifts from Lite to Balanced, likely increasing AI credit consumption. On October 2, Gemini 3.5/3.6 Flash, Kimi K2.7 Code, and Claude Opus 4.7 retire in favor of Gemini 3.8 Flash, Kimi K3, and Claude Opus 5 ([GitHub Changelog](https://github.blog/changelog/2026-07-31-upcoming-august-2026-model-deprecations-in-github-copilot/)). Whether Copilot can bounce from its score-1 floor depends on how the 9/28 relaunch lands.

## OpenHands 1.0: First Production Release for Open-Source Coding Agent

OpenHands reached its 1.0 milestone with production-ready Docker sandboxing and a plugin system ([DEV Community](https://dev.to/jamilxt/openhands-just-hit-10-heres-how-to-run-it-on-your-own-machine-without-handing-over-the-keys-5666)). It scores 68% on SWE-bench Verified at $0.20–$1.05 per task on self-hosted hardware — a fraction of commercial agents. Paired with McKinsey's build-vs-buy data, the open-source coding agent camp is emerging as a credible third force.

## Cursor: Score 71, 14th Consecutive Decline — D-64

Cursor dropped to 71, extending its decline to 14 straight days and 28 points total from its August 27 peak of 99. On the product side, Cursor added self-hosted machines and computer use on Linux and Mac for browser and desktop control ([Cursor Blog](https://cursor.com/blog)). With the OpenAI model cutoff (November 12) now 64 days away, Fable 5.1's 73.4% coding benchmark score — the best any model has achieved on Cursor — suggests Anthropic integration may paradoxically lift model quality post-departure.
