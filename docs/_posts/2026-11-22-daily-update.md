Microsoft entered the AI coding model race at Ignite 2026, shipping MAI Code 2 and its lighter sibling MAI Code 2 Flash([InfoWorld](https://www.infoworld.com/article/4250152/microsoft-launches-mai-code-2-models-to-challenge-openai-and-anthropic-in-ai-coding.html)). Code 2 targets complex multi-file debugging and repo-wide reasoning, while Flash handles frequent routine edits. Microsoft claims Code 2 achieves 98% of GPT-6.1 Sol's performance at 40% of the price, averaged across four coding benchmarks([TNW](https://thenextweb.com/news/microsoft-mai-code-2-licensed-weights-ignite)).

## Microsoft: MAI Code 2 Changes the Game

Code 2 is immediately available in GitHub Copilot, and trusted customers can license the model weights for customization([The New Stack](https://thenewstack.io/microsoft-mai-code-2/)). Flash claims parity with GPT-6 Luna at 65% cost and Claude Haiku 5.5 at 20%. Output token pricing sits at $2.50–$5/M, making it attractive for enterprise-volume usage. The caveat: performance figures come from Microsoft's own benchmarks, and the pricing comparison uses a launch discount that expires May 2027.

## Google Stitch Loop: The Agent That Never Stops Shipping

Google Labs announced Stitch Loop on November 18 — a long-running product agent that connects to your GitHub codebase and live metrics (logs, user behavior, feedback) to automatically detect security, latency, and accessibility issues and open pull requests([Google Blog](https://blog.google/innovation-and-ai/models-and-research/google-labs/stitch-loop/)). It supports 180+ integrations and custom MCP servers, with human approval required for every PR([FourWeekMBA](https://fourweekmba.com/?p=311350)). Currently waitlist-only, with Google AI Ultra subscribers getting priority access.

## Gemini 4 Neon: Day 5 of the Budget Coding Model

Google's Gemini 4 Neon hits day 5 since launch. At $3/M input and $15/M output tokens, it ranked #3 on the Artificial Analysis Intelligence Index with a score of 61 at xhigh thinking([eWeek](https://www.eweek.com/news/google-gemini-4-neon-ai-coding-costs/)). Google positions Neon as competitive with Claude Opus 5.5 and GPT-6.2 Sol at a lower price point([Digital Trends](https://digitaltrends.com/computing/google-says-gemini-4-neon-can-hang-with-claude-opus-5-5-and-gpt-6-2-sol-for-less)).

## ANT IPO: Post-Debut Momentum

Anthropic's November 19 Nasdaq debut under ticker ANT surged 30–38% on day one([Al Jazeera](https://www.aljazeera.com/economy/2026/11/19/anthropic-starts-trading-in-the-us-after-blockbuster-ipo), [Saxo](https://www.home.saxo/en-gb/content/articles/equities/anthropic-debut-uk-19112026)). The IPO raised $81.3B, with total fundraising including a private placement reaching $107.3B — a record([Stocktwits](https://stocktwits.com/news-articles/markets/equity/anthropic-stock-jumps-38-in-nasdaq-debut-after-record-107-3-b-ipo/cNbihePR900)). Amazon and Google hold approximately 28.4% post-IPO, and insiders can sell up to 10% of locked-up shares from day one.
