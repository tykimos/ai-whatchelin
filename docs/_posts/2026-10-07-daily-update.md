GitHub Copilot has finally overtaken Cursor. After 85 weeks pinned at a floor of 1, Copilot climbed to 21 while Cursor — in freefall since the SpaceX acquisition — dropped to 17 on its 41st consecutive day of decline. It's the first time Copilot has sat above Cursor since 2025, and the crossover marks a structural shift in the AI coding tool landscape.

## GitHub Copilot: The Structural Rebound

Copilot's climb isn't just momentum — it's feature-driven. The Code Review API went GA on October 2, enabling programmatic code review via REST and GraphQL with the default effort level raised from Lite to Balanced([GitHub Changelog](https://github.blog/changelog/2026-10-02-copilot-code-review-api-support-and-new-default-effort-level)). HydraFusion multi-model orchestration expanded from CLI-only to VS Code and the Copilot app([IT Brief](https://itbrief.co.uk/story/github-launches-hydrafusion-preview-for-copilot-coding)), and Computer Use hit public preview, letting agents automate desktop apps on macOS and Windows([GitHub Changelog](https://github.blog/changelog/2026-10-01-github-copilot-can-now-interact-with-desktop-apps)). A second model deprecation wave is scheduled for October 19, retiring GPT-5.5, GPT-5.4, Gemini 3.7 Flash, and Grok 4.5 in one sweep([GitHub Changelog](https://github.blog/changelog/2026-09-18-upcoming-deprecation-of-selected-github-copilot-models-in-mid-october/)).

## Cursor: What D-36 Means

Cursor has 36 days left until OpenAI cuts off model access on November 12. Despite announcing a frontier model and the Origin platform at Compile 2026, market confidence hasn't recovered([DevOps.com](https://devops.com/openai-cuts-off-cursors-model-access-after-spacex-acquisition/)). At 17, Cursor is at its lowest score this year.

## Anthropic: One Week to IPO Day — The Weight of $2 Trillion

Anthropic's pre-IPO investor day is October 14, exactly one week away. According to the FT, investors project a $2 trillion-plus valuation, which would surpass SpaceX's $1.77 trillion listing to become the largest IPO in history([PYMNTS](https://pymnts.com/news/artificial-intelligence/2026/anthropic-could-seek-2-trillion-valuation-in-record-ipo)). Some backers project an annualized revenue run rate of $100–120 billion by year-end([Trending Topics](https://www.trendingtopics.eu/anthropic-investors-expect-ipo-valuation-of-2-trillion-more-than-spacex/)). Claude Code remains the primary growth engine driving enterprise ARR.

## Codex: Daily Sprint Continues

OpenAI's Codex team is on Day 8 of its four-week daily improvement sprint([OpenAI Community](https://community.openai.com/t/video-meet-the-new-codex-cli-updates/1403548)). The Pro 500 plan ($500/month) offers Ultrafast mode at 300 tokens per second, and GPT-6.1 Sol is settling in at one-fifth of Astra's cost([Nerdschalk](https://nerdschalk.com/gpt-6-1-sol-price-availability/)).
