The AI coding tool market is bracing for a pivotal weekend. GitHub Copilot's unified experience launches tomorrow (Sep 28), OpenAI DevDay follows the day after (Sep 29), and Cognition just became a $48B company — three seismic events converging in 48 hours.

## OpenAI DevDay D-2: The "o" Agent and Pro Max at $500/Month

OpenAI DevDay (Sep 29, Fort Mason, San Francisco) is two days away ([OpenAI](https://openai.com/index/devday-2026/)). Sam Altman opens the keynote, which will be livestreamed for free, with roughly a dozen product announcements expected. The always-on "o" agent, a GPT-6 Cyber security model preview, and the Pro Max $500/month plan are the headline items ([Forbes](https://www.forbes.com/sites/jonmarkman/2026/09/21/openai-plans-to-introduce-managed-agents-at-devday-2026/)). GPT-6 Cyber would be OpenAI's fourth security model of 2026 ([Crypt0's News](https://www.crypt0snews.com/news/2026-09-25-openai-s-september-29-devday-brings-a-fourth-security-model-.html)).

## GitHub Copilot: Unified Experience Launches Tomorrow

Starting September 28, GitHub will merge Copilot Chat on github.com, Copilot Chat in GitHub Mobile, and the Copilot cloud agent into a single unified experience ([GitHub Blog](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)). Separate policies will collapse into one, enabled by default. Chat data retention extends from 28 days to account lifetime, and code review defaults shift from Lite to Balanced ([C# Corner](https://www.c-sharpcorner.com/article/preparing-for-the-github-copilot-unified-experience-coming-september-28)). New models including Claude Opus 5.5, GPT-6 Sol, GPT-6 Luna, and Grok 4.7 have also been added ([GitHub Changelog](https://github.blog/changelog/2026-09-25-github-copilot-weekly-releases-september-21/)).

## Cognition: $48B Valuation, $1B ARR Milestone

Cognition closed its Series E on September 8, raising over $2B at a $48B valuation ([TechCrunch](https://techcrunch.com/2026/08/12/ai-coding-startup-cognition-reportedly-already-in-talks-to-raise-at-40b-valuation/)). As of September 25, the company has hit $1B in annualized revenue — more than doubling from $492M in May. SWE-2, its next-generation software engineering model, is rolling out as a research preview ([Devin Docs](https://docs.devin.ai/release-notes/overview)), while GPT-6 Astra integration has significantly improved automated testing quality ([OpenAI](https://openai.com/index/cognition-devin-testing-with-astra/)).

## Claude Code: /buddy Backlash Amid Fable 5.1 Dominance

Claude Code holds the #1 spot in LogRocket's AI dev tool rankings, with Fable 5.1 posting the highest WebDev Arena score of any model in any tool ([LogRocket](https://blog.logrocket.com/ai-dev-tool-power-rankings/)). However, the removal of the /buddy feature has sparked fierce community backlash — Issue #45596 has drawn 270 comments and 1,184 upvotes, making it one of the most heated discussions in the project's history.

## Cursor: 39th Straight Day of Decline, Drops to 37

Cursor fell to 37, marking its 39th consecutive day of decline. Since the SpaceX acquisition closed on August 14, Cursor has shed 62 points from its 99 peak, with OpenAI model access termination (Nov 12) now D-46 away ([CNBC](https://www.cnbc.com/2026/08/29/openai-cursor-spacex-model-access.html)). Agent harness optimizations cut token costs by 7% ([Cursor Changelog](https://cursor.com/changelog)), but the exodus shows no sign of reversing.

## Codex CLI: v0.157.0 Stable Release Adds Conversation Forking

Codex CLI shipped v0.157.0 stable on Sep 25 ([GitHub](https://github.com/openai/codex/releases)). Key additions include GPT-6 Sol/Luna Amazon Bedrock support, fullscreen transcripts enabled by default, and automatic background-server startup for eligible sessions. The standout feature is conversation forking (f shortcut), which lets developers clone an active conversation from another app and continue it seamlessly. A Windows stability patch (v0.157.1) followed on Sep 26.
