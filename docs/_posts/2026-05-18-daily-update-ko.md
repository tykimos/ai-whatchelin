AI 코딩 도구 시장이 사상 최대의 '슈퍼 먼데이'를 앞두고 숨을 고르고 있다. 내일(5월 19일) Google I/O 키노트에서 새 Gemini 모델 발표가 유력하고([Android Authority](https://www.androidauthority.com/what-to-expect-from-google-io-2026-3664979/)), 같은 날 Anthropic의 Code with Claude London이 종일 개발자 컨퍼런스로 열리며([claude.com](https://claude.com/code-with-claude/london)), Musk v. Altman 배심원 심리도 시작된다([TechTimes](https://www.techtimes.com/articles/316675/20260515/openai-jury-begin-deliberations-monday-judge-weighs-altman-removal-500b-restructure-reversal.htm)). 여기에 두 가지 굵직한 발표가 더해졌다.

## xAI: Grok Build 베타 출시 — 코딩 에이전트 전쟁 참전

Elon Musk의 xAI가 첫 코딩 에이전트 **Grok Build**를 베타로 출시하며 본격적으로 개발자 시장에 뛰어들었다([Engadget](https://www.engadget.com/2173482/xai-coding-agent-grok-build/)). Grok Build는 최대 8개 AI 에이전트를 동시에 실행하는 3단계(계획→검색→빌드) 워크플로우를 지원하며, 기반 모델은 **Grok 4.3 beta**(16에이전트 Heavy 아키텍처, 200만 토큰 컨텍스트)다([Dataconomy](https://dataconomy.com/2026/05/15/xai-launches-grok-build-coding-agent-for-developers/)). SWE-Bench Verified 70.8%로 Codex(79%)나 Claude Code(87.6%)에는 미치지 못하지만, 초기 베타치고는 인상적이다. 현재 SuperGrok Heavy 구독자($300/월, 프로모 $99/월)에게만 제공된다([eWeek](https://www.eweek.com/news/xai-grok-build-coding-agent/)). Musk가 직접 X에서 베타 테스터를 모집하며 공세를 펼치고 있다([Slashdot](https://developers.slashdot.org/story/26/05/17/0214254/elon-musks-xai-launches-grok-build-its-first-ai-coding-agent)).

## OpenAI + Dell: Codex 엔터프라이즈 온프레미스 배포

OpenAI와 Dell Technologies가 Codex를 하이브리드·온프레미스 엔터프라이즈 환경에 배포하는 파트너십을 발표했다([OpenAI](https://openai.com/index/dell-codex-enterprise-partnership/)). Dell AI Data Platform과 Codex를 연결해, 기업 내부 코드베이스·문서·운영 지식에 Codex를 직접 적용할 수 있게 된다([SiliconANGLE](https://siliconangle.com/2026/05/18/dell-targets-enterprise-ai-execution-gap-local-agentic-ai-systems-integrated-ai-infrastructure/)). Codex 주간 사용자 400만 명을 돌파한 가운데, 코드 리뷰·테스트 커버리지를 넘어 리드 검증·보고서 작성 등 비코딩 업무까지 확장되고 있다.

## Google I/O: Gemini Omni 유출 + Gemini 4 기대감 최고조

Google I/O 키노트가 5월 19일 오전 10시(PT)에 시작된다([io.google](https://io.google/2026/)). Gemini 4.0 발표 여부는 아직 불확실하지만, Gemini 3.2 또는 3.5 업데이트가 유력하다([NokiaPowerUser](https://nokiapoweruser.com/google-io-2026-gemini-spark-omni-gemini-3-5-rumors/)). **Gemini Omni** — 동영상 리믹스·인채팅 편집·템플릿 기반 생성이 가능한 비디오 AI 모델이 사전 유출됐다([Lovegen](https://lovegen.ai/blog/gemini-omni-leak-google-io-2026)). 'Gemini Spark', 'Team Food' 메모리 시스템 등 내부 코드네임도 속속 드러나고 있다([MindStudio](https://www.mindstudio.ai/blog/google-io-2026-leaks-codenames-features)).

## Code with Claude London: 3트랙·확장 세션까지

Anthropic의 Code with Claude London이 내일(5/19) 종일 진행된다([claude.com](https://claude.com/code-with-claude/london)). **Research**·**Claude Platform**·**Claude Code** 3개 트랙으로 구성되며, MCP(Model Context Protocol)가 핵심 주제다([AI Expert Magazine](https://www.aiexpertmagazine.com/anthropic-code-with-claude-2026-everything-you-need-to-know/)). 5/20 인디 개발자 확장 세션 별도 개최([claude.com](https://claude.com/code-with-claude/london-extended)).

## Cursor 3.4 + GitHub Copilot 14주 연속 하락

Cursor 3.4에서 **/multitask** 병렬 서브에이전트와 **인터랙티브 캔버스**가 추가됐다([Cursor Changelog](https://cursor.com/changelog)). Copilot 인기도는 69로 14주 연속 하락 — 6/1 사용량 과금 전환 D-14, 가입 중단이 지속된다([GitHub Blog](https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/)).
