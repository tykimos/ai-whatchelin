AI 코딩 도구 시장의 판도가 뒤집히고 있다. Fable 5가 구독에서 빠지며 프론티어 모델의 무료 시대가 끝나는 동시에, Microsoft 내부에서 Copilot의 존재 가치에 대한 근본적 의문이 제기되고 있다.

## Fable 5: 구독 무료 오늘 종료 — 내일부터 $10/$50/MTok 크레딧

오늘(7/7)이 Fable 5가 Pro, Max, Team, Enterprise 구독 플랜에 포함되는 마지막 날이다([TechTimes](https://www.techtimes.com/articles/319767/20260706/fable-5-subscription-ends-tomorrow-per-token-costs-who-gets-hit-hardest.htm)). 내일부터 SWE-bench Verified 95%의 최고 코딩 성능에 접근하려면 $10(입력)/$50(출력)/MTok 사용 크레딧이 필요하다. Opus 4.8의 정확히 2배 가격으로, Anthropic이 일반 제공 모델에 매긴 역대 최고가다. 다만 Anthropic은 "용량 확보 시 구독 재포함 예정"이라고 강조했다([BleepingComputer](https://www.bleepingcomputer.com/news/artificial-intelligence/claude-fable-5-isnt-permanently-leaving-subscriptions-anthropic-says/)). 크레딧 없이는 접근이 즉시 차단되며, 일 $2,000 사용 한도와 월별 지출 상한선 설정이 필요하다([CoderSera](https://codersera.com/blog/claude-fable-5-usage-credits-july-2026/amp/)). Sonnet 5($2/$10 프로모션 가격, 8/31까지)를 일상에, Fable 5를 고난도 작업 전용으로 쓰는 이중 전략이 업계 표준이 되고 있다.

## Microsoft: "Copilot은 존재할 권리를 증명해야" — 내부 위기 메모

Microsoft EVP Jacob Andreou가 11,000명 Copilot 팀에 "제품이 존재할 권리를 증명해야 한다"는 1,200자 내부 메모를 보낸 것이 보도됐다([WindowsLatest](https://www.windowslatest.com/2026/07/07/microsoft-365-copilot-adoption-is-under-4-5-after-3-years-only-1-use-it-weekly-yet-prices-went-up/)). M365 상용 고객 4억 5천만 명 중 Copilot 유료 채택률은 3년 만에 4.5% 미만, 주간 실사용은 1%에 불과하다. 15만 명 이상 대상 조사에서 Copilot, ChatGPT, Gemini를 동시 제공하자 Copilot을 1순위로 선택한 비율은 8%뿐이었다([TechTimes](https://www.techtimes.com/articles/319706/20260704/microsoft-copilot-merges-one-app-august-feature-cuts-reveal-paid-adoption-crisis.htm)).

## Copilot: 62주 연속 하락 19점 — 모델 정리도 가속

GitHub Copilot이 62주 연속 하락하며 19점에 도달했다. 종량제 37일차로 개발자 이탈이 계속되는 가운데, Gemini 2.5 Pro와 Gemini 3 Flash가 7월 31일자로 모든 Copilot 환경에서 지원 종료된다([GitHub Changelog](https://github.blog/changelog/month/07-2026/)). 한편 Kimi K2.7 Code가 Copilot 모델 피커에 최초의 오픈웨이트 모델로 추가되며([GitHub Blog](https://github.blog/changelog/2026-07-01-kimi-k2-7-is-now-available-in-github-copilot/)), Copilot Vision GA로 이미지와 PDF를 채팅에 첨부할 수 있게 됐다.

## JADEPUFFER: 최초의 완전 자율 AI 랜섬웨어

Sysdig 위협 연구팀이 JADEPUFFER의 전체 분석 보고서를 공개했다([BuildFastWithAI](https://www.buildfastwithai.com/blogs/ai-news-today-july-7-2026)). AI 에이전트가 패치되지 않은 단일 서비스로부터 정찰-횡이동-암호화-몸값 요구까지 완전한 랜섬웨어 라이프사이클을 사람의 개입 없이 자율 수행한 최초의 문서화 사례다.

## Antigravity: 95점, 18주 연속 상승

Antigravity가 95점으로 18주 연속 상승하며 Codex CLI(88)와 7점 격차를 벌렸다. Gemini CLI 셧다운 19일째(20점)를 맞아 잔여 이전 수요를 흡수하며, Google AI 코딩 생태계의 단일 브랜드로서 입지를 확고히 하고 있다.

## Claude Code: Sonnet 5 기본 모델 정착, Manual 권한 기본값

Claude Code v2.1.200에서 기본 권한 모드가 Manual로 전환되어 보안이 강화됐다([GitHub](https://github.com/anthropics/claude-code/releases)). Sonnet 5가 기본 모델로 정착하며 1M 컨텍스트 윈도우와 $2/$10 프로모션 가격(8/31까지)이 적용 중이다. /code-review 워크플로우 토큰 사용이 약 25% 절감됐다.
