GitHub Copilot이 52주 연속 인기도 하락을 기록하며 30점에 도달했다. 정확히 1년 전인 2025년 6월 말 90점대에서 시작된 하락세가 단 한 주도 반등 없이 이어진 것이다. 종량제 과금 26일째를 맞은 가운데 에이전틱 세션당 $30-40의 비용 부담은 여전히 개발자 이탈을 가속화하고 있다([GitHub Discussions](https://github.com/orgs/community/discussions/192948)). 반면 Copilot CLI는 이번 주 탭 터미널 인터페이스 GA를 달성하며 제품력 개선에는 나서고 있다([GitHub Changelog](https://github.blog/changelog/2026-06-23-copilot-cli-new-terminal-interface-is-generally-available/)).

## Fable 5: 차단 14일째, 의회 답변 기한일

Fable 5 수출통제가 14일째에 접어들었다. 오늘 6월 26일은 초당파 의원 4명이 상무장관 Lutnick에게 서면 답변을 요구한 기한일이다([explainx.ai](https://explainx.ai/blog/when-will-fable-5-be-available-again-2026)). 모델 트래픽은 여전히 0으로 확인되며, NSA 국장의 "Mythos가 기밀 시스템을 자율적으로 뚫었다"는 상원 증언이 해제 논의를 복잡하게 만들고 있다([TechTimes](https://www.techtimes.com/articles/318783/20260621/claude-fable-5-resurfaces-android-app-nsa-breach-testimony-reshapes-ban.htm)). 예측시장은 7월 1일 전 복원 확률 57%, 7월 8일 정부 신원인증 정책이 핵심 경로로 부상 중이다.

## Claude Code v2.1.191: /rewind 지원과 안정성 대폭 개선

Claude Code가 v2.1.191로 업데이트되며 대규모 안정성 개선을 완료했다([GitHub Releases](https://github.com/anthropics/claude-code/releases)). `/rewind` 명령어로 `/clear` 이전 시점의 대화를 재개할 수 있게 되었고, 스트리밍 중 CPU 사용량이 37% 감소했다. 중간 연결 끊김 시 부분 응답 보존, WSL2 마우스 휠 스크롤 수정, 백그라운드 에이전트 강제 종료 후 부활 방지 등 실사용 불편이 대거 해소됐다.

## GPT-4.5 내일 은퇴, GPT-5.6은 7월로

GPT-4.5가 내일 6월 27일 ChatGPT에서 공식 은퇴한다([OpenAI Help](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)). 2026년 2월 출시 후 4개월의 짧은 생애를 마감하며, GPT-5와 GPT-5.3-Codex가 완전 대체했다. GPT-5.6의 6월 출시 예측은 완전히 빗나갔다 — Polymarket에서 "6/28까지 미출시" 확률이 81%까지 치솟았고, 7월 중순이 차기 유력 창으로 부상 중이다([Polymarket](https://polymarket.com/event/when-will-gpt-5pt6-be-released)).

## Cursor 3.9: 커스터마이즈 페이지로 도구 통합

Cursor가 3.9 버전에서 플러그인, 스킬, MCP 서버를 하나의 커스터마이즈 페이지로 통합했다([Cursor Changelog](https://cursor.com/changelog)). SpaceX의 $600억 인수가 Q3 마감을 향해 진행 중인 가운데, 제품은 계속해서 SDK 역량 확장과 자동 리뷰 개선을 밀어붙이고 있다.

## Antigravity 84, 9주 연속 상승 — Gemini CLI 반대급부

Antigravity가 84로 상승하며 9주 연속 상승세를 이어갔다. Gemini CLI 셧다운 이후 개인 사용자 이탈이 Antigravity CLI로 직접 흡수되는 구도가 굳어지고 있다. Gemini CLI는 36으로 하락하며 기업 전용 전환 9일째를 맞았다.
