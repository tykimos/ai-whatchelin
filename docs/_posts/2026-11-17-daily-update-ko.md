내일이면 AI 업계 역사상 최대 IPO의 가격이 결정된다. Anthropic이 $70-78 가격 범위에서 825백만 주의 Class A 주식을 Nasdaq ANT 티커 아래 상장하며, 목표 모집 규모는 $610억 — SpaceX에 이어 역대 두 번째다([Renaissance Capital](https://www.renaissancecapital.com/IPO-Center/News/122657/anthropic-sets-terms-for-61-billion-ipo-targeting-a-1.2-trillion-market-cap)). 주문장은 수배 초과 청약 상태이지만, Fortune에 따르면 Anthropic은 시장이 기대했던 것보다 더 큰 할인율로 IPO를 진행하고 있다([Fortune](https://fortune.com/2026/11/10/anthropic-lower-than-expected-ipo-valuation-smart-strategy-or-red-flag/)). 11월 19일 거래 개시가 유력하다([FourWeekMBA](https://fourweekmba.com/ai-anthropics-ipo-day-by-day-pricing-18-nov-trading-19-nov/)).

## GitHub Copilot: 모델 대퇴출 익일, 55일 연속 상승 체제 유지

어제 Claude Opus 4.8, Claude Opus 5, GPT-5.6 Terra가 모든 Copilot 영역에서 제거되었다([GitHub Blog](https://github.blog/changelog/2026-10-15-upcoming-deprecation-of-selected-github-copilot-models-in-mid-november)). 연간 Individual 구독자만 Opus 4.8을 유지하며, 나머지 사용자는 Opus 5.5 또는 GPT-6.1 Sol로 전환 완료해야 한다([dev.classmethod.jp](https://dev.classmethod.jp/en/articles/github-copilot-model-deprecation-nov-2026/)). 대퇴출에도 불구하고 Copilot은 99점을 유지하며 55일 연속 상승 기록을 이어가고 있다. 12월 14일에는 Claude Fable 5, Claude Haiku 4.5, Gemini 3.8 Flash 등 6개 모델이 추가로 퇴출될 예정이다([AI TREND LAB](https://note.com/aitrendlab/n/nc27e6861dd15?hl=en)).

## Claude Code: v2.1.322 Vertex Fast Mode 추가

Claude Code v2.1.322가 출시되어 Vertex AI의 global, us, eu 리전에서 Fast Mode를 지원한다([Havoptic](https://www.havoptic.com/r/claude-code-2.1.322)). Vertex가 Fast Mode를 거부하면 자동으로 표준 속도로 폴백된다. Fable 5.2가 기본 모델로 전환된 지 8일째로, $8/$40/MTok 가격과 1M 컨텍스트 윈도우로 안정적인 운영이 계속되고 있다.

## Cursor: OpenAI 차단 6일째, 86일째 바닥

OpenAI 모델 차단 이후 6일째, Tab 자동완성·자동 모델 선택·클라우드 에이전트 등 핵심 기능이 여전히 비활성 상태다([Tom's Guide](https://www.tomsguide.com/ai/openai-is-leaving-cursor-in-november-here-are-your-3-options)). SpaceX 인수 이후 $29.3B 가치 평가에도 불구하고, 개발자 이탈이 가속화되고 있다. Grok 4.7과 Anthropic 모델에 의존하는 체제로 전환했으나 86일째 바닥(1점)이다.

## Gemini 4 Carbon: 도입 할인 D-13

Gemini 4 Carbon 도입 할인 종료까지 13일 남았다([DEV Community](https://dev.to/aitecharchive/gemini-4-carbon-in-github-copilot-vs-argon-test-by-dec-1-4fc5)). 12월 1일부터 GitHub Copilot 토큰당 가격이 2배로 오르므로, 현재가 테스트 적기다.
