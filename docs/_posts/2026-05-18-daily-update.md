Two more major stories dropped today.

## xAI: Grok Build Beta Launches — Entering the Coding Agent War

Elon Musk's xAI has launched its first coding agent, **Grok Build**, in early beta([Engadget](https://www.engadget.com/2173482/xai-coding-agent-grok-build/)). The tool can spawn up to 8 concurrent AI agents through a three-stage plan→search→build workflow, powered by **Grok 4.3 beta** (16-agent Heavy architecture, 2M token context)([Dataconomy](https://dataconomy.com/2026/05/15/xai-launches-grok-build-coding-agent-for-developers/)). It scores 70.8% on SWE-Bench Verified — behind Codex (79%) and Claude Code (87.6%), but respectable for an early beta. Currently limited to SuperGrok Heavy subscribers at $300/month ($99/month introductory promo)([eWeek](https://www.eweek.com/news/xai-grok-build-coding-agent/)). Musk personally pushed for public beta testers on X([Slashdot](https://developers.slashdot.org/story/26/05/17/0214254/elon-musks-xai-launches-grok-build-its-first-ai-coding-agent)).

## OpenAI + Dell: Codex Goes On-Premises

OpenAI and Dell Technologies announced a partnership to bring Codex to hybrid and on-premises enterprise environments([OpenAI](https://openai.com/index/dell-codex-enterprise-partnership/)). The collaboration connects Codex with Dell's AI Data Platform and AI Factory, allowing enterprises to apply Codex directly to internal codebases, documentation, and operational knowledge([SiliconANGLE](https://siliconangle.com/2026/05/18/dell-targets-enterprise-ai-execution-gap-local-agentic-ai-systems-integrated-ai-infrastructure/)). With Codex now at 4M+ weekly users, use cases are expanding beyond code review and test coverage into lead qualification, report writing, and cross-tool coordination.

## Google I/O: Gemini Omni Leaked + Gemini 4 Anticipation Peaks

The I/O keynote starts May 19 at 10 a.m. PT from Shoreline Amphitheatre([io.google](https://io.google/2026/)). While Gemini 4.0 isn't confirmed, reports point to Gemini 3.2 or 3.5([NokiaPowerUser](https://nokiapoweruser.com/google-io-2026-gemini-spark-omni-gemini-3-5-rumors/)). **Gemini Omni** — a video AI model with remix, in-chat editing, and template creation — has already leaked([Lovegen](https://lovegen.ai/blog/gemini-omni-leak-google-io-2026)). Internal codenames like "Gemini Spark" and "Team Food" memory system are also surfacing([MindStudio](https://www.mindstudio.ai/blog/google-io-2026-leaks-codenames-features)).

## Code with Claude London: Three Tracks + Extended Day

Anthropic's Code with Claude London runs tomorrow with three parallel tracks: **Research**, **Claude Platform**, and **Claude Code**, with MCP as a core theme([AI Expert Magazine](https://www.aiexpertmagazine.com/anthropic-code-with-claude-2026-everything-you-need-to-know/)). ## Cursor 3.4 + GitHub Copilot's 14-Week Slide

Cursor 3.4 introduced **/multitask** parallel subagents and **interactive canvases** in the Agents Window([Cursor Changelog](https://cursor.com/changelog)). Copilot's score dropped to 69 — its 14th consecutive week of decline, with usage-based billing D-14 and signups still paused([GitHub Blog](https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/)).
