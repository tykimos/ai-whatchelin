OpenAI의 Sam Altman이 미국 정부에 주요 AI 기업들의 지분 5%를 제공하는 방안을 제안했다([Bloomberg](https://www.bloomberg.com/news/articles/2026-07-02/openai-proposes-giving-the-us-government-a-5-stake-ft-says)). GPT-5.6 Sol의 정부 승인 제한 프리뷰와 Fable 5 수출통제 해제 직후 나온 이 제안은 AI 규제 환경의 근본적 변화를 시사한다.

## OpenAI: 미 정부 5% 지분 제안, AI 규제 판도 바꾸나

Altman은 단순히 OpenAI만의 제안이 아니라 미국 주요 AI 개발사 모두가 정부에 5% 지분을 제공하는 구조를 제시했다([Bloomberg](https://www.bloomberg.com/news/articles/2026-07-02/openai-proposes-giving-the-us-government-a-5-stake-ft-says)). GPT-5.6 Sol이 이미 ~20개 정부 승인 기관에만 제한 프리뷰 중인 상황에서, 정부와의 관계 재정립을 서두르는 모습이다. Sol은 $5/$30, Terra는 $2.50/$15, Luna는 $1/$6/MTok으로 가격이 책정되어 있으며 Cerebras에서 750 tok/s 속도로 7월 중 출시 예정이다([OpenAI](https://openai.com/index/previewing-gpt-5-6-sol/)).

## Anthropic, 매출에서 OpenAI 추월 — Fortune 보도

Fortune이 Anthropic의 자체 보고 매출이 OpenAI를 넘어섰다고 보도했다([Fortune](https://fortune.com/2026/07/02/sam-altman-new-world-order-ai-openai-google-anthropic/)). Anthropic은 연환산 $470억 매출과 2029년 흑자 전환을 예고한 반면, OpenAI는 $250-330억으로 추정된다. $965억 밸류에이션과 10월 IPO를 앞둔 Anthropic의 기세가 무섭다. 한편 Anthropic은 중국 경쟁사 감시용으로 삽입했던 비밀 추적 코드를 제거하고 있다([The Register](https://www.theregister.com/ai-and-ml/2026/07/01/anthropic-is-removing-its-covert-code-for-catching-chinese-competitors/5265366)).

## Copilot: 삼중 업데이트에도 57주째 하락 — 24점

GitHub Copilot이 Kimi K2.7 Code 오픈웨이트 모델, Vision GA, 자동 모델 선택을 한꺼번에 출시했지만 57주 연속 하락해 24점을 기록했다([GitHub Changelog](https://github.blog/changelog/2026-07-01-kimi-k2-7-is-now-available-in-github-copilot/)). 종량제 첫 달 에이전틱 세션 $30-40/일 비용 충격이 이탈을 가속화하고 있다. Claude Sonnet 5도 ZDR로 Copilot에 추가됐다([GitHub](https://github.com/features/copilot/whats-new)).

## Claude Code v2.1.198: Chrome GA, 백그라운드 에이전트 자동 PR

Claude Code v2.1.198이 Chrome 통합 GA, 워크트리 백그라운드 에이전트 자동 커밋·푸시·드래프트 PR, 알림 훅 시스템을 도입했다([GitHub Releases](https://github.com/anthropics/claude-code/releases)). Sonnet 5가 기본 모델로 확정되며 1M 컨텍스트와 $2/$10/MTok 프로모션 가격이 8월 31일까지 적용된다([Anthropic](https://www.anthropic.com/news/claude-sonnet-5)). Claude는 Microsoft Foundry/Azure에서도 GA로 출시되어 엔터프라이즈 접근성이 확대됐다.

## Antigravity 90 돌파 — 13주 연속 상승

Google Antigravity가 90점을 돌파하며 13주 연속 상승세를 이어갔다. CLI v2.1.4에서 antigravity_guide 내장 스킬, --project 플래그, OSC8 터미널 하이퍼링크가 추가됐다. Gemini CLI 셧다운 이후 최대 수혜자로 Codex CLI(88)와 2점 격차를 유지하고 있다.
