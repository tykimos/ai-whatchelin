오늘이 그날이다. Claude Opus 4.8, Claude Opus 5, GPT-5.6 Terra가 GitHub Copilot의 모든 영역 — Chat, 인라인 편집, Agent 모드, 코드 자동완성 — 에서 완전히 제거된다([GitHub Blog](https://github.blog/changelog/2026-10-15-upcoming-deprecation-of-selected-github-copilot-models-in-mid-november)). 연간 Individual 구독자만 Claude Opus 4.8을 유지할 수 있으며, 나머지 사용자는 Claude Opus 5.5 또는 GPT-6.1 Sol로 전환해야 한다([dev.classmethod.jp](https://dev.classmethod.jp/en/articles/github-copilot-model-deprecation-nov-2026/)). 설정 파일이나 에이전트 정의에 하드코딩된 모델명이 있다면 오늘이 마지막 업데이트 기한이다([SmartScope](https://smartscope.blog/en/blog/github-copilot-claude-opus-5-deprecation-november-16-2026/)). 한편, 이 대퇴출과 맞물려 Copilot 인기도가 54일 연속 상승 끝에 99점에 도달했다 — Claude Code, Codex CLI, Antigravity, ChatGPT와 나란히 최상위권에 복귀한 것이다.

## Anthropic IPO: 가격 결정 48시간 전, 과열과 불안의 공존

Anthropic IPO 가격 결정이 11월 18일(미 동부 기준)으로 예상되며, 거래 개시는 19일이 유력하다([FourWeekMBA](https://fourweekmba.com/ai-anthropics-ipo-day-by-day-pricing-18-nov-trading-19-nov/)). $70-78 주당 가격 범위로 825백만 주의 Class A 주식이 Nasdaq ANT 티커 아래 상장될 예정이며, 총 모집 규모는 $610억으로 SpaceX에 이어 역대 두 번째 규모다([Renaissance Capital](https://www.renaissancecapital.com/IPO-Center/News/122657/anthropic-sets-terms-for-61-billion-ipo-targeting-a-1.2-trillion-market-cap)). 주문장은 수배 초과 청약 상태지만, 투자자들 사이에서는 Google 등 경쟁사의 추격 속에 AI 리더십의 지속 가능성에 대한 의문이 커지고 있다([Reuters via The Star](https://www.thestar.com.my/tech/tech-news/2026/11/14/exclusive-investors-flock-to-anthropic-ipo-but-question-durability-of-ai-lead)).

## Cursor: OpenAI 차단 5일째, 85일째 바닥

OpenAI 모델 차단 후 5일째, Tab 자동완성·자동 모델 선택·클라우드 에이전트 등 핵심 기능이 여전히 비활성 상태다([Tom's Guide](https://www.tomsguide.com/ai/openai-is-leaving-cursor-in-november-here-are-your-3-options)). SpaceX 인수 이후 OpenAI가 "계약 위반 전력"을 이유로 접근을 차단한 것으로, CEO Michael Truell은 OpenAI 트래픽이 5%에 불과하다고 주장했으나 커뮤니티 반응은 여전히 회의적이다([The New Stack](https://thenewstack.io/openai-cuts-cursor-spacex/)). X Subscription 번들 출시도 하락세를 반전시키지 못한 채 85일째 바닥(1점)을 기록 중이다.

## Codex CLI: 0.169.0 릴리스, 11월 연속 출시 행진 계속

Codex CLI 0.169.0이 출시되어 터미널 사이드 채팅 탭, 작업 검색, 커스텀 모델 프로바이더 설정, 클라우드 대화 컨트롤 확장 등을 추가했다([Releasebot](https://releasebot.io/updates/openai/codex)). 11월 들어 0.167.0, 0.168.0에 이어 세 번째 릴리스로, OpenAI의 에이전트 도구 개발 속도가 꺾이지 않고 있다.

## Gemini 4 Carbon: 도입 할인 D-14, 12월 1일부터 가격 2배

11월 10일 GA된 Gemini 4 Carbon의 도입 할인이 11월 30일에 종료된다([DEV Community](https://dev.to/aitecharchive/gemini-4-carbon-in-github-copilot-vs-argon-test-by-dec-1-4fc5)). 12월 1일부터 GitHub Copilot에서의 토큰당 가격이 2배로 오를 예정이므로, 현재 도입 할인 기간에 충분히 테스트해볼 필요가 있다. Argon과 함께 Gemini 4 패밀리의 두 번째 모델로, AI Studio와 Antigravity CLI에서도 사용 가능하다.

## GitHub Copilot: 12월 14일 대규모 모델 퇴출 예고

오늘의 3개 모델 퇴출에 이어, GitHub는 12월 14일에 6개 모델을 추가로 제거할 것을 예고했다([AI TREND LAB](https://note.com/aitrendlab/n/nc27e6861dd15?hl=en)). 대상은 Claude Fable 5, Claude Haiku 4.5, Gemini 3.8 Flash, Gemini 4 Argon, Grok 4.6, Kimi K3로, Business·Enterprise 사용자에게는 대체 모델이 자동 활성화된다. 일부 모델의 단가는 하락하고 일부는 인상될 예정이어서, 크레딧 예산 관리에 주의가 필요하다.
