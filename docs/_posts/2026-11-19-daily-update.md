The largest AI IPO in history just had its first day on the market. Anthropic's ANT opened at $111.50 on Nasdaq, a 34% surge above the $83 offering price([Investing.com](https://www.investing.com/news/analyst-ratings/anthropic-stock-jumps-34-in-nasdaq-debut-after-record-ipo-93CH-5039675)). The stock touched an intraday high near $115 before profit-taking pulled it down to the mid-$90s by afternoon([Yahoo Finance](https://finance.yahoo.com/markets/stocks/articles/anthropic-jumps-17-record-nasdaq-180734709.html)). The fully diluted market cap sits around $1.5 trillion, with the order book at 6x oversubscription and an unusual 20% retail allocation([Fortune](https://fortune.com/2026/11/18/anthropic-prices-ipo-83-per-share-1-5-trillion/)).

## GPT-6.2 Astra / Sol: OpenAI's Timing War

On the eve of Anthropic's listing, OpenAI officially released GPT-6.2 Astra and Sol([OpenAI Developer Community](https://community.openai.com/t/gpt-6-2-astra-and-sol-are-now-available/1417531)). Astra targets professional work at $8/$40 per million tokens — a 20% cut from GPT-6 — while Sol handles everyday tasks at $2/$10([9to5Mac](https://9to5mac.com/2026/11/17/openai-upgrades-chatgpt-and-codex-with-new-gpt-6-2-astra-and-sol-models/)). Both ship with tighter cyber safeguards and are available in ChatGPT Work, Codex, and the API as `gpt-6.2-astra` and `gpt-6.2-sol`([CASRAI](https://casrai.org/news/openai-gpt-6-2-astra-sol-release-2026)).

## Claude Code v2.1.326: Code Mode Joins Agent Teams

Released November 16, Claude Code v2.1.326 enables Code Mode to work with agent teams([dev.classmethod.jp](https://dev.classmethod.jp/en/articles/20261117-cc-updates-v2-1-326/)). Teammate agents now also run in Code Mode, and the release adds sandbox write-path restrictions and Remote Control streaming responses([havoptic.com](https://www.havoptic.com/r/claude-code-2.1.326)). Note: Opus 4.8 fast mode sunsets November 30.

## Codex CLI 0.170.0: Voice Comes to the Terminal

Codex CLI shipped version 0.170.0 on November 18, introducing WebRTC negotiation for realtime voice calls directly in the TUI([OpenAI Changelog](https://developers.openai.com/codex/changelog)). This is the 116th release of 2026, as the terminal agent continues blurring the line between CLI and full IDE.

## Cursor: Day 8 of the OpenAI Cutoff

Eight days into the OpenAI model access termination, Cursor sits at rock bottom for the 88th consecutive day([Tom's Guide](https://www.tomsguide.com/ai/openai-is-leaving-cursor-in-november-here-are-your-3-options)). Live Apps, Voice Chat, and Multiplayer Projects shipped this month, but the paradox of innovation without an engine persists.
