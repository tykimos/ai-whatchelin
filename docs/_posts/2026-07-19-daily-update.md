Anthropic's Fable 5 free access officially ends today, July 19 at 11:59 PM PT ([BleepingComputer](https://www.bleepingcomputer.com/news/artificial-intelligence/claude-fable-5-stays-free-for-paid-users-until-july-19-as-anthropic-buys-more-time/)). After three extensions since the June 12 export-control disruption, there's no sign of a fourth — starting tomorrow, Fable 5 shifts to prepaid credits at $10/$50 per million input/output tokens ([Dataconomy](https://dataconomy.com/2026/07/13/claude-fable-5-free-access-extended-july-19/)). Claude Code's 50% bonus weekly limits also expire alongside it ([Help Net Security](https://www.helpnetsecurity.com/2026/07/13/claude-code-weekly-limits-promotion-extended/)).

## Kimi K3 — China's 2.8T-Parameter Challenger

Moonshot AI unveiled Kimi K3, a 2.8-trillion-parameter MoE model with a 1M-token context window ([Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/moonshot-releases-2-8-trillion-parameter-kimi-k3)). It reached #1 on Arena.ai's Frontend Code Arena with a 76% pairwise win rate, beating Fable 5, and scored 88.3 on Terminal-Bench 2.1 ([Fortune](https://fortune.com/2026/07/16/moonshots-kimi-k3-pushes-chinese-ai-into-fable-level-territory/)). Priced at $3/$15 per million tokens, open weights are promised by July 27 ([CNBC](https://www.cnbc.com/2026/07/17/moonshot-ai-kimi-k3-model-openai-anthropic-china.html)).

## Claude Code v2.1.215 — Autonomous Skill Execution Restricted

Today's Claude Code v2.1.215 restricts `/verify` and `/code-review` skills to only run when directly invoked by the user ([Releasebot](https://releasebot.io/updates/anthropic/claude-code)). Yesterday's v2.1.214 was a major security and stability patch covering a Windows PowerShell 5.1 permission bypass, forced prompts for commands over 10,000 characters, and progress heartbeats for long-running tool calls.

## Gemini 3.5 Pro — Delayed Again

Google has delayed Gemini 3.5 Pro once more after the rebuilt model fell short on coding and complex reasoning benchmarks ([BuildFastWithAI](https://www.buildfastwithai.com/blogs/ai-news-today-july-18-2026)). Alphabet shares dropped roughly 4%. With Gemini CLI already transitioned to Antigravity CLI ([Google Developers Blog](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/)), the continued delay adds uncertainty across Google's AI ecosystem.

## Copilot CLI v1.0.71 — Voice and Canvas Support

GitHub Copilot CLI v1.0.71 introduced voice device selection via `/voice devices`, canvas-based extension interactions, and hard-blocked workspace modifications in plan mode ([GitHub Releases](https://github.com/github/copilot-cli/releases/tag/v1.0.71)). Despite 74 weeks of declining popularity, the tool continues shipping meaningful feature updates.

## Opus 5 "Honeycomb" — Community Buzz

A model labeled "Claude Honeycomb EAP" briefly appeared in Cursor's model picker on July 8–9 ([TechTimes](https://www.techtimes.com/articles/320265/20260712/fable-5-free-through-july-19-anthropic-blinks-again-opus-5-leak-surfaces-cursor.htm)). Leaked specs suggest a 1M-token context window, an "xhigh" reasoning effort tier, and Opus 4.8 safety fallback routing. The community expects a mid-July to early-August launch window, but Anthropic has made no official announcement.
