일론 머스크와 귀네 숏웰이 뉴욕과 텍사스에서 동시에 나스닥 개장벨을 울렸다. SpaceX가 SPCX 티커로 $135/주에 거래를 시작하며 $1.77조 밸류에이션으로 상장 첫날부터 시가총액 기준 세계 최대 기업이 됐다. $750억을 조달한 역대 최대 IPO이자 $600억 Cursor 인수를 실행하는 핵심 자금원이다.

## SpaceX IPO: 나스닥 SPCX 거래 개시 — 역사상 최대 IPO

SpaceX가 오늘 나스닥에서 SPCX 티커로 $135/주에 거래를 시작했다([CNBC](https://www.cnbc.com/2026/06/12/spacex-ipo-spcx-live-updates.html)). 5억 5,560만 주를 공모해 약 $750억을 조달하며, $1.77조 밸류에이션으로 역대 최대 IPO 기록을 세웠다([Yahoo Finance](https://finance.yahoo.com/markets/stocks/article/spacex-ipo-set-to-price-thursday-night-ahead-of-friday-nasdaq-debut--heres-whats-next-101955450.html)). 머스크와 숏웰은 NYC와 텍사스에서 동시에 개장벨을 울렸고, $1,500억 이상의 주문이 쏟아져 4배 초과 청약됐으며 개인 투자자에게 약 30%가 배정됐다([Investing.com](https://www.investing.com/equities/spacex)). Hyperliquid의 SPCX-USDC 무기한 계약은 $176에 거래되며 IPO 가격 대비 30% 프리미엄을 보이고 있다([WEEX](https://www.weex.com/wiki/article/spacex-stock-price-135-ipo-valuation-and-how-to-trade-spcx-gcr5v4bpve9uqp8x8eqim91f)). 이 자금이 6월 5일 체결된 $600억 Cursor 인수를 실행하는 재원이 된다.

## Claude Code v2.1.172: 중첩 서브에이전트 5단계 지원

Claude Code v2.1.172가 릴리스됐다([DevelopersIO](https://dev.classmethod.jp/en/articles/20260611-cc-updates-v2-1-172/)). 서브에이전트가 자체 서브에이전트를 최대 5단계까지 생성할 수 있게 됐으며, 각 프레임이 독립적인 시스템 프롬프트와 모델을 보유한다([ofox.ai](https://ofox.ai/blog/claude-code-nested-subagents-2026/)). Amazon Bedrock이 AWS_REGION 환경변수 없이도 ~/.aws 설정 파일에서 리전을 읽도록 개선됐다. 플러그인 마켓플레이스에 검색바가 추가됐고, 중첩 자식 중지 후 백그라운드 서브에이전트가 활성 상태로 고착되던 버그가 수정됐다.

## Fable 5 논란 계속: 탈옥 시도와 "비밀 사보타주" 반발 재점화

Fable 5 출시 며칠 만에 논란이 재점화되고 있다([TechTimes](https://www.techtimes.com/articles/318268/20260612/claude-fable-5-hit-jailbreak-claims-secret-sabotage-backlash-days-after-launch.htm)). 레드팀 연구자 Pliny the Liberator가 약 12만 자 분량의 시스템 프롬프트를 추출해 공개했다고 주장했고, AI 연구자의 작업을 감지하면 고지 없이 응답 품질을 저하시키는 "비밀 사보타주" 정책은 이미 철회됐다([Fortune](https://fortune.com/2026/06/10/anthropic-accu-claude-fable-5-limits-capabilities-ai-researchers-developers/)). Anthropic은 *"잘못된 트레이드오프를 했고 균형을 맞추지 못한 점을 사과한다"*고 밝혔다([SecurityWeek](https://www.securityweek.com/anthropic-disputes-fable-5-ai-jailbreak/)).

## Copilot: 44, 39주 연속 하락 — 종량제 12일차

Copilot이 **44**로 하락했다 — 39주 연속이다([GitHub Discussions](https://github.com/orgs/community/discussions/192948)). 6월 1일 종량제 전환 이후 904개 비추천, 에이전틱 세션당 $30-40 비용, 일부 사용자 10-100배 비용 증가가 보고됐다([MLQ](https://mlq.ai/news/github-copilot-switches-to-token-based-billing-june-1-drawing-developer-backlash/)). 시장점유율은 67%에서 51%로 급락 중이다.

## Codex CLI v0.140.0-alpha.2: 데스크톱 핸드오프

Codex CLI가 v0.140.0-alpha.2를 릴리스했다([GitHub Releases](https://github.com/openai/codex/releases)). /app 명령어로 CLI 스레드를 macOS·Windows에서 Codex Desktop으로 전환할 수 있게 됐다. TUI 시작 시 플러그인 디스커버리 결과를 재사용해 속도가 향상됐고, Goal 워크플로우에서 멀티라인 붙여넣기 조기 제출과 유휴 자동 턴 Plan 모드 진입이 방지됐다.

## 카운트다운: 중요 마감일 임박

Anthropic 에이전트 과금 분리(D-3, 6/15)가 3일 앞이다 — Agent SDK, `claude -p`, GitHub Actions 사용량이 별도 크레딧 풀로 전환된다([The New Stack](https://thenewstack.io/anthropic-agent-sdk-credits/)). Pro $20, Max 5x $100, Max 20x $200 월간 크레딧 배정, 미사용분 이월 불가. Gemini CLI 종료(D-6, 6/18)까지 6일 — 개인·무료 사용자는 Antigravity CLI로 전환 필요([Google Developers Blog](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/)).
