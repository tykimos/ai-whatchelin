GitHub Universe 2026이 오늘 샌프란시스코 Fort Mason에서 개막했다. Jay Parikh CEO의 키노트에서 Copilot의 에이전트 퍼스트 전환이 공식 선언됐으며, 이슈부터 머지까지 전 과정을 AI가 주도하는 새로운 소프트웨어 딜리버리 비전이 제시됐다([GitHub Blog](https://github.blog/news-insights/company-news/github-universe-2026-evolving-every-layer-of-the-stack/)).

## GitHub Copilot: 7대 발표 한눈에

**Copilot 앱**은 에이전트 퍼스트로 설계된 새로운 인터페이스다. 코드뿐 아니라 스펙, 디자인 토론, 텔레메트리 분석까지 지원한다([GitHub Blog](https://github.blog/news-insights/company-news/github-universe-2026-evolving-every-layer-of-the-stack/)). **Copilot Fusion**은 멀티 모델 오케스트레이션 기능으로, 작업의 추론·코드 생성·디버깅·도구 사용 요구를 평가해 최적의 모델 조합을 선택한다. GitHub은 Artificial Analysis Coding Agent Index에서 Fusion Max가 Opus 5.5 Max 2점 차이 내에서 절반 비용, 40% 적은 시간으로 작동한다고 밝혔다([GitHub Blog](https://github.blog/news-insights/company-news/github-universe-2026-evolving-every-layer-of-the-stack/)).

**Copilot 프로젝트**는 오늘부터 GA로 제공되며, 여러 레포를 넘나드는 에이전트 작업을 병렬 세션으로 관리할 수 있다([GitHub Blog](https://github.blog/news-insights/company-news/github-universe-2026-evolving-every-layer-of-the-stack/)). **세션 연속성**은 GitHub 앱, VS Code, CLI, 웹 사이를 오가며 같은 클라우드 에이전트 세션을 이어갈 수 있게 한다. **코드 리뷰 Max**는 ReviewBench 고위험 이슈 부문 최고 F1 점수를 기록했고([Mezha](https://mezha.net/eng/news/mezha-8d24f5677c199a45090df6e4)), **Copilot 오토메이션**은 AI 워크플로에 자기 개선 기능을 더했다. **Enterprise 통합**으로 Enterprise 고객은 별도 구독 없이 AI 크레딧만으로 전체 Copilot 기능을 사용할 수 있게 됐다.

## ChatGPT: Pro 200 그랜드파더링 내일 종료

내일(10/29) 기존 ChatGPT Pro $200 구독자의 그랜드파더링 사용량 한도가 하향된다([ProPakistani](https://propakistani.pk/2026/09/30/chatgpt-gets-500-pro-plan-as-openai-halves-pro-200-limits/)). 9/29 DevDay에서 출시된 $500 Pro 500 티어의 Ultrafast 전용 접근권이 핵심 차별점으로, 일반 Pro 200 사용자에게는 갈림길이 된다.
