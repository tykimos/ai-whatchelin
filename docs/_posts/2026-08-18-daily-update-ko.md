AI 코딩 도구 시장이 전례 없는 양극화를 보이고 있다. 오늘 기준 인기도 99점에 도달한 도구가 7개 — Claude Code, ChatGPT, Codex CLI, Antigravity, Claude AI, Codex CLI, Cursor — 로 역대 최다다. 반면 GitHub Copilot과 Gemini CLI는 1점에 고정된 채 Sept 1 대폐기를 앞두고 있다. 중간 지대에 남은 건 Windsurf(86)와 Aider(68)뿐이다.

## Cursor Origin: 출시 이틀째, GitHub에 대한 도전 본격화

Cursor의 에이전트 우선 git 호스팅 플랫폼 Origin이 얼리 베타 이틀째를 맞았다([Cursor Changelog](https://cursor.com/changelog/origin-code-hosting)). 리포, PR, 코드 브라우징, GitHub 양방향 동기화를 지원하며 Vercel 배포, Depot·Buildkite CI 통합도 포함됐다([TechStartups](https://techstartups.com/2026/08/17/cursor-launches-origin-a-github-rival-built-for-ai-coding-agents/)). SpaceX $600억 인수 이후 첫 플랫폼급 제품으로, AI 에이전트를 위해 설계된 코드 호스팅이라는 점에서 GitHub과의 직접 경쟁이 불가피하다. Cursor Builds도 모든 Cloud Agent 환경에서 기본 적용되어 에이전트 시작 시간이 3배 빨라졌다([TechTimes](https://www.techtimes.com/articles/324667/20260817/cursor-builds-goes-default-agent-fleets-survive-bad-commits-start-three-times-faster.htm)).

## DeepSeek 가격 인상 이틀째 — 커뮤니티 반응 갈려

DeepSeek의 API 가격 인상이 시행 이틀째에 접어들었다. V4-Flash 출력 토큰이 피크 시간 $1.32/MTok으로 371% 올랐고, V4-Pro는 $3.96/MTok으로 355% 상승했다([Bloomberg](https://www.bloomberg.com/news/articles/2026-08-13/deepseek-increases-prices-for-ai-services-by-multiple-times)). 피크·오프피크 이중 과금 체계 도입은 IPO를 앞둔 수익화 전략의 일환이다([Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/deepseek-raising-api-prices-1-174027670.html)). Stripe의 OpenRouter $70억+ 인수 확정([TechCrunch](https://techcrunch.com/2026/08/16/stripe-will-reportedly-acquire-ai-gateway-startup-openrouter-for-7b/))과 맞물려, "저렴한 AI API" 시대의 종말이 가속화되고 있다.

## Copilot D-14: 대폐기까지 2주

GitHub Copilot의 Sept 1 대규모 모델 폐기까지 14일 남았다([GitHub Changelog](https://github.blog/changelog/2026-07-31-upcoming-august-2026-model-deprecations-in-github-copilot/)). MAI-Code-1-Flash도 Sep 10 폐기 예정이며 MAI-Code-1.1-Flash로 전환해야 한다([GitHub Changelog](https://github.blog/changelog/2026-08-11-upcoming-deprecation-of-mai-code-1-flash/)). 인기도 1점이 97주째 이어지고 있다.
