Google officially released Gemini CLI as open-source under the Apache 2.0 license, jumping squarely into the AI coding CLI race. Anyone with a personal Google account gets free access to Gemini 2.5 Pro with a 1-million-token context window — 60 requests per minute and 1,000 per day at no charge.

## Gemini CLI: Official Open-Source AI Agent Debut

Google introduced Gemini CLI as an "open-source AI agent" via an official blog post([Google Blog](https://blog.google/technology/developers/introducing-gemini-cli-open-source-ai-agent/)). Built on a ReAct loop with built-in tools and local/remote MCP server support, it handles complex tasks like bug fixing, feature development, and test coverage improvement. It shares its technology base with Gemini Code Assist, so the same AI is available in VS Code as well([GitHub](https://github.com/google-gemini/gemini-cli)). Unlike Claude Code ($20/month+) or Codex CLI (requires paid ChatGPT), Gemini CLI is completely free — a compelling entry point for developers exploring AI coding tools.

## Cursor 3.3: Team Marketplace and Context Usage Visibility

Cursor shipped its 3.3 update([Cursor Changelog](https://cursor.com/changelog)). Users can now see a detailed breakdown of their agent's context usage. Team Marketplace was introduced, allowing admins to create and manage plugin distribution without needing a connected repository first. Plugins bundle MCP servers, skills, subagents, rules, and hooks, with three distribution modes: Default Off, Default On, or Required.

## GitHub: Enterprise-Managed Plugins for Copilot CLI

GitHub added enterprise-managed plugins for Copilot CLI in public preview([GitHub Blog](https://github.blog/changelog/2026-05-06-enterprise-managed-plugins-in-github-copilot-cli-are-now-in-public-preview/)). Admins can now configure and distribute plugins across their enterprise to set baseline standards for every user's Copilot CLI client. Meanwhile, community backlash over the June 1 usage-based billing transition (D-24) continues, and Copilot's popularity score dropped for the fifth consecutive week to 79.

## Codex: Spark Research Preview + Security Hardening

OpenAI released Codex-Spark in research preview for ChatGPT Pro users — text-only with a 128k context window([OpenAI Developers](https://developers.openai.com/codex/changelog)). The Codex CLI TUI gained quick reasoning controls via Alt+, and Alt+. shortcuts. Advanced Account Security was also introduced for ChatGPT and Codex, adding phishing-resistant sign-in, login alerts, and automatic training exclusion.
