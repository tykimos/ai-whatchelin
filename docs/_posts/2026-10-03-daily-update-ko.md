Anthropic이 추수감사절 전 나스닥 상장을 추진하고 있다. Bloomberg에 따르면 Goldman Sachs, JPMorgan Chase, Morgan Stanley와 IPO 절차를 논의 중이며, 예상 시가총액은 $1.8조~$2조에 달한다([Bloomberg](https://www.bloomberg.com/news/articles/2026-10-01/anthropic-said-to-target-mega-ipo-before-thanksgiving-holiday)). 2026년 2분기 매출 $109억, 영업이익 $5.59억을 기록하며 흑자 전환에 성공한 점이 상장 근거를 뒷받침한다([Yahoo Finance](https://finance.yahoo.com/technology/article/anthropic-reportedly-looking-to-ipo-as-early-as-mid-november-180315768.html)).

## Claude Frontier Academy: $1억 투자로 엔지니어 1만 명 양성

Anthropic이 10월 2일 Claude Frontier Academy를 발표했다. $1억을 투자해 2027년까지 1만 명의 Frontier Deployed Engineer를 양성하겠다는 계획이다([CNBC](https://www.cnbc.com/2026/10/02/anthropic-to-invest-100-million-to-train-ai-engineer-talent.html)). 의과대학 레지던시를 모델로 한 12주 프로그램으로, Accenture·Deloitte·Morgan Stanley 등의 엔지니어들이 첫 코호트를 구성한다([Unite.AI](https://www.unite.ai/new-anthropic-academy-backs-10-000-engineer-residencies-with-100m/)).

## PixelLeak: AI 코딩 에이전트 사상 최대 기업 데이터 유출

AI 코딩 에이전트들이 300개 이상 조직의 내부 스크린샷 13,000건을 공개 GitHub 저장소에 게시한 PixelLeak 사건이 발생했다([Bitdefender](https://www.bitdefender.com/en-us/blog/hotforsecurity/pixelleak-ai-coding-agents-github-screenshots)). GitHub CLI의 이미지 첨부 기능 제한이 근본 원인으로, 결제 기록과 미공개 기능이 900개 이상 저장소에 노출됐다([eSecurity Planet](https://www.esecurityplanet.com/news/news-ai-coding-agent-github-image-leak/)).

## ChatGPT: Finances 기능 무료 사용자로 확대

OpenAI가 10월 2일 ChatGPT Finances를 미국 내 Free·Go 사용자에게 확대 출시했다([Digg](https://digg.com/ai/lodtl763)). 은행 계좌를 연동해 지출·저축·투자 인사이트를 제공하는 기능으로, 이전에는 유료 구독자 전용이었다.

## JetBrains Air: IDE 에이전트 시장 본격 진출

JetBrains가 Air EAP를 출시해 IDE 에이전틱 개발 시장에 참전했다([JetBrains Blog](https://blog.jetbrains.com/ai/2026/10/air-in-ides-eap/)). 디버깅·프로파일링·시맨틱 코드 검색을 에이전트에게 제공하며, Junie Lite는 무료로 사용 가능하다.

## Antigravity: Claude Opus 5.5·Sonnet 5.5 조용히 추가

Google Antigravity가 Claude Opus 5.5와 Sonnet 5.5를 모델 피커에 추가했다([Startup Fortune](https://startupfortune.com/google-antigravity-adds-anthropics-claude-opus-55-and-sonnet-55/)). 멀티 프로바이더 에이전트 플랫폼으로의 전략 전환을 시사한다.
