Developers found 'gpt-5.6' strings in Codex rollout logs — codenamed 'iris-alpha' with an estimated 1.5M token context window, prediction markets pricing 80-89% probability of public release by June 30 ([ChatForest](https://chatforest.com/reviews/openai-gpt-5-6-canary-leak-release-date-prediction-markets-2026/)). With Build 2026 just two days away, both Microsoft and OpenAI are showing their next-generation cards.

## Microsoft Build D-2: Project Polaris Leaks

Microsoft's homegrown coding model 'Project Polaris' leaked ahead of Build 2026 ([Windows News](https://windowsnews.ai/article/microsoft-build-2026-homegrown-ai-models-to-power-github-copilot.420887)). Built on a mixture-of-experts architecture, it reportedly outperforms GPT-4 Turbo on HumanEval and MBPP, with GA expected in August. A 'Code Content Guarantee' indemnifying enterprise customers against IP claims is the key differentiator for the enterprise market. This is the first output from Mustafa Suleyman's team, freed from OpenAI training restrictions in April ([The Information](https://www.theinformation.com/newsletters/ai-agenda/microsoft-release-new-coding-model-next-week-comeback-attempt)).

## Copilot: 26-Week Decline, D-2 to Usage-Based Billing

Copilot's popularity score dropped to 57, setting yet another all-time low ([GitHub Docs](https://docs.github.com/en/copilot/how-tos/manage-and-track-spending/prepare-for-your-move-to-usage-based-billing)). Just 2 days remain until June 1 usage-based billing — Pro gets $10 in AI Credits, Pro+ gets $39, Business $19/user, Enterprise $39/user. Code completions stay free, but agent and chat consume credits. Whether Build 2026's Project Polaris can reverse 26 weeks of decline is the central question heading into next week.

## DeepSWE: Fundamental Questions About SWE-Bench Reliability

Datacurve released the DeepSWE benchmark with 113 contamination-free tasks ([VentureBeat](https://venturebeat.com/technology/deepswe-blows-up-the-ai-coding-leaderboard-crowns-gpt-5-5-and-finds-claude-opus-exploiting-a-benchmark-loophole)). GPT-5.5 leads at 70% solve rate versus Claude Opus at 54%. More critically, it identified a ~32% verifier error rate in SWE-Bench Pro — raising fundamental questions about the reliability of the benchmark that has defined the AI coding leaderboard for the past year.

## Mozilla: Claude Mythos Fixes 271 Firefox Vulnerabilities

Mozilla fixed 271 Firefox vulnerabilities using Claude Mythos Preview — a 10x improvement over earlier Claude models ([BuildFastWithAI](https://www.buildfastwithai.com/blogs/ai-news-today-may-30-2026)). The project demonstrates agentic AI's practical value for large-scale security scanning across millions of lines of legacy code.

## TechCrunch: Developers Refusing to Work Without AI

METR research found most developers won't work on tasks without AI anymore, raising concerns about skill atrophy and dependency ([TechCrunch](https://techcrunch.com/2026/05/29/coders-are-refusing-to-work-without-ai-and-that-could-come-back-to-bite-them/)). Removing AI assistants reportedly feels like "losing a limb." Combined with last week's HN #1 piece on "using AI to write better code more slowly," the discourse around AI coding tools is shifting from speed to sustainability.
