AI 코딩 도구 시장이 이번 주말 두 개의 대형 이벤트를 앞두고 긴장감이 고조되고 있다. GitHub Copilot 통합 경험이 내일(9/28) 출시되고, OpenAI DevDay가 모레(9/29) 열리면서 48시간 안에 시장 지형이 크게 바뀔 가능성이 있다.

## GitHub Copilot: 통합 경험 D-1, 내일 출시

GitHub이 9월 28일부터 Copilot Chat(github.com), Copilot Chat(Mobile), Copilot 클라우드 에이전트를 하나의 통합 경험으로 재출시한다([GitHub Blog](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)). 기존 개별 정책은 단일 정책으로 통합되며 기본 활성화된다. 채팅 데이터 보관이 28일에서 계정 수명으로 확대되고, 코드 리뷰 기본값이 Lite에서 Balanced로 상향된다([C# Corner](https://www.c-sharpcorner.com/article/preparing-for-the-github-copilot-unified-experience-coming-september-28)). 10월 1일부터 신규 Business/Enterprise 좌석은 선불 결제가 필수다.

## OpenAI DevDay D-2: "o" 에이전트와 Pro Max $500 요금제

OpenAI DevDay(9/29, 샌프란시스코 Fort Mason)까지 이틀 남았다([OpenAI](https://openai.com/index/devday-2026/)). Sam Altman의 기조연설이 무료 라이브스트리밍되며, 약 12개의 제품 발표가 예상된다. 상시 에이전트 "o"의 공식 출시, GPT-6 Cyber(사이버보안 특화 모델) 프리뷰, 그리고 Pro Max $500/월 요금제가 핵심 발표로 꼽힌다([Forbes](https://www.forbes.com/sites/jonmarkman/2026/09/21/openai-plans-to-introduce-managed-agents-at-devday-2026/)).

## Codex CLI v0.156: 풀스크린 TUI와 음성 대화

Codex CLI가 v0.156.0을 출시하며 선택적 풀스크린 UI(/tui), 기본 활성화된 음성 대화(F8 토글), /usage 대시보드, 워크트리 기본 지원을 추가했다([Releasebot](https://releasebot.io/updates/openai/codex)). GPT-6 Sol/Luna 지원과 Amazon Bedrock 통합도 포함됐다. 9월 22일 기준 총 1,125개 이상의 릴리스를 기록하며 하루 평균 2회 이상 업데이트 속도를 유지하고 있다.

## Cursor: 39일 연속 하락, 37점

Cursor가 37점을 기록하며 39일 연속 하락세를 이어가고 있다. SpaceX 인수(8/14) 이후 99에서 62점이 빠졌으며, OpenAI 모델 접근 종료(11/12)까지 D-46이다([CNBC](https://www.cnbc.com/2026/08/29/openai-cursor-spacex-model-access.html)). 9월 10일 출시한 Projects(코디네이터 에이전트)와 9월 23일의 배포 봇(Rollouts, Security Review) 발표에도 하락 반전 조짐이 없다([Cursor](https://cursor.com/changelog)).
