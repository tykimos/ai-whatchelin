AI 코딩 도구 시장이 사상 최대의 '슈퍼 먼데이'를 앞두고 숨을 고르고 있다. 내일(5월 19일) Google I/O 키노트에서 새 Gemini 모델 발표가 유력하고([Android Authority](https://www.androidauthority.com/what-to-expect-from-google-io-2026-3664979/)), 같은 날 Anthropic의 Code with Claude London이 종일 개발자 컨퍼런스로 열리며([claude.com](https://claude.com/code-with-claude/london)), Musk v. Altman 배심원 심리도 시작된다([TechTimes](https://www.techtimes.com/articles/316675/20260515/openai-jury-begin-deliberations-monday-judge-weighs-altman-removal-500b-restructure-reversal.htm)). 세 이벤트가 동시에 터지면 화요일 아침 시장 판도가 완전히 달라질 수 있다.

## Google I/O: Gemini Omni 유출 + Gemini 4 기대감 최고조

Google I/O 키노트가 5월 19일 오전 10시(PT)에 시작된다([io.google](https://io.google/2026/)). Gemini 4.0 발표 여부는 아직 불확실하지만, Gemini 3.2 또는 3.5 업데이트가 유력하다는 보도가 나오고 있다([NokiaPowerUser](https://nokiapoweruser.com/google-io-2026-gemini-spark-omni-gemini-3-5-rumors/)). 가장 주목할 유출은 Gemini Omni — 동영상 리믹스, 인채팅 편집, 템플릿 기반 생성이 가능한 비디오 AI 모델이 일부 사용자에게 먼저 노출됐다([Lovegen](https://lovegen.ai/blog/gemini-omni-leak-google-io-2026)). 여기에 Android XR 안경 프리뷰도 확정됐다([Android Authority](https://www.androidauthority.com/what-to-expect-from-google-io-2026-3664979/)). Gemini CLI 인기도는 78로, I/O 전야 분위기를 반영해 꾸준히 상승 중이다.

## Code with Claude London: 3트랙·확장 세션까지

Anthropic의 Code with Claude London이 내일(5/19) 종일 진행된다([claude.com](https://claude.com/code-with-claude/london)). 올해는 **Research**(모델 최신 연구), **Claude Platform**(프로덕션 에이전트 배포), **Claude Code**(대규모 운용) 3개 병렬 트랙으로 구성되며, MCP(Model Context Protocol)가 핵심 주제로 다뤄진다([AI Expert Magazine](https://www.aiexpertmagazine.com/anthropic-code-with-claude-2026-everything-you-need-to-know/)). 5월 20일에는 **인디 개발자·초기 스타트업** 대상 확장 세션이 별도로 열린다([claude.com](https://claude.com/code-with-claude/london-extended)). 현장 등록은 마감됐지만 라이브스트림은 무료 오픈이다.

## OpenAI: Codex 모바일 확대 + Windows 샌드박스

Codex가 ChatGPT 모바일 앱(iOS/Android)에 프리뷰로 탑재되어, 이동 중에도 연결된 Mac에서 돌아가는 Codex를 제어할 수 있게 됐다([TechCrunch](https://techcrunch.com/2026/05/14/openai-says-codex-is-coming-to-your-phone/)). 무료 플랜 포함 전 플랜에서 이용 가능하며, 주간 사용자가 400만 명을 돌파했다([eWeek](https://www.eweek.com/news/openai-codex-mobile-chatgpt-app/)). Windows 전용 샌드박스도 새로 도입되어, 방화벽 기반 네트워크 차단과 파일 쓰기 제한으로 보안이 강화됐다([OpenAI Developers](https://developers.openai.com/codex/changelog)). Enterprise 고객에게는 CI/스크립트용 Codex 액세스 토큰도 지원되기 시작했다.

## Cursor: 3.4 릴리스 + Bugbot 과금 모델 변경

Cursor 3.4에서 **/multitask** 명령이 에디터에 추가되어, 비동기 서브에이전트로 요청을 병렬 처리할 수 있게 됐다([Cursor Changelog](https://cursor.com/changelog)). 에이전트 창에 **인터랙티브 캔버스**가 도입되어 대시보드, 테이블, 다이어그램 등을 직접 만들 수 있다. Bugbot은 시트 요금을 폐지하고 사용량 기반 과금으로 전환했으며, PR 한 건당 평균 $1.00~$1.50이 소요된다([Releasebot](https://releasebot.io/updates/cursor)).

## GitHub Copilot: 14주 연속 하락 + 과금 전환 D-14

Copilot 인기도가 69로 내려오며 14주 연속 하락세를 이어갔다([GitHub Blog](https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/)). 6월 1일 사용량 기반 과금 전환 D-14, Pro에서 Opus 모델 제거, 신규 가입 중단이 겹치면서 분위기가 차갑다([TechSifted](https://techsifted.com/posts/github-copilot-changes-may-2026/)). 그나마 밝은 소식은 **Copilot App 테크니컬 프리뷰**가 5/14에 출시된 것 — 이슈·PR에서 바로 에이전트 세션을 시작할 수 있는 데스크톱 클라이언트다([GitHub Blog](https://github.blog/changelog/2026-05-14-github-copilot-app-is-now-available-in-technical-preview/)).
