OpenAI가 ChatGPT, Codex, 개발자 API를 Greg Brockman 총괄 아래 단일 조직으로 병합한다([TechCrunch](https://techcrunch.com/2026/05/16/openai-co-founder-greg-brockman-reportedly-takes-charge-of-product-strategy/)). Brockman은 내부 메모에서 "단일 에이전틱 플랫폼에 투자하고 ChatGPT와 Codex를 하나의 통합 경험으로 만들겠다"고 밝혔다([The Next Web](https://thenextweb.com/news/openai-brockman-chatgpt-codex-unified-agentic-platform)). Codex가 먼저 코딩 이외 업무로 확장된 뒤 ChatGPT와 리서치 도구 Atlas가 순차적으로 통합되며, 내부적으로 에이전틱 "슈퍼앱"이라 부르고 있다([Benzinga](https://www.benzinga.com/markets/tech/26/05/52622210/openai-merges-chatgpt-and-codex-taps-greg-brockman-to-lead-product-strategy-ahead-of-potential-ipo-r)). Q4 2026 IPO를 앞둔 시점에서 투자자 압박에 대응하는 전략적 집중으로 읽힌다.

## 월요일 3대 빅뱅: Google I/O + Code with Claude London + Musk 배심원

5월 19일 월요일에 AI 코딩 역사상 가장 바쁜 하루가 펼쳐진다. Google I/O 키노트에서 Gemini 4와 에이전틱 코딩 제품이 공개될 예정이고([Android Authority](https://www.androidauthority.com/what-to-expect-from-google-io-2026-3664979/)), Anthropic의 Code with Claude London 컨퍼런스는 Ami Vora, Boris Cherny, Angela Jiang이 참석하는 풀데이 워크숍으로 진행된다([claude.com](https://claude.com/code-with-claude/london)). 동시에 Musk v. Altman 9인 배심원 심리가 시작돼 OpenAI의 2025년 기업 전환과 Altman 해임 여부가 논의된다([TechTimes](https://www.techtimes.com/articles/316675/20260515/openai-jury-begin-deliberations-monday-judge-weighs-altman-removal-500b-restructure-reversal.htm)).

## GitHub Copilot: 14주 연속 하락, 70선 돌파

Copilot 인기도가 14주 연속 떨어지며 70까지 내려갔다. 6월 1일 사용량 기반 과금 전환(D-14)과 Pro 플랜에서 Opus 모델 제거가 신뢰를 계속 잠식하고 있다([GitHub Blog](https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/)). Microsoft의 Claude Code 라이선스 강제 취소가 단기 사용량을 끌어올릴 수 있지만, 개발자 만족도 회복과는 별개 문제다.

## Codex CLI: 슈퍼앱 합류 효과로 83 돌파

ChatGPT/Codex 통합 발표와 함께 Codex CLI 인기도가 83으로 상승했다. 주당 400만 명이 Codex를 사용 중이며([eWeek](https://www.eweek.com/news/openai-codex-mobile-chatgpt-app/)), 모바일 앱 출시 후 접근성이 대폭 확대됐다. 슈퍼앱 전환이 Codex CLI 단독 제품의 미래에 어떤 영향을 미칠지 주목된다.
