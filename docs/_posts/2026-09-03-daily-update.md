Cursor can't stop falling. Since SpaceX's $60B acquisition triggered the change-of-control clause in its OpenAI partnership, Cursor's popularity score has dropped from 99 to 83 over seven consecutive days ([Developers Digest](https://www.developersdigest.tech/blog/ai-coding-tools-pricing-2026)). OpenAI's CEO dismissed it as "only 5% of traffic," but the developer migration numbers tell a different story.

## Cursor: D-70 to OpenAI Shutoff, Developer Exodus Accelerates

With GPT model access ending November 12, Cursor is pivoting hard to Grok 4.6 and Anthropic Claude ([Value Add VC](https://valueaddvc.com/blog/ai-coding-tools-ranked-2026-cursor-copilot-windsurf-devin-and-claude-code-compared)). The ₹649 (~$7) Start plan launched in July is holding its 3M Indian developer base ([Cursor Blog](https://cursor.com/blog/cursor-start-india)), but globally developers are moving to Claude Code and Codex CLI. The seven-day slide compounds the Aur0ra ransomware incident (Aug 27) and the SpaceX Origin data-terms controversy (Aug 18) that eroded trust.

## Claude: Fable 5.1 Already the Default After Just Two Days

Anthropic's Claude Fable 5.1, released September 1, became the default Fable model in Claude Code the very next day ([VentureBeat](https://venturebeat.com/technology/anthropics-claude-fable-5-1-and-mythos-5-1-arrive-with-a-75-cost-reduction-for-fable-cache-reads)). Terminal-Bench jumped to 55.8% (vs. Fable 5's 42%), and cache reads are now 75% cheaper at $0.25/MTok. Mythos 5.1 remains restricted to vetted cybersecurity and life-sciences organizations ([MacRumors](https://www.macrumors.com/2026/09/01/anthropic-claude-fable-5-1/)).

## GitHub Copilot: September Reset in Full Swing

Copilot's sweeping September 1 changes are now live ([GitHub Blog](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)). Business credits cut 37% (3,000 to 1,900), Enterprise cut 44% (7,000 to 3,900), and six models deprecated including Gemini 3.1 Pro and Claude Opus/Sonnet 4.5 and 4.6 ([GitHub Changelog](https://github.blog/changelog/2026-08-31-selected-github-copilot-models-deprecated/)). The unified Copilot experience merging Chat, Mobile, and cloud agent launches September 28.

## Codex CLI & Antigravity: Steady Improvements

Codex CLI added Vim undo (u) and redo (Ctrl+R), plus plugin marketplace install/remove from remote registries ([Releasebot](https://releasebot.io/updates/openai/codex)). Antigravity CLI now supports GEMINI_API_KEY for direct Gemini API access without sign-in, and added Gemini Enterprise business authentication ([Google Developers Blog](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/)).
