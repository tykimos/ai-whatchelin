Fable 5 정지 8일째, 오늘이 환불 마감일이다. GPT-5.6 출시 확률이 83%에서 90%로 급등하며 다음 주 AI 시장의 판도 변화가 예고되고 있다.

## Fable 5: 오늘 환불 마감 — 정지 8일째, 복원 시점 여전히 불명

6월 9일 출시 3일 만에 미국 상무부 수출 통제로 정지된 Fable 5·Mythos 5의 환불 마감이 오늘 23:59 PT다([TechJack Solutions](https://techjacksolutions.com/ai-brief/fable-5-refund-window-closes-june-20-what-anthropics-billing/)). 6월 9~14일 사이 구매 건만 대상이며, 이후 구매분은 일반 환불 절차를 따른다. Anthropic 국제사업 총괄은 서울 오피스 런칭에서 "수일 내 복원에 매우 확신한다"고 밝혔으나([TechTimes](https://www.techtimes.com/articles/318668/20260618/fable-5-export-ban-day-six-anthropic-opens-seoul-office-vows-models-back-days.htm)), 백악관은 모든 탈옥 취약점 제거를 복원 전제조건으로 요구하고 있어 보안 전문가들은 기술적으로 불가능하다고 지적한다([InfoQ](https://www.infoq.com/news/2026/06/claude-5-release/)). AI 안전 담당 David Sacks는 "가능한 빨리" 복원하겠다고 밝혔지만 구체적 일정은 없다.

## GPT-5.6: 예측시장 90% — 다음 주 출시 거의 확실

GPT-5.6 출시 확률이 Polymarket에서 6월 22~28일 기준 **90%**로 급등했다(어제 83%)([Polymarket](https://polymarket.com/event/when-will-gpt-5pt6-be-released)). 계약 거래량은 $960,325 이상이며, iris-alpha 코드명에 1.5M 컨텍스트 윈도우가 예상된다. OpenAI 수석 과학자 Pachocki가 "의미 있는 개선"이라 평가한 점, Fable 5 공백으로 인한 경쟁 기회, 그리고 Anthropic IPO 준비 시점과 맞물려 전략적 발표가 유력하다([TechTimes](https://www.techtimes.com/articles/318492/20260616/gpt-56-openai-chief-scientist-calls-it-meaningful-leap-june-launch-nears.htm)).

## Gemini CLI 셧다운 D+2: 워크어라운드 가이드 급증

Gemini CLI 폐쇄 이틀째, 개발자 커뮤니티에 마이그레이션 워크어라운드가 급증하고 있다. `gemini` 바이너리를 호출하던 CI/CD 파이프라인에서 HTTP 410 에러가 지속되고 있으며, MCP `serverUrl` 필드명 변경으로 인한 사일런트 장애가 가장 위험하다([DigitalApplied](https://www.digitalapplied.com/blog/gemini-cli-to-antigravity-cli-migration-june-18-2026-guide)). 대체제 Antigravity CLI(`agy`)의 무료 일간 요청 20회 제한과 폐쇄 소스 정책은 오픈소스 커뮤니티의 강한 반발을 사고 있다([Groundy](https://groundy.com/articles/google-sunsets-gemini-cli-on-june-18-forced-migration-to-antigravity-cli-breaks/)). 엔터프라이즈 라이선스 보유 기업만 Gemini CLI를 유지할 수 있으며, 개인 사용자 파이프라인은 완전히 사망했다.

## Kiro iOS 앱 출시 — 스마트폰에서 코딩 세션 관리

AWS Kiro가 iOS 앱을 조기 액세스로 출시해 모바일에서 코딩 세션을 관리하고 에이전트 변경사항을 승인할 수 있게 됐다([DevOps.com](https://devops.com/aws-previews-ios-app-to-manage-kiro-ai-coding-workflows/)). CLI V3 프리뷰에서는 터미널 기반 스펙 기반 개발, 태그 기반 에이전트 설정이 도입됐다. AWS Summit New York에서 항공우주급 EARS 표기법을 사용하는 스펙 기반 개발이 공개되며 Kiro의 차별화 전략이 뚜렷해졌다([TechTimes](https://www.techtimes.com/articles/318546/20260617/aws-summit-new-york-2026-kiro-brings-aerospace-spec-standards-ai-coding.htm)).

## Copilot 47주 연속 하락 — 36점, 종량제 D-20

Copilot 인기도가 36으로 47주 연속 하락했다([GitHub Discussions](https://github.com/orgs/community/discussions/categories/copilot-news-and-announcements)). 종량제 20일차로, Pro 플랜 $10/월에 $15 크레딧 포함이지만 에이전틱 세션당 $30-40이 소진되어 2시간 만에 월간 크레딧의 8%가 소진되는 사례가 보고됐다([gHacks](https://www.ghacks.net/2026/06/02/github-copilot-usage-based-billing-takes-effect-drawing-developer-backlash-over-rapid-credit-depletion/)). CVSS 9.6 프롬프트 인젝션(CVE-2025-53773)과 새로 발견된 2FA 코드 탈취 취약점(CVE-2026-42824)이 신뢰를 더욱 잠식하고 있다.

## Claude Design 베타 출시 — 디자인에서 코드까지 원스톱

Anthropic이 Claude Design 베타를 유료 플랜(Pro·Max·Team·Enterprise) 사용자에게 공개했다([WindowsNews](https://windowsnews.ai/article/anthropic-launches-claude-design-beta-with-wysiwyg-canvas-and-code-handoff-for-paid-users.427631)). WYSIWYG 캔버스에서 UI 요소를 드래그·리사이즈·스타일링하면 Claude가 실시간으로 코드를 업데이트하며, Figma 등에서 디자인 시스템을 임포트할 수 있다([explainx.ai](https://explainx.ai/blog/claude-design-june-2026-update-design-sync-2026)). `/design-sync` 명령어로 Claude Code와 직접 연동해 프로토타입을 프로덕션 코드로 전환하는 워크플로우가 완성됐다. claude.ai/design 또는 데스크톱 앱 사이드바에서 접근 가능하다.
