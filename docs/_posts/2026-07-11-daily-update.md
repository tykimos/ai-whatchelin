Cursor shipped version 3.11 with side chats — parallel agent conversations that run alongside the main thread without interruption. Use `/side` to ask questions, explore alternatives, and sanity-check decisions while the main agent keeps working, then `@`-mention the side chat to pull findings back ([Cursor Changelog](https://cursor.com/changelog)). Meanwhile, Antigravity broke through to 99 in a historic 22-week streak, and tomorrow's Fable 5 subscription inclusion deadline looms.

## Cursor 3.11: Side Chats and Agent Transcript Search

Side chats are durable, full agent conversations that share context with the main chat but run independently ([Cursor Changelog](https://cursor.com/changelog)). Create them with `/side`, `/btw`, or the `+` button. Agent Transcript Search (Cmd+K in Agents Window) adds a local search index that scales to thousands of past conversations. Cloud Agent Hooks (`beforeSubmitPrompt`, `afterAgentResponse`, `stop`, etc.) enable monitoring and self-correcting loops. Team MCP server configuration lets admins distribute MCP servers across cloud agents, IDE, and CLI in one setup.

## Claude Code v2.1.207 — Auto Mode Default on Bedrock/Vertex/Foundry

## Fable 5 Subscription Inclusion D-1 — Ends Tomorrow

Anthropic's July 7 extension of free Fable 5 access on paid plans expires tomorrow at 11:59:59 PM PT ([Forbes](https://www.forbes.com/sites/sandycarter/2026/07/07/claude-fable-5-extends-by-five-more-days-10-moves-to-make-now/)).
