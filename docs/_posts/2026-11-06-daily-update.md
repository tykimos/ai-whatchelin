OpenAI significantly upgraded its image generation model, expanding ChatGPT's creative toolset. Meanwhile, GitHub Copilot is accelerating its IDE expansion, and Cursor faces the final countdown to losing OpenAI model access.

## ChatGPT: Images 2.6 Launches with GIF Creation and Saved References

OpenAI released ChatGPT Images 2.6 on November 4 ([OpenAI Release Notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)). The new image model generates faster and maintains better detail consistency across edits. GIF creation is now supported directly in conversations, and users can save reference images for reuse in later chats. This is the first major image update since Images 2.5 (September 8), which cut latency 50% and introduced Sketch mode.

## ChatGPT: GPT-6.1 Terra Rollout Expanding

GPT-6.1 Terra is rolling out across ChatGPT Work and Codex ([Releasebot](https://releasebot.io/updates/openai)). Following the October 1 API pricing confirmation ($2/$10/MTok), the model is now being deployed to Work and Codex environments, with Pro users getting first access. Usage allowances for Pro and Business Premium plans were doubled on October 29.

## GitHub Copilot: JetBrains Air Integration, 42-Day Streak

GitHub Copilot became available in JetBrains Air on November 3 ([GitHub Changelog](https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air)). Existing Copilot subscriptions work seamlessly, lowering the barrier for JetBrains developers. This follows the Xcode 27.3 beta integration announced the same day ([9to5Mac](https://9to5mac.com/2026/11/03/xcode-27-3-adds-github-copilot-to-its-built-in-coding-assistant)) — two IDE expansions in 48 hours. The score climbs to 81 on a 42-day winning streak, with 10 days until the November 16 model swap (Opus 4.8/5 to Opus 5.5, GPT-5.6 Terra to GPT-6.1 Sol) ([GitHub Blog](https://github.blog/changelog/2026-10-15-upcoming-deprecation-of-selected-github-copilot-models-in-mid-november)).

## Cursor: OpenAI Cutoff D-6, Day 73 at Bottom

Six days remain until Cursor's OpenAI model access is fully terminated on November 12 ([Tom's Guide](https://www.tomsguide.com/ai/openai-is-leaving-cursor-in-november-here-are-your-3-options)). Day 73 at a score of 1 with no reversal in sight. OpenAI will not ship new models before the cutoff ([VPS Ranking](https://vpsranking.com/news/ai/ai-2026-08-28-openai-cursor-contract-winddown/)), and Cursor continues its pivot to Grok 4.7 and Anthropic models.

## Anthropic: IPO Roadshow D-3, Mythos 5.5 Speculation Continues

The Anthropic IPO roadshow could begin as early as the week of November 9 — just 3 days away ([Leverage Shares](https://leverageshares.com/us/insights/when-is-the-anthropic-ipo/)). The Mythos 5.5 reference spotted on November 1 remains unconfirmed 5 days later ([TestingCatalog](https://www.testingcatalog.com/anthropic-prepares-to-release-claude-mythos-5-5-model/)). Claude Code's co-author line now appears on 13.8% of GitHub commits, tracking toward the 20% end-of-2026 forecast ([X/con_golias](https://x.com/con_golias/status/2118301334835208380)).

## Postman: Unauthorized Plugin Injection Controversy

A Postman desktop update reportedly auto-added Postman plugins to Claude Code and Codex without user consent ([Mezha](https://mezha.net/eng/news/mezha-3d570273b493dad39d47211c_postman_update_added/)). The same behavior was reported in GitHub Copilot CLI. No evidence of data collection has emerged, but the incident highlights trust concerns around third-party integrations in the AI coding tool ecosystem.
