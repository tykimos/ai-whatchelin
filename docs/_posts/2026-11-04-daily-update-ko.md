Goldman Sachs와 ByteDance의 AI 도구 접근 제한이 보안 측면의 전환점이었다면, Revolut의 자체 호스팅 전환은 비용 측면의 전환점이다. 기업들이 AI 코딩 도구를 단순 구독에서 인프라 관리로 재편하고 있다.

## Revolut: 자체 호스팅 GLM으로 AI 코딩 비용 90% 절감

Revolut이 약 2,000명의 엔지니어를 Claude Code 등 메터드 API에서 Z.ai의 GLM-5.3 자체 호스팅으로 전환해 AI 코딩 추론 비용을 약 90% 절감했다([StartupHub.ai](https://www.startuphub.ai/ai-news/artificial-intelligence/2026/revolut-says-self-hosted-ai-cut-coding-costs-90)). Nvidia B200 56대 위에서 운영되며, 4월 자체 호스팅 이후 코딩 시간 60%, 리드 타임 70% 개선을 보고했다. AI Engineer 컨퍼런스에서 공개된 수치로, Revolut 자체 공식 발표는 아직 없다.

## Anthropic IPO: 수정 S-1에 $895B 컴퓨팅 비용 공개, 로드쇼 D-5

Anthropic이 10월 26일 S-1을 제출한 후, 11월 2일 수정 S-1이 공개되며 핵심 재무 세부사항이 드러났다([Yahoo Finance](https://finance.yahoo.com/markets/article/anthropics-new-ipo-filing-puts-its-computing-bill-near-900-billion-151830444.html)). 수정 S-1에는 약 $895B(8,950억 달러)의 컴퓨팅·데이터센터 계약이 포함되어 있으며, 이 중 ~$70B는 1년 이내 지급 예정이다. 3분기 실적은 매출 약 $17B, 영업손실 $567M으로, 전 분기 $974M 영업이익에서 반전했다([CNBC](https://www.cnbc.com/2026/10/26/anthropic-ipo-live-updates-ai-s-1-filing.html)). 일부 투자자들은 AI 시장 변동성을 이유로 $2T 목표 대비 $1.5~1.6T으로 밸류에이션 하향을 요구하고 있다([Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/anthropic-updates-ipo-filing-investors-034041239.html)). 가격대가 포함된 수정 S-1이 아직 제출되지 않은 상태로, 로드쇼는 이르면 11월 9일 주간에 시작될 수 있다([Leverage Shares](https://leverageshares.com/us/insights/when-is-the-anthropic-ipo/)).

## GitHub Copilot: 77점, 40일 연속 상승 — Xcode 통합, 모델 교체 D-12

GitHub Copilot이 40일 연속 상승하며 77점을 기록했다. 11월 3일 공개된 Apple Xcode 27.3 베타 1에 GitHub Copilot이 빌트인 코딩 어시스턴트로 탑재되었다 — Apple이 Xcode에 서드파티 AI 도구를 네이티브 통합한 최초의 사례다([9to5Mac](https://9to5mac.com/2026/11/03/xcode-27-3-adds-github-copilot-to-its-built-in-coding-assistant)). 11월 16일에는 Claude Opus 4.8, Claude Opus 5, GPT-5.6 Terra가 제거되고 Claude Opus 5.5와 GPT-6.1 Sol로 교체된다([GitHub Blog](https://github.blog/changelog/2026-10-15-upcoming-deprecation-of-selected-github-copilot-models-in-mid-november)).

## Antigravity: 플러그인 마켓플레이스 출범, 67개 런치 파트너

Google이 10월 29~30일 Antigravity 플러그인 마켓플레이스를 공식 오픈했다([WikiDocs](https://wikidocs.net/blog/@openwiki/35105/)). Figma, Jira, Notion, Stripe 등 67개 런치 파트너가 참여하며, Customizations 패널이나 터미널에서 `agy plugin install` 명령으로 설치할 수 있다. Google Cloud 개발자 플러그인도 등장해 사전 인증된 Developer Knowledge MCP 서버를 통한 문서 그라운딩과 안전·비용 가드레일을 제공한다([AI Agent Store](https://aiagentstore.ai/ai-agent-news/this-week)). IDE를 넘어 플랫폼으로의 전환을 선언한 셈이다.

## Cursor: OpenAI 모델 차단 D-8, 71일째 바닥

11월 12일 OpenAI 모델 접근 완전 차단까지 8일 남았다([Bloomberg](https://www.bloomberg.com/news/articles/2026-08-29/openai-to-end-partnership-with-cursor-after-spacex-acquisition)). 공급망 공격 후속 조치와 맞물려 71일 연속 1점을 기록 중이다. Goldman Sachs의 AI 도구 제한 조치에서도 Cursor는 이미 제외 대상에서 빠져 있어, 엔터프라이즈 시장에서의 존재감이 사실상 소멸했다.

## OpenAI: 12월 사용량 풀 통합에 커뮤니티 반발

OpenAI가 12월부터 Plus, Pro, Business 플랜의 ChatGPT와 Codex 사용량을 단일 토큰 예산으로 통합한다([ARY News](https://arynews.tv/openai-to-combine-chatgpt-and-codex-usage-limits-for-premium-subscribers)). Pro/Business Premium 대상 Codex/Work 사용량 2배 인상 직후 나온 변경이라 커뮤니티 반발이 거세다 — OpenAI 포럼의 Codex 레이트 리밋 스레드는 100건을 넘겼고, 개발자들은 3~4개 프롬프트만에 한도에 도달한다고 보고하고 있다([OpenAI Community](https://community.openai.com/t/codex-usage-limit-is-reached-too-quickly-even-with-chatgpt-plus/1379502)).

## 11월 데드라인 캘린더

이번 달은 AI 코딩 생태계에서 주요 전환점이 몰려 있다. Cursor의 OpenAI 모델 접근 차단(11/12)과 Anthropic 이용정책 업데이트(11/12)가 같은 날 예정되어 있으며, GitHub Copilot의 모델 교체(11/16), 추수감사절 전 Anthropic 상장(11월 중), Claude Sonnet 4.5 API 퇴장(11/30) 등이 연이어 진행된다([The Neuron](https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-wednesday-november-4-2026/)). OpenAI의 Agent Builder와 Evals API 중단도 11월 말로 예정되어 있다.
