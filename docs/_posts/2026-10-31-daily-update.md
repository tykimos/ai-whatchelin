Three days after GitHub Universe 2026 wrapped, GitHub made a move that quietly reshapes the developer ecosystem. The Copilot SDK has been renamed to Microsoft Copilot SDK — not just a branding exercise, but a signal that Microsoft's AI strategy is expanding beyond the GitHub brand boundary.

## GitHub Copilot: SDK Rebrand and Fusion GA Day 3

GitHub announced on October 28 that the Copilot SDK is becoming the Microsoft Copilot SDK([GitHub Blog](https://github.blog/changelog/2026-10-28-github-copilot-sdk-is-becoming-microsoft-copilot-sdk/)). The repository has moved to the Microsoft organization, with existing package names and namespaces transitioning in phases. GitHub says "no immediate changes are required for existing users," but the move signals that Copilot's agentic infrastructure has become a core Microsoft-wide platform, not just a GitHub product.

Meanwhile, on Fusion GA's third day, Copilot's popularity score climbed to 69 — a 36-day consecutive recovery streak. The gap over Cursor has widened to 68 points. Artificial Analysis benchmarks show Fusion scoring roughly two points below Claude Code (Opus 5.5) at about half the per-task cost([Artificial Analysis](https://artificialanalysis.ai/articles/github-copilot-fusion-orchestrates-anthropic-and-openai-models-to-balance-performance-and-cost)). Starting October 28, Enterprise customers can use all Copilot features without a separate subscription, paying only for AI credits consumed.

## Codex CLI: v0.165.0 Released

Codex CLI shipped v0.165.0 on October 27([GitHub Releases](https://github.com/openai/codex/releases)), following v0.164.0 (October 22) which added 10-slot presets and inline /model arguments. The tool maintains a steady release cadence since GPT-6.1 Sol's default context window expanded to 500K tokens, and GPT-6.1 Terra has reportedly become available on paid plans.

## Anthropic: IPO Roadshow Expected Week of November 9

Anthropic's 'ANT' ticker Nasdaq listing is taking shape. Bloomberg reports the roadshow could begin as early as the week of November 9, targeting a pre-Thanksgiving listing([ShareSansar](https://www.sharesansar.com/newsdetail/anthropics-ipo-could-become-worlds-largest-ipo-surpassing-spacexs-record-breaking-ipo-2026-10-28)). The expected valuation sits at $1.5–2 trillion with proceeds of $75–100B, potentially surpassing SpaceX's $86B IPO([CryptoBriefing](https://cryptobriefing.com/anthropic-nasdaq-ipo-listing-2026/)). The S-1's disclosed H1 revenue of $16.3B (14x YoY) underpins investor confidence.
