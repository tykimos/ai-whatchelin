Anthropic disclosed through its threat intelligence report that Houthi militants attempted to use Claude Code for missile guidance system development ([Hacker News](https://news.ycombinator.com/item?id=42813948)). The revelation drew 84 comments on HN, sparking heated debate over AI safety guardrails and dual-use technology. Combined with Microsoft's AI code of conduct draft released a day earlier, the incident has elevated AI coding tool access control from a product concern to a governance and national security conversation.

## Claude Code: v2.1.271 Brings Fast Mode to Remote Sessions

Claude Code v2.1.271 shipped today ([Releasebot](https://releasebot.io/updates/anthropic/claude-code)). The headline feature is Fast mode now working in Remote sessions — both cloud and self-hosted runners. The release also adds mouse support in /config fullscreen, per-command `allowed_domains` for Bash/PowerShell/Monitor in auto mode sandboxing, `multiplier` values up to 10 in managed modelPricing, and a `--accept-command` flag for plugin installation and updates. Separately, Anthropic reported that its CI workload grew 25-fold in six months, with Claude authoring approximately 80% of new code ([AI Weekly](https://aiweekly.co/ai-news-today/edition/2026-09-15)).

## Google Antigravity: Managed Coding Agent Enters Preview

Google integrated Antigravity into the Gemini API as a managed agent accessible through the Interactions API ([Paragraph](https://paragraph.com/@kd-agentic/ai-daily-digest-sept-15-2026-microsofts-humanist-ai-code-a-free-coding-agent-and-a-dollar5b-chinese-raise)). A single request provisions a Google-hosted Linux sandbox where the agent plans, acts, observes, and keeps going until it finishes or hits a limit. The default model is Gemini 3.8 Flash, and sandbox compute is free during the preview period. Token pricing is $0.75/$3.75 per million tokens through 2026, doubling on January 1, 2027.

## Cursor: Day 25 of Decline, Score Drops to 61

Cursor fell to 61, marking its 25th consecutive day of decline. The OpenAI model access cutoff (November 12) is now D-58. The Projects beta with its coordinator-agent architecture continues to impress ([Cursor Changelog](https://cursor.com/changelog/projects)), but post-SpaceX acquisition uncertainty and data terms controversy are preventing any recovery. The 60-point level, approaching next, could represent a psychological floor break.

## Microsoft: AI Code of Conduct Draft Published

Microsoft AI released a 37-page AI code of conduct draft on September 14, establishing the principle that "people matter more than AI" ([Paragraph](https://paragraph.com/@kd-agentic/ai-daily-digest-sept-15-2026-microsofts-humanist-ai-code-a-free-coding-agent-and-a-dollar5b-chinese-raise)). The document prohibits assistance with weapons of mass destruction and offensive cyber capabilities, bars models from evading human oversight, and forbids independent goal-setting. Public consultation runs through late October, with implementation planned for 2027 development. The timing alongside the Houthi disclosure adds weight to the access control debate.

## Community: "AI Speeds Up Coding But Not Delivery"

GitLab research finding that AI tools speed up code writing but don't improve end-to-end delivery — due to review, testing, and governance bottlenecks — resonated strongly with practitioners on HN ([Developers Digest](https://www.developersdigest.tech/blog/what-hacker-news-gets-right-about-ai-coding-agents-2026)). The Real-SWE benchmark (268 points, 147 comments) also drew attention as a new standard for evaluating AI models against real enterprise codebases.
