Satya Nadella said it himself — VS Code's decade of dominance crumbled in six months after Claude Code arrived. In an interview with Gergely Orosz published November 16, the Microsoft CEO called it "the thing that hit us," acknowledging that IDEs have been fading as developers move to terminal-based AI agents([Windows Latest](https://www.windowslatest.com/2026/11/23/the-thing-that-hit-us-satya-nadella-admits-vs-code-faded-in-six-months-after-a-decade-on-top-because-of-claude-code-and-some-developers-say-theyve-stopped-opening-it/)). Stack Overflow's 2026 Developer Survey backs this up: VS Code usage fell from 75.9% to 70.9%, while Claude Code hit 65.5% in the AI coding agents category([ExplainX](https://explainx.ai/blog/satya-nadella-claude-code-ide-faded-pragmatic-engineer-november-2026)).

## VS Code's Crisis and Microsoft's Counter

Nadella said IDEs "faded away" but stopped short of a death sentence. He suggested the IDE's role may shift from writing code to serving as a documentation hub([Windows Report](https://windowsreport.com/satya-nadella-admits-claude-code-is-changing-the-future-of-vs-code-as-developers-move-away-from-ides/)). Microsoft is responding by opening VS Code to Claude, Codex, and Copilot agents alike. VS Code 1.146 (Nov 11) added an agent inbox and model comparisons; 1.147 (Nov 18) brought model routers and scheduled agent requests([ExplainX](https://explainx.ai/blog/satya-nadella-claude-code-ide-faded-pragmatic-engineer-november-2026)).

## Anthropic: Fable 5.2 and Mythos 5.2 Launch, ANT at $99

Anthropic released Claude Fable 5.2 and Mythos 5.2 on November 9([Anthropic](https://www.anthropic.com/news/claude-fable-and-mythos-5-2)). Both share the same architecture — Fable is open to all users, while Mythos is restricted to vetted cybersecurity and life-sciences organizations. Pricing is $8/$40 per million tokens. Fable 5.2 scored 49.1% on FrontierCode 2.0 versus 45.5% for Opus 5.5([Constellation Research](https://www.constellationr.com/insights/news/anthropic-releases-mythos-52-fable-52)). ANT stock has settled near $99 after debuting at $111.50, now on trading day 5([Upstox](https://upstox.com/us-stocks/anthropic-pbc-class-a-share-price/)).

## GitHub Copilot: Generational Shift Complete

Claude Opus 4.8, Opus 5, and GPT-5.6 Terra were removed from all Copilot surfaces on November 16([GitHub Blog](https://github.blog/changelog/2026-11-16-github-copilot-models-deprecated-on-november-16-2026)), replaced by Gemini 4 Carbon and MAI Code 2. Claude Opus 5.5 and GPT-6.1 Sol are the recommended replacements([GitHub Blog](https://github.blog/changelog/2026-11-16-github-copilot-weekly-releases-november-9)).

## OpenAI: GPT-6.2 Astra Clears 'High' Self-Improvement Threshold

GPT-6.2 Astra and Sol launched November 17([OpenAI](https://openai.com/index/introducing-gpt-6-2-astra-sol)). Astra is the first externally deployed model to meet OpenAI's "High" AI Self-Improvement threshold, with API pricing at $8/$40 per million tokens — 20% cheaper than GPT-6 Astra([Pulse2](https://pulse2.com/openai-introduces-gpt-6-2-astra-and-sol-with-improved-performance-and-lower-task-costs/)).

## Cursor: OpenAI Blackout Day 12

OpenAI cut off model access to Cursor (SpaceXAI subsidiary) on November 12, now on day 12([ClickUp](https://clickup.com/learn/topic/ai/tools/cursor/news/)). Cursor 3 runs on its in-house Composer 2.5 and xAI models, but it has sat at the bottom of popularity rankings for 123 consecutive days.
