The AI coding tool wars are shifting from "who writes the code" to "who validates it." Anthropic's Claude Ship beta and GitHub's Copilot Fusion GA landing in the same week signals that the race is now about owning the entire developer workflow.

## Claude Ship: AI That Reviews, Fixes, and Merges PRs

Anthropic unveiled Claude Ship beta on November 23 — a suite of AI agents that automatically review pull requests, fix bugs, and decide what's ready to merge([TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes)). It completes the full-cycle vision: Claude Code writes, Ship verifies. Claude Code itself reached v2.1.327, adding Code Mode support with agent teams enabled and real-time streaming for remote sessions([Claude World](https://claude-world.com/articles/claude-code-november-2026-whats-new/)). Sonnet 4.5 retires November 30, replaced by Sonnet 5.5.

## Copilot Fusion GA and Microsoft Ignite

GitHub Copilot Fusion reached general availability on October 28([GitHub Blog](https://github.blog/changelog/2026-10-28-route-and-orchestrate-models-with-github-copilot-fusion)). Instead of users picking models, Fusion automatically routes tasks to the best-fit model. At Microsoft Ignite on November 17, GitHub added MAI Code 2 and MAI Code 2 Flash in-house models, refreshed the Copilot CLI, and scheduled six legacy models for deprecation on December 14([VPSRanking](https://vpsranking.com/news/ai/ai-2026-11-17-github-copilot-ignite-updates/)). Copilot's Terminal-Bench 4.1 lead at 71.2% over Claude Code's 65.8% may partly reflect the Fusion routing advantage([MorphLLM](https://www.morphllm.com/best-ai-coding-agents-2026)).

## GPT-6.2 Astra and Sol: One Week In

OpenAI launched GPT-6.2 Astra and Sol on November 17([OpenAI](https://openai.com/index/introducing-gpt-6-2-astra-sol)). Astra targets demanding professional work (API: $8/$40 per 1M tokens, 20% below GPT-6 Astra), while Sol handles everyday coding. OpenAI claims 6.2pp improvement and 22% fewer output tokens versus GPT-6 Astra([Digital Trends](https://www.digitaltrends.com/computing/openai-gpt-6-2-astra-sol-launch/)). Codex CLI hit v0.170 with WebRTC voice calls and automatic session recovery([OpenAI Changelog](https://learn.chatgpt.com/docs/changelog)).

## Agent Swarms: Devin Bots vs Replit Missions

Cognition's Devin Bots split projects into parallelized task sessions, with early customers seeing 10x usage growth in two weeks([Fortune](https://fortune.com/2026/11/17/exclusive-cognition-bets-on-devin-bots-coding-agents-in-challenge-to-anthropics-duet-and-openais-dots/)). Replit countered with Missions — agent swarms that pursue multi-day goals instead of responding to single prompts([The New Stack](https://thenewstack.io/replit-missions-agent-swarms/)).

## ANT IPO and the Cursor Blackout

Anthropic (ANT) is on IPO day 6. It priced at $83, opened at $111.50, and closed day one at $97.17, raising $81.3 billion — the largest IPO in history([TechRepublic](https://www.techrepublic.com/article/news-anthropic-ipo-nasdaq-trading-debut/)). The stock has been oscillating in the $95–99 range since. Cursor's OpenAI model blackout is now at day 13, and it has spent 124 consecutive days at the bottom of popularity rankings([ClickUp](https://clickup.com/learn/topic/ai/tools/cursor/news/)).
