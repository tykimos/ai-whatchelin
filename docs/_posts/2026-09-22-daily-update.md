The Copilot unified experience countdown hits D-6. Starting September 28, GitHub Copilot Chat, Mobile, and Cloud Agent merge into a single session, and the code review default automatically shifts from Lite to Balanced ([GitHub Blog](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)). Meanwhile, Cursor dropped another 2 points to 47 — day 33 of its post-SpaceX acquisition slide.

## Cursor: Day 33 Decline, 47 — OpenAI Model Cutoff D-51

Cursor fell from 49 to 47 today, marking 33 consecutive days of decline since SpaceX closed the $60B acquisition on August 14 ([TechCrunch](https://techcrunch.com/2026/08/15/spacex-officially-closes-its-cursor-acquisition/)). With OpenAI set to cut off Cursor's model access on November 12 ([CNBC](https://www.cnbc.com/2026/08/29/openai-cursor-spacex-model-access.html)), the Projects beta hasn't stemmed the bleeding yet. Cursor says OpenAI models account for only 5% of traffic, but market sentiment continues to erode.

## Codex CLI v0.155.1: Experimental Voice Chat and Touch ID

Codex CLI v0.155.0 shipped experimental voice conversations with live transcripts and microphone controls ([Releasebot](https://releasebot.io/updates/openai/codex)). Reasoning summaries now appear in the status row in real time, and Touch ID verification for MCP requests is available on supported Macs. Follow-up v0.155.1 fixed local TUI sessions by disabling reasoning summaries by default and respecting explicit settings for provider compatibility ([Releasebot](https://releasebot.io/updates/openai/codex)).

## Claude Code: Projects Coordinator and Agent Teams Research Preview

Anthropic redesigned Claude Projects on September 17, introducing a parallel architecture where threads do the work and a coordinator directs them ([Releasebot](https://releasebot.io/updates/anthropic)). Agent Teams entered research preview, enabling multiple Claude Code sessions to work on related tasks simultaneously and share results through a team structure. Claude Code v2.1.278 switched to a server-side auto mode classifier by default, eliminating classifier overhead costs ([Claude Code Changelog](https://code.claude.com/docs/en/changelog)).

## GPT-5.5 Retirement D-22 — ChatGPT Word Integration Expands

GPT-5.5 retires from ChatGPT and Codex on October 14 — 22 days out ([Releasebot](https://releasebot.io/updates/openai/chatgpt)). The Microsoft Word integration is now available across all plans, enabling drafting, summarizing, proofreading, and formatting from the ChatGPT sidebar. A new speech-to-text model has also rolled out to all plans with improved multilingual transcription accuracy.
