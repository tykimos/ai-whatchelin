Anthropic의 Code with Claude 도쿄가 오늘 개막했다. 이틀 전 폭탄처럼 투하된 Fable 5의 열기가 채 식기도 전에, Research·Platform·Code 3트랙으로 구성된 이번 컨퍼런스가 일본 시장을 겨냥한 Anthropic의 본격적인 행보를 알렸다.

## Code with Claude 도쿄: NEC 파트너십과 3만 명 배포

Code with Claude 도쿄가 Research·Platform·Code 3트랙으로 개막했다([claude.com](https://claude.com/code-with-claude/tokyo)). NEC가 Anthropic의 일본 최초 글로벌 파트너로 발표됐으며, NEC 그룹 전 세계 직원 3만 명 이상에게 Claude를 배포한다([ChatForest](https://chatforest.com/builders-log/code-with-claude-tokyo-june-10-builder-preview-guide/)). 4월 추첨에서 탈락한 참가자들의 요청으로 내일 인디 개발자 전용 Extended 세션이 추가됐다([claude.com](https://claude.com/code-with-claude/tokyo-extended)). Fable 5 출시 직후 열리는 만큼 새로운 기능 발표에 대한 기대가 높다.

## Fable 5 첫 반응: "괴물급이지만 느리고 비싸다"

Fable 5 출시 이틀째, 개발자들의 첫 반응이 쏟아지고 있다. Simon Willison은 "괴물급 성능"이라며 던진 모든 작업을 소화했다고 평가하면서도, 느린 속도와 높은 비용($10/$50/M 토큰)을 지적했다([Simon Willison](https://simonwillison.net/2026/Jun/9/claude-fable-5/)). Latent Space는 이용약관 변경에 대한 논란을 조명했다([Latent Space](https://www.latent.space/p/ainews-anthropic-claude-fable-5-mythos)). AWS Bedrock에도 동시 출시돼 엔터프라이즈 접근성이 확보됐고([AWS Blog](https://aws.amazon.com/blogs/aws/anthropic-claude-fable-5-on-aws-mythos-class-capabilities-with-built-in-safeguards-now-available/)), GitHub Copilot에서도 Fable 5를 GA로 사용할 수 있다([GitHub Changelog](https://github.blog/changelog/2026-06-09-claude-fable-5-is-generally-available-for-github-copilot/)).

## Copilot: 46, 37주 연속 하락

Copilot이 **46**을 기록하며 37주 연속 하락했다([ghacks](https://www.ghacks.net/2026/06/02/github-copilot-usage-based-billing-takes-effect-drawing-developer-backlash-over-rapid-credit-depletion/)). 종량제 10일차, JetBrains 설문에서 경력 10년 이상 개발자의 46%가 Claude Code를, 9%만 Copilot을 선택했다([NxCode](https://www.nxcode.io/resources/news/github-copilot-getting-worse-2026-developers-switching)). Stack Overflow 2026 조사에서 시장점유율이 67%에서 51%로 급락한 상태다.

## SpaceX IPO D-2: 역대 최대 상장 초읽기

SpaceX IPO 가격 결정이 내일(6/11), 나스닥 거래 개시가 모레(6/12)다([TradingKey](https://www.tradingkey.com/analysis/stocks/us-stocks/261904604-spacex-ipo-spcx-date-set-for-june-12-175-trillion-valuation-tradingkey)). 주당 $135, $1.75조 밸류에이션으로 역대 최대 IPO가 된다. 나스닥-100 편입이 15거래일 내 가능한 패스트트랙 규정이 적용되어, 인덱스 펀드의 약 $70억 매수가 예상된다([eciks.org](https://eciks.org/7803-24831-qqq-spacex-ipo-nasdaq-100-june-2026)). Cursor $600억 인수 자금이 이 IPO로 확보된다.

## 이번 주 카운트다운

Anthropic 에이전트 과금 분리(D-5, 6/15), Gemini CLI 종료(D-8, 6/18) — Agent SDK와 `claude -p` 사용량이 구독 풀에서 분리되며, Pro $20·Max 5x $100·Max 20x $200 크레딧 풀이 적용된다([codersera](https://codersera.com/blog/anthropic-june-2026-billing-change-claude-code/)). Gemini CLI 종료 후에는 기업 고객만 접근 가능하며, 나머지는 Antigravity CLI로 전환해야 한다([Google Developers Blog](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/)).
