Codex CLI has finally overtaken Cursor. Riding an 8-day streak fueled by GPT-5.6 Luna's 80% price cut, it hit 98 today — one point above Cursor's 97, marking the first time a terminal-native agent has surpassed the dominant IDE-based tool in popularity. Meanwhile, Claude Opus 4.1's API enters its final hours before permanent retirement tomorrow.

## Codex CLI: Hits 98 — First-Ever Cursor Overtake, Luna Streak Day 8

The ripple effects of GPT-5.6 Luna's 80% price cut (Jul 30) continue into day eight([VentureBeat](https://venturebeat.com/technology/ai-price-wars-openai-cuts-gpt-5-6-luna-prices-by-80-as-model-competition-shifts-toward-cost)). Codex CLI climbed 91→92→93→94→95→96→97→98, gaining one point per day. After tying Cursor at 97 yesterday, it broke through today for a historic first overtake. The 10x reduction in auto-review costs is the primary driver. Cursor remains steady at 97 with its iPad launch and Router rollout providing support, but terminal-first developers are noticeably migrating.

## Anthropic: Opus 4.1 Permanent Retirement Tomorrow — D-1

Claude Opus 4.1 (claude-opus-4-1-20250805) permanently retires from the API tomorrow, August 5([Anthropic](https://platform.claude.com/docs/en/about-claude/model-deprecations)). This is exactly 60 days after the June 5 deprecation notice. After tomorrow, all requests to that model ID will return errors — migration to Opus 4.8 is mandatory([TheRouter.ai](https://therouter.ai/news/anthropic-deprecates-claude-opus-4-1-august-5-migration-guide/)). The 50% weekly usage boost for Claude Code Pro and Max subscribers continues through August 19.

## OpenAI: Astra September at Earliest — Federal Review Required

Astra has no confirmed release date, pricing, or API access([FelloAI](https://felloai.com/all-we-know-about-chatgpt-6/)). It must pass a new federal pre-release review process expected to take approximately 30 days, putting the earliest public window in September. OpenAI is also expected to publish a technical report on the Hugging Face breach this month([WinBuzzer](https://winbuzzer.com/2026/07/29/hugging-face-ceo-seeks-openai-traces-and-defensive-compute-xcxwbn/)).

## GitHub Copilot: Major Model Deprecations September 1

GitHub announced it will deprecate multiple models across all Copilot experiences on September 1([GitHub Changelog](https://github.blog/changelog/2026-07-31-upcoming-august-2026-model-deprecations-in-github-copilot/)). Claude Sonnet 4.6 will remain available only for individual annual plan subscribers. Gemini 2.5 Pro and 3 Flash were already removed on July 31.

## DeepSeek: V4 Pro GA Imminent — Mid-August Expected

DeepSeek V4-Flash-0731 was promoted from preview to official release([Hugging Face Blog](https://huggingface.co/blog/ResterChed/deepseek-v4-flash-official-release)). V4 Pro GA has been described only as "coming soon," but reporting points to a mid-August release window([deepseekv4pro.com](https://deepseekv4pro.com/news/deepseek-v4-ga-mid-august-release-window-harness-beta)). Responses API and Codex support are expected to ship alongside.
