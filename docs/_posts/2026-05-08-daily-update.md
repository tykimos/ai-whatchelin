Anthropic signed a 7-year, $1.8 billion cloud computing deal with Akamai Technologies, sending Akamai stock soaring roughly 27%([Bloomberg](https://www.bloomberg.com/news/articles/2026-05-08/anthropic-inks-1-8-billion-computing-deal-with-akamai), [CNBC](https://www.cnbc.com/2026/05/08/akamai-stock-ai-cloud-infrastructure-deal.html)). Coming on the heels of the SpaceX Colossus data center partnership, this marks Anthropic's second major infrastructure expansion in a week — a clear signal that the AI coding war is now an infrastructure war.

## Claude Cowork Goes GA — Agentic AI Beyond Coding

Claude Cowork and Claude Code on Desktop are now generally available on all paid plans for macOS and Windows([eWeek](https://www.eweek.com/news/claude-cowork-general-availability-enterprise-controls/)). New enterprise features include role-based access controls, group spend limits, expanded OpenTelemetry analytics, and Zoom connector support. This marks Anthropic's push to extend agentic AI from coding into general knowledge work. Claude Code's popularity score rises from 97 to 98.

## Claude Code: TrustFall Security Debate Enters Day Two

The 'TrustFall' one-click RCE vulnerability disclosed by Adversa.AI continues to dominate Hacker News([CodeSecAI](https://codesecai.com/ai-coding-agents-trustfall-rce-2026/), [Hacker News](https://news.ycombinator.com/item?id=48037986)). Anthropic's stance that user consent ("Yes, I trust this folder") constitutes sufficient authorization has split the community. Meanwhile, Snyk announced it is embedding Claude models into its AI security platform for automated vulnerability discovery, prioritization, and developer-ready fixes([SD Times](https://sdtimes.com/ai/may-8-2026-ai-updates-from-the-past-week-coder-agents-launch-snyk-claude-partnership-opsera-cursor-partnership-and-more/)).

## Cursor: Bugbot Self-Learning and Opsera DevSecOps Integration

Cursor's Bugbot now self-improves from PR feedback through learned rules and gained MCP server support for richer review context([Cursor Blog](https://cursor.com/blog/bugbot-learning)). Resolution rate is nearing 80%. Separately, Opsera shipped DevSecOps Agents — Architecture Analyzer, Security/SQL Scanner, and Compliance Auditor — as a native Cursor IDE plugin([SD Times](https://sdtimes.com/ai/may-8-2026-ai-updates-from-the-past-week-coder-agents-launch-snyk-claude-partnership-opsera-cursor-partnership-and-more/)). The score climbs from 92 to 93, a new all-time high.

## GitHub Copilot: D-23 and GPT-4.1 Deprecation Notice

The countdown to usage-based billing hits 23 days([GitHub Blog](https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/)). GitHub also announced the upcoming deprecation of GPT-4.1 across Copilot, pushing users toward GPT-5.5([GitHub Features](https://github.com/features/copilot/whats-new)). VS Code's April–May updates added semantic workspace search, `/chronicle` chat history, and BYOK support([GitHub Changelog](https://github.blog/changelog/2026-05-06-github-copilot-in-visual-studio-code-april-releases/)). The score holds at 78 — six consecutive weeks of decline.
