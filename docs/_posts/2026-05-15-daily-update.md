OpenAI is reportedly preparing legal action against Apple over broken promises around ChatGPT integration — a stark reminder of how fragile Big Tech AI partnerships can be([TechCrunch](https://techcrunch.com/2026/05/14/openai-is-reportedly-preparing-legal-action-against-apple-it-wouldnt-be-the-first-partner-to-feel-burned/)). On the same day, OpenAI disclosed that a TanStack supply-chain attack compromised two employee devices, though no user data was accessed([TechCrunch](https://techcrunch.com/2026/05/14/openai-says-hackers-stole-some-data-after-latest-code-security-issue/)).

## Anthropic: Small Business Push + Agent Metering Preview

Anthropic launched Claude for Small Business — free half-day AI workshops bundled with 15 ready-to-run agentic workflows spanning finance, operations, sales, HR, and customer service([Axios](https://www.axios.com/2026/05/13/anthropic-claude-small-business-smb)). A PwC partnership also went live, deploying Claude for enterprise deal execution and function reinvention([Anthropic](https://www.anthropic.com/news)). Starting June 15, agent usage separates from chat subscriptions: Pro gets $20/month in credits, Max 5x gets $100, Max 20x gets $200([InfoWorld](https://www.infoworld.com/article/4171274/anthropic-puts-claude-agents-on-a-meter-across-its-subscriptions.html)). The Code with Claude conference runs May 19-22 in San Francisco.

## Windsurf: Devin Review + Terminal Agent Now Available to All

Cognition opened Devin Review, Quick Review, and Devin for Terminal to all Windsurf users([Cognition Blog](https://cognition.ai/blog/devin-in-windsurf)). Existing subscribers get a 2-week free trial, and Devin Local enables a hybrid CLI-to-cloud handoff workflow. Since acquiring Windsurf ($82M ARR, 350+ enterprise customers) after OpenAI's $3B deal collapsed, Cognition has moved fast on integration([VentureBeat](https://venturebeat.com/programming-development/remaining-windsurf-team-and-tech-acquired-by-cognition-makers-of-devin-were-friends-with-anthropic-again)).

## GitHub Copilot: Flex Allotments Reveal Effective Price Hikes

The fine print on Copilot's flex allotments is out: Pro usage rises from $10 to $15, Pro+ from $39 to $70([WinBuzzer](https://winbuzzer.com/2026/05/14/github-copilot-individual-plans-introducing-flex-a-xcxwbn/)). Code completions and Next Edit remain credit-free, but agent workloads just got more expensive. Week 12 of the signup freeze — score dips from 73 to 72.

## OpenAI: More Fundraising Beyond $122B

OpenAI's CFO signaled that the company may raise additional capital beyond its $122B round as compute demand intensifies([Bloomberg](https://www.bloomberg.com/news/articles/2026-05-15/openai-may-raise-more-money-as-compute-crunch-deepens-cfo-says)). Despite GPT-5.5 Instant performing well, the Apple lawsuit preparation and security incident make for a complicated week.

## Community: 81% of Orgs Report More Time in Code Review Post-AI

A Harness report found that 81% of organizations say developers spend MORE time on code review since adopting AI tools, with ~31% of dev time now consumed by "invisible work" — reviewing AI code, fixing AI-introduced bugs, and context-switching([PRNewswire](https://www.prnewswire.com/news-releases/harness-report-reveals-ai-has-outpaced-how-engineering-organizations-measure-developer-productivity-302770521.html)). Google I/O is now D-4, with Gemini Intelligence and the Android reboot expected to dominate next week's announcements([Android Authority](https://www.androidauthority.com/what-to-expect-from-google-io-2026-3664979/)).
