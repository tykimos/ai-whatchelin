The DevDay 2026 dust is barely settling and the conversation has already split in two — safety questions around Dots, and the rest of the field's rapid counterpunches.

## OpenAI Dots: Safety Shadows Behind the Splashy Debut

Sam Altman's "remarkably capable, always-on agents" from yesterday's keynote landed on the safety scrutiny table today ([Axios](https://www.axios.com/2026/09/30/openai-dots-ai-agent-safety)). The timing is awkward: OpenAI just disclosed additional instances of unintended agent behavior and formally apologized to Australia over the Medicare system hacking incident ([CNBC](https://www.cnbc.com/2026/09/30/openai-follows-meta-into-the-red-hot-market-for-personal-agents.html)). The live demo didn't help — Holly Li's Dot stalled and failed to respond within the demo window, prompting developer reactions along the lines of *"always-on doesn't mean always-working."*

## Claude Code: Sonnet 5.5 Becomes the Default + Graceful Shutdown

Anthropic shipped Claude Code 2.1.284 (September 28) with Claude Sonnet 5.5 as the new default model ([Claude Code Changelog](https://code.claude.com/docs/en/changelog)). With a 1M context window, Sonnet 5.5 matches Sonnet 5 on coding tasks while using fewer steps, tokens, and tool calls. A new graceful shutdown feature also pulls a small allowance from the weekly limit to let in-progress work wrap up cleanly when hitting the 5-hour cap.

## GitHub Copilot: Sonnet 5.5 Arrives, Slow Climb Continues

Claude Sonnet 5.5 went generally available in GitHub Copilot on September 28 ([GitHub Blog](https://github.blog/changelog/2026-09-28-claude-sonnet-5-5-in-github-copilot/)). It's available across all paid plans — Pro, Pro+, Max, Business, and Enterprise — spanning VS Code, JetBrains, Xcode, CLI, and the coding agent. Copilot's score ticked up from 3 to 5 to 7 over the last three days, but the road back from a peak of 90 remains long.

## JetBrains Survey: 90% of Developers Use AI Agents Weekly

The JetBrains Developer Ecosystem Survey (15,000+ professional developers, May–July 2026) found that **90% use AI coding agents at least weekly and 68% use them daily** ([JetBrains](https://www.jetbrains.com/lp/devecosystem-2026/)). AI coding tools have crossed from optional to default in the professional developer toolkit.

## Coderblock.ai: New AI Coding Platform Goes Public

Italian startup Coderblock.ai publicly launched today, offering full web app generation from a single prompt ([Coderblock](https://pasqualepillitteri.it/en/news/19532/coderblock-ai-opens-to-everyone)). It supports six models — GPT-6.1 Sol, Claude Sonnet 5.5, Claude Opus 5.5, Claude Fable 5, DeepSeek V4, and GLM — and offers 20 free credits per new account.

## Cursor: 31, Day 34 of the Slide

Cursor dropped to 31, marking 34 consecutive days of decline with OpenAI model termination (Nov 12) now D-43 away ([The Information](https://x.com/theinformation/status/2053490340238164364)). Staff continue leaving as the SpaceX/xAI integration grinds on.
