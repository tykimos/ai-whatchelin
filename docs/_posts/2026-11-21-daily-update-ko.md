GPT-6.2 Astra와 Sol의 벤치마크 엇갈림이 이어지는 가운데, 오늘의 주요 뉴스는 오히려 가격과 플랫폼 쪽에서 나왔다. GPT-5.6 Sol 20% 할인 프로모션이 당초 11월 21일 종료 예정이었으나, OpenAI가 고객 이메일을 통해 11월 30일까지 연장을 통보한 것으로 확인됐다([RuntimeWire](https://runtimewire.com/article/gpt-5-6-sol-promo-pricing-november-30-customer-email)). OpenAI 공식 문서에는 여전히 "최소 11월 21일까지"라고 명시되어 있어([developers.openai.com](https://developers.openai.com/api/docs/models/gpt-5.6-sol.md)), 공식 업데이트를 주시할 필요가 있다.

## Apple: Mac용 AI 에이전트 개발 중

TechCrunch가 11월 19일 보도한 바에 따르면, Apple이 Mac에서 사용자 대신 앱 조작, 웹사이트 접근, 코딩까지 수행하는 AI 에이전트를 개발하고 있다([TechCrunch](https://techcrunch.com/2026/11/19/apple-may-be-developing-its-own-ai-agent-that-runs-your-mac)). 아직 개발 단계이지만, Apple이 AI 코딩 도구 시장에 진입할 가능성이 열린 셈이다. Xcode에 이미 AI 기능이 있지만, 범용 에이전트는 차원이 다른 도전이다.

## OpenAI 연구: 코딩 에이전트 자율 완료율 46%

OpenAI가 최근 연구 보고서에서 코딩 에이전트가 사람에게 2~4시간 걸리는 작업의 46%를 자율적으로 완료한다고 발표했다([WireTensors](https://wiretensors.ai/news/ai-tools-roundup-2026-11-21/)). 3월의 23%에서 두 배로 뛰었다. 이 수치는 Codex CLI, Claude Code 등 에이전트형 도구들이 왜 99점대를 유지하는지를 설명하는 핵심 지표다.

## GPT-6.2: 벤치마크 분열 2일째

어제에 이어 GPT-6.2 Astra의 벤치마크 엇갈림이 계속되고 있다. Vals Vibe Code Bench에서는 55.16%로 1위([Hermes](https://hermes-ai.net/news/openai-s-gpt-6-2-astra-tops-real-world-coding-maintenance-benchmark-at-55/)), FrontierCode 2.0에서는 Fable 5.2(50.2%)에 뒤지며 44.2%([vktr.com](https://www.vktr.com/ai-platforms/gpt62-sol-nears-astra-on-mergeready-code-at-a-fifth-of-the-cost/)). "최고의 코딩 모델은 측정 방법에 달렸다"는 이번 주의 교훈이 굳어지고 있다.

## GitHub Copilot: 주간 릴리스 (11월 16일)

11월 16일 주간 릴리스에서 엔터프라이즈 관리자 설정이 추가됐다([GitHub Blog](https://github.blog/changelog/2026-11-16-github-copilot-weekly-releases-november-9)). 11월 9일에는 Gemini 4 Carbon이 Pro+/Max/Business/Enterprise 사용자에게 제공되기 시작했으며, VS Code 1.146이 에이전트 모델 비교 기능을 도입했다.
