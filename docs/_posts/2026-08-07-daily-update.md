Claude Code played its enterprise card today with self-hosted runners. On the same day, Cursor pushed model routing costs down by 68%, and GitHub Copilot onboarded Kimi K3 as its latest open-weight frontier model. The AI coding tool market is shifting from price wars to infrastructure wars.

## Claude Code: v2.1.224 — Self-Hosted Runner Targets Enterprise

Anthropic shipped `claude self-hosted-runner` in Claude Code v2.1.224 for Team and Enterprise plans([code.claude.com](https://code.claude.com/docs/en/changelog)). Code and tool execution can now stay entirely within an organization's network. The release also adds SHA-256-verified plugin installation from HTTPS zip archives, cross-session messaging via SendMessage/ListAgents, JWT-aware credential masking with AWS SigV4 re-signing, and removes the previous 200-subagent session cap. Yesterday's v2.1.223 patched a bash permission bypass and workflow sandbox circumvention([releasebot.io](https://releasebot.io/updates/anthropic/claude-code)).

## Cursor: Router Auto Intelligence — Fable-Level Quality at 68% Lower Cost

Cursor Router unveiled two new modes: Auto Intelligence and Auto Balance([cursor.com](https://cursor.com/changelog)). Auto Intelligence delivers above-Fable-level user satisfaction at 68% lower cost — an 18% further reduction since the router's initial launch. Auto Balance outperforms Opus 4.8 at 41% lower cost with 3% higher user satisfaction. Opus 5 has been integrated into the routing system. The data proves what Router promised at launch: you don't always need the most expensive model.

## GitHub Copilot: Kimi K3 Goes GA — Open-Weight Models Enter Enterprise

Moonshot AI's open-weight model Kimi K3 is now generally available across all GitHub Copilot plans([GitHub Blog](https://github.blog/changelog/2026-08-06-kimi-k3-is-now-available-in-github-copilot/)). Hosted on Fireworks AI at $3/$15 per million tokens, K3 delivers frontier-level agentic coding performance. Business and Enterprise admins must manually enable the Kimi K3 policy. Copilot CLI also shipped v1.0.79-6 with session history and long-session scroll fixes.

## OpenAI: Atlas D-2 Countdown, Codex Goal Mode GA

Atlas shuts down August 9, two days from now([Search Engine Land](https://searchengineland.com/openai-chatgpt-atlas-deprecation-482003)). Its browser agent features are being absorbed into ChatGPT and Codex. Codex has shipped Goal mode to GA across the app, IDE extension, and CLI, while Auto-review is upgrading to GPT-5.6 Luna with an expected 10x cost reduction([OpenAI](https://openai.com/products/release-notes/)). GPT-5.4 and GPT-5.4 mini deprecation is set for August 31.

## DeepSeek: Price Hike Fallout Continues

DeepSeek's "significant" price increase warning is now on day three of community shockwaves. Trust has eroded after the June permanent 75% cut was reversed and peak/off-peak pricing was introduced in July([The Next Web](https://thenextweb.com/news/deepseek-significant-api-price-increase)). Startups dependent on V4 Flash pricing are accelerating their evaluation of Kimi K3 and Llama alternatives([SCMP](https://www.scmp.com/tech/tech-trends/article/3363129/deepseek-signals-significant-price-hike-amid-surge-demand-low-cost-ai-models)).
