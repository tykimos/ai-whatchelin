Anthropic이 역사를 새로 쓰고 있다. Q2 매출 $109억으로 첫 흑자 분기에 진입할 전망인 가운데, CNBC 디스럽터 50 1위, Microsoft Maia 칩 협상, 게이츠 재단 $2억 파트너십, KPMG 27만 6천 명 전면 배포까지 — 하루 만에 다섯 건의 메가딜이 동시에 터졌다.

## Anthropic, Q2 매출 $109억으로 첫 흑자 분기 전망

CNBC에 따르면 Anthropic이 Q2에 $109억 매출을 기록할 전망이다([CNBC](https://www.cnbc.com/2026/05/20/anthropic-revenue-explosive-growth-ipo-profitable-quarter.html)). 이는 작년 전체 연간 매출을 한 분기 만에 넘어서는 수준이다. Q1 매출 $48억에서 수개월 만에 2배 이상 성장했으며, 달성 시 $5.59억 영업이익을 기록하며 창사 이래 첫 흑자가 된다. 다만 하반기 컴퓨트·학습 비용 증가로 연간 흑자 유지는 불확실하다. 현재 $9,000억 밸류에이션 투자 라운드가 진행 중이다.

## Microsoft Maia 칩 임대 협상 — 다섯 번째 컴퓨트 소스

Bloomberg에 따르면 Anthropic이 Microsoft의 Maia 200 추론 칩으로 구동되는 서버 임대를 위한 초기 협상에 들어갔다([Bloomberg](https://www.bloomberg.com/news/articles/2026-05-21/anthropic-in-talks-to-use-microsoft-ai-chips-information-says)). Maia 200은 경쟁 가속기 대비 달러당 토큰 30% 이상 효율적이다. Amazon, Google, Nvidia, SpaceX Colossus에 이어 다섯 번째 컴퓨트 소스가 추가되는 셈이다. Microsoft 주가는 이 소식에 2% 상승했다([Investing.com](https://uk.investing.com/news/stock-market-news/microsoft-rises-2-as-anthropic-eyes-deal-for-custom-maia-ai-chips-4692950)).

## 게이츠 재단 $2억 + KPMG 27만 명 — AI 사회 공헌과 엔터프라이즈 동시 확장

게이츠 재단과 4년간 $2억 규모 파트너십을 체결했다([Anthropic](https://www.anthropic.com/news/gates-foundation-partnership)). OpenAI의 $5천만 게이츠 계약의 4배 규모로, AI-자선단체 간 역대 최대 계약이다. 같은 날 KPMG가 138개국 27만 6천 명 전원에 Claude를 배포하는 글로벌 전략 제휴를 발표했다([Anthropic](https://www.anthropic.com/news/anthropic-kpmg)) — Big Four 최초의 전면 Claude 도입이다. CNBC 디스럽터 50에서도 OpenAI를 제치고 1위에 올랐다([CNBC](https://www.cnbc.com/2026/05/19/2026-cnbc-disruptor-50-rankings-anthropic-no-1.html)).

## Claude Code v2.1.145 + Copilot CLI v1.0.51

Claude Code v2.1.145가 `/code-review` 명령어(기존 `/simplify`에서 개명)와 MCP 페이지네이션 수정을 포함해 릴리스됐다([code.claude.com](https://code.claude.com/docs/en/changelog)). GitHub Copilot CLI도 v1.0.51을 출시하며 `/security-review` 슬래시 명령어(실험적)를 추가했다([GitHub](https://github.com/github/copilot-cli/releases)). Code with Claude London Extended 최종일에서는 인디 개발자 워크숍이 마무리됐다.

## Antigravity 2.0 롤백 사태 3일째 — 55로 하락

Antigravity 2.0 자동 업데이트 참사가 3일째 계속되고 있다([Google AI Developers Forum](https://discuss.ai.google.dev/t/antigravity-2-0-a-rushed-un-tested-release/145483/6)). 설정 경로 불일치로 확장 프로그램·설정이 통째로 삭제되며 v1.23.2로 수동 롤백하는 개발자가 속출 중이다. I/O 당일 62까지 급등했던 점수가 55로 추락 — 급등분의 2/3가 소실됐다. 한편 Gemini CLI → Antigravity CLI 전환 기한은 6월 18일이다([Google Developers Blog](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/)).

## Copilot 17주 연속 하락 66 — 사용량 과금 D-11

GitHub Copilot이 66으로 17주 연속 하락했다([GitHub Blog](https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/)). 6월 1일 사용량 기반 과금까지 11일 남았다. GPT-5.3-Codex가 기본 모델로 강제 전환됐고 웹 채팅에서 Gemini 모델이 모두 삭제됐다.
