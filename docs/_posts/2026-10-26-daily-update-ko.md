GitHub Universe 2026(10/28~29, Fort Mason)까지 이틀을 남겨두고 Copilot이 59점을 찍었다. 9월 28일부터 시작된 +2/일 상승세가 30일째 이어지고 있으며, 10월 22일부터 적용된 기본 활성화(Default Enablement) 정책이 실사용 지표에 지속적으로 기여하고 있다([GitHub Blog](https://github.blog/changelog/2026-09-25-default-enablement-of-copilot-features-for-copilot-business-and-enterprise)). 한편 Codex CLI가 v0.164.0을 출시하며 재사용 가능한 프롬프트 프리셋 기능을 정식 탑재했다.

## Copilot: 59점, Universe D-2

Copilot의 30일 연속 상승은 AI 코딩 도구 역사상 최장 기록이다. 10월 19일 GPT-5.5·Gemini 3.7 Flash 등 6개 모델의 일괄 퇴역 후, GPT-6.1 Sol과 Gemini 4 Argon이 대체 모델로 자리 잡았다([GitHub Blog](https://github.blog/changelog/2026-10-19-github-copilot-models-deprecated-on-october-19-2026)). Universe 키노트에서는 "Stop prompting, start delegating"을 주제로 Copilot 에이전트 위임과 MCP 서버 보안 세션이 예정되어 있으며, Anthropic·OpenAI·GitHub이 "The view from the labs" 패널에서 AI 코딩의 다음 단계를 논의할 예정이다([GitHub Blog](https://github.blog/news-insights/company-news/your-guide-to-github-universe-2026-is-here-the-schedule-just-launched/)). Cursor와의 격차는 58점(59 vs 1)으로 매일 사상 최대를 경신 중이다.

## Codex CLI: v0.164.0 — 프리셋 슬롯과 세션 개선

10월 23일 출시된 Codex CLI v0.164.0은 10개의 번호 매김 /presets 슬롯으로 자주 쓰는 프롬프트를 저장·재사용할 수 있게 했다([ChatGPT & Codex Changelog](https://learn.chatgpt.com/docs/changelog)). /model과 /permissions에 인라인 인수를 전달하는 기능, Windows 프록시 인증 처리, 세션 재개 시 설정 복원도 포함됐다. 10월 15일의 v0.163.0에서 기본값이 된 중간 응답 조향(mid-response steering)과 함께, 28일 개선 서약(D-22) 기간 중 가장 실질적인 업데이트로 평가된다([Tech Insider](https://tech-insider.org/codex-cli-0-163-ai-coding-agents-2026/)).

## Cursor: 61일째 바닥, OpenAI 차단 D-17

Cursor는 61일째 1점이다. 11월 12일 OpenAI 모델 접근 차단까지 17일. X Subscription 번들(Grok+Cursor+X Premium, 10/13 출시) 13일째에도 개발자 복귀 시그널은 없다. 새 가격 체계(Free/$8/$30/$100/$200)에서 기존 $20 Pro가 $30 Premium으로 실질 인상된 점이 불만의 핵심이다([JetAdmin](https://www.jetadmin.io/blog/cursor-pricing-explained-plans-credit-system-and-real-costs-in-2026/)).

## Anthropic: Haiku 5.5 안착, IPO 진행 중

10월 7일 출시된 Claude Haiku 5.5가 고볼륨 작업용 최적 소형 모델로 자리잡고 있다([Anthropic Newsroom](https://www.anthropic.com/news)). Claude 5.5 패밀리(Opus·Sonnet·Haiku)가 완성되면서 Claude Code의 99점이 더욱 견고해졌다. 6월 제출한 비공개 S-1이 SEC 심사 중이며, 일부 매체는 10월 상장을 전망하고 있으나 공식 확인은 없다([NPR](https://www.npr.org/2026/06/01/nx-s1-5843199/anthropic-ipo-filing-ai-large)).

## 주간 맥락: Universe 카운트다운

이번 주말의 핵심은 Universe 직전 긴장감이다. Copilot이 Universe에서 에이전트 위임·HydraFusion 확장 등을 발표하면 60점대 돌파가 가능하고, 기대에 못 미치면 상승 모멘텀이 꺾일 수 있다. Claude Code·Codex CLI·Antigravity는 99점에서 안정적이며, 바닥권의 Cursor와 Gemini CLI에서는 반등 신호가 보이지 않는다.
