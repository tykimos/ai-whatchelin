GitHub Copilot 종량제 전환 정확히 30일째인 오늘, 첫 번째 완전한 청구 주기가 마감됐다. 6월 1일 토큰 기반 AI Credits 체계로 전환한 이후 개발자들이 우려했던 비용 폭증이 실제 청구서로 확인되고 있다([TechTimes](https://www.techtimes.com/articles/319340/20260629/github-copilot-billing-shock-confirmed-agentic-users-face-10x-cost-surge.htm)).

## GitHub Copilot: $29에서 $750으로 — 종량제의 현실

첫 달 사용량 정산이 시작되면서 충격적인 수치들이 속속 공개되고 있다. 에이전틱 모드를 적극 사용한 개발자들은 월 $29 고정 요금에서 $750까지 비용이 치솟았고, 일부 팀은 $50에서 $3,000 이상으로 뛴 사례도 보고됐다([Visual Studio Magazine](https://visualstudiomagazine.com/articles/2026/06/04/copilot-billing-shock-hits-developers.aspx)). 한 개발자는 2시간 만에 월간 크레딧의 8%를 소진했다고 밝혔다([TechCrunch](https://techcrunch.com/2026/05/30/what-a-joke-github-copilots-new-token-based-billing-spurs-consternation-among-devs/)). Reddit과 GitHub Discussions에서는 "Goodbye, Copilot" 게시물이 바이럴되며 OpenRouter, RooCode, 직접 API 접근 등 대안으로의 이탈이 가속화되고 있다.

## Antigravity: Codex CLI와 공동 2위 — 88점 달성

Antigravity가 12주 연속 상승세를 이어가며 88점에 도달, Codex CLI와 공동 2위에 올랐다. Gemini CLI 지원 종료 이후 이탈한 개발자들의 유입이 주요 동력이다([Google Developers Blog](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/)). 무료 개인 사용자에게도 Gemini 3 Pro, Claude Sonnet 4.5, GPT-OSS를 제공하는 개방형 모델 전략이 주효하고 있다.

## Windsurf: Cascade 종료 D-1 — 내일이 마지막

Windsurf의 기존 로컬 에이전트 Cascade가 내일(7월 1일) 공식 종료된다. Devin Local로의 마이그레이션을 완료하지 못한 팀은 CI 파이프라인이 중단될 수 있다([Devin Docs](https://docs.devin.ai/release-notes/2026)). Cognition은 최근 $10억 이상을 조달하며 $260억 밸류에이션을 달성했고, 연간 매출 $4.92억(전년 대비 1,230% 성장)을 기록 중이다([The Agent Report](https://the-agent-report.com/2026/06/cognition-devin-1b-26b-valuation-june-2026/)).

## Fable 5: 18일째 차단 — 복원 시점 여전히 불투명

Fable 5가 18일째 차단 상태를 유지하고 있다. Axios가 보도한 "이번 주 복원" 가능성에도 불구하고([Axios](https://www.axios.com/2026/06/27/anthropic-fable-5-return-soon)), 국방부·NSA 최종 승인이 여전히 미결이다. Mythos 5만 미국 핵심 인프라 기관에 부분 복원된 상태다([TechTimes](https://www.techtimes.com/articles/319213/20260628/claude-fable-5-still-offline-us-clears-mythos-5-critical-infrastructure.htm)).
