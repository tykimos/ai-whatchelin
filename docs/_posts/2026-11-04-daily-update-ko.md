Goldman Sachs와 ByteDance의 AI 도구 접근 제한이 보안 측면의 전환점이었다면, Revolut의 자체 호스팅 전환은 비용 측면의 전환점이다. 기업들이 AI 코딩 도구를 단순 구독에서 인프라 관리로 재편하고 있다.

## Revolut: 자체 호스팅 GLM으로 AI 코딩 비용 90% 절감

Revolut이 약 2,000명의 엔지니어를 Claude Code 등 메터드 API에서 Z.ai의 GLM-5.3 자체 호스팅으로 전환해 AI 코딩 추론 비용을 약 90% 절감했다([StartupHub.ai](https://www.startuphub.ai/ai-news/artificial-intelligence/2026/revolut-says-self-hosted-ai-cut-coding-costs-90)). Nvidia B200 56대 위에서 운영되며, 4월 자체 호스팅 이후 코딩 시간 60%, 리드 타임 70% 개선을 보고했다. AI Engineer 컨퍼런스에서 공개된 수치로, Revolut 자체 공식 발표는 아직 없다.

## Anthropic IPO: 수정 S-1에 $895B 컴퓨팅 비용 공개, 로드쇼 D-6

Anthropic이 10월 26일 S-1을 제출한 후, 11월 2일 수정 S-1이 공개되며 핵심 재무 세부사항이 드러났다([Yahoo Finance](https://finance.yahoo.com/markets/article/anthropics-new-ipo-filing-puts-its-computing-bill-near-900-billion-151830444.html)). 수정 S-1에는 약 $895B(8,950억 달러)의 컴퓨팅·데이터센터 계약이 포함되어 있으며, 이 중 ~$70B는 1년 이내 지급 예정이다. 3분기 실적은 매출 약 $17B, 영업손실 $567M으로, 전 분기 $974M 영업이익에서 반전했다([CNBC](https://www.cnbc.com/2026/10/26/anthropic-ipo-live-updates-ai-s-1-filing.html)). 일부 투자자들은 AI 시장 변동성을 이유로 $2T 목표 대비 $1.5~1.6T으로 밸류에이션 하향을 요구하고 있다([Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/anthropic-updates-ipo-filing-investors-034041239.html)). 리테일 투자자는 [ipo.anthropic.com](https://www.kucoin.com/news/flash/anthropic-ipo-website-launched-retail-investors-in-multiple-countries-can-apply)을 통해 미국·영국·캐나다·호주·일본 등에서 청약 가능하다. 로드쇼는 이르면 11월 10일 시작될 수 있으며([Leverage Shares](https://leverageshares.com/us/insights/when-is-the-anthropic-ipo/)), 추수감사절 전 상장이 여전히 가장 유력하다.

## GitHub Copilot: 77점, 40일 연속 상승 — Xcode 통합, 모델 교체 D-12

GitHub Copilot이 40일 연속 상승하며 77점을 기록했다. 주목할 만한 확장으로, 11월 3일 공개된 Apple Xcode 27.3 베타 1에 GitHub Copilot이 빌트인 코딩 어시스턴트로 탑재되었다 — Apple이 Xcode에 서드파티 AI 도구를 네이티브 통합한 최초의 사례다([9to5Mac](https://9to5mac.com/2026/11/03/xcode-27-3-adds-github-copilot-to-its-built-in-coding-assistant)). 11월 16일에는 Claude Opus 4.8, Claude Opus 5, GPT-5.6 Terra가 제거되고 Claude Opus 5.5와 GPT-6.1 Sol로 교체된다([GitHub Blog](https://github.blog/changelog/2026-10-15-upcoming-deprecation-of-selected-github-copilot-models-in-mid-november)). 연간 구독 개인 사용자는 Claude Opus 4.8만 예외적으로 유지된다. 12월 1일 AI 크레딧 기반 과금 전면 전환도 예정되어 있다([GitHub Blog](https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/)).

## Cursor: OpenAI 모델 차단 D-8, 71일째 바닥

11월 12일 OpenAI 모델 접근 완전 차단까지 8일 남았다([Bloomberg](https://www.bloomberg.com/news/articles/2026-08-29/openai-to-end-partnership-with-cursor-after-spacex-acquisition)). 공급망 공격 후속 조치와 맞물려 71일 연속 1점을 기록 중이다. Goldman Sachs의 AI 도구 제한 조치에서도 Cursor는 이미 제외 대상에서 빠져 있어, 엔터프라이즈 시장에서의 존재감이 사실상 소멸했다.

## OpenAI: 12월 사용량 풀 통합에 커뮤니티 반발

OpenAI가 12월부터 Plus, Pro, Business 플랜의 ChatGPT와 Codex 사용량을 단일 토큰 예산으로 통합한다([ARY News](https://arynews.tv/openai-to-combine-chatgpt-and-codex-usage-limits-for-premium-subscribers)). Pro/Business Premium 대상 Codex/Work 사용량 2배 인상 직후 나온 변경이라 커뮤니티 반발이 거세다 — OpenAI 포럼의 Codex 레이트 리밋 스레드는 100건을 넘겼고, 개발자들은 3~4개 프롬프트만에 한도에 도달한다고 보고하고 있다([OpenAI Community](https://community.openai.com/t/codex-usage-limit-is-reached-too-quickly-even-with-chatgpt-plus/1379502)).

## 기업 AI 도구 운영 패러다임 변화

Goldman Sachs의 접근 제한(보안), ByteDance의 외부 도구 차단(기밀 보호), Revolut의 자체 호스팅(비용)까지 — 기업들이 AI 코딩 도구를 "구독하는 것"에서 "직접 운영하는 것"으로 이동하고 있다. MUFG는 Claude Code 대안을 자체 개발했고, Deutsche Bank은 1만 5천 명에게 코딩 어시스턴트를 제공하되 코드 책임은 개발자에게 귀속시킨다([PYMNTS](https://www.pymnts.com/news/artificial-intelligence/2026/goldman-benches-its-vibe-coders-while-bny-lets-everyone-build/)).
