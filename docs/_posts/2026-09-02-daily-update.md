Anthropic launched Claude Fable 5.1 and Mythos 5.1 yesterday (September 1), reigniting the frontier model race ([Roo Newsletter](https://roo.beehiiv.com/p/claude-fable-5-1-mythos-5-1-whats-new)). Fable 5.1 scores 55.8% on Terminal-Bench 4.0, a major jump from Fable 5's 42.0%, and cache reads dropped 75% to $0.25/MTok ([CellCog](https://cellcog.ai/blog/fable-5-1-release-date/)). Meanwhile, Cursor's slide shows no sign of stopping.

## Anthropic: Fable 5.1 + Mythos 5.1 — The Frontier Gets Sharper

Fable 5.1 keeps the same $10/$50/MTok input/output pricing as its predecessor, but the 75% cache read reduction (from $1 to $0.25) materially lowers costs for large-codebase workflows ([Claude Platform Docs](https://platform.claude.com/docs/en/models/fable-5-1/overview)). Mythos 5.1 ships on the same base model with different safeguards, restricted to Project Glasswing participants and vetted cyberdefenders and life scientists ([Fortune](https://fortune.com/2026/09/02/whats-inside-anthropic-claude-fable-mythos-5-1-smarts-safeguards-anti-distillation-mechanisms/)). Claude Security now runs on Mythos 5.1, and the model includes EU AI Act statistical watermarking for all post-August 2 releases ([Cybersecurity News](https://cybersecuritynews.com/anthropic-launches-fable-and-mythos-5-1/)).

## Cursor: Day 6 at 85 — Where Is the Floor?

Cursor fell for a sixth consecutive day to 85, shedding 14 points total since its 99 peak on August 27. With OpenAI's November 12 model access cutoff now D-71 away ([CNBC](https://www.cnbc.com/2026/08/29/openai-cursor-spacex-model-access.html)), the transition to Grok 4.6 and Anthropic's Claude models remains the central challenge. The market is watching whether SpaceX-owned Cursor can stabilize before confidence erodes further.

## Claude.ai: Microsoft 365 Write Tools + Claudeforce

Claude.ai's Microsoft 365 connector gained write capabilities — draft and send email, manage calendar events, and create or update files in OneDrive and SharePoint ([Releasebot](https://releasebot.io/updates/anthropic/claude)). Separately, the Claudeforce partnership with Salesforce was unveiled, embedding Claude as the default reasoning model across Agentforce, Slack, and developer tools with 37 prebuilt sales skills heading into a September open beta ([AI Agent Store](https://aiagentstore.ai/ai-agent-news/today)).

## Meta: Muse Code — First AI Coding Agent

Meta entered the AI coding agent market with Muse Code, launched alongside Muse Spark 1.2. The agent supports full-stack software engineering workflows ([AI Agent Store](https://aiagentstore.ai/ai-agent-news/this-week)).
