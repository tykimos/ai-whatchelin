AI 코딩 도구 시장이 기업 단위의 지각변동을 겪고 있다. Anthropic이 역사적인 IPO 로드쇼에 돌입한 가운데, GitHub은 48시간 후 대규모 모델 교체를 앞두고 있고, Cursor는 OpenAI 없이 3일째를 보내고 있다.

## Anthropic IPO: $70-78 가격대, 최대 $1조+ 밸류에이션

Anthropic이 11월 10일 IPO 로드쇼를 시작했다([Anthropic](https://anthropic.com/news/roadshow-launch)). 8억 2,500만 주 Class A 주식을 Nasdaq에 ANT 티커로 상장할 예정이며, 주당 가격은 $70-78로 제시되었다([RTTNews](https://www.rttnews.com/3712632/anthropic-sets-ipo-price-range-at-70-78-per-share-launches-roadshow.aspx)). 밸류에이션은 $9,160억~$1.4조 범위로 추정되며, 가격 결정은 추수감사절 전인 11월 18-24일경으로 예상된다([Implicator](https://www.implicator.ai/anthropic-could-start-ipo-roadshow-week-of-nov-9-putting-debut-before-thanksgiving/)). 인수 주관사는 Morgan Stanley, Goldman Sachs, JPMorgan, Citi가 맡고 있다.

## GitHub Copilot: 모델 대퇴출 D-2, Enterprise Server 연동 추가

11월 16일 Claude Opus 4.8, Claude Opus 5, GPT-5.6 Terra 세 모델이 Copilot에서 완전 제거된다([GitHub Blog](https://github.blog/changelog/2026-10-15-upcoming-deprecation-of-selected-github-copilot-models-in-mid-november)). Chat, 인라인 편집, Agent 모드, 코드 자동완성 전 영역이 대상이다([dev.classmethod.jp](https://dev.classmethod.jp/en/articles/github-copilot-model-deprecation-nov-2026/)). 한편 11월 13일에는 GitHub Enterprise Server가 Copilot 앱과 연동되기 시작했다([GitHub Blog](https://github.blog/changelog/2026-11-13-github-enterprise-server-support-in-the-github-copilot-app)). Copilot은 97점으로 52일째 연속 상승 중이다.

## Cursor: OpenAI 차단 3일째, 핵심 기능 여전히 마비

OpenAI 모델 접근 차단 후 3일째, Tab 자동완성, 자동 모델 선택, 클라우드 에이전트 등 핵심 기능이 여전히 동작하지 않는다([Tom's Guide](https://www.tomsguide.com/ai/openai-is-leaving-cursor-in-november-here-are-your-3-options)). SpaceX 인수 후 OpenAI가 "계약 위반 전력"을 이유로 차단을 단행했으며([The Decoder](https://the-decoder.com/openai-cuts-off-cursor-after-spacex-acquisition-citing-musks-history-of-breaking-contracts/)), CEO Michael Truell은 OpenAI 모델이 전체 트래픽의 5%에 불과하다고 주장하지만 실질적 영향은 더 크다([CryptoBriefing](https://cryptobriefing.com/cursor-openai-5-percent-traffic/)). 82일째 바닥(점수 1)이다.

## Google Gemini 4 Carbon: Antigravity CLI에 합류

Google이 11월 12일 Gemini 4 Carbon을 공식 출시했다([NewsBytesApp](https://www.newsbytesapp.com/news/science/google-launches-gemini-4-carbon-exclusively-for-ai-ultra-subscribers/tldr)). AI Studio, Gemini API, Antigravity CLI에서 사용 가능하며 11월 30일까지 도입 할인이 적용된다. 사이버보안 전용이었던 Argon에 이어 일반 개발자 대상으로 확대된 두 번째 Gemini 4 모델이다([Axios](https://axios.com/2026/09/30/google-gemini-4)).
