Anthropic이 코드 리뷰의 판도를 바꿀 카드를 꺼냈다. 11월 23일 공개된 Claude Ship은 PR을 자동으로 리뷰하고, 버그를 수정하며, 머지 여부까지 판단하는 AI 에이전트 스위트다([TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes)). 현재 베타 단계이며, 얼리 어답터가 프로덕션 워크플로우에서 테스트 중이다. AI가 코드를 "작성"하는 것을 넘어 "검증·승인"까지 맡겠다는 선언 — 개발 프로세스 자체를 에이전트가 운영하는 시대의 신호탄이다.

## Claude Ship: 코드 리뷰 자동화의 첫 발

Claude Ship은 일상적인 코드 변경을 대상으로 리뷰, 수정, 승인을 일괄 처리한다([TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes)). 기존 Claude Code가 코드 작성에 집중했다면, Ship은 그 다음 단계인 품질 게이트를 에이전트에게 위임하는 구조다. 한편 Revenium은 Claude Code 세션 비용을 실시간 추적하는 Sidekick을 출시해, 에이전트 비용 관리 생태계도 함께 성장하고 있다([IT Brief UK](https://itbrief.co.uk/story/revenium-launches-sidekick-for-claude-code-cost-control)).

## Cognition·Replit: 에이전트 군단 경쟁 가열

Cognition은 프로젝트를 태스크 단위로 분할하고 여러 Devin 세션을 병렬 실행하는 'Devin Bots'를 공개했다. 초기 고객 수십 곳에서 2주 만에 사용량이 10배 증가했다([AI Agent Store](https://aiagentstore.ai/ai-agent-news/this-week)). Replit도 단일 프롬프트가 아닌 며칠짜리 목표를 에이전트 떼가 추적·실행하는 'Missions'를 선보이며, 에이전트가 장기 프로젝트를 운영하는 패러다임을 제시했다([AI Agent Store](https://aiagentstore.ai/ai-agent-news/this-week)).

## ANT 주가 · Cursor 블랙아웃

ANT는 IPO 6일차를 맞았다. 11월 19일 $111.50에 시초가를 형성한 뒤 $95~99 구간에서 등락 중이며, 시장은 Claude Ship 발표가 주가에 어떤 영향을 줄지 주시하고 있다([Nasdaq](https://www.nasdaq.com/articles/why-anthropic-stock-and-down-today)). Cursor는 OpenAI 모델 공급 중단 13일째이며, 124일 연속 인기도 최하위를 기록 중이다([ClickUp](https://clickup.com/learn/topic/ai/tools/cursor/news/)).
