OpenAI pulled back the curtain on 'Astra,' its next-generation model family, while Codex CLI continued its Luna price-cut momentum for a sixth straight day to reach 97 — tying Cursor for the first time. The AI tool landscape is shifting fast, with open-source and regulatory forces reshaping the competitive map.

## OpenAI: Astra — 10 Unsolved Math Problems Signal Next-Gen Power

OpenAI teased its next-generation model family 'Astra' on August 1 by publishing solutions to 10 previously unsolved mathematics problems, including constructing the first non-sofic group([OpenAI](https://openai.com/index/ten-advances-in-mathematics/)). All proofs were published as formal Lean proofs on GitHub. Fields Medalist Timothy Gowers endorsed one proof for journal publication([Bleeping Computer](https://www.bleepingcomputer.com/news/artificial-intelligence/openai-teases-astra-its-next-major-ai-model-after-it-solves-10-long-standing-math-problems/)). Total compute cost was approximately $2,000. Astra uses multiple agents collaborating over hours or days, but no release date, pricing, or API access has been announced.

## Codex CLI: Reaches 97, Ties Cursor — Luna Streak Day 6

The GPT-5.6 Luna 80% price cut continues driving Codex CLI upward for a sixth consecutive day, tying Cursor at 97([VentureBeat](https://venturebeat.com/technology/ai-price-wars-openai-cuts-gpt-5-6-luna-prices-by-80-as-model-competition-shifts-toward-cost)). The steady climb from 91 (91→92→93→94→95→96→97) is fueled by 10x auto-review cost savings and the GPT-5.1-Codex-Max model. Tomorrow could see Codex CLI overtake Cursor for the first time.

## DeepSeek: V4-Flash Open-Sourced — Beats Own Pro on Coding

DeepSeek open-sourced V4-Flash-0731 on July 31 under MIT license([OpenSourceForu](https://www.opensourceforu.com/2026/08/deepseek-open-sources-v4-flash/)). With 284B total parameters (13B active per token via MoE), 1M context window, and $0.14/$0.28/MTok pricing, it beat DeepSeek's own V4-Pro-Preview across all nine agent and coding benchmarks([MarkTechPost](https://www.marktechpost.com/2026/07/31/deepseek-upgrades-deepseek-v4-flash-0731-with-major-agentic-and-coding-gains/)).

## GitHub Copilot: Billing Preview App Retires Today

The Copilot Billing Preview App officially retired today, August 3([GitHub Changelog](https://github.blog/changelog/2026-07-07-copilot-billing-preview-app-will-be-retired-on-august-3/)). Users are directed to built-in billing settings for AI usage tracking and per-user budget management.

## Claude: Claude Tag Replaces Slack Integration

Claude Tag officially replaces Claude in Slack on Team and Enterprise plans starting today([Claude Code What's New](https://code.claude.com/docs/en/whats-new)). The transition moves Slack-based Claude interactions to a new tag-based interface.
