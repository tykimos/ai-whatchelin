Anthropic이 Code with Claude 도쿄 컨퍼런스 전날, 역대 최강 공개 모델 Claude Fable 5를 전격 출시했다. Mythos 계열 최초의 공개 릴리스인 Fable 5는 기존 모든 Anthropic 모델을 거의 모든 벤치마크에서 능가한다. AI 코딩 도구 시장의 판도가 다시 한번 요동치고 있다.

## Claude Fable 5: Anthropic 역대 최강 공개 모델

Anthropic이 Claude Fable 5를 출시했다([Anthropic](https://www.anthropic.com/news/claude-fable-5-mythos-5)). Mythos 클래스 모델의 첫 공개 버전으로, 거의 모든 벤치마크에서 기존 Anthropic 모델을 초월한다. 가격은 입력 $10/M 토큰, 출력 $50/M 토큰으로 Mythos Preview의 절반 이하다([TechCrunch](https://techcrunch.com/2026/06/09/anthropic-released-claude-fable-5-its-most-powerful-model-publicly-days-after-warning-ai-is-getting-too-dangerous/)). Pro, Max, Team, Enterprise 구독자에게 6월 22일까지 무료로 제공된다. Stripe는 "수개월의 엔지니어링을 며칠로 압축했다"며 5천만 줄 코드베이스 마이그레이션을 하루에 완료했다고 밝혔다([CNBC](https://www.cnbc.com/2026/06/09/anthropic-mythos-claude-fable-5.html)). 안전성 측면에서는 별도의 안전 분류기가 고위험 도메인에서 거부 대신 Opus 4.8로 폴백하며, 1,000시간 이상의 외부 레드팀 테스트에서 범용 탈옥이 발견되지 않았다. Claude Mythos 5도 함께 출시됐지만, Project Glasswing 파트너와 일부 생의학 연구자로 제한된다.

## Claude Code v2.1.169: 안전 모드와 /cd 명령어

Claude Code v2.1.169가 릴리스됐다([Releasebot](https://releasebot.io/updates/anthropic/claude-code)). `--safe-mode` 플래그로 플러그인·스킬 등 커스터마이제이션을 비활성화한 채 트러블슈팅이 가능하다. `/cd` 명령어로 프롬프트 캐시를 중단하지 않고 작업 디렉토리를 변경할 수 있다. `disableBundledSkills` 설정과 `claude agents --json` 개선, 원격 세션 CPU 사용량 절감도 포함됐다.

## Code with Claude 도쿄: 내일 개막

Anthropic의 개발자 컨퍼런스 Code with Claude 도쿄가 6월 10-11일 개최된다([claude.com](https://claude.com/code-with-claude/tokyo)). Research·Platform·Code 3트랙으로, Fable 5 출시 직후 열리는 만큼 새로운 발표가 기대된다. 둘째 날은 인디 개발자 워크숍과 Applied AI 핸즈온이 진행된다([ChatForest](https://chatforest.com/builders-log/code-with-claude-tokyo-june-10-builder-preview-guide/)).

## Google CEO: 신규 코드 75%가 AI 생성

Google CEO 순다르 피차이가 신규 코드의 75%가 AI로 생성된다고 밝혔다([Fast Company](https://www.fastcompany.com/91531519/google-ceo-says-75-of-the-companys-code-is-ai-generated)). 2024년 초 25%에서 급증한 수치로, Snap도 65%를 보고했다([DevOps.com](https://devops.com/google-ceo-says-75-of-new-code-is-ai-generated/)). 엔지니어 역할이 코드 작성에서 AI 감독으로 전환되는 흐름이 가속화되고 있다.

## GitHub Copilot: 47, 36주 연속 하락

Copilot이 **47**을 기록하며 36주 연속 하락했다([The Register](https://www.theregister.com/ai-and-ml/2026/06/02/github-copilot-users-threaten-exit-as-metered-billing-kicks-in/5249826)). 종량제 9일차, Fable 5 출시로 경쟁 압력이 한층 가중됐다. SpaceX IPO(D-3, 6/12 거래 개시)가 Cursor 인수 자금을 확보하면서 대안 IDE 선택지도 넓어지고 있다.
