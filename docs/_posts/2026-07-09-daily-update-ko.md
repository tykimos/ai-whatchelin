OpenAI의 GPT-5.6 Sol/Terra/Luna 3종 모델이 오늘 공식 공개된다. 약 2주간의 정부 제한 프리뷰를 거친 후 트럼프 행정부가 광범위한 출시를 승인했다([CNBC](https://www.cnbc.com/2026/07/08/openai-expanding-gpt-5point6-ai-model-release-ending-government-limits.html)). 같은 날 SpaceXAI-Cursor의 Grok 4.5도 글로벌 공개로 전환되면서, AI 코딩 도구 시장에서 전례 없는 동시 출시 경쟁이 벌어지고 있다.

## GPT-5.6: 3종 모델 동시 GA — Sol $5, Terra $2.50, Luna $1

미 상무부가 Sol의 강화된 사이버보안 능력에 대한 평가를 마치고 광범위한 출시를 승인했다([Neowin](https://www.neowin.net/news/openai-to-release-gpt-56-sol-terra-and-luna-on-july-9/)). Sol(플래그십, $5/$30 per MTok), Terra(범용, $2.50/$15), Luna(경량, $1/$6) 3종 체제로, 특히 Terra는 GPT-5.5급 성능을 절반 가격에 제공한다([OpenAI Community](https://community.openai.com/t/introducing-gpt-5-6-series-sol-terra-and-luna/1384931)). Cerebras와의 파트너십으로 Sol Fast 모드에서 초당 750토큰도 이번 달 중 출시 예정이다.

## Grok 4.5: SpaceX-Cursor 합작 모델 글로벌 출시

어제 프라이빗 베타로 공개된 Grok 4.5가 오늘 전 세계로 확대됐다([Bloomberg](https://www.bloomberg.com/news/articles/2026-07-08/spacexai-cursor-unveil-grok-ai-model-for-legal-finance-tasks)). $60B 인수 후 첫 합작 모델인 Grok 4.5는 1.5T 파라미터 V9 기반에 Cursor의 개발자 데이터로 보강됐다. Opus 4.8 대비 60% 저렴한 $2/$6 per MTok으로, 가격 전쟁의 새로운 기준점을 제시했다([VentureBeat](https://venturebeat.com/technology/spacexs-grok-4-5-launches-at-half-the-price-of-rivals-heres-why-that-could-rattle-anthropic-and-openai)).

## Claude Code "백도어" 논란 — 중국 MIIT 보안 경보

중국 공업정보화부(MIIT)가 Claude Code v2.1.91~v2.1.196에 사용자 위치·신원 데이터를 원격 서버로 전송하는 보안 취약점이 있다고 경고했다([CNBC](https://www.cnbc.com/2026/07/08/china-anthropic-ai-claude-code-backdoor-security-threat.html)). Anthropic은 반증류(anti-distillation) 추적 코드의 존재를 인정하면서도 실험적 남용 방지 기능이라고 해명했다([SCMP](https://www.scmp.com/news/china/article/3359901/anthropic-hits-back-after-china-warns-claude-code-backdoor-risks)). 알리바바는 7월 10일부터 전 직원의 Anthropic 도구 사용을 금지하고 자체 AI 어시스턴트 "Qoder"로 전환을 명령했다.

## Codex CLI v0.143.0: GPT-5.6 지원 + 원격 플러그인

Codex CLI v0.143.0이 GPT-5.6 Sol/Terra/Luna의 Amazon Bedrock 지원, 원격 플러그인 기본 활성화, 시스템 프록시 지원(PAC/WPAD 포함) 등을 추가하며 출시됐다([GitHub](https://github.com/openai/codex/releases)). MCP 도구가 기본적으로 도구 검색을 사용하도록 변경되어 플러그인 생태계가 한층 확대됐다.
