AI 역대 최대 IPO의 첫 거래일이 현실이 됐다. Anthropic의 ANT는 오늘 Nasdaq에서 $111.50에 시초가를 형성하며 $83 공모가 대비 34% 급등으로 출발했다([Investing.com](https://www.investing.com/news/analyst-ratings/anthropic-stock-jumps-34-in-nasdaq-debut-after-record-ipo-93CH-5039675)). 장중 최고가는 $115 부근까지 치솟았으나, 오후 들어 차익 실현 매물이 쏟아지며 $95선으로 하락했다([Yahoo Finance](https://finance.yahoo.com/markets/stocks/articles/anthropic-jumps-17-record-nasdaq-180734709.html)). 풀리 딜루티드 시가총액은 약 $1.5조, 주문장 6배 초과 청약에 리테일 20% 배분이라는 이례적 구조도 관심을 끌었다([Fortune](https://fortune.com/2026/11/18/anthropic-prices-ipo-83-per-share-1-5-trillion/)).

## GPT-6.2 Astra / Sol: OpenAI의 타이밍 전쟁

Anthropic 상장 전야에 OpenAI가 GPT-6.2 Astra와 Sol을 공식 출시했다([OpenAI Developer Community](https://community.openai.com/t/gpt-6-2-astra-and-sol-are-now-available/1417531)). Astra는 전문 업무용으로 $8/$40/MTok(GPT-6 대비 20% 인하), Sol은 일상 업무용 $2/$10/MTok에 제공된다([9to5Mac](https://9to5mac.com/2026/11/17/openai-upgrades-chatgpt-and-codex-with-new-gpt-6-2-astra-and-sol-models/)). ChatGPT Work·Codex·API에서 `gpt-6.2-astra`와 `gpt-6.2-sol`로 접근 가능하며, 사이버 보안 가드레일이 강화됐다([CASRAI](https://casrai.org/news/openai-gpt-6-2-astra-sol-release-2026)).

## Claude Code v2.1.326: 에이전트 팀에 Code Mode 합류

11월 16일 출시된 Claude Code v2.1.326에서 Code Mode가 에이전트 팀과 함께 작동하게 됐다([dev.classmethod.jp](https://dev.classmethod.jp/en/articles/20261117-cc-updates-v2-1-326/)). 팀원 에이전트도 Code Mode로 실행되며, 샌드박스 쓰기 경로 제한과 Remote Control 스트리밍 응답 등이 추가됐다([havoptic.com](https://www.havoptic.com/r/claude-code-2.1.326)). Opus 4.8 fast mode는 11월 30일 종료 예정이다.

## Codex CLI 0.170.0: 터미널에서 음성 통화

Codex CLI가 11월 18일 0.170.0을 출시하며 TUI 내 WebRTC 실시간 음성 통화를 도입했다([OpenAI Changelog](https://developers.openai.com/codex/changelog)). 2026년 누적 116번째 릴리스로, 터미널 에이전트가 IDE와의 경계를 계속 허물고 있다.

## Cursor: OpenAI 차단 8일째

OpenAI 모델 접근 차단 8일째로, 88일 연속 최하점(1점)이 이어지고 있다([Tom's Guide](https://www.tomsguide.com/ai/openai-is-leaving-cursor-in-november-here-are-your-3-options)). Live Apps, 음성 채팅, 멀티플레이어 Projects 등 혁신 기능이 출시되고 있으나, 엔진 없는 차의 역설은 계속된다.
