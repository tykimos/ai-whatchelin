Slack today launched **Slack Code**, pulling AI coding agents out of the terminal and into group chat ([Slack Blog](https://slack.com/blog/news/slack-code-channels-for-agents)). Invite Claude Code, Devin, GitHub Copilot, or Vercel's agent into a dedicated channel, and the entire team can watch the agent work, steer it, review output, and ship — all in real time ([VentureBeat](https://venturebeat.com/orchestration/slack-wants-to-drag-ai-coding-out-of-the-terminal-and-into-the-group-chat)). Available on every Slack plan, this marks a shift from solo terminal-based vibe coding to team-collaborative AI development ([iTechPost](https://www.itechpost.com/articles/237094/20260821/slack-code-launches-collaborative-ai-coding-channels-vibe-coding.htm)).

## Claude Code: Fourth Release in Four Days

Claude Code v2.1.238 shipped, fixing a prompt caching bug for custom LLM gateways, a Linux idle session CPU spike, and a voice mode freeze on native builds ([Releasebot](https://releasebot.io/updates/anthropic/claude-code), [Gradually.ai](https://www.gradually.ai/en/changelogs/claude-code/)). That's four versions this week — Anthropic's release cadence continues to outpace the field.

## Copilot: 101-Week Decline, Mass Deprecation D-11

GitHub Copilot set an unprecedented 101-consecutive-week popularity decline record. With 11 days until the September 1 mass model deprecation, six or more older models will retire simultaneously ([GitHub Roadmap](https://github.com/github/roadmap/issues/1308)). On the bright side, Grok 4.6 is now GA across eight development surfaces including VS Code, JetBrains, and Xcode ([GitHub Blog](https://github.blog/changelog/2026-08-14-grok-4-6-is-now-available-in-github-copilot/)).

## Windsurf: Devin Local Gets Practical Upgrades

Windsurf added `.devinignore` file support, automatic context from open editor files, and persistent "Always Allow" MCP permissions across sessions ([Releasebot](https://releasebot.io/updates/windsurf)). The repeated re-authorization friction that plagued agent workflows in practice is now gone.

## OpenAI: Astra Safety Framework Rewrite, Week 2

OpenAI's Astra safety framework rewrite enters its second week with frontier RL training still paused ([Forbes](https://www.forbes.com/sites/jonmarkman/2026/08/09/openai-pauses-astra-after-it-nears-first-ever-critical-cyber-risk/)). GPT-5.4 retirement is D-10 (August 31), and o3 retires August 26.
