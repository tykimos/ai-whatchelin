GitHub Copilot이 10월 19일 예고된 대규모 모델 퇴역까지 3일을 남겨두고 39점으로 상승하며 회복세를 이어가고 있다. 반면 Cursor는 51일 연속 하락으로 마침내 1점에 도달, 더 이상 떨어질 곳이 없는 바닥을 찍었다.

## Copilot: 10/19 모델 대폐기 D-3, Universe D-12

GitHub Copilot의 두 번째 10월 모델 퇴역 웨이브가 3일 뒤로 다가왔다([GitHub Changelog](https://github.blog/changelog/2026-09-18-upcoming-deprecation-of-selected-github-copilot-models-in-mid-october)). GPT-5.5, GPT-5.4, GPT-5.4 mini, GPT-5 mini, Gemini 3.7 Flash, Grok 4.5 등 6개 모델이 Chat, 인라인 편집, 에이전트 모드, 코드 완성 전 영역에서 제거된다. 대체 모델은 GPT-5.6 Sol/Luna, Gemini 3.8 Flash, Grok 4.6이며, Business/Enterprise 관리자가 글로벌 기본값을 비활성화하지 않았다면 자동 전환된다([C# Corner](https://www.c-sharpcorner.com/article/preparing-for-github-copilot-model-changes)). 10/2 1차 웨이브(Gemini 3.5/3.6 Flash, Kimi K2.7 Code, Claude Opus 4.7)에 이은 두 번째 정리다. Universe(10/28-29)까지 12일 — Copilot은 39점으로 Cursor 대비 38점 차 리드를 기록 중이다.

## Cursor: 51일 연속 하락, 1점 바닥

Cursor가 51일 연속 하락하며 1점을 기록, 사실상 바닥에 도달했다. SpaceX 인수 완료(8/14) 이후 시작된 하락이 더 이상 내려갈 수 없는 지점까지 왔다([Gigazine](https://gigazine.net/gsc_news/en/20260816-spacex-officially-closes-cursor-acquisition/)). SpaceXAI 소유 아래 Grok 계열 모델 전환이 진행 중이고, OpenAI 모델 접근 차단(11/12)까지 27일이 남았다. 핵심 문제는 모델 손실보다 개발자 신뢰 이탈 — 한때 99점을 기록하던 도구가 두 달 만에 바닥을 찍은 것은 AI 코딩 툴 역사상 가장 급격한 추락이다.

## Anthropic: 투자자 데이 후 로드쇼 일정 조율 중

Anthropic이 10월 14일 SF 본사에서 기관 투자자 대상 프리IPO 투자자 데이를 개최했다([Crypto Briefing](https://cryptobriefing.com/anthropic-targets-november-ipo-delay/)). Morgan Stanley, Goldman Sachs, JPMorgan, Citi가 주관사로 참여하며, 11월 9일 주간 공식 로드쇼 시작이 유력하다([Implicator](https://www.implicator.ai/anthropic-could-start-ipo-roadshow-week-of-nov-9-putting-debut-before-thanksgiving/)). 밸류에이션 목표는 1.8조~2조 달러로, 5월 시리즈 H의 $9,650억 대비 약 2배 수준이다. 추수감사절 전 상장이 목표지만 일정은 유동적이다.

## Codex CLI: 매일 개선 스프린트 12일차

Codex CLI 매일 개선 스프린트가 12일차에 접어들었다([Havoptic](https://www.havoptic.com/releases/openai-codex/2026/10)). v0.161.0(10/7)에서 GPT-6.1 Sol이 기본 모델로 전환된 이후 v0.162.1(10/9)까지 TUI 크래시, 시작 오류 등이 꾸준히 수정되고 있다. URL 클릭, 태스크 고정, Git 워크트리 관리 등 UX 개선도 병행 중이다.

## Claude Code: Haiku 5.5 기본 전환 안정화

Claude Code v2.1.296(10/9)이 최신 릴리스로, Desktop-게이트웨이 간 설정 동기화가 추가됐다([Havoptic](https://www.havoptic.com/releases/claude-code/2026/10)). v2.1.293(10/7)에서 Haiku 5.5가 기본 모델로 전환되며 1M 컨텍스트 윈도우를 제공한다. v2.1.294(10/8)에서는 인스트럭션 기반 훅의 차단 규칙 해석 버그가 수정됐다.
