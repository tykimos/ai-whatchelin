Local AI runner Ollama closed a $65M Series B led by Theory Venture, reaching 9 million monthly active developers([techstartups.com](https://techstartups.com/2026/08/10/top-tech-news-today-august-10-2026-apple-google-meta-openai-unitree-more/)). Demand for running open-weight models locally — without cloud API dependency — is exploding. DeepSeek's looming price hike could accelerate this shift further.

## OpenAI: Legacy API Endpoint Batch Shutdown

Today (Aug 10), OpenAI shut down another batch of legacy API endpoints([openai.com](https://openai.com/products/release-notes/)). This follows the first wave on July 23. The o1, o3-mini, GPT-3.5, and GPT-4 models are scheduled for full retirement on October 23. GPT-5.4/5.4 mini will be removed from ChatGPT-authenticated Codex on August 31, and the DALL-E GPT retires August 30. OpenAI's consolidation around GPT-5.6 is becoming unmistakable.

## Meta: 30B-Parameter Agent on a Single GPU

Meta dropped a 30-billion-parameter agent that runs on a single GPU([techstartups.com](https://techstartups.com/2026/08/10/top-tech-news-today-august-10-2026-apple-google-meta-openai-unitree-more/)). Simultaneously, Muse Spark 1.1 — a multimodal agentic model — launched on the public Meta Model API at $1.25/$4.25 per MTok, roughly 25% of OpenAI/Anthropic pricing. A two-track strategy: local execution capability plus cheap cloud API access.

## DeepSeek: Price Hike Countdown Day 6

DeepSeek's "significant" price increase warning continues to reverberate on day six([Bloomberg](https://www.bloomberg.com/news/articles/2026-08-06/deepseek-plans-significant-price-increase-for-its-ai-services)). V4 Flash processing 8 trillion tokens in a single day on August 1 overwhelmed compute capacity. Founder Jun Song stated that even a 2-10x increase would "still undercut most Western rivals," but the exact percentage, affected tiers, and effective date remain undisclosed([explainx.ai](https://www.explainx.ai/blog/deepseek-api-price-increase-jun-song-august-2026)). Ollama's local model ecosystem is emerging as a natural hedge for DeepSeek-dependent developers.

## GitHub Copilot: Agent App Activity Metrics API

The Copilot usage metrics API now tracks third-party agent app activity([github.blog](https://github.blog/changelog/2026-08-07-copilot-usage-metrics-api-adds-agent-app-activity/)). Enterprise and organization 1-day and 28-day reports now include per-agent breakdowns — session counts, user-initiated interaction counts — giving admins visibility into which agents their teams actually use. September 1 mass model deprecation is now D-22.
