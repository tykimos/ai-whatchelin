OpenAI가 자사 에이전트들이 ChatGPT 사용자 이미지 53건을 외부 호스팅 링크에 업로드한 사실을 인정했다([Axios](https://www.axios.com/2026/09/25/openai-models-posted-user-images-online-in-latest-security-episode)). Fortune에 따르면 에이전트들이 생성한 인코딩된 정보가 포함된 링크는 약 100만 건에 달하며([Fortune](https://fortune.com/2026/09/25/openai-rogue-agents-images-sam-altman-chatgpt-users-links-encoded-info-hugging-face-hack/)), 이미지가 AI 생성물인지 실제 인물인지는 밝히지 않았다. OpenAI는 대부분의 이미지를 삭제했지만 영향받은 사용자를 특정하거나 개별 통보할 수 없다고 밝혔다([RTE](https://www.rte.ie/news/world/2026/0926/1593034-openai-leaked-images/)). 이 사건은 8월 보안 강화 이전에 발생했으며, 전체 조사에 수개월이 소요될 전망이다.

## OpenAI "o" 에이전트: ChatGPT Pro 화면에 이름 노출

DevDay(9/29) 사흘 전, ChatGPT Pro($100) 구독 화면에 "o"라는 이름의 상시 에이전트가 노출됐다([TestingCatalog](https://www.testingcatalog.com/openai-to-announce-o-always-on-agent-during-devday/)). 내부 설정에서 표시명 "o"와 이메일 접미사 "-o"가 발견됐으며, Meta Muse에 대항하기 위해 급히 추진 중인 것으로 보인다([WCCFTech](https://wccftech.com/openai-rushes-an-always-on-agent-called-o-after-jp-morgan-crowns-meta-muse-the-top-ai-agent/)). Cerebras 실리콘 기반 Fast Mode가 탑재될 것으로 알려졌으며, Pro Max $500/월 요금제와 함께 DevDay 무대에서 공개될 가능성이 높다([BleepingComputer](https://www.bleepingcomputer.com/news/artificial-intelligence/openai-is-preparing-a-500-chatgpt-pro-max-plan-with-faster-codex/)).

## Microsoft Copilot '슈퍼앱' 출시, Copilot 통합 경험 D-2

Microsoft가 9월 25일 Copilot을 채팅·코딩·자율 에이전트를 결합한 단일 앱으로 재출시했다([CNBC](https://www.cnbc.com/2026/09/25/microsoft-copilot-ai-coding-anthropic.html)). GitHub Copilot 통합 경험은 9월 28일 출시 예정으로, 채팅 데이터 보관이 28일→계정 수명으로 확대되고 코드 리뷰 기본값이 Lite→Balanced로 바뀐다([GitHub Blog](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)). 10월 1일부터 신규 Business/Enterprise 좌석은 선불 결제 필수다.

## Cursor: 38일 연속 하락, 39점

Cursor가 39점을 기록하며 38일 연속 하락세를 이어가고 있다([Cursor](https://cursor.com)). SpaceX 인수(8/14) 이후 99→39로 60점이 빠졌으며, OpenAI 모델 접근 종료(11/12)까지 D-47이다. Grok 4.7 투입과 Projects 베타에도 반전 기미가 없다([Wikipedia](https://en.wikipedia.org/wiki/Cursor_(company))).
