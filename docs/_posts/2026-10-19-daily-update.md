Today GitHub Copilot's October model purge goes live. GPT-5.5, GPT-5.4, GPT-5.4 mini, GPT-5 mini, Gemini 3.7 Flash, and Grok 4.5 are being removed from all Copilot experiences, with automatic migration to GPT-5.6 Sol/Luna, Gemini 3.8 Flash, and Grok 4.6([GitHub Changelog](https://github.blog/changelog/2026-09-18-upcoming-deprecation-of-selected-github-copilot-models-in-mid-october)). This follows the October 2 first wave that retired Gemini 3.5/3.6 Flash, Kimi K2.7 Code, and Claude Opus 4.7([GitHub Changelog](https://github.blog/changelog/2026-10-02-selected-models-in-github-copilot-deprecated)), completing the legacy model cleanup.

## Copilot: Hits 45, Universe D-9

With both deprecation waves complete, Copilot rises to 45. Agentic autofix, which went GA on October 15, is now auto-fixing code scanning alerts and opening draft PRs, adding real production value([GitHub Blog](https://github.blog/changelog/label/copilot/)). [GitHub Universe 2026](https://github.blog/news-insights/company-news/your-guide-to-github-universe-2026-is-here-the-schedule-just-launched/) (Oct 28–29) is just 9 days out, with tracks on Copilot agent delegation and MCP server security already announced. Expect a next-gen Copilot agent roadmap reveal.

## Claude Code: v2.1.294 Safety Hook Fix, Anthropic IPO Looms

Claude Code v2.1.294 (Oct 8) fixed instruction-based hooks so blocking rules properly take effect([Havoptic](https://www.havoptic.com/releases/claude-code/2026/10)). The v2.1.293 (Oct 7) release switched the default model to Haiku 5.5 with its 1M-token context window, and v2.1.292 (Oct 6) added marketplace plugin installation. Meanwhile, Anthropic's IPO is expected in October–November, with Claude Code — now past $2.5B annualized revenue — positioned as the key growth driver([Yahoo Finance](https://finance.yahoo.com/markets/stocks/articles/anthropic-files-confidentially-ipo-965-162331922.html)).
