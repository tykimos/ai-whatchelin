Today, June 18, 2026, Gemini CLI has been shut down for individual users. An open-source project that ran under Apache 2.0 for nearly a year and accepted over 6,000 community pull requests has been replaced by a single closed-source binary.

## Gemini CLI: The End of Open-Source Trust

Starting today, the `gemini` command returns errors for all individual users ([DigitalApplied](https://www.digitalapplied.com/blog/gemini-cli-to-antigravity-cli-migration-june-18-2026-guide)). Every CI/CD pipeline, shell script, and cron job that depended on `gemini` stops working — there is no grace period ([AI Builder Club](https://www.aibuilderclub.com/blog/google-kills-gemini-cli-june-18-2026)). The replacement, Antigravity CLI (`agy`), is a closed-source Go binary that swaps the free 1,000 daily requests for weekly compute caps ([The Register](https://www.theregister.com/ai-ml/2026/05/20/bye-bye-gemini-cli-google-nudges-devs-toward-antigravity/5243605)). Hacker News commenters called it a "bait-and-switch" — building community contributions under open source, then locking the successor behind proprietary walls ([HN](https://news.ycombinator.com/item?id=48196867)). Enterprise customers with Gemini Code Assist Standard/Enterprise retain access.

## Copilot App GA: Desktop Agents Arrive

The GitHub Copilot desktop app is now generally available on macOS, Windows, and Linux ([GitHub Blog](https://github.blog/changelog/2026-06-17-github-copilot-app-generally-available/)). Developers can start agent sessions directly from issues or PRs and run parallel AI coding sessions across repositories. Canvases let you collaborate with agents on the same plan, PR, terminal, or browser session in real time. Whether this is enough to stop a 45-week decline streak remains to be seen.

## Codex CLI v0.140.0: Migration Tool Targets Claude Code Users

Codex CLI shipped v0.140.0 stable ([OpenAI Developers](https://developers.openai.com/codex/changelog)). The `/import` command can selectively migrate settings, project config, and recent chats from Claude Code. New additions include `/usage` for daily/weekly/cumulative token tracking, `codex delete` for permanent session removal, managed Amazon Bedrock auth, and encrypted local MCP OAuth credential storage ([Releasebot](https://releasebot.io/updates/openai/codex)).

## Fable 5: Suspension Day 6, Washington Face-to-Face Talks

Claude Fable 5's suspension has entered its sixth day ([EisnerAmper](https://www.eisneramper.com/insights/artificial-intelligence-insights/fable-5-suspension-facts-and-timeline-0626/)). Anthropic dispatched Tom Brown and Sarah Heck to Washington for face-to-face negotiations with Commerce Department officials ([explainx.ai](https://explainx.ai/blog/when-will-fable-5-be-available-again-2026)). There is no official timeline for reinstatement, and Anthropic maintains the directive was based on a "misunderstanding." The tracker at isfable5back.com still reads "No" ([isfable5back](https://isfable5back.com/)).

## Google & Kaggle AI Agents Intensive Day 4

Google and Kaggle's free five-day AI Agents Intensive course has entered its fourth day ([Google Blog](https://blog.google/innovation-and-ai/technology/developers-tools/kaggle-genai-intensive-course-vibe-coding-june-2026/)). The course teaches building production-ready AI agents using natural language workflows, with vibe coding as the headline focus this year. The first course last November reached over 1.5 million learners ([Kaggle](https://www.kaggle.com/competitions/5-day-ai-agents-intensive-vibecoding-course-with-google)).
