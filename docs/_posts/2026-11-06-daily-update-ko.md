OpenAI가 이미지 생성 모델을 대폭 업그레이드하며 ChatGPT의 크리에이터 도구 영역을 확장했다. 한편 GitHub Copilot은 IDE 진출을 가속화하고, Cursor는 OpenAI 모델 접근 종료를 일주일 앞두고 있다.

## ChatGPT: Images 2.6 출시, GIF 생성·참조 이미지 저장

OpenAI가 11월 4일 ChatGPT Images 2.6을 출시했다([OpenAI Release Notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)). 새 이미지 모델은 기존 대비 생성 속도가 빨라졌고, 편집 간 디테일 일관성이 크게 개선되었다. GIF 생성 기능이 추가되어 대화 내에서 짧은 애니메이션을 만들 수 있으며, 참조 이미지를 저장해 이후 대화에서 재사용할 수 있는 기능도 포함되었다. 이는 Images 2.5(9월 8일, 지연시간 50% 감소, Sketch 기능)에 이은 두 달 만의 메이저 업데이트다.

## ChatGPT: GPT-6.1 Terra 롤아웃 확대

GPT-6.1 Terra가 ChatGPT Work과 Codex에서 롤아웃 중이다([Releasebot](https://releasebot.io/updates/openai)). 10월 1일 API 가격($2/$10/MTok)이 확정된 이후 Work/Codex 환경에도 순차 적용되고 있으며, Pro 사용자부터 접근 가능하다. 10월 29일에는 Pro와 Business Premium 플랜의 사용량 한도가 두 배로 증가했다.

## GitHub Copilot: JetBrains Air 통합, 42일 연속 상승

GitHub Copilot이 11월 3일 JetBrains Air에서 사용 가능해졌다([GitHub Changelog](https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air)). 기존 Copilot 구독을 그대로 사용할 수 있어 JetBrains 생태계 개발자들의 진입 장벽이 크게 낮아졌다. Xcode 27.3 베타 통합(11/3)에 이어 이틀 연속 IDE 확장 소식이다([9to5Mac](https://9to5mac.com/2026/11/03/xcode-27-3-adds-github-copilot-to-its-built-in-coding-assistant)). 점수는 81점으로 42일 연속 상승하며, 11월 16일 모델 교체(Opus 4.8/5 → Opus 5.5, GPT-5.6 Terra → GPT-6.1 Sol)까지 10일 남았다([GitHub Blog](https://github.blog/changelog/2026-10-15-upcoming-deprecation-of-selected-github-copilot-models-in-mid-november)).

## Cursor: OpenAI 차단 D-6, 73일째 바닥

11월 12일 OpenAI 모델 접근 완전 차단까지 6일 남았다([Tom's Guide](https://www.tomsguide.com/ai/openai-is-leaving-cursor-in-november-here-are-your-3-options)). 73일 연속 1점을 기록하며 반등 기미가 없다. OpenAI는 차단일까지 신규 모델을 제공하지 않으며([VPS Ranking](https://vpsranking.com/news/ai/ai-2026-08-28-openai-cursor-contract-winddown/)), Cursor는 Grok 4.7과 Anthropic 모델로 전환을 진행 중이다.

## Anthropic: IPO 로드쇼 D-3, Mythos 5.5 출시설 지속

Anthropic IPO 로드쇼가 이르면 11월 9일 주간에 시작될 수 있어 3일 남았다([Leverage Shares](https://leverageshares.com/us/insights/when-is-the-anthropic-ipo/)). Mythos 5.5 관련 참조가 공식 페이지에서 발견된 지 5일이 지났으나 아직 공식 발표는 없다([TestingCatalog](https://www.testingcatalog.com/anthropic-prepares-to-release-claude-mythos-5-5-model/)). Claude Code는 GitHub 커밋의 13.8%에 co-author 라인이 포함되어 있어, 2026년 말 20% 목표 달성 가능성에 주목하고 있다([X/con_golias](https://x.com/con_golias/status/2118301334835208380)).

## Postman: 무단 플러그인 삽입 논란

Postman 데스크톱 업데이트가 사용자 동의 없이 Claude Code와 Codex에 Postman 플러그인을 자동 추가한 것으로 알려졌다([Mezha](https://mezha.net/eng/news/mezha-3d570273b493dad39d47211c_postman_update_added/)). GitHub Copilot CLI에서도 동일한 현상이 보고되었다. 데이터 수집 증거는 아직 없지만, AI 도구 생태계에서의 서드파티 통합 신뢰 문제를 부각시킨 사건이다.
