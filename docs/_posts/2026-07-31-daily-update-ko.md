OpenAI가 출시 3주 만에 GPT-5.6 Luna 가격을 80% 인하하며 AI 모델 가격전쟁의 새 국면을 열었다. 글로벌 경쟁 압박 속에서 프론티어 AI 랩들의 가격 결정력이 빠르게 약화되고 있다는 신호다.

## OpenAI: GPT-5.6 Luna 80% 인하, Terra 20% 인하

OpenAI가 7월 30일 GPT-5.6 Luna 가격을 $1/$6에서 $0.20/$1.20(백만 토큰당 입출력)으로 80% 대폭 인하했다([VentureBeat](https://venturebeat.com/technology/ai-price-wars-openai-cuts-gpt-5-6-luna-prices-by-80-as-model-competition-shifts-toward-cost)). Terra 역시 $2.50/$15에서 $2/$12로 20% 내렸고, 플래그십 Sol은 $5/$30 유지다([CNBC](https://www.cnbc.com/2026/07/30/open-ai-price-cut-gpt.html)). 7월 9일 GA 출시 후 불과 3주 만의 인하로, 추론 인프라 개선과 Anthropic·Google의 공격적 가격 전략이 배경이다([Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/openai-just-cut-gpt-5-013753910.html)). Codex CLI Auto-review가 GPT-5.6 Luna를 사용하는 만큼, 이번 인하로 Auto-review 비용이 약 10배 절감될 전망이다([Releasebot](https://releasebot.io/updates/openai/codex)).

## GitHub Copilot: Gemini 2.5 Pro & 3 Flash 오늘 공식 퇴장

오늘(7월 31일) Gemini 2.5 Pro와 Gemini 3 Flash가 GitHub Copilot 전 경험에서 공식 폐기된다([GitHub Changelog](https://github.blog/changelog/2026-07-02-upcoming-deprecation-of-gemini-2-5-pro-and-gemini-3-flash/)). Copilot Chat, 인라인 편집, Ask·Agent 모드, 코드 완성 전반에 적용되며, 사용자는 Gemini 3.1 Pro 또는 Gemini 3.5 Flash로 전환해야 한다([GitHub Changelog X](https://x.com/GHchangelog/status/2072828939777560672)). 어제 발표된 Copilot Visual Studio 7월 업데이트에서는 Copilot SDK 기반 새 에이전트와 .NET/Azure 팀 전문성이 내장됐다([GitHub Blog](https://github.blog/changelog/2026-07-30-github-copilot-in-visual-studio-july-update/)).

## Cursor: $20 단일 밴드 가격 체계 + iPad 본격 지원

Cursor가 7월 28일부터 Pro·Pro+·Ultra를 $20/월 단일 밴드로 통합하고 사용량 초과분만 추가 과금하는 방식으로 전환했다([Cursor Changelog](https://cursor.com/changelog)). iPad용 분할 화면 채팅, 풍부한 diff 뷰, 개선된 마크업 등 대화면 편집 기능도 추가됐다([Releasebot](https://releasebot.io/updates/cursor)). Cursor Router의 지능형 모델 라우팅이 Auto 모드를 구동하며 30-60% 비용 절감 효과를 내고 있다.

## Antigravity: v1.1.8 — 구조화 출력과 JSON 스키마 검증

Antigravity v1.1.8(7월 28일)이 `json`·`stream-json` 구조화 출력 포맷, 커스텀 JSON 스키마 검증, 서브에이전트 페이로드 보강, `copyOnSelect` 설정을 추가했다([Antigravity Changelog](https://antigravity.google/changelog)). 27주 연속 99점을 유지하며 CLI 에이전트 도구 중 가장 안정적인 행보를 이어가고 있다.
