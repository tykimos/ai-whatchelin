OpenAI가 GPT-5.6 Sol을 일부 Codex 사용자에게 몰래 배포한 사실이 오늘 발각됐다. 개발자들이 히든 시스템 프롬프트 파라미터를 통해 모델 교체를 감지한 것이다([TechTimes](https://www.techtimes.com/articles/319297/20260629/openai-silently-rolled-gpt-56-some-codex-users-hidden-prompt-exposes-swap.htm)). 이는 AI 벤더의 모델 변경 투명성에 대한 근본적 물음을 제기한다.

## OpenAI: GPT-5.6 비밀 배포와 "Juice 값" 논란

OpenAI는 6월 26일 GPT-5.6을 정부 승인 파트너 약 20개 기관에만 공개한다고 발표했다([OpenAI](https://openai.com/index/previewing-gpt-5-6-sol/)). 그러나 Codex 사용자들이 `/status` 명령으로 353,000 토큰 컨텍스트 윈도우와 "Juice 값 128"을 감지하며 비공개 배포가 드러났다([TechTimes](https://www.techtimes.com/articles/319297/20260629/openai-silently-rolled-gpt-56-some-codex-users-hidden-prompt-exposes-swap.htm)). GPT-5.6은 Sol(최상위), Terra(중간), Luna(경량) 3개 티어로 구성된 새 명명 체계를 도입했으며, Sol은 서브에이전트 병렬 실행이 가능한 ultra 모드를 탑재했다([9to5Mac](https://9to5mac.com/2026/06/26/openai-upgrading-chatgpt-and-codex-with-new-gpt-5-6-models-in-limited-release/)). 한편 GPT-4.5는 6월 27일 ChatGPT에서 공식 퇴장했다([OpenAI Help](https://help.openai.com/en/articles/9624314-model-release-notes)).

## Cursor: SpaceX 인수 후 첫 iOS 앱 정식 출시

Cursor가 App Store에 iPhone/iPad 앱을 정식 출시했다([9to5Mac](https://9to5mac.com/2026/06/29/cursor-releases-iphone-and-ipad-app-following-recent-acquisition-by-spacex/)). SpaceX $600억 인수 후 첫 주요 제품 발표로, 앱에서 코딩 에이전트 원격 실행, 스크린샷/비디오 리뷰, 이미지 주석 피드백, 차이점 검토 및 PR 머지, 음성 대화 기능을 제공한다. 모바일 코딩 환경이 아닌 AI 에이전트 원격 관리 레이어로 설계된 점이 특징이다.

## Fable 5: 17일째 차단, 복원 "이번 주 내" 보도에도 불구

Fable 5가 17일째 차단 상태를 유지하고 있다. Axios는 6월 27일 트럼프 행정부가 복원에 "가까워졌다"고 보도했으나([Axios](https://www.axios.com/2026/06/27/anthropic-fable-5-return-soon)), 국방부와 NSA의 최종 승인이 남아있다. Mythos 5만 Annex A 미국 기관에 부분 복원됐다. 오스트리아는 EU 집행위에 Anthropic의 유럽 내 법인 설립을 촉구하는 공식 서한을 보내며, Fable 5 차단이 EU AI 주권 논의를 촉발시켰다([Jerusalem Post](https://www.jpost.com/business-and-innovation/tech-and-start-ups/article-900712)).

## Claude Code v2.1.193 — /rewind·셸 모드·MCP 인증

Claude Code 최신 버전이 `/rewind`로 `/clear` 이전 대화 복원, `claude mcp login/logout` 셸 인증, 명령 출력 자동 응답 등을 도입했다([Anthropic](https://code.claude.com/docs/en/whats-new)). 배경 서브에이전트가 자동 거부 대신 메인 세션에서 권한 프롬프트를 표시하고, CPU/메모리 사용량도 줄었다.

## Copilot 55주 연속 하락 — 27까지 추락

GitHub Copilot이 55주 연속 하락하며 27에 도달했다. 종량제 전환 29일째, 에이전틱 세션당 $30-40 비용이 이탈을 가속시키고 있다([GitHub Discussions](https://github.com/orgs/community/discussions/197089)).
