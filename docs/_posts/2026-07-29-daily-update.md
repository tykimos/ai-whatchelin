Codex CLI completely overhauls its session management with a plugin marketplace, Cursor enters India with country-specific pricing, and the AI safety conversation escalates as over 1,100 employees from leading AI companies sign a public letter calling for coordinated deceleration.

## Codex CLI v0.146.0: Session Management Overhaul

Codex CLI shipped v0.146.0 with a comprehensive session management rework([Codex Changelog](https://developers.openai.com/codex/changelog)). Users can now name sessions with `/new` or `/clear`, pin important threads, switch between side conversations, and fork threads with paginated history. The release also adds Agent Plugins manifest support, workspace plugin publishing, and marketplace access for Amazon Bedrock and Claude Code plugins([Releasebot](https://releasebot.io/updates/openai/codex)). WebSocket support for remote Code Mode hosts rounds out the update.

## Cursor Start: India-Specific Plan at ₹649/Month

Cursor launched "Cursor Start," its first country-specific plan, priced at ₹649/month (~$7 USD) for the Indian market([Cursor Blog](https://cursor.com/blog/cursor-start-india)). The plan includes Grok 4.5 access, Composer, cloud agents, Cursor for iOS, plugins, MCP servers, hooks, and skills. India is Cursor's third-largest market with 3M+ developers, and the plan represents a 65% discount from the global Pro tier($20)([The Next Web](https://thenextweb.com/news/cursor-start-india-pricing-own-models-spacex)).

## OpenAI: GPT Transcribe API and ChatGPT Sign-In Launch

OpenAI released two new transcription models: GPT Transcribe for accurate file transcription and GPT Live Transcribe for low-latency streaming, both supporting free-form context and keyword hints([OpenAI Release Notes](https://openai.com/products/release-notes/)). Separately, "Sign in with ChatGPT" entered beta across Airtable, GitLab, HubSpot, Notion, Supabase, and Vercel, and a new Academic Researchers Program offers 12 months of complimentary team workspaces for verified faculty([ChatGPT Release Notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)).

## AI Slowdown Letter: 1,100+ Employees Sign

Over 1,100 employees from OpenAI, Anthropic, Google, and Meta signed an open letter urging Washington to build tools for an international AI slowdown mechanism([BuildFastWithAI](https://www.buildfastwithai.com/blogs/ai-news-today-july-29-2026)). On the same day, Cyera acquired AI agent security firm Oasis Security for approximately $1B, underscoring that AI safety is becoming a top priority for both policy and investment.

## VS Code 1.131 Insiders: Subagent Visibility Boost

VS Code 1.131 Insiders shipped with clearer subagent activity — model name, elapsed time, and active tool calls are now visible without opening the conversation([VS Code Updates](https://code.visualstudio.com/updates/v1_131)). Experimental built-in dictation using an offline Nemotron model and a hybrid Markdown editor for the Agents window were also added.
