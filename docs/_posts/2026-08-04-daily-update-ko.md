Codex CLI가 드디어 Cursor를 넘었다. GPT-5.6 Luna 80% 인하 효과가 8일 연속 이어지며 98점을 기록, Cursor(97)를 1점 차로 추월한 것은 사상 처음이다. 동시에 Claude Opus 4.1 API는 내일(8월 5일) 영구 폐기를 앞두고 마지막 날을 보내고 있다.

## Codex CLI: 98점 — Cursor 첫 추월, Luna 8일 연속 상승

GPT-5.6 Luna 80% 인하(7/30)의 파급 효과가 8일째 계속되고 있다([VentureBeat](https://venturebeat.com/technology/ai-price-wars-openai-cuts-gpt-5-6-luna-prices-by-80-as-model-competition-shifts-toward-cost)). Codex CLI는 91→92→93→94→95→96→97→98로 매일 1점씩 상승하며, 어제 Cursor와 동점(97)을 이룬 뒤 오늘 98로 사상 첫 추월을 달성했다. 자동 리뷰 비용이 10배 절감된 것이 핵심 동력이다. Cursor는 iPad 출시와 Router 출시로 97을 유지하고 있지만, 터미널 중심 개발자들의 이탈이 감지되고 있다.

## Anthropic: Opus 4.1 내일 영구 폐기 — D-1 카운트다운

Claude Opus 4.1(claude-opus-4-1-20250805) API가 내일(8월 5일) 영구 폐기된다([Anthropic](https://platform.claude.com/docs/en/about-claude/model-deprecations)). 6월 5일 공식 폐기 공지 후 정확히 60일 만이다. 이후 해당 모델 ID로의 요청은 에러를 반환하며, Opus 4.8로의 마이그레이션이 필수다([TheRouter.ai](https://therouter.ai/news/anthropic-deprecates-claude-opus-4-1-august-5-migration-guide/)). Claude Code 50% 사용량 부스트는 8월 19일까지 유지된다.

## OpenAI: Astra 최소 9월 — 연방 사전심사 30일 필요

Astra는 출시일·가격·API 접근 등 어떤 것도 확정되지 않았다([FelloAI](https://felloai.com/all-we-know-about-chatgpt-6/)). 새로운 연방 사전 출시 심사(~30일)를 통과해야 하며, 최빠른 공개 시점은 9월이다. OpenAI는 Hugging Face 침해 사건에 대한 기술 보고서도 8월 중 발표 예정이다([WinBuzzer](https://winbuzzer.com/2026/07/29/hugging-face-ceo-seeks-openai-traces-and-defensive-compute-xcxwbn/)).

## GitHub Copilot: 9/1 대규모 모델 폐기 예고

GitHub이 9월 1일부로 Copilot 전 경험에서 다수 모델을 폐기한다고 발표했다([GitHub Changelog](https://github.blog/changelog/2026-07-31-upcoming-august-2026-model-deprecations-in-github-copilot/)). Claude Sonnet 4.6는 연간 구독 개인 사용자에게만 유지된다. Gemini 2.5 Pro와 3 Flash는 이미 7월 31일 폐기됐다.

## DeepSeek: V4 Pro GA 임박 — 중순 출시 유력

DeepSeek V4-Flash-0731이 프리뷰에서 공식 릴리스로 승격됐다([Hugging Face Blog](https://huggingface.co/blog/ResterChed/deepseek-v4-flash-official-release)). V4 Pro GA는 "곧"이라고만 안내하고 있으며, 언론 보도에 따르면 8월 중순 출시가 유력하다([deepseekv4pro.com](https://deepseekv4pro.com/news/deepseek-v4-ga-mid-august-release-window-harness-beta)). Responses API와 Codex 지원도 함께 제공될 전망이다.

Codex CLI가 Cursor를 추월한 것은 상징적이다. 터미널 기반 에이전트가 IDE 기반 도구를 인기도에서 앞서기 시작한 것은 GPT-5.6 Luna 가격 인하의 직접적 결과다. 내일 Opus 4.1이 완전히 사라지면서, AI 코딩 도구 시장의 모델 세대교체가 한층 가속될 것이다.
