어제 예고한 '슈퍼 먼데이'가 현실이 됐다. 세 개의 메가 이벤트가 동시에 터졌고, 여기에 Cursor의 자체 모델 출시까지 더해지며 AI 코딩 도구 시장이 24시간 만에 완전히 재편되고 있다.

## Musk v. Altman: $1,340억 소송, 2시간 만에 끝장

Oakland 연방법원 배심원단이 Elon Musk의 OpenAI·Sam Altman·Greg Brockman 상대 전 청구를 **만장일치로 기각**했다([NPR](https://www.npr.org/2026/05/18/nx-s1-5822366/musk-altman-openai-jury-verdict-claims-dismissed)). 자선 신탁 위반과 부당이득 청구 모두 소멸시효를 초과한 것으로 판단됐으며, Microsoft 관련 청구도 연쇄적으로 무너졌다([GeekWire](https://www.geekwire.com/2026/jury-finds-musk-waited-too-long-to-sue-openai-and-microsoft-finding-defendants-not-liable-on-all-claims/)). Musk는 X에서 "달력 기술적 문제"라며 제9순회 항소를 선언했지만([CNBC](https://www.cnbc.com/2026/05/18/musk-altman-openai-trial-verdict.html)), 11일간의 증인 심리와 수백 건의 증거를 뒤집기는 쉽지 않을 전망이다.

## Cursor: Composer 2.5 — "우리 모델로 Opus 4.7을 이긴다"

Cursor가 자체 개발 모델 **Composer 2.5**를 출시했다([Cursor Blog](https://cursor.com/blog/composer-2-5)). SWE-Bench Multilingual **79.8%**, CursorBench v3.1 **63.2%**로 Claude Opus 4.7과 GPT-5.5에 필적하는 성능이다([The Decoder](https://the-decoder.com/cursors-composer-2-5-matches-opus-4-7-and-gpt-5-5-benchmarks-at-a-fraction-of-the-cost/)). 입력 $0.50/M, 출력 $2.50/M으로 경쟁 모델 대비 현저히 저렴하다. Kimi K2.5 스캔들 이후 자체 모델 개발에 올인했던 Cursor가 드디어 결실을 맺은 셈이다. 첫 주 사용량 2배 프로모션도 진행 중이다.

## Google I/O 2026: Antigravity 무료 공개 + Gemini 3.5 임박

Google I/O 키노트가 오늘 오전 10시(PT)에 시작된다([io.google](https://io.google/2026/)). 사전 발표와 유출을 종합하면: **Antigravity**가 대기자 명단도, 신용카드도 없는 **무료 퍼블릭 프리뷰**로 공개된다([Google Developers Blog](https://developers.googleblog.com/build-with-google-antigravity-our-new-agentic-development-platform/)). Editor View와 Manager Surface 이중 인터페이스로 다중 에이전트를 오케스트레이션하는 에이전트 퍼스트 IDE다. Gemini 3.5 Pro 발표가 유력하며([StartupFortune](https://startupfortune.com/deepmind-employee-signals-gemini-35-ahead-of-google-io-2026-launch/)), Gemini Omni 비디오 모델, Android 17, Googlebooks(크롬북 후속) 등 대형 발표가 줄줄이 예고됐다.

## Code with Claude London: Claude Code 생태계 확장

Anthropic의 Code with Claude London이 오늘 종일 진행된다([claude.com](https://claude.com/code-with-claude/london)). Research·Platform·Code 3개 트랙에 MCP가 핵심 주제다. **Claude Code v2.1.144**가 동시에 릴리스됐는데, /resume로 백그라운드 세션 재개, MCP 터널, 셀프호스팅 샌드박스 지원이 추가됐다([Releasebot](https://releasebot.io/updates/anthropic/claude-code)). 내일(5/20)에는 인디 개발자를 위한 확장 세션이 별도 개최된다.

## Copilot: 15주 연속 하락, 68까지 추락

GitHub Copilot이 **15주 연속 인기도 하락** 기록을 세우며 68까지 떨어졌다([GitHub Blog](https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/)). 6/1 사용량 과금 전환 D-13. 4월 사용량 보고서가 공개되면서 예상 비용에 놀란 개발자들의 이탈이 가속화되고 있다([GapVelocity](https://www.gapvelocity.ai/blog/github-copilots-new-usage-based-billing-what-changed-why-developers-are-upset-and-what-it-means)).
