11월 둘째 날, AI 코딩 도구 시장의 긴장감이 한층 고조되고 있다. Anthropic의 Mythos 페이지에서 차세대 모델의 흔적이 발견됐고, Cursor의 OpenAI 모델 접근 차단까지 열흘이 남았다. 시장 판도를 바꿀 수 있는 이벤트들이 11월 전반에 집중돼 있다.

## Claude: Mythos 5.5 레퍼런스 최초 포착

TestingCatalog이 11월 1일 Anthropic의 Mythos 페이지에서 Claude Mythos 5.5 레퍼런스를 발견했다고 보도했다([TestingCatalog](https://www.testingcatalog.com/anthropic-prepares-to-release-claude-mythos-5-5-model/)). 출시 시점은 "다음 주 가능성"으로 언급됐으나 확정되지 않았다. Fable 5.5 체크포인트의 A/B 테스트도 일부 사용자에게 진행 중이라는 소셜 미디어 보고가 있다([TestingCatalog](https://www.testingcatalog.com/anthropic-prepares-to-release-claude-mythos-5-5-model/)). Mythos 5.1이 9월 1일 출시 후 Glasswing/승인 접근 전용으로 제한된 점을 감안하면, 5.5 역시 초기에는 제한적 접근이 예상된다.

## Cursor: OpenAI 모델 차단 D-10

OpenAI가 8월 29일 발표한 Cursor와의 파트너십 종료가 현실로 다가오고 있다. 11월 12일 GPT 모델 접근이 완전 차단되면, Cursor 사용자 중 OpenAI 모델에 의존하는 약 5%는 자체 API 키를 등록하거나 Grok/Claude로 전환해야 한다([Bloomberg](https://www.bloomberg.com/news/articles/2026-08-29/openai-to-end-partnership-with-cursor-after-spacex-acquisition)). Cursor CEO는 OpenAI 트래픽 비중이 5%에 불과하다고 밝혔지만, 상징적 의미는 크다 - SpaceX 인수 후 69일째 바닥(점수 1)에 머물며 회복 기미가 보이지 않는다.

## GitHub Copilot: 73점, 38일 연속 회복

Copilot이 73점으로 올라서며 38일 연속 상승세를 기록했다. Universe 2026에서 발표한 Copilot Fusion GA와 프로젝트 기능이 모멘텀을 유지하고 있다. 11월 16일 모델 퇴장(Claude Opus 4.8/5 -> Opus 5.5, GPT-5.6 Terra -> GPT-6.1 Sol/GPT-6 Luna)이 예정돼 있어, 모델 라인업 현대화가 가속 중이다([GitHub Blog](https://github.blog/changelog/)).

## Anthropic: IPO 로드쇼 1주 전

Anthropic의 S-1 등록 신고서가 10월 26일 SEC에 제출된 이후, 11월 9일 주 로드쇼가 예상된다. Nasdaq 티커 "ANT", 12개월 매출 $19.7B, 순손실 $109.7B이 공시됐다([IPO Scoop](https://www.iposcoop.com/the-ipo-buzz-anthropic-ant-proposed-files-its-s-1/)). Mythos 5.5 출시 시점이 로드쇼 직전과 겹칠 가능성이 있어, 전략적 타이밍에 대한 관측이 나오고 있다.

## OpenAI: Sonnet 4.5 퇴장 카운트다운

Claude Sonnet 4.5의 API 퇴장이 11월 30일로 예정돼 있다([ScriptByAI](https://www.scriptbyai.com/anthropic-claude-timeline/)). Opus 4.5는 11월 24일 이전에는 퇴장하지 않을 전망이다. 5.5 세대가 완전히 자리 잡으면서 구세대 모델의 정리가 본격화되고 있다.
