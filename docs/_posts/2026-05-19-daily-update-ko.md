'슈퍼 먼데이'가 막을 내렸다. Google I/O 키노트, Cursor 자체 모델 출시, Musk v. Altman 만장일치 기각이 동시에 터지면서 AI 코딩 도구 시장이 24시간 만에 근본적으로 재편됐다.

## Google I/O 2026: Gemini 3.5 Flash GA + Antigravity 2.0 전면 출시

Google I/O 키노트의 핵심은 **Gemini 3.5 Flash GA**다. 다른 프론티어 모델 대비 4배 빠른 출력 속도를 자랑하며, Terminal-Bench 2.1 **76.2%**, MCP Atlas **83.6%**로 코딩 벤치마크를 석권했다([Tom's Guide](https://www.tomsguide.com/news/live/google-io-2026-live-news-updates)). 가격은 입력 $1.50/M, 출력 $9.00/M, 캐시 $0.15/M으로 1M 토큰 컨텍스트 윈도우를 제공한다([Artificial Analysis](https://artificialanalysis.ai/models/gemini-3-5-flash)). Gemini 3.5 Pro는 내달 출시 예정이다([Analytics Insight](https://www.analyticsinsight.net/artificial-intelligence/google-io-2026-live-updates-gemini-android-17-xr-glasses-and-more)).

**Antigravity 2.0**이 전 세계에 정식 출시됐다. 단순한 무료 프리뷰가 아니라, 데스크톱 앱·CLI·SDK 삼위일체 구성이다([TechCrunch](https://techcrunch.com/2026/05/19/google-launches-antigravity-2-0-with-an-updated-desktop-app-and-cli-tool/)). 다중 에이전트 오케스트레이션, 음성 명령 지원, AI Studio 프로젝트 내보내기가 추가됐으며, 새로운 **AI Ultra** 플랜($100/월)은 Pro 대비 5배 높은 AI 한도를 제공한다([Android Headlines](https://www.androidheadlines.com/2026/05/google-io-2026-antigravity-developer-tools-ai-studio-mobile-app.html)). **Gemini Spark**도 공개됐는데, Gemini 앱 안에서 24/7 작동하는 개인 AI 에이전트로 Google Cloud VM 위에서 구동된다([MacRumors](https://www.macrumors.com/2026/05/19/google-io-2026-roundup/)).

## Cursor Composer 2.5 — 자체 모델 시대 개막

Cursor가 **Composer 2.5**를 출시했다. SWE-Bench Multilingual **79.8%**, CursorBench v3.1 **63.2%**로 Opus 4.7과 GPT-5.5에 필적한다([The Decoder](https://the-decoder.com/cursors-composer-2-5-matches-opus-4-7-and-gpt-5-5-benchmarks-at-a-fraction-of-the-cost/)). 입력 $0.50/M, 출력 $2.50/M으로 경쟁사 대비 파격적이다. Elon Musk가 수시간 내 SNS에서 증폭시켰고, xAI Colossus 2를 활용한 대규모 후속 모델 훈련 파트너십도 발표됐다([Cursor Blog](https://cursor.com/blog/composer-2-5)).

## Musk v. Altman: $1,340억 소송 만장일치 기각

Oakland 배심원단이 Musk의 전 청구를 **만장일치로 기각**했다. 자선 신탁 위반과 부당이득 모두 소멸시효 초과 판정이다([NPR](https://www.npr.org/2026/05/18/nx-s1-5822366/musk-altman-openai-jury-verdict-claims-dismissed)). Musk는 "달력 기술적 문제"라며 제9순회 항소를 선언했지만([CNBC](https://www.cnbc.com/2026/05/18/musk-altman-openai-trial-verdict.html)), 법적 불확실성이 해소되면서 OpenAI 영리 전환이 속도를 낼 전망이다.

## Code with Claude London Day 1 + v2.1.144

Anthropic의 Code with Claude London이 Research·Platform·Code 3트랙으로 진행됐다. **Claude Code v2.1.144**에서 /resume 백그라운드 세션, MCP 터널, 셀프호스팅 샌드박스가 추가됐다([Releasebot](https://releasebot.io/updates/anthropic/claude-code)). 내일(5/20) 인디 개발자 확장 세션이 이어진다.
