GitHub Copilot이 드디어 Cursor를 추월했다. 85주 동안 바닥(1점)에 머물렀던 Copilot이 21점까지 올라선 반면, SpaceX 인수 이후 41일 연속 추락 중인 Cursor는 17점으로 떨어졌다. 2025년 이후 처음으로 Copilot이 Cursor 위에 선 이 교차점은 AI 코딩 도구 시장의 판도가 바뀌고 있음을 보여준다.

## GitHub Copilot: 반등의 구조적 원인

Copilot의 반등은 단순한 숫자 게임이 아니다. 10월 2일 Code Review API GA 출시로 REST/GraphQL을 통한 프로그래머블 코드 리뷰가 가능해졌고, 기본 노력 수준이 Lite에서 Balanced로 상향됐다([GitHub Changelog](https://github.blog/changelog/2026-10-02-copilot-code-review-api-support-and-new-default-effort-level)). HydraFusion 멀티모델 오케스트레이션이 CLI에서 VS Code와 Copilot 앱으로 확장됐고([IT Brief](https://itbrief.co.uk/story/github-launches-hydrafusion-preview-for-copilot-coding)), Computer Use 퍼블릭 프리뷰로 macOS·Windows 데스크톱 앱 자동화가 시작됐다([GitHub Changelog](https://github.blog/changelog/2026-10-01-github-copilot-can-now-interact-with-desktop-apps)). 10월 19일에는 GPT-5.5, GPT-5.4, Gemini 3.7 Flash, Grok 4.5 등 6개 모델이 한꺼번에 폐기되는 2차 웨이브가 예정돼 있다([GitHub Changelog](https://github.blog/changelog/2026-09-18-upcoming-deprecation-of-selected-github-copilot-models-in-mid-october/)).

## Cursor: D-36의 의미

Cursor에게 남은 시간은 36일이다. 11월 12일 OpenAI 모델 접근 차단 시한까지의 카운트다운이 계속되는 가운데, Compile 2026에서 발표한 자체 프론티어 모델과 Origin 플랫폼이 시장 신뢰를 회복하지 못하고 있다([DevOps.com](https://devops.com/openai-cuts-off-cursors-model-access-after-spacex-acquisition/)). 17점은 올해 최저치다.

## Anthropic: IPO 1주일 전 — $2조의 무게

Anthropic 프리IPO 투자자 데이가 10월 14일로 1주일 앞으로 다가왔다. FT에 따르면 투자자들은 $2조 이상의 밸류에이션을 전망하고 있으며, SpaceX IPO($1.77조)를 넘어 역대 최대 상장이 될 수 있다([PYMNTS](https://pymnts.com/news/artificial-intelligence/2026/anthropic-could-seek-2-trillion-valuation-in-record-ipo)). 2026년 말 연환산 매출 $1,000억~$1,200억을 예상하는 투자자도 있다([Trending Topics](https://www.trendingtopics.eu/anthropic-investors-expect-ipo-valuation-of-2-trillion-more-than-spacex/)). Claude Code가 이 성장의 핵심 동력으로, 엔터프라이즈 ARR 견인의 주축이다.

## Codex: 일일 스프린트 계속

OpenAI Codex 팀의 4주 일일 개선 스프린트가 8일째를 맞았다([OpenAI Community](https://community.openai.com/t/video-meet-the-new-codex-cli-updates/1403548)). Pro 500 플랜($500/월)의 Ultrafast 모드는 초당 300토큰 생성을 제공하며, GPT-6.1 Sol이 Astra의 1/5 비용으로 정착하고 있다([Nerdschalk](https://nerdschalk.com/gpt-6-1-sol-price-availability/)).
