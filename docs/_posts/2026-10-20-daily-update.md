Codex CLI v0.163.0 has reached stable, bringing a meaningful usability leap to the terminal coding agent. The headline additions are a searchable `/config` command for modifying settings without restarting, mid-response steering that redirects the agent immediately when you send a follow-up, and parallel execution of independent read-only tools([Codex Blog](https://codex.danielvaughan.com/2026/10/16/codex-v0163-stable-release-config-follow-up-parallel-tools-daybreak/)). Daybreak is also now enabled by default for eligible accounts.

## Codex CLI: /config Command Streamlines Workflow

The `/config` command in v0.163.0 opens an in-session preference browser — search settings, change them, and keep working without a restart([Havoptic](https://www.havoptic.com/r/openai-codex-rust-v0.163.0)). The configurable leader key in `/keymap` (default Ctrl+X) and voice mute moving to F9 round out the ergonomic improvements. Combined with v0.162.0's clickable URLs, task pinning, and Git worktree management from Oct 8, Codex CLI is steadily closing the gap with IDE-class convenience.

## GPT-5.5 Retirement Fallout: "gpt-5.5 model is not supported"

GPT-5.5 was permanently removed from ChatGPT, Work, and Codex across all plans on October 14([OpenAI Changelog](https://learn.chatgpt.com/docs/changelog)). Six days later, "gpt-5.5 model is not supported" errors continue to surface as developers discover stale model IDs in workspace defaults, saved configurations, custom agents, and scheduled tasks([DevelopersDig](https://www.developersdigest.tech/blog/codex-gpt-5-5-not-supported-chatgpt-account-fix-2026)). The fix is straightforward — switch to gpt-5.6-sol or gpt-6.1-sol. API key-authenticated users are unaffected([OrcaRouter](https://www.orcarouter.ai/blog/gpt-5-5-remains-available-openai-api-codex-api-key)).

## Antigravity: Gemini 4 Argon Rollout Expanding to Pro

Google began rolling out Gemini 4 Argon in the Antigravity desktop app and CLI on October 13, starting with AI Ultra subscribers([Antigravity Blog](https://antigravity.google/blog/gemini-4-argon-in-google-antigravity)). Reports indicate that AI Pro tier access started expanding around October 15([pasqualepillitteri](https://pasqualepillitteri.it/ja/news/24648/gemini-4-argon-antigravity-ai-pro-shuukan-waku)). Meanwhile, Claude Sonnet 4.6, Opus 4.6, and GPT-OSS-120B are scheduled for removal from Antigravity on November 2([Layer3 Labs](https://www.layer3labs.io/guides/google-antigravity-cli)).
