GitHub Copilot dropped three major updates in a single day. It added the open-weight Kimi K2.7 Code model to the model picker, opened Vision GA to all subscribers including Free, and shipped auto model selection that routes tasks to the optimal model in real time ([GitHub Changelog](https://github.blog/changelog/2026-07-01-kimi-k2-7-is-now-available-in-github-copilot/)). Despite all of this, its 57-week decline marches on.

## Copilot: Triple Update Still Can't Stop the Bleed — 24 Points, Billing Day 32

Kimi K2.7 Code is the first open-weight model to appear in the Copilot model picker ([GitHub Changelog](https://github.blog/changelog/2026-07-01-kimi-k2-7-is-now-available-in-github-copilot/)). Hosted on Microsoft Azure, it's rolling out to Pro/Pro+/Max plans, with Business/Enterprise requiring admin policy activation. Copilot Vision also went GA on July 1, letting all subscribers — including Free — attach images and PDFs directly to chat prompts ([GitHub Changelog](https://github.blog/changelog/2026-07-01-copilot-vision-is-generally-available/)). Auto model selection evaluates reasoning complexity, code generation difficulty, and tool orchestration needs in real time to route to the best model ([GitHub Changelog](https://github.blog/changelog/2026-07-01-copilot-cli-auto-model-selection-routes-based-on-task/)). Yet Copilot still fell to 24 in its 57th consecutive week of decline — usage-based billing at $30-40/day for agentic sessions continues to drive the exodus.

## Claude Code v2.1.198: Chrome GA, Background Agent Auto-PR

Claude Code v2.1.198 shipped on July 1 ([GitHub Releases](https://github.com/anthropics/claude-code/releases)). Three headline features: Chrome integration is now GA, background agents in worktrees automatically commit, push, and open a draft PR when they finish code work, and a new notification system fires hooks when agents complete or need input. A /dataviz skill was also added for chart and dashboard design guidance. Sonnet 5 is confirmed as the default model with 1M context and $2/$10 per MTok promotional pricing through August 31 ([Anthropic](https://www.anthropic.com/news/claude-sonnet-5)).

## Fable 5 Restoration Day 2 — Smooth Progress, Cloud Access Pending

Fable 5's second full day of global restoration passed without incident ([ExplainX](https://explainx.ai/blog/is-fable-5-back-2026)). The 99%+ jailbreak classifier is operational with a 50% weekly usage cap through July 7. AWS, Google Cloud, and Azure access is being restored "as soon as possible" but isn't complete yet ([CNBC](https://www.cnbc.com/2026/06/30/anthropic-says-trump-admin-has-lifted-export-controls-on-claude-fable-5-and-mythos-5.html)).

## Antigravity Breaks 90 — 13-Week Streak

Google Antigravity hit 90 on its 13th consecutive week of gains. The biggest beneficiary of Gemini CLI's shutdown, it now leads Codex CLI (88) by 2 points and has firmly established itself in the top tier.

## GPT-5.6 Sol/Terra/Luna: Limited Preview Continues, GA "Coming Weeks"

The GPT-5.6 triple-model family announced June 26 continues its limited preview with ~20 pre-approved organizations ([OpenAI](https://openai.com/index/previewing-gpt-5-6-sol/)). Sol is priced at $5/$30, Terra at $2.50/$15, and Luna at $1/$6 per MTok. The Cerebras launch at 750 tokens/second is on track for July ([VentureBeat](https://venturebeat.com/technology/openai-unveils-gpt-5-6-sol-terra-and-luna-models-but-only-accessible-to-limited-preview-partners-for-now-per-us-gov/)).
