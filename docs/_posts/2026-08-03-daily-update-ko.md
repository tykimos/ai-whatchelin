OpenAI가 차세대 모델 패밀리 'Astra'를 깜짝 공개했다. 아직 API나 가격은 없지만, 멀티 에이전트 시스템으로 미해결 수학 난제 10개를 해결해 보이며 업계에 충격파를 던졌다. Codex CLI는 Luna 가격 인하 모멘텀 6일째 이어가며 97에 도달, Cursor와 나란히 섰다.

## OpenAI: Astra — 수학 10문제 해결로 차세대 모델 예고

OpenAI가 8월 1일 'Astra'라는 차세대 모델 패밀리를 공개했다([OpenAI](https://openai.com/index/ten-advances-in-mathematics/)). 최초의 비-소픽 군(non-sofic group) 구성을 포함한 미해결 수학 문제 10개를 풀었으며, 모든 증명은 Lean 형식 증명으로 GitHub에 공개됐다. 필즈 메달 수상자 티모시 가워스(Timothy Gowers)가 한 증명의 학술지 게재를 지지했다([Bleeping Computer](https://www.bleepingcomputer.com/news/artificial-intelligence/openai-teases-astra-its-next-major-ai-model-after-it-solves-10-long-standing-math-problems/)). 총 연산 비용은 약 $2,000. 여러 에이전트가 수시간~수일간 협업하는 구조로, 출시 일정·가격·API 접근은 아직 미정이다.

## Codex CLI: 97 도달, Cursor와 동점 — Luna 6일 연속 상승

GPT-5.6 Luna 80% 인하 효과가 6영업일째 이어지며 Codex CLI가 97로 올라 Cursor와 동점을 기록했다([VentureBeat](https://venturebeat.com/technology/ai-price-wars-openai-cuts-gpt-5-6-luna-prices-by-80-as-model-competition-shifts-toward-cost)). 91에서 시작해 매일 1점씩 상승 중이다(91→92→93→94→95→96→97). Auto-review 비용 10배 절감과 GPT-5.1-Codex-Max 모델이 핵심 동력이며, 내일이면 Cursor를 추월할 가능성도 열려 있다.

## DeepSeek: V4-Flash 오픈소스 — 코딩 벤치마크서 자사 Pro 능가

DeepSeek이 7월 31일 V4-Flash-0731을 MIT 라이선스로 오픈소스 공개했다([OpenSourceForu](https://www.opensourceforu.com/2026/08/deepseek-open-sources-v4-flash/)). 총 284B 파라미터(MoE, 토큰당 13B 활성), 1M 컨텍스트 윈도우, $0.14/$0.28/MTok 가격이다. 자사 V4-Pro-Preview를 에이전트·코딩 벤치마크 9개 전부에서 추월했다([MarkTechPost](https://www.marktechpost.com/2026/07/31/deepseek-upgrades-deepseek-v4-flash-0731-with-major-agentic-and-coding-gains/)).

## GitHub Copilot: Billing Preview App 오늘 폐쇄

Copilot Billing Preview App이 오늘(8월 3일) 공식 폐쇄됐다([GitHub Changelog](https://github.blog/changelog/2026-07-07-copilot-billing-preview-app-will-be-retired-on-august-3/)). AI 사용량 추적과 사용자별 예산 설정은 내장 빌링 설정으로 이전됐다.

## Claude: Claude Tag, Slack 대체 시작

Claude Tag가 오늘부터 Team/Enterprise 플랜에서 Claude in Slack을 공식 대체한다([Claude Code What's New](https://code.claude.com/docs/en/whats-new)). Slack 내 Claude 사용 방식이 새로운 태그 기반 인터페이스로 전환된다.
