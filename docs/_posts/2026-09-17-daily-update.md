The US Department of Justice ruled yesterday that GitHub, Microsoft, and OpenAI did not violate copyright law by having their AI coding tools generate code without original authors' credit — closing a legal cloud that had hung over the entire AI coding industry. On the same day, Anthropic redesigned the Claude app by merging its workspaces, and OpenAI tested its first advertising agents inside ChatGPT. Cursor's decline stretched to day 28 as the 50-floor test looms.

## DOJ Copyright Ruling: Legal Risk Lifted for AI Coding Tools

The DOJ announced on September 16 that GitHub, Microsoft, and OpenAI did not violate copyright law when their AI coding tools generated code without original author credit or license notices ([GitHub yaojiejia/agents-radar #150](https://github.com/yaojiejia/agents-radar/issues/150)). The ruling directly addresses the open-source community's core concern dating back to Copilot's early days. While AI training data copyright issues extend beyond coding tools, this decision is expected to influence legal precedent across generative AI broadly.

## Claude: App Unification Redesign + v2.1.274

Anthropic merged Claude's Cowork and chat into a single app and added new Docs and Slides tools ([Releasebot](https://releasebot.io/updates/anthropic/claude)). Claude Design now works directly inside conversations, letting users draft reports, presentations, and visuals in one place. The rollout is starting with Pro and Max plans. Separately, Claude Code v2.1.274 shipped today with a visible warning for critical memory usage and a new `CLAUDE_CODE_MCP_STARTUP_WAIT_MS` parameter to control MCP server connection wait times ([Gradually.ai](https://www.gradually.ai/en/changelogs/claude-code/)).

## OpenAI: First Ad Agents Tested Inside ChatGPT

OpenAI tested sponsored agents inside ChatGPT on September 16 with Wayfair and Angi as launch advertisers ([AI Weekly](https://aiweekly.co/ai-news-today/openai-news)). When users search for furniture or home services, the brand's agent provides tailored recommendations. This is the first signal of ChatGPT's revenue model expanding beyond subscriptions. Meanwhile, GPT-5.5 is scheduled to retire from ChatGPT and Codex across all plans on October 14 ([Releasebot](https://releasebot.io/updates/openai/chatgpt)).

## Cursor: 57 Points, Day 28 of Decline — 50-Floor Test Looms

Cursor hit 57, extending its streak to 28 consecutive days of decline. The fall from 99 started after the SpaceX acquisition closed on August 14 and shows no sign of stabilizing ([CBS News](https://www.cbsnews.com/news/spacex-cursor-60-billion-ai-acquisition/)). OpenAI's November 12 model access termination notice, the Origin data terms controversy, and SpaceX governance concerns are all compounding ([CNBC](https://www.cnbc.com/2026/08/29/openai-cursor-spacex-model-access.html)). The Projects beta and Grok 4.6 transition are technically underway, but there's still no catalyst for sentiment recovery.

## Claude Sonnet 5 Price Increase Cancelled

The Anthropic developer platform confirmed that Claude Sonnet 5's introductory pricing ($2/$10 per MTok) is now the permanent standard price ([Releasebot](https://releasebot.io/updates/anthropic/claude-developer-platform)). The previously scheduled increase to $3/$15 per MTok on September 1 was never applied, and the intro price is now official. A meaningful cost reduction for API users.
